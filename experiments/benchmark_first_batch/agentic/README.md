# Agentic representative trials

This directory prepares and audits real Harbor 0.23 Trials through the existing circuit harness. It does not implement a simulator, remote controller, model transport, or agent loop. `CircuitAgent` delegates to stock Harbor Pi 0.87; `FrozenCandidateVerifier` evaluates the submitted candidate using Spectre.

Each run uses one attempt and one concurrent Trial, with no automatic retry. The coordinator must reserve a Spectre slot before `run`, because final evaluation starts automatically when the agent phase ends. During a performance quiet window, preparation and local analysis may continue, but do not start `run`.

## Deployment inputs

Set these variables to absolute local paths. Keep private deployment files in an ignored directory with mode 0600. Never put model keys, remote host names, credentials, or proxy values in tracked files.

```sh
export AGENTIC_OUTPUT=/absolute/ignored/output
export CIRCUIT_HARNESS=/absolute/circuit/harness
export HARBOR_PYTHON=/absolute/harbor-venv/bin/python
export EVAS_PUBLIC_CHECKOUT=/absolute/frozen/evas/source
export EVAS_PUBLIC_CODEX=/absolute/native/codex
```

`HARBOR_PYTHON` must be the venv launcher path, not its resolved symlink. The environment must contain Harbor 0.23 and the harness dependencies. The public checkout is a fixed revision source snapshot with Git identity, not a development checkout. Build a matching EVAS kernel separately using the EVAS README. Native public sessions require the supported Codex sandbox entry, but that executable does not perform the model generation in a Pi Trial.

Provide the model key in `BENCHMARK_MODEL_KEY` only when executing `run`; the adapter passes it through the existing profile environment reference. It never reads a user credential store. `--remote-config` accepts the existing operator JSON containing a `remote` object. That private file is copied into the ignored attempt configuration. Docker networking and any proxy required by the agent image are deployment inputs; this directory changes no global network configuration.

## Freeze a representative task

```sh
python3 -B experiments/benchmark_first_batch/agentic/snapshot.py \
  spec-latched-comparator --label fresh-v1 --kernel /absolute/matched/evas-kernel
```

This freezes the current task's actual checker bytes, public materials, instruction, candidate reference, and all cases under `AGENTIC_OUTPUT/representatives/`. The existing first-batch runtime produces individual condition packages; this adapter restores the complete original `cases.json`, recomputes the manifest inventory, and calls the harness `package_identity(..., purpose='final')`. Final execution uses the existing `python3.12 -B` checker entry. It does not run Spectre. A changed checker or stimulus requires a new snapshot label; do not edit old frozen material.

A multi-file candidate is kept as the contract's complete file list. If a supplied public project uses the same paths as the candidate, its source project is exported under `public-materials/project/` to satisfy the session's separate public/candidate namespaces. The formal candidate paths remain unchanged.

`--public-probe` executes the original reference through the native public API only, with no model call or remote solve. Keep failures. Identification references without `dut.va` are generated by the existing task solution's fit of supplied public data.

## Public feedback limits

The native session currently requires `manifest.models` to equal `candidate_files`. It cannot load an additional immutable public fixture as a separate model. The exported materials explicitly disclose this when applicable. `evas_simulate` then provides only candidate compatibility diagnostics; it cannot reproduce the complete closed loop or measurement circuit. Public Python/data materials are also copied to `/work/public` for ordinary local analysis.

The original comparator reference was rejected by EVAS; the first actual GLM comparator Trial received seven `backend_error` responses and still passed both independent Spectre conditions. These failures remain in the tool trace. Do not describe that Trial as a baseline with unrestricted public feedback. The first comparator snapshot also preceded explicit macro restriction disclosure; new snapshots retain the current source contract, including the macro rule. Final guard rejection under an undisclosed rule cannot measure model task difficulty.

## Prepare and execute one Trial

```sh
python3 -B experiments/benchmark_first_batch/agentic/runtime.py prepare \
  --name comparator-flash-example \
  --declaration "$AGENTIC_OUTPUT/representatives/spec-latched-comparator-fresh-v1/public-declaration.json" \
  --materials "$AGENTIC_OUTPUT/representatives/spec-latched-comparator-fresh-v1/public-materials" \
  --final-package "$AGENTIC_OUTPUT/representatives/spec-latched-comparator-fresh-v1/final-all-conditions" \
  --remote-config /absolute/private/operator-config.json \
  --kernel /absolute/matched/evas-kernel \
  --agent-image sha256:IMMUTABLE_AGENT_IMAGE_ID \
  --gateway-host DOCKER_REACHABLE_HOST \
  --base-url MODEL_ENDPOINT --model SERVED_MODEL_ID
python3 -B experiments/benchmark_first_batch/agentic/runtime.py preflight \
  --name comparator-flash-example
```

Optional `preflight --check-environment` verifies the local container bridge and cleanup. It starts no model generation and performs no remote solve. Static preflight alone does not establish endpoint reachability. An authenticated model-list response establishes a served ID, not a successful generation or vendor internal routing.

After the coordinator releases the required resources, run exactly once:

```sh
python3 -B experiments/benchmark_first_batch/agentic/runtime.py run \
  --name comparator-flash-example
python3 -B experiments/benchmark_first_batch/agentic/audit.py comparator-flash-example
```

The runtime preserves started/finished receipts, refuses implicit reruns, and bounds process cleanup on timeout. Initial settings of 1200 seconds, 80 public actions and 16 public simulations are engineering settings, not user budget ceilings. Increase them when evidence identifies a limiting resource; use a new attempt ID and retain the predecessor.

Harbor's command can exit zero even when the Trial has an exception. The audit returns exit 2 for a Trial exception or missing verifier result. It reports actual endpoint model IDs, transcript token fields, stop reasons, public actions, candidate/package identity, independent case results, and archive checksum verification. A graded score zero is a completed evaluation. `cost_usd: null` means billing is unknown; Pi's zero cost can reflect missing price metadata. Raw logs remain private; publish sanitized evidence separately.

## Increase a Pi output limit

The first flash Trial ended with `stopReason=length`, before writing a candidate. Its three bash tools worked; no final solve occurred. Stock Harbor Pi's custom endpoint entry supplied only a model ID. A local transport fixture confirmed Pi's default serialized limit was 16384.

Pi 0.87 supports the standard `before_provider_request` extension. The supplied extension changes only the output ceiling, and logs the previous/requested scalar values under `/logs/agent/output-budget.jsonl`. It preserves prompts, tools, messages, sampling and the stock agent loop. Build a task private image on a stock Pi/Node image whose immutable identity was verified:

```sh
docker build --build-arg BASE_IMAGE=VERIFIED_LOCAL_PI_IMAGE_TAG \
  -f experiments/benchmark_first_batch/agentic/Dockerfile.pi-budget \
  -t LOCAL_BUDGET_IMAGE_TAG experiments/benchmark_first_batch/agentic
```

Use its immutable image ID with `prepare --max-output-tokens 65536`. The extension is loaded from Harbor's task config directory, so it does not require project trust or a change to Harbor. It uses no credentials. A network-disabled local HTTP transport fixture confirmed an actual Pi request contained `max_completion_tokens: 65536`. The subsequent actual Flash attempt recorded the GLM provider's `max_tokens: 65536` override and received real model responses. This is an explicit new attempt with a resource change. That attempt later reached its agent deadline and its frozen candidate encountered an unrelated legacy preflight deployment failure; neither event is a valid circuit score.

## Representative matrix

The intended matrix is the two actual endpoint IDs `glm-5.3` and `glm-5.3-flash`, covering specification, identification, integration, repair, verification, measurement and optimization. The fixed seven representatives are `spec-latched-comparator`, `identify-sh-acquisition`, `integrate-tdc-measurement-chain`, `repair-sar-abort`, `verify-sar-flow`, `measure-adc-spectrum`, and `optimize-vco-step`. The VCO formal task is frozen and its three-condition reference plus twelve paired performance waveforms have passed the independent sealed evidence audit. The fixed 14-cell pilot is running; results are not complete. Record task revisions and public limitations per cell. Keep failed attempts in the denominator and distinguish deployment errors, model output limits, final guard errors and fully graded candidate rejection.

Optimization final packages run the main performance condition with 13 solves, plus two other functional conditions. Use the independently calibrated performance operator profile with a 900-second server limit, a 256-MiB archive limit, and a calibration `job_wait_timeout_s` of 1200. The main waveform remains raw; all twelve paired waveforms are retained as lossless gzip, with decompressed bytes, hashes and parsed rows independently verified. The initial 1-GiB declaration exceeded the existing harness 256-MiB maximum and was rejected before creating a job; that historical deployment failure is retained. Prepare with `--optimization-final --verifier-timeout 1500` and run with `--run-timeout 4200`; do not use the normal 180-second/256-MiB profile. `FrozenCandidateVerifier` polls under Harbor's verifier deadline, so `job_wait_timeout_s` is recorded from the operator configuration rather than inserted as an unsupported `FinalEvaluationConfig` field. The optimization preparation guard requires both recorded wait and verifier bounds of at least 1200. Public simulator budgets stay independent.

Archive auditing reuses `verification_measurement.regrade_measurement.SealedArchive` and `verify_seal`. It verifies the complete sealed member inventory, completion/result artifact receipts, request identity, package/candidate bundle identities, working candidate bytes, every reported case's original/executed VA bytes, and the declared output relocation spans with unchanged bytes outside those spans. The report's checker/source/netlist/waveform identities are checked against archived bytes; archived code is never executed. A source-contract rejection may validly have no cases or candidate_files declaration and is still score zero. A completed pass requires the entire frozen case set and fully graded cases.

Run the local audit regressions with both normal and optimized Python. An optional private evidence root additionally checks the retained real v4 pass and flash missing-candidate failure:

```sh
AGENTIC_ACTUAL_EVIDENCE=/absolute/retained/runtime-inventory \
  python3 -B experiments/benchmark_first_batch/agentic/test_audit.py -v
AGENTIC_ACTUAL_EVIDENCE=/absolute/retained/runtime-inventory \
  python3 -O -B experiments/benchmark_first_batch/agentic/test_audit.py -v
```

Synthetic fixtures cover source rejection, compile failure, output relocation, incomplete successful case sets, and corruption resealed at the transport layer. They perform no model or remote requests.

A nonnull Harbor verifier result alone does not establish a completed evaluation: the audit requires exactly one bound sealed archive/evaluation and matching report/verifier scores. Every graded case requires simulator return code zero, a sealed PSF ending in END, verified waveform hash, the actual parser's row count, and finite observations covering the frozen signal set and interval. A report without that evidence cannot be called a complete pass.

New snapshots and attempts disclose the complete action envelope in public_protocol.py. The current flash Trial remains frozen with its old interface description, and its HTTP400 invalid_action attempts remain in the raw Pi trace; they are distinct from accepted public-session action receipts.

New native snapshots publish the complete outer action envelope, including an example and the actual four tool argument schemas. `evas_read` with an empty path lists declared files. `evas_write` replaces a whole declared candidate file; the end of the agent phase, including its deadline, freezes the latest complete candidate, while `evas_submit` explicitly ends editing. An action or simulation quota error alone does not freeze the candidate. Ordinary container files are not collected as candidate files. Old frozen Trials are preserved, including HTTP 400 errors from incomplete envelope disclosure.

Validate the public envelope against the installed harness without a model or solver call:

```sh
CIRCUIT_HARNESS=/path/to/harness "$HARBOR_PYTHON" -B \
  experiments/benchmark_first_batch/agentic/test_public_protocol.py
```

The test compares native `tool_schemas()` and actual request acceptance, including empty read paths, ID limits and a trailing newline. Prepared attempts marked `withdrawn-before-run.json` cannot run; create an explicit new attempt with the corrected operator profile instead. An infrastructure receipt without a checker report is still sealed and checked, but is classified as ungraded rather than zero.
