# 可选候选：原二次阈值表的解析逆

`analytic_inverse.va` 尚未执行Spectre，不是参考替换或准入。工程理由是已有公开
阈值偏移模型本身是严格单调的二次函数；无需255个比较也无需二分控制流，可以
直接恢复实数阈值索引并校准邻界。只在原采样事件计算，held_code和transition不变。

设 u=k/256，s=skew，y=clip(vin/vref,0,1)，阈值关系 y=(1+s)u-su²。稳定求根：

`u = 2y / (1+s + sqrt((1+s)² - 4sy))`。

这由二次根有理化得到，s=0也自然等于y，无除以s或相近数相减。公开范围s∈[-.3,.3]，
导数1+s-2su≥.7，判别式≥.49、分母≥1.4，所以逆连续且无奇异分支。真实代码为
clip(floor(256u),0,255)；输入低于0/高于vref保持原端点饱和。

浮点根在精确阈值上可能把floor偏一格，因此VA对estimate+1和estimate分别用原来
完全相同的阈值表达式及原sample比较；`>=`仍归更高代码。邻界修正既不调整阈值，
也不以公开容差掩盖码误差。数学精确实数的估计正确；双精度测试覆盖每个原阈值
本身及上下相邻可表示数、skew两端/零/内点、多个vref。它不是Spectre浮点证据，
后端还必须跑现有三个功能条件和实际重复耗时才能评价。

候选固定算一次sqrt、无循环；能否减少冷编译开销未知。不同函数调用可能有编译
代价，不能凭源码短宣称更快。保留事件内线性和旧二分候选，由主队列选诊断与重复
计划，不改变原100us/10000转换负载、accuracy或checker。
