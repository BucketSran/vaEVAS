# 时钟滤波器重复系数计算候选

原创四级时钟驱动 leaky low-pass 电压模型，对每级有效采集/建立时间尺度计算
精确系数 a=1-exp(-Δt/τ)，按同时更新的级间电压递推，在采样间保持输出。
Δt 是本次与上次实际采样时间的间隔，首样本以 t=0 为初始时刻。
用途是模拟 SC/时钟采集滤波链随采样间隔和建立时间尺度变化的响应。
这是明确的行为模型合同，不称晶体管表征。

baseline 每次模拟求值按当前 elapsed 计算四个实际有用的指数系数，采样时消费；
reference 将同样计算移入采样事件。它保持真实采样间隔、首样本和同时级间更新。
输入仍在仿真器中连续运行，输出过渡相同，不含无用循环或自旋。
100 us、100 MHz 固定工作覆盖10000次采样；两个短case改变采样间隔、全部时间尺度
和输入频率，阻止只对单一默认周期缓存或误用线性系数的伪优化。

exp计算确实重复发生且有足够成本，再用至少5对AB交替测试。功能由独立递推式
按实际时钟时刻检查输入、全部采样后/保持电平，误差50uV；参考解不定义预期。

随计时记录。无可重复改善则舍弃，不放宽容差或增加无用运算。
