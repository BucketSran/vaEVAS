# 采样 DAC 重复解码候选

原创 12-bit 电压 DAC，按采样时钟保存输入位对应的加权电压，用于 SAR 重构或发射链
行为仿真。baseline 每次模拟求值重复读取十二个逻辑电压并求加权和，再在采样事件保存。
reference 把实际解码移入采样事件。两者相同端口、比例、偏置、延时和输出过渡；不含
人为循环、死代码或未消费的计算。本候选可能被 AHDL 编译优化消除，须先实测。

固定性能工作为 100 us、100 MHz 更新、10000 个 12-bit 码，二进制计数器覆盖全码域
超过两轮；另验不同输出比例/偏置与低逻辑电压。独立 oracle 检查实际十二位刺激、
时钟边沿、采样后 2/8 ns 和采样前 0.5 ns 的输出，误差 40 uV。
任何位权、4095 满量程分母和保持时刻变化均不算有效优化。

未做实际运行，未声明性能改善，尚非正式题。先两侧三个case功能校准，再profile
确认解码成本是否实际发生、是否是可改善limiter。性能case热身后至少5对交替，
保存Spectre CPU/elapsed、实际步数和端到端时间及各启动分项；差异小于波动则舍弃。
协调者统一通过harness排队，不新增远端编排。
