# 四项优化的原始 quiet 五对收据

`quiet_four_tasks_receipt.json` 过滤主任务已有实际分析，仅保留VCO、power、SAR、UART。
未启动新仿真，也不是四个正式Harbor包的同job重复评分。来源为本地保留的
`runs/benchmark-first-batch-20261008/performance-all-analysis-v1.json`，完整分析SHA256：
`3a62c085546b0ec2a2c9421cdbf060c90f145be50d1ded4b0ca69323fc92c393`。
收据保留原manifest SHA及每次archive、native日志、波形、源码、网表、criterion、
report和候选bundle身份。Raw仅在本地归档保留；这些哈希不是可下载URL。

每题一次baseline/reference预运行，然后5对严格AB交替；48个实际求解全部成功，
40个测量均通过冻结的功能判据和native零错误检查，失败未从分母删除。原始点功能
加强判据的已有全条件回放另由`raw_point_waveform_replay.json`绑定；它不等于新判据
下重启Spectre。正式包reference与负例校准由主任务另行执行，不计在这里。

四题在步数、intrinsic CPU、intrinsic elapsed、完整进程耗时上均5/5 reference较少。
完整进程中位耗时分别下降83.41%、42.88%、48.99%、65.34%；这是该固定负载与环境
中的实际收益，不能把约96%–99%的native指标下降当作用户等待时间下降。

native intrinsic elapsed(s)也独立保留：VCO5.51316 [5.47856,5.59704] → 0.118472
[0.116830,0.121962]；Power1.14653 [1.13546,1.18394] → 0.004216 [0.004142,0.004299]；
SAR1.66567 [1.65613,1.67925] → 0.075918 [0.075425,0.076593]；UART2.94318
[2.91807,2.99020] → 0.048176 [0.047785,0.049079]。CPU是native记账，不能和墙钟相减。

所选48日志的host本地时钟跨度为2026-10-08 03:21:32至03:39:49，精度1秒、时区未
声明。这18分17秒是执行窗口，含队列间隙和未选Flash求解，不是48个solver CPU或
单个用户请求耗时；所选48次solver进程elapsed求和138.044s，其中40测量为115.431s。
所有单job耗时保留，可查看各题baseline/ref区间；不得拿窗口跨度计算性能比率。

后台为Spectre21.1.0.509.isr12、同一host身份哈希/Xeon Gold6326，固定`+mt=1`、
相同网表和容差、psfascii完整波形。主任务在窗口起点记录1.37/1.69/2.20负载（64逻辑
CPU）及一个非本队列Spectre，未停止他人作业；所以“quiet”表示本队列顺序运行，
不表示独占主机。原生没有报告rejected steps，保持unknown/null，不能推断为零。
全部候选仍保持必要的真实VCO分辨率、资格计时、SAR240位决策、UART80位与有限边沿。

`compact_receipts.py` 能从本地保留分析和原档案再生成收据；它核对每archive/native
哈希，保留角色/顺序，Flash新功能收据另做当前oracle的原PSF逐点回放。它不向远端
发起操作。统计准入另由generator绑定当前网表全部12次并调用共享paired_summary
重算，不能仅信这里的摘要。
