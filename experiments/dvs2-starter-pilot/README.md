# DVS-2 八张起始卡的四后端功能试点

2026-09-27。执行已完成，见 [结果与证据](RESULTS.md)。以下保留运行前约定；冻结原稿随私有证据归档。用户确认运行全部 7 类、8 张起始卡，非完整 DVS-2 验证集。

后续[故障归因](DIAGNOSIS.md)已发现 V6 原始数组语法和 Gnucap 数值选项遗漏，另定位各后端的事件/求解问题。下述历史协议未静默改写；新的正式比较需修订并重新冻结输入与有效设置。

## Brief：范围与验收

在同一获准服务器比较 Spectre、EVAS 0.8.7、OpenVAF-R v24.0.2mob＋ngspice 46、Gnucap＋modelgen-verilog。复用固定用户态安装与容器，DUT 原始源码保持相同；网表只适配调用和输出。此次不修复模拟器，不把失败改写成另一种模型后计为通过，不做速度排名。

输入均为外部 PWL；S=1 V、T=1 us、终点 4 us。源码由 `evas/validation/cases/` 维护，完整条件由 `suite.py` 生成；契约见 `CASE_CARDS.md`。分组条件数为 V1=1、V2=4（主条件及三个单因素对照）、V3=1、V4=2（C0/C1）、V5=1、V6=1、V7 线性=3（主条件、交换实例顺序、只改 A 输入）、V7 非线性=2（lambda=0.5/2），合计 15 个试点条件；并非正式 DVS-2 分母。

V7 线性“只改 A 输入”使用原 A 输入的 0.5 倍，B 保持不变。所有条件在看到本轮后端结果前固定。V4 初始时钟/复位低，保持值和输出初始工作点为 0.1 V；其 C0/C1 与案例卡一致。

## KPI：何谓完成

- 15 个条件均对四条链路尝试编译/执行；同源码的编译拒绝可共享诊断，编译不支持时不运行不存在的产物。
- 成功产生波形的链路核对实际输入、平台状态、保持和可见输出边沿；保留错误及观察资格不足，不强求四后端通过。
- 每条记录绑定模型、刺激、运行器、配置、工具身份、命令、日志和原始输出哈希；原始产物在私有运行目录归档。
- 解析判据先用合成正确/错误波形及非法观察校准。校准成功仅覆盖所列性质，不宣称一般 checker 正确。

## Plan：固定设置与执行顺序

1. 生成 15 个条件的相同物理刺激与三个网表外壳；校准独立分析程序。
2. Spectre 先跑基础和细化设置，记录版本及实际 options/告警。
3. 在冻结环境依次运行 EVAS、OpenVAF-R→ngspice、modelgen→C++→Gnucap，成功运行的链路均保留基础/细化两档。
4. 下载并校验原始证据，统一分析。仅复跑有明确环境/适配原因的失败，保留原尝试。

| 条件 | 基础档 | 细化档 |
| --- | --- | --- |
| 输出间隔／最大步长请求 | 1 ns | 0.1 ns |
| Spectre reltol / vabstol / iabstol | 1e-5 / 1e-8 V / 1e-12 A | 1e-6 / 1e-9 V / 1e-13 A |
| ngspice reltol / vntol / abstol | 同上数值，保留其不同含义 | 同上数值，保留其不同含义 |
| Gnucap reltol / vntol / abstol | 同上数值；核对实际接受情况 | 同上数值；核对实际接受情况 |
| EVAS | SCS 的 step/maxstep 请求；记录实际间隔 | 仅细化 step/maxstep；不把其他参数假定为已生效 |

同名或同数值设置不代表相同精度。Spectre 使用明确的 `method=traponly`，导出接受点（不强制 strobe）；其他后端记录其实际算法或默认值。两档设置只检查结果变化，不能凭二点证明收敛。不对拒绝的设置静默丢弃。

首轮上限为 15 条件×4 链路×2 档设置，即最多 120 次电路仿真；前端失败后复用同源码的诊断。每次仿真最多 90 s，编译阶段最多 90 s，Spectre 许可证等待最多 30 s。版本/选项读取不计电路运行。串行使用单 CPU 亲和性和单线程环境；容器启动、编译、许可证等待、求解和导出不拆成未经测量的纯求解时间。

## 预先规定的观测与结论边界

静态、参考、连续动态与隐式关系使用独立解析答案逐样点比较；V2 分别判差模和相对共模；V6 绝对阈值 0.6 mV，V1/V7 为 1 mV。V7 非线性用单调括区二分提供参考界，并核对残差。事件案例同时检查平台与边沿时刻，允许事件定位变化及其传播；所有采样误差均只针对导出的观测点。下述细节以 V4 为例，其他事件模型按各卡的完整边沿和定位窗口展开：

- 检查 time/输入/时钟/复位/输出列完整、有限、时间有序、覆盖 [0,4 us]；验证实际输入逐点符合 PWL，输入误差目标 1e-7 V。
- 平台数值目标 1 mV；按合法采样定位展开最多 6 uV 的采样值变化。检查所有远离边沿的平台样点，而不只检查少数锚点；超过 1 ns 的观察空隙须报告。
- 输出 10%/50%/90% 边沿使用有序相邻点的线性插值测量，记录括区宽度；完整边沿估计为 (t90-t10)/0.8，目标 25 ns，首轮诊断阈值 1%。
- 由输出反推事件仅作为联合行为诊断，不视为内部 cross 实测。cross 合法定位窗口分别为时钟 [0,40 ps]、复位 [0,20 ps]；时间测量括区传播成区间，精度不足留未决。检查所有边沿是否能由同一事件历史解释，不能逐点挑选最有利事件。
- 保存相对名义分段线性输出的最大观测误差及其所在时刻，不能将其直接称作连续时间最大误差。
- 平台/可见事件失败可形成明确反例；全部观测满足仍只报告“本轮所列观测通过”，不自动授予正式 DVS-2 P。完整观察不确定度与漏脉冲资格尚需后续论证。

## 风险、停止条件与记录

模型语法合法性与后端支持分开判断。编译器拒绝合法结构、编译器崩溃、导出问题及数值/语义不符分列。来源无法确认、超时、许可证或容器失败保存现场；不修改全局环境或模拟器。结果见 [RESULTS.md](RESULTS.md)，阶段命令/退出码/哈希由运行器保存。若需要扩展新的模型语义或更大实验，单独列为下一轮。
