# 模型试做发现的公开合同缺口

第一轮实际模型候选暴露了五题的公式或事件边界不够明确。旧候选在当前checker下的原始结果保持不变，但这些结果不能直接解释为模型未遵循公开规格。

| 任务 | 旧材料的问题 | 新版公开规则 |
| --- | --- | --- |
| 003 流水线ADC级 | gain-two residue没有完整写出共模平移公式 | 明确残差、区域码、供电钳位和PHI2更新公式 |
| 183 RDAC校准控制器 | checker使用20ps输出过渡窗口，题面未给完成期限 | 数字输出在初始化或决策沿后20ps内完成，参考转发连续 |
| 353 三抽头FFE | 只明确data采样，未说明tap码是否锁存 | data和两组tap码在同一clk上升沿采样，沿间保持输出目标 |
| 396 正交LO | “两个完整周期”未明确资格计数起点 | 第8个合格上升沿，即第二遍四状态序列进入00时，报告资格 |
| 346 时间计数仪表 | 未明确武装期间结果码的输出 | 内部计数继续，结果码保持0，stop或溢出时才发布 |

随后对全部19道按规格建模题和10道测试与表征题进行公开合同复核，又确认六题有相同性质的缺口：

| 任务 | 旧材料的问题 | 新版公开规则 |
| --- | --- | --- |
| 038 可编程增益放大器 | clipping metric只给高低含义，未给电压 | metric固定为0/0.9V，与模拟输出钳位参数分开 |
| 071 有限获取采样保持 | 获取monitor未给电压 | monitor固定为0/0.9V |
| 060 占空比仪表 | 未给首次完整周期前码值 | 所有码位初始化并保持0V至首次完整周期 |
| 170 比较器延迟仪表 | 未给首launch前数值报告 | delay_ps、overdrive_mv、polarity、valid初值均为0 |
| case-0018 增益与建立仪表 | 未给首launch前数值报告 | gain、gain_valid、settling_ns、settled、status初值均为0 |
| 186 SAR前端逻辑 | 未给控制器输出完成期限 | 触发事件后200ps内完成数字输出变化 |

这些修改只明确公开要求。既有checker、激励、容差、候选源码、参考解和公开测试文件均不改变。测试与表征生成器同步保存四道受影响仪表的新版题面，不重生成其他任务。

独立诊断核对了原候选和实际波形身份。183候选使用50ps过渡；只在分析副本调整观察窗口后，其两条旧波形均通过，说明原拒绝来自未公开期限。353的两个模型都连续解码tap码。396的一个模型到第9沿才报告资格，另一个模型则确有资格输出永久为0的实现错误。时间计数仪表的一个模型在武装期间实时输出累加值。这些不同原因分别保留，不能用一个失败比例概括。

共十一题的两个模型均须从新版公开材料重新试做Agentic与one-shot。旧答案作为旧公开版本探索保留，不修改源码、不选择历史最好答案，也不升级为新版成绩。其余26题的公开材料不变，继续使用原冻结实验。作者电路校准可以在核对实际执行文件相同后引用既有证据；这种复用不是新的Spectre运行，也不能代替新版模型试做。

完整原响应、轨迹、波形和诊断脚本保留在本地ignored运行归档。公开报告只保留必要身份及结论，不宣称原始归档已公开下载。当前新版模型试做仍待完成，五个spec尚未验收。公开复核包含四份真实PASS波形的原样重评分及明确标记的反事实分析；另两项使用合成分析波形。这些诊断不计作新的模型成绩或实际仿真。
