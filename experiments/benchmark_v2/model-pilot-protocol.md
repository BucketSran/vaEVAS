# 本轮模型试做协议与统计口径

本轮比较两个模型配置 glm-5.3、glm-5.3-flash，覆盖37道任务和Agentic、one-shot两种方式，共148个设计单元。任务数按规格建模19、数据建模1、扩展集成2、调试修复5、测试与表征10划分。模型实验仍在执行；本文记录实际采用的协议，不是完成报告。

## 材料与候选

同一道题的两种方式获得相同版本的题面与全部公开文件。Agentic通过文件和公开工具按需读取；one-shot将完整公开目录一次性放入请求。UTF-8文本保留原内容，其他文件用base64封装。文件摘要相同只能证明材料内容相同，不能证明模型实际使用材料的能力相同。

参考解、作者错版、隐藏激励、checker和终评期望不进入模型材料。Agentic使用原生Harbor/Pi工具循环，允许读写、公开仿真及自定义临时测试台；`evas_`前缀工具在本轮调用的实际后端为Spectre。公开反馈不包含隐藏评分，终评只在解题结束、候选冻结后运行。

one-shot请求没有工具或执行反馈。只接收一个完整files JSON对象，允许一个完整外层JSON代码围栏；不修补源码、补全截断输出或在多个答案之间挑选。Agentic验收最后完整保存的候选，不选择历史最优版本。有效模型响应耗尽预算仍未形成候选时，记录未提交；若有候选则按原字节走独立验收。

## 实际资源设置

| 项目 | Agentic | one-shot |
| --- | --- | --- |
| 解题时间 | 每个原生Agent阶段1200秒 | 单次请求1200秒超时 |
| 单次响应输出预算 | Pi 0.87.0原生默认16384 | 请求显式max_tokens=32000 |
| 工具与公开仿真 | 最多100个公开动作、24次公开仿真；每次180秒 | 无工具、无反馈 |
| 正式终评 | 独立1800秒窗口 | 完整候选冻结后独立终评 |
| 重试与候选选择 | Harbor不自动重开Trial；保留Pi原生会话恢复；不选best-of | 不自动重发；不选best-of |

Harbor的Trial级`max_retries=0`不等于所有层级都关闭重试。固定Pi 0.87.0的会话层默认允许最多3次恢复，基础等待2秒；hysteresis的一次真实轨迹记录了Connection error后的首次自动恢复成功。OpenAI SDK和Pi底层请求封装在该路径的重试次数为0。Pi会话恢复仍属于原解题过程，使用原时间预算，原错误和恢复事件全部保留。协调者在过程结束后显式重开环境失败尝试则单独计数。

两个模型在各自方式下采用相同配置。两种方式的交互权限、时间使用方式和输出预算不同，因此结果不能解释为严格控制总计算量后工具使用的单独收益。Agentic使用thinking=medium；one-shot未显式设置thinking，保留服务端实际usage和finish reason，不推断与Agentic推理配置等价。

Agentic的16384来自固定Pi版本的默认配置；原job/catalog没有显式max output字段。一次无外网的本地请求捕获核对了相同镜像和模型定义生成的max_completion_tokens=16384，实际预算耗尽响应也报告该输出数。原在线请求没有逐次截获完整HTTP载荷，这一证据限制单独保留。

Agent镜像固定为`sha256:6c28c93cf6f4b8c0294b079605772e157ee4a84477afe3173132455d72c0efe1`，预装Node 22.23.3与Pi 0.87.0。环境修复只影响预安装与网络连通，不替换原生Agent循环。Spectre全局并发最多4；API曾在较高并发下发生429，随后限制为4个共享槽，其中Agentic和one-shot各2。槽数不增加每个单元的解题预算。

## 异常与版本

- 原始评分、源码、请求、响应、轨迹和未知尝试全部保留。原始证据不因后续诊断、重判或重试而覆盖。
- 公开规格澄清涉及十一题，详见[合同修正](model-contract-clarifications.md)。旧公开版本的尝试单列为探索；新版本的两个模型、两种方式重新试做。其余26题按实际材料身份复用原冻结尝试。
- checker或终评入口变化若未影响解题材料和反馈，可对同一冻结候选重新评分。复用既有波形的判定标为归档重判；激励变化则必须以原候选运行新的电路仿真。两者都不是新的模型求解。
- 308的私有激励增加同一reset样本后的重复signal采样，公开材料与checker不变。旧六条件结果保留，one-shot使用原冻结候选在新激励下重新仿真；尚未开始的Agentic试做直接使用新版终评。该修正不授权给模型补充答案或追加求解预算。
- clock-frequency第三私有例延长观察窗口以覆盖完整分频周期。作者五个登记变体及额外诊断已完成新实际仿真；既有两个模型候选原字节补判均通过，尚未开始的Flash Agentic使用新版终评。两次私有修订的[独立证据](author-calibration-private-overlays.md)与模型求解次数分开记录。
- 对明确限流或已诊断的连接中断，单次显式环境重试使用相同题面、完整材料和预算，保留原请求及错误。调度先等待在途任务结束并检查恢复证据；新尝试有独立身份。格式错误、预算耗尽和有效错误答案不借此重试。有效响应的格式错误也不会获得第二次机会。
- 无响应超时的原因若无法确认，保持未知，不归因为模型思考或服务故障。语法非法的候选与后端不能支持合法VA的环境缺陷分开诊断，均不能伪造电路评分。
- POR完整one-shot材料约7.45 MB，两个模型实际收到HTTP 400、code1261及“Prompt exceeds max length”。该方式的上下文适用性因此单列，保留在设计分母中，不能记作电路实现错误或事前删去材料。

## 最终统计

分别报告148个设计单元、每种方式74个单元、实际记录的请求、会话内恢复及独立尝试数、有候选数、有效电路评分数、通过数及各类未评分原因。上下文拒绝、环境异常、预算未提交、格式失败和非法源码均有单独记录。总体任务完成情况与有效评分子集的通过比例分开，不能用减少分母提高成绩。

每题权重相同，不按文件数、代码长度或工作量加权。五类成绩与32个P1归口来源分开报告，标出038、093、370等跨类复用。相同电路和同源变体之间存在相关性，37题不等于37个独立电路来源。系统题的文件数量也不增加分值。

正式参考入口另行执行作者source solve、固定交付路径、会话提交、候选冻结与私有终评。此验收不是模型成绩。原始bulk归档和部署配置留在本地ignored运行目录，公开报告发布精简身份与结论，不承诺原始归档已经可下载。
