# 真实来源 Verilog-A 首轮初筛

实验日期：2026-10-03。此处保存首轮内部初筛结果，未作为正式 benchmark 发布。

**Codex `gpt-6.1-sol` 首轮 6/6 通过，GLM `glm-5.3` 首轮 3/6 通过。**
这批任务有真实工程来源，但当前证据支持把它们作为完整规格到代码的基线，
不足以单独支撑一个面向强模型、强调困难度的新 benchmark。

## 成绩

每题独立生成一次，无工具、无仿真反馈、不修补正式答案。两路均请求 `xhigh`，
但不同 CLI、不同模型的 effort 名称不保证推理预算相同。

| 任务 | 来源 | Spectre 条件 | Codex | GLM |
|---|---|---:|---|---|
| AND2 对照 | 课题组 | 2 | 通过 | 通过 |

| ZOOM 九路时序 | 课题组 | 2 | 通过 | 行为失败 |
| 流水线 ADC 增益校准 | 课题组 | 2 | 通过 | 编译失败 |

全部 12 份正式提交已完成，无生成超时。Codex 通过 13/13 条件，GLM 通过 7/13 条件。
GLM 九路时序生成耗时约 842 秒，接近 850 秒上限；这份答案仍按正常完成评分。

“通过”指该题所有条件通过。总计 13 组条件，每份完整题集检查 5,773 个数值点和
1,575 个数字边沿；这些是有限观测，不能等同于穷尽全部输入空间。
运放除输出电压还检查输入支路电流；外部 R/C 负载、非零直流工作点也在评分内。

## 已观察到的失败与诊断

- GLM VCO：输出 `bound_step(...)`，缺少 Verilog-A 系统任务前缀 `$`，
  Spectre 报 `VACOMP-2259` 未定义函数。独立诊断只添加该字符后，两组条件均通过。
- GLM 增益校准：用 `integer k` 遍历模拟总线，Spectre 报 `VACOMP-1192`，
  并报告循环中的 `transition` 非法。独立诊断只改为 `genvar k` 后，两组条件均通过。
- GLM 九路时序：能够编译，但两组配置的九路输出均没有被观察到有效边沿，
  合计缺少 1,400 个预期边沿。`clk_hi`/`clk_nx` 的形参顺序与所有调用不一致，
  时间参数被传给整数计数参数，纳秒/微秒数值转换为零，脉冲枚举循环不执行。
  独立诊断仅调整这两个函数的形参顺序后，两组条件均通过。

这些诊断由评测者对副本做最小修改，**不计为模型通过，不回传给模型，不改变正式评分**。
前两例失败集中在语言使用规则，而不是已经观察到的校准算法或相位算法错误。
第三例是函数参数接线错误。三个失败经上述小范围人工修改均通过，说明本轮并未找到
需要大幅重构模型才能解决的难例。我们没有测模型看到仿真反馈后能否自行修复。

## 任务与评分如何校准

先从原始资产构建明确规格；`SOURCE.md` 逐题说明改编，原始文件未修改。
原实验说明记录 Spectre 21.1.0.509.isr12；参考解先通过全部 13 条件，之后才请求模型生成。
机器报告的 `spectre_version` 字段为空，本次整理未独立恢复版本探测证据。
另有六个可编译的语义错误版本均被拒绝：AND→OR、SAR CDAC 极性反转、
SAR 时序包络缩短、校准方向错误、VCO 忽略控制电压、运放忽略输出电阻。

期望值不从参考波形提取：数字任务按状态机/脉冲日历生成；VCO 按频率积分求边沿；
运放按独立 ODE 和解析输入电流生成判据。参考解通过后冻结题面、参考解、判据和适配器身份。
这是首轮校准，不是对 checker 完备性的证明。

## 调用渠道和环境故障

- Harbor 0.23.0；Docker 基础镜像固定 digest；已补齐本机缺少的 Compose 5.5.1。
- GLM 通过已有 Claude Code 兼容渠道使用 `glm-5.3`，safe mode、空工具集、空 MCP。
- Codex 使用桌面内置 CLI 0.159.0-alpha.12.1，模型 `gpt-6.1-sol`。
  独立临时 home 仅提供认证，关闭宿主指令、技能、工具和搜索。
- 最初 PATH 中旧 Codex CLI 0.154.0 的三个请求被服务端拒绝，没有产生候选答案。
  切换现有桌面 CLI 后重新发起首次有效生成；这些旧渠道错误单独保留，不计模型功能分数。
- 每题生成预算 850 秒，Harbor agent 上限 900 秒；远端单次仿真上限 90 秒。
  该轮没有把基础设施故障混入 Verilog-A 功能失败。

不同 CLI 的底层系统提示不同，GLM 返回的 token 统计口径也不应与 Codex 简单等同。
生成时间是该次调用的墙钟时间，含渠道开销，不能据此断言模型本体的推理速度。

## 对 vaBench 的决定建议

1. 保留这批真实资产和题目，作为来源明确的基线、编译与仿真回归集。
2. 暂不通过复制同类规格、扩位宽、扩参数组合来扩建主要难题集。
3. 下一轮应检验不同工程能力：在闭环系统里满足指标、诊断并修复现有模型、
   从测量数据或电路约束建立/校准模型。每类先做少量真实任务并校准 checker，再讨论规模化。

边界：这里给出了完整公式或状态转换，不考查自主选择建模抽象；SAR 没有真实比较器闭环，
校准题没有接入完整 ADC 模型。每题一次生成、六个精选样本，不能推出整个 Verilog-A 领域已经解决。
Cadence 例子也可能与训练材料相近，真实来源不等于保证未被模型见过。
