## 判定覆盖什么

[history.py](history.py) 只处理互不重叠的线性有限边沿及其保持状态。
每个事件的时刻偏移属于事先规定的区间；采样目标随同一个偏移变化，后续保持和
下一边沿也使用这个目标。初态、沿长和延迟固定，不能通过任意拟合隐藏错误。

算法将输入数值转换为精确有理数。相同保持段上的所有约束取交集；沿内保留全部
观察约束。区间包围采用多仿射表达式的角点界，分支时完整覆盖原事件域。
候选时刻只是搜索建议，接受前仍对全部约束逐项精确核对。

- **P（相容）**：找到并核验同一组时刻满足所有 `|误差| + B ≤ ε`。
- **F（不相容）**：通过区间排除覆盖整个事件域，证明没有共同历史满足 `|误差| ≤ ε + B`。
- **I（未决）**：误差带无法裁决、搜索预算用尽，或输入/所需合同不合格。

这里的 P/F/I 是指定观察模型内的数学结论，**不是模拟器正式资格**。
区间过宽可能留下 I；找不到候选解不会自动变成 F。初版每条轨迹最多检查 256 个区间盒。
重复时标未经侧别解释时保留 I，不删除行；中断边沿、额外内部回调和未采样窄脉冲不在已实现范围。

## 校准与证据复用

[校准控制](test_history.py)包含协议中的逐点合法但历史矛盾反例、合法整体偏移、
误差与不确定度的 P/I/F 边界、采样与边沿冲突、前一采样值延续、错误沿形及预算耗尽。
[适配检查](test_recheck.py)另用手算锚点、缺列/NaN/重复时间/错误单位/稀疏或截断输出，
以及证据目录禁止写入、错误收据拒绝，验证本地读取边界。它们是构造的方法控制，不计入仿真器分母。

[recheck.py](recheck.py)先核对公开收据绑定的历史文件清单，再逐一验证实际读取的
运行记录、条件、DUT、设置、网表和波形哈希。条件须匹配 v1 快照；只复用 v1 格式读取器，
新的事件合同使用独立有理数定义，不调用旧逐点包络或 EVAS/任务 checker 生成答案。
原执行失败完整保留，不伪造缺失波形，也不重复启动电路。

真实数据按两个明确的**条件性场景**分析：

1. 把读入数值和名义输入事件域视为精确量，`B=0`。
2. 用协议中的候选总预算 `B=0.25 mV` 做敏感性分析。

所有点的目标均为 `ε=1 mV`。第二个数值是待论证预算，**不是已测得的误差界**；
输入根、导出时标、电压误差及原生/插值语义尚未全部取得资格。因此真实运行的
`formal_dvs_qualification` 一律仍为 I；即使两个场景结论一致，也不能认证连续时间正确性。
本轮还不单独认证 V5 的延迟/完整沿长 1% 门槛；需要独立定位区间与传播后的误差界。

## 复现

在仓库根目录运行校准，不访问网络或模拟器：

```sh
python3 -B -m unittest discover -s experiments/dvs2-history-validation -p 'test_*.py' -v
python3 -B scripts/verify_validation_version.py
```

已有获准原始证据的本地副本时，可重判到一个新的输出路径：

```sh
python3 -B experiments/dvs2-history-validation/recheck.py \
  runs/dvs2-starter-20260927-01/evidence \
  --output runs/dvs2-history-reanalysis-new/analysis.json
```

脚本拒绝向证据目录内写入或覆盖已有分析文件。没有这份私有归档时只能运行公开的
构造控制，不能把它们当成对历史波形的复现。公开结果保留输入/分析器摘要及逐配置状态，
不分发原始日志、商业依赖或机器配置。
