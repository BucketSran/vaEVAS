## slew 差异及步长诊断

设 x=t/U，U=2^-30 s。输入从 (0,0) 到 (2,4)，再到 (4,-4)，以后保持 -4；限速为 +1/U 与 -2/U。
输出先按 y=x 上升。下降输入为 u=12-4x，故交点满足 x=12-4x，即 x*=12/5。交点后：

```text
y(x) = x                      , 0 <= x <= 12/5
       36/5 - 2x              , 12/5 <= x <= 28/5
       -4                     , x >= 28/5
```

在 x=3，独立答案为 1.2 V；Spectre 基础档为 1.125 V，细化档为 1.1875 V。EVAS 符合独立答案。
首轮两个配置的完整导出点分别与下式相符至 3.6e-15 V 内：

```text
y[k] = clip(u[k], y[k-1] - 2*Δx, y[k-1] + Δx)
```

这支持“交点所在有限时间步留下偏差”的解释，是波形级推断，不是对 Spectre 私有源码或 LRM 违规的断言。
追加实验只改 step/maxstep，保持细化档 reltol=1e-7、vabstol=1e-10、模型、刺激、共同观察网格及 1 mV 目标。原失败不被替换。

| 反向追赶配置 | 最大误差（mV） | Spectre 导出点数 | 达到 1 mV |
| --- | ---: | ---: | --- |
| sl-reverse-base | 75 | 160 | 否 |
| sl-reverse-fine | 12.5 | 301 | 否 |
| sl-reverse-step-128 | 4.6875 | 1063 | 否 |
| sl-reverse-step-512 | 0.78125 | 4129 | 是 |
| sl-reverse-step-2048 | 0.29296875 | 16411 | 是 |
| sl-reverse-step-8192 | 0.048828125 | 65557 | 是 |

反射场景具有相同误差序列。追加 8 配置中 Spectre 6/8 达标、EVAS 8/8 达标。
误差随更细步长下降，观察点数也明显增加；这里未进行隔离计时，不能据此给速度倍数。无需为了模仿粗步长偏差而改坏 EVAS 的解析交点。
