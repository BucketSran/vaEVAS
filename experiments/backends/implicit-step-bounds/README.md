# 隐式 DAE 的动态模型步长对照

两个同源微例在 EVAS 与实际 Spectre 的33个固定观察点均满足原1e-7 V绝对预算。
这里只验证无事件隐式 DAE 的动态 `$bound_step`，不表示原 R01 工程模型恢复或全时域误差得到证明。
模型、原生小型 PSF、EVAS strobe 数据和收据都保留在本目录；完整执行日志和构建产物仅本地可用。

## 测什么，怎样判通过

两个模型都满足 `y+y*y=z`、`z'=1+2*y`、`z(0)=0`，冷启动选择 `y(0)=0`。
对原关系求导得到 `(1+2*y)*y'=1+2*y`，因此在本次 `[0,1]` 的非奇异分支上 `y=t`。
`voltage` 请求 `1/64/(1+y)` 的下一步上限；`conditional` 在输入 `u=t` 大于0.5时请求
`1/64/(1+z)`。请求只影响数值网格，物理答案相同。

两个后端分别保留 `i/32` 的33个原生或强制观察点，包含 t=0。每条波形须满足独立答案预算，
同一观察点的后端差值也须不超过1e-7 V。分析不插值，不删除缺失点，不把重采样值当原生观察。

| 模型 | EVAS 对独立答案的最大误差 | Spectre 导出对独立答案的最大误差 | 后端有限配对最大误差 |
| --- | ---: | ---: | ---: |
| voltage | 6.66e-16 V | 2.95e-9 V | 2.95e-9 V |
| conditional | 4.44e-16 V | 7.35e-10 V | 7.35e-10 V |

数值以 [result.json](result.json) 的原生导出 token 分析为准。
Spectre 为 `21.1.0.509.isr12`，原生 PSF 读回 `reltol=1e-9`、`abstol(V)=1e-9`、`maxstep=1 s`、
`method=traponly`、`lteratio=3.5` 和 `relref=sigglobal`。
EVAS 使用本次源码构建的 debug 内核，公开 CLI 请求为 `reltol=1e-9`、`vabstol=1e-9`、`max_step=1 s`，使用认证 Picard/Taylor 传播。
这些记录不表示两者使用相同积分算法，或具有相同的内部接受时刻。

## 重查证据

从仓库根目录运行以下命令即可重新检查保留文件身份、全部观察点及答案和配对误差：

```sh
python3 -B experiments/backends/implicit-step-bounds/analyze.py --self-test
```

`--self-test` 先检查正确答案可通过、单点超差会失败，以及缺失首尾观察会拒绝。
分析复用[共享 PSF 读取器](../evidence/README.md)，保留原十进制 token。
EVAS 的 JSON 字符串可精确往返原 binary64 值，比较时恢复其二进制数值。
这项命令重判已有实际执行，不会调用模拟器。

[receipt.json](receipt.json) 记录请求与有效设置、执行命令和预算、模型与输入哈希、
EVAS 基线和未提交源码补丁、内核 SHA、Spectre 工具身份及材料可用性。
`implementation.patch` 是该 EVAS 执行身份的紧凑源码快照，可在收据指定基线应用；它不是另一份实现入口。
要重新执行，需要自行构建相同 EVAS 源码或取得 Spectre 许可与工具环境。
仅保留哈希的完整日志与构建文件不具有公开下载地址，不能据此声称完整远端流程已公开复现。

数学和实现边界见[连续动态手册](../../../evas/docs/math/continuous.md#隐式-dae-的模型步长请求)。
单独的内部回归检查每个 EVAS 接受段不超过认证模型请求，以及失败候选在同控制器中的纯回退和重试；
本次有限后端配对不能证明这两个内部性质。一般 DAE 与事件、复位的组合仍明确拒绝。

源码快照使用零上下文补丁以避免补丁格式中的空行空格影响仓库检查。可在指定基线上用 `git apply --unidiff-zero` 应用；已独立重建并核对收据所列六个文件的 SHA。原有带上下文补丁与旧收据保留在本地历史，数值结果没有重判。
