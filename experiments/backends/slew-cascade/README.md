# 两级固定 slew 对照

本批检查 Issue #66 的 C3 固定前馈。EVAS 原先拒绝两层 `slew`，本次实现让第二层读取
第一层完整的分段历史。三个模型覆盖斜坡、平台追赶和反向追赶。
数学方法与支持边界见[算子手册](../../../evas/docs/math/operators.md#两级固定-slew-的完整分段历史)。

## 按原预算选择 Spectre 设置

独立公式给出每个实际观察时刻的输入、一级和二级电压。
三个节点各允许 **1 µV** 绝对误差，必须覆盖起点和终点，不删除转折点附近的结果。
这是本批固定预算，不替换支持总表中原 8 个精度用例的标准。

| 模型／配置 | Spectre 一级最大误差 | Spectre 二级最大误差 | 独立检查 |
| --- | ---: | ---: | --- |
| 斜坡，基础与收紧档 | 0 | 0 | 两档通过 |
| 平台追赶，基础与收紧档 | 0 | 0 | 两档通过 |
| 反向追赶，基础档 | 5.540 mV | 3.713 mV | 超差 |
| 反向追赶，仅收紧容差 | 4.987 mV | 4.018 mV | 超差 |
| 反向追赶，收紧容差及全程步长 | 221.641 µV | 162.781 µV | 超差 |
| 反向追赶，局部细化步长 | 1.637 pV | 1.228 pV | 通过 |

Spectre 为 **21.1.0.509.isr12**。8 个配置均实际运行成功，5 个满足独立电压预算。
按事先声明的预算选取斜坡和平台的基础档、反向的局部细化档，三个模型均取得合格参考。
三个超差配置原样保留。这说明本例的参考精度需要控制转折附近的步长，不能把基础档的差值直接归为 EVAS 错误。
这也不证明 Spectre 的私有算法或所有 `slew` 模型都需要这种设置。

| 设置 | 请求 reltol | 实际 reltol | vabstol | maxstep |
| --- | ---: | ---: | ---: | --- |
| 基础档 | 1e-7 | 1e-8 | 1e-9 V | 0.01 s |
| 仅收紧容差 | 1e-9 | 1e-10 | 1e-11 V | 0.01 s |
| 容差及全程步长收紧 | 1e-9 | 1e-10 | 1e-11 V | 0.0005 s |
| 局部细化 | 1e-9 | 1e-10 | 1e-11 V | 通常 0.01 s，指定窗口 1e-7 s |

各档使用 `errpreset=conservative`、`method=traponly`、`iabstol=1e-15 A`，不加 strobe 或 VA 观察事件。
瞬态日志与 PSF 读回的 reltol 比请求小十倍，两种值都保留，不能把预设名称当成实际参数。
局部细化采用 Spectre 21.1 用户手册第 247–248 页的动态参数接口
`param=maxstep param_vec=[...] param_step=0`。
四个窗口分别以独立解析交点 `8/3、32/9、40/3、208/9 s` 为中心，前后各 0.001 s。
日志记录参数变化，原生观察网格另核对窗口内步长，具体数值见[收据](receipt.json)。
这是针对已知解析转折的配置，不是自动为任意模型选择步长的方法。

## 独立答案和 EVAS 检查

两级限速分别为 ±0.5、±0.25 V/s，初值等于输入首值。
斜坡 `u=t` 得到 `h=t/2、y=t/4`。平台输入 `u=min(t,4)` 得到
`h=min(t/2,4)、y=min(t/4,4)`。
反向刺激为 `(0,0),(2,4),(4,-4),(24,-4)`。由相交条件独立求得：

- `h=t/2`，直到 `t=8/3`；随后 `h=max(-4,8/3-t/2)`。
- `y=t/4`，直到 `t=32/9`；随后 `y=max(-4,16/9-t/4)`。

[检查器](../../../evas/validation/slew_cascade/compare.py)用 Python Fraction 计算这些公式，
不读取 EVAS 的内部解作为答案。校准包括 3 个正确控制和 15 个错误控制，分别检出输出错误、
一级历史错误、终点丢失、非有限值和重复时刻。
EVAS 对照使用相同 VA、刺激和全部 Spectre 原生时刻，固定 `vabstol=1e-10 V、reltol=0、max_step=1 s`。
8 次 EVAS 请求共 **185,999 个时刻**，全部独立检查通过，最大误差为 `2.961e-16 V`。
5 个参考达标配置的同刻比较也通过，局部细化反向例的两端最大差为 `1.637e-12 V`。
三个参考超差配置的配对失败仍保留。响应哈希及逐次结果见收据，有限点检查不是全时域证明。

开发回归另检查非零初值、非对称限速、两个实例、直接嵌套与内部节点两种写法、查询密度、
时间尺度、交点相邻浮点数和外部增益。误差预算不足时仍拒绝。
Rust 测试在同一个 Controller 中重复失败，再放宽请求预算重试，检查状态、队列和历史没有被失败试算改写。
三层、混合算子、非单位别名、状态输入及反馈继续拒绝。

## 复核与材料

从仓库根目录生成新的输入，不覆盖旧目录：

```sh
python3 -B evas/validation/slew_cascade/compare.py calibrate
python3 -B evas/validation/slew_cascade/compare.py freeze --output runs/slew-inputs
python3 -B evas/validation/slew_cascade/compare.py freeze-refinement --output runs/slew-refinement-inputs
```

服务器执行复用 [callback_probe.py](../sample-edge-filter/callback_probe.py) 的 `run(inputs, outputs, profile)`。
本批串行使用 1 线程、4 GiB 内存、32 MiB 单文件上限，主仿真单次最多 90 秒，许可证等待最多 30 秒。
完成后用同一检查器的 `analyze` 命令，传入 `--inputs`、`--raw`、新 `--output` 和 `--kernel`。

输入生成器、数学答案和紧凑收据在仓库内。原始波形、完整日志和 EVAS 响应为 **local-only**，
保存在 `current/runs/evas-backlog-20261011/` 的 `slew-*` 目录，远端原件也保留。
收据记录清单和哈希，哈希不等于公开下载入口。本批是开发对照，不是未见论文评价集，
也不完成 #66 的动态参数、深层组合或 C4 滤波直接通路。
