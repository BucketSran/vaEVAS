## 首轮结果

[收据](first-run.json)记录基于 main `f8b8ea52` 的 EVAS 0.12.2 / IR16 内核、ngspice 47、
脚本摘要、输入与输出摘要、平台和请求设置。运行时没有行为改动。

| 固定对象 | 结果 |
| --- | --- |
| 1、4、16、64 个未知节点的仿射网络 | 每组 3 个静态样本、7 个 PWL 观察均通过；也符合预设解析解 |
| `static_nonlinear.json` | 3 个样本通过；包含非零参考电压与负多项式底数 |
| 固定周期计数器 | 5 个非边沿观察通过；也符合 `floor(t/.25)` |
| 其余 5 个 smoke manifest | 翻译器明确不支持；逐项名称和原因保留在收据 |

已执行共同子集共 15 个静态样本、33 个瞬态观察。最大归一化差异约 0.00645，
小于通过边界 1。该结果不表示通用事件、动态算子或全部 smoke 已与 ngspice 对照通过。
原 31 条件矩阵未重跑，也不更改历史成绩或正式验证资格。

首次调试用 `^` 翻译整数幂，ngspice 对负底数产生 NaN；修正为重复乘法后重新使用新目录执行。
这是翻译语义修正，没有放宽预算或删除负输入。最终脚本另有 7 项校准检查，包含错误波形拒绝。
