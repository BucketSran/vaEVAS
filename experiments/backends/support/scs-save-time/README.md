# SCS 时间保存选择

`save time y u` 现在能完成输入适配、编译、Rust 运行和输出。无同名电气节点时，`time` 不再报未知节点，独立时间轴保存在 `saved.times`，电压列依次为 `y`、`u`。重复选择不增加列。

若电路确有 `time` 节点，仍保存其电压。只有非节点 `time` 时，沿用 EVAS 默认节点列；这些列包括地节点，不等于 Spectre 的完整默认保存集合。`Time` 区分大小写，未知节点与 `V(node)` 等范围外语法继续拒绝。Spectre 会警告并忽略未知 `Time`，EVAS 保留严格拒绝。

Spectre 21.1.0.509.isr12 实际执行了八个串行探测，包括默认保存、仅时间、混合选择、重复选择、未知大写名称和同名节点。PSF 将 sweep 时间和 TRACE 中的同名记录分别编码；非节点 `time` 还能产生 `param_real` 记录，EVAS 不导出这项记录。既有通用读取器会把两个同名记录都误作新行，因此本次按 TRACE 声明顺序读取 VALUE，原文件未改写。

[固定输入](inputs.json)保留共同 VA、两端原网表及哈希。[有限对照](reference.json)固定 10 nV 电压门槛，只配对二进制时间完全相同的原生行，没有插值。七个可运行正例共 21 个配对点，最大电压差约 0.89 fV。所有 Spectre 电压行另按 `u=t,y=2t` 或同名节点控制 `V(time)=3+2t,V(y)=6+4t` 检查。参考没有零时刻原生行，零时刻只由独立开发回归验证，不称为已配对。Spectre 实际 reltol 为 1e-8，EVAS 为请求的 1e-7；其余生效设置和原始身份在收据中。

[开发回归](../../../../evas/tests/test_scs_save.py)验证默认保存、同名节点、重复选择、未知输入、strobeonly 行对齐，以及真实 simulate CLI 和 manifest CSV 导出。CSV 路径保存全部节点，不按 SCS 的 save 选择裁列。内核与 IR 未改变。

[原请求摘要](originals.json)保留 261–280 的原模型、原台架、精度和预算身份。20 项均移除首阻塞；269 完成运行并通过冻结旧 checker，其余为事件变量除法 8 项、非仿射谓词 8 项、源误差与动态组合 3 项。完整请求仍有 19 项拒绝，原历史结果不改写，也不把这次旧 checker 回放当正式 benchmark 或新增 Q 成绩。
