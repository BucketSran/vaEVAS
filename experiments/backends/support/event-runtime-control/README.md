# 有界事件循环与数组

EVAS 0.19.0 / IR23 支持隔离观察事件中的运行期循环、带检查的整数运算与数组读写。
[PR #188](https://github.com/BucketSran/vaEVAS/pull/188) 已将这一有限能力合入 main。
[0.19.0 验收收据](version019.json)记录版本更新后重跑的三个实际参考配对；旧候选收据仍保留原身份。
原 CDS/MUX 整题没有因此通过，不新增 Q 成绩。

例如 `n=3` 时，循环按源码顺序写数组，退出后 `i=3`；循环体不在 IR 中反复展开。
早期候选以主分支 `969b1b88770c03b2bc519e8397b7e0969be9947a` 为基线；
其原结果见 [result.json](result.json)，源码与内核身份见 [receipt.json](receipt.json)。
这些历史记录与上方 0.19.0 收据分别保留，不能据此称原 CDS 请求恢复。

循环的初始化、条件、循环体和更新依次读取当前候选状态。一个事件内全部循环（含嵌套循环）共用 4096 次循环体执行预算，超限明确失败。每个源 integer 算术中间节点检查 signed32 溢出，后续抵消不能掩盖它；整数除法与余数按向零截断，例如 `-5/2=-2`、`-5%2=-1`。数组下标必须是合法整数表达式，运行时检查有限、整数及原声明边界，不夹边界、不跳过写入。`Select` 只运行选中分支。

这些节点只服务普通事件执行路径中的隔离观察者。物理贡献、历史输入和初始化不因此获得新的运行期语言准入；主分支既有 implicit timer bridge 明确拒绝运行期 Loop/ArrayWrite。原 100000 项 IR、深度 96 及所有原模拟精度和时间限制保持。一次事件失败会丢弃该候选的数组、标量、display 和历史影响，再由原控制器决定接受或重试。

[独立模型与 checker](../../../../evas/validation/event_runtime/README.md) 保留三个已经实际运行的 Spectre 微例、原生 display/五个观察时刻摘录、设置与身份收据，以及独立答案和校准工具。三例精确整数答案分别为：顺序数组 `i=3, acc=10`；嵌套循环 `i=2, j=3, acc=21`；商余组合 `i=2, q=2, rem=1, acc=5`。实际回调时刻为 0.5；电压只检查原生 0、0.25、0.5、0.75、1 五点，预算 100 nV，不插值、不补点。原始 PSF、完整 stdout、内核和私有配置留在本地，公开哈希不等于提供下载。

原三条 CDS 的前端可编译并不代表完成。已保留的独立 F20+IR23 诊断在精确 transition 根与事件包围一致性处拒绝，没有原 checker 分数；本次语言交付不带 core20、history 扩展或 source proof 性能复用，不把它们列作语言包必需依赖。
