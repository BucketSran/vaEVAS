# Pulse 时间舍入与保存策略

有限线性 pulse 的拐点不一定能用浮点时间精确表示。现在 EVAS 为这些拐点保存原数值身份和舍入界，按最大斜率换算为全时域电压误差界；这个误差随电压求解和固定 timer 采样状态继续传播。误差经后续放大后超出原电压预算，仍须拒绝。

当前只支持不含算子的代数电压关系，以及固定 timer、initial/final 采样。非零源误差与算子、cross 或状态定时器组合仍明确拒绝，因为单个电压误差界不能证明导数和连续历史。它不是一般 pulse 动态能力的完成声明。

## 实际结果

同一 delay=1e9 s、rise/width/fall=0.2 s、gain=3 模型，原宽预算10 µV完成，原紧预算0.5 µV拒绝。独立有理数计算检查原脉冲与传输后折线的全部联合折点；两条折线之间的差分段线性，因此这些点给出全时域最大值。把申报误差界减半会失败。后续固定事件才放大采样状态的回归也保留，防止误差在采样后消失。

同模型实际 Spectre 21.1.0.509.isr12 对照的五个同时间原生点，最大差1.431 µV，低于预先固定的10 µV门槛。请求的相邻浮点 strobe 点并未全部出现在 Spectre 导出中，详见[紧凑结果](summary.json)。因此只报告这五点，不声称完成全部请求时刻的取证，也不据此新增Q资格。原始归档保留在本地 runs，公开文件不足以独立重跑商业参考结果。

显式 strobeoutput=all/strobeonly 的五张独立控制见[保存策略用例与 checker](../../../../evas/validation/strobe/README.md#显式保存策略)。保存策略只筛选观察集合；物理接受历史和完整求解结果在成对控制中相同。EVAS 省略 strobeoutput 时保留原保存规则，不能推断与 Spectre 默认集合相同。

测试入口为 evas/tests/test_source_uncertainty.py、test_scs.py、test_strobe.py，数学和接口边界见[事件误差合同](../../../../evas/docs/math/events.md)。本次不修改旧判据、原70请求成绩或历史通过数。
