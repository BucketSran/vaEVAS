# 保存源折点，避免漏掉窄脉冲

`.scs` 导出波形现在同时保留常规输出点和信号源折点。此前只按 maxstep 保存时，一段落在两点之间的窄脉冲可能完全消失，后续插值会得到错误输入。

例如源在0.25秒开始上升、0.375秒达到1 V、0.4375秒回到0 V。只保存0、0.5、1秒时，看不到这个脉冲。新网格保留上述折点，0.3125秒的独立插值答案为输入0.5 V、三倍增益输出1.5 V。

本次仅扩展保存点，不改变源定义、maxstep、模型或checker。源在stop之外的折点不加入输出；多个源取并集，仍受原100000点总预算限制。额外查询沿用EVAS原误差验收。

[实际同源对照](summary.json)使用相同VA、PWL刺激和数值容差。Spectre为21.1.0.509.isr12，本次已实际执行；EVAS复用未变的main7c15c1cb Rust内核，只修改保存适配器。6个时间完全相等的原生点中，输入和输出差均为0，覆盖脉冲峰值。没有插值配对或事件排除窗口；这不证明一般电路全时域一致，也不新增论文Q成绩。

[EVAS输入](evas.scs)只移除Spectre的显式保存策略字段，保留两个强制时刻；[Spectre原输入](spectre.scs)和[共同模型](dut.va)均保留。显式strobeoutput的实现另行验收。

开发回归覆盖窄脉冲、多个源、pulse、stop范围和输出预算，以及连续历史与事件采样消费者。原任务输入插值失败的历史成绩保留，原70请求的新成绩须由最终集成版本另行执行。
