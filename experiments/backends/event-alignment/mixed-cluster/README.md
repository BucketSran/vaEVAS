# 极近源根与固定 timer

两个原模型保留 PWL 的 binary64 端点 0.1/0.9、阈值 0.5/0.5000000000000001、
固定 `timer(0.5)`、显式时间容差 1e-12 s、表达式容差 1e-9 V 和 stop=1 s。
[合同](contract.json)在执行前冻结，以 Fraction 根独立规定物理顺序和查询计数。
held 模型在第一个 cross 将保持时钟从 0.9 改为 0.75，并用 `idt(1)` 检查历史。
fixed 模型输出零积分列。两者没有改变旧七例分母。

当前 EVAS 候选扩展精确可排序的连接簇，先后执行 first、timer、second。
原输出网格和稀疏网格事件记录一致；未知内部根继续拒绝。
Rust 控制器测试在第二个源根故意制造无法认证的 held 参数，证明失败回退状态、
包围、积分历史、日程、游标、记录和已有输出；修正后同实例与新控制器结果一致。

Spectre 21.1.0.509.isr12 实际执行原模型与插桩模型各一份，共四次，均取得波形。
两个原/插桩 PSF `VALUE` 段逐字节相等。插桩日志按 first、timer、second 输出，
但各模型的三个 `$abstime` 相同：fixed 为 `5.00000000000500044450e-1` s，
held 为 `5.00000000000500155473e-1` s。约 0.500 ps 的延迟在原 1 ps 时间预算内，
源 guard 偏移约 4e-13 V，亦在原表达式预算内。日志输出顺序不能证明内部保留了
EVAS 所认证的三个不同物理时刻。
