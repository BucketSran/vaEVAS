# 实际事件日志与单因素控制

本次诊断复用 Spectre 21.1.0.509.isr12，保留独立的未插桩模型，另在事件体内
加入 `$strobe`，以 `%.20e` 记录 `$abstime`、源值、guard 与状态。
事件时间来自该日志，不从 PSF 的十进制时间 token 推断真实回调先后。
每组原模型与插桩模型的 PSF `VALUE` 段逐字节一致；这只证明保存的有限波形未改变。

原模型、相邻 binary64 查询诊断各保留一对，共八次执行。第二轮四项单因素
控制各保留一对，又有八次执行；均取得波形。两个归档各 158 个文件由调用方核对。
原始材料位于日常入口的 `runs/issue-closure-20261008/event-reference-v1/`
和 `event-reference-v2b/`，属于 local-only；本页不是公开完整复现包。
紧凑原始 hash 和重算结果见 [event-reference-controls.json](evidence/event-reference-controls.json)。

## C1：观察设置会影响实际回调

C1 的输入从 0 到 binary64 的 6 µs 线性升至 3 V，阈值为 binary64 的 0.7 V。
以这些原数定义的精确 PWL 根比 binary64 查询 `1.4e-6` 晚约 `1.00027e-23` s。
EVAS 在该字面查询保留前态，在下一 binary64 查询给出后态；增加查询点没有改变事件记录。

| Spectre 条件 | 日志中的实际回调时刻 / s |
| --- | --- |
| 原观察网格、原显式 cross 容差 | 1.39999999999999993665e-6 |
| 相邻 binary64 观察网格、原显式 cross 容差 | 1.40000000100000004615e-6 |
| 相邻网格，仅时间容差改为 1e-18 s | 1.40000000000049989784e-6 |
| 相邻网格，仅表达式容差改为 1e-18 V | 1.39999999999999993665e-6 |
| 原网格移除 strobeoutput / strobetimes | 1.40000000099999983440e-6 |

前两项实际回调差约 1 fs，超过仅由 PSF 输出舍入造成的投影差。
收紧显式时间容差使延迟缩小，但这些结果没有建立唯一的精确边界阶段规则。
它们支持按原事件允许窗口检验兼容性；不能支持把 EVAS 改成最近浮点投影，
也不能替代原观察点的严格逐点结果。原 C1 阶段差仍为 F。

## M1：timer 定位与积分残差分别变化

M1 的独立答案为 `q=1` 于 [2 µs,6 µs)，
`z=1e6*min(max(t-2e-6,0),4e-6)` V。方法保持 traponly，
第二轮只把两个 timer 的显式时间容差从 1e-12 改为 1e-18 s。

| 条件 | 上升回调 / s | 上升后的 z 相对实际回调积分偏移 / V |
| --- | --- | --- |
| 原容差、原网格 | 1.99999917424811170992e-6 | 约 1.17424811e-6 |
| 原容差、相邻网格 | 1.99999917424811170992e-6 | 约 1.17424811e-6 |
| timer 时间容差 1e-18 | 1.99999999999999990950e-6 | 约 4.12875944e-7 |

此处偏移在上升后、下降前的原生行计算，不把这段子域当作完整通过判决。
严格 timer 控制把上升回调移至名义 binary64 时刻，但第一条事件后 z 仍非零。
严格档最终保持 `3.9999984128759465` V；按完整独立答案的最大绝对误差
约为 1.58712406 µV，仍超过原 1 µV 电压预算。原 F 保留。

观测与事件不连续点附近的离散积分误差一致，但仅凭波形不能确定专有积分器的内部公式。
这项单因素控制证明剩余电压差不能全归因于 timer 的提前回调。
EVAS 的精确连续积分答案无需复制该离散偏移；严格波形对齐仍有缺口。

新增极近混合事件簇另有[冻结原配置诊断与实际 Spectre 对照](mixed-cluster/README.md)；
它的精确顺序证明与上述参考输出不能互相代替。
