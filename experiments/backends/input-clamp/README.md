# 输入限幅与 VCO 的有限观测对照

## 普通条件边界修复与新参考

四端首轮的 EX-01 在普通限幅比较边界被 EVAS 拒绝。本次将原始 PWL 的有界有理数
证书用于普通比较，保留真实等号侧别与旧两参数 API 的接受范围。证书耗尽、真实输入
不确定性和不支持的来源仍按原边界处理；没有放宽电压容差或添加比较 epsilon。

新跑同一 EX-01 Spectre 请求，并以其原域内全部40,005个导出时刻查询组合候选。
输入和输出逐点差均为0 V。原模型、刺激、stop和预算不变；这只是有限观测结果，
观测误差资格与请求/有效设置差异仍缺，不能授予 paper P。
Spectre 请求 reltol=1e-5，实际 conservative 为1e-6；EVAS 同名参数不代表相同误差约束。

[本次紧凑证据](boundary-followup.json)绑定源码清单、内核、逐件原始输入和新参考身份，
并记录独立分支与组合回归。实际执行的是 PR100/101/102 组合候选，不能冒充单个 PR
或 main 的结果。原始数据、失败与完整双审日志继续在本机和已有服务器保留。
下文 VCO 历史结果及普通相位分歧不因本次 EX-01 修复而改变。

CO-VCO-01 检查输入仿射频率限幅后，`idtmod` 是否积分限幅后的分段面积，
以及 `sin(2πphase)` 是否使用同一历史。最新[边界证书证据](certificate-evidence.json)
记录修复后全部40,840行配对及仍存在的普通相位分歧。
下文的[早期精简证据](evidence.json)与逐点拒绝诊断保留原身份，不代表最新实现。

后续实现 `043290c0` 将同一个有界原输入证书用于直接 PWL 的 `idtmod`，
并允许限幅模型中的无 reset、只依赖驱动源的独立 `idt`。

[实现证据](alignment-implementation.json)。下文各历史修订的范围与原结果不改写。

新增的常频、PWL、限幅和事件微实验见[分层对照](../spectre-alignment/README.md)。

在常频回绕例中，PSF时间文字的舍入区间包含数学根；
不能把按该文字解析后出现的普通相位差直接归因于 Spectre 内部取模算法。
普通相位原严格失败、未配对行和完整观测资格缺口均保留。

## 新 Spectre 容差与步长控制

[控制档证据](control-evidence.json)保留两次新 Spectre 执行及同刻 EVAS 复跑。
源码、刺激、初值和输出请求不变，只分别调整容差族和最大步长；物理验收预算保持不变。

| Spectre 实际设置 | 圆周相位最大误差 | 正弦最大误差 | 普通相位与执行缺口 |
| --- | ---: | ---: | --- |
| reltol=1e-9，vabstol=1e-10V，maxstep=200ps | 4.60e-11 cycle | 2.89e-10 V | 40,878行；第一中心到1的另一侧，EVAS与Spectre第一和第三中心相差近1cycle |
| reltol=1e-6，vabstol=1e-7V，maxstep=100ps | 2.60e-9 cycle | 1.63e-8 V | 80,749行；末时刻超过EVAS精确stop，完整EVAS请求被拒绝 |

两档均实际使用 `traponly`，各观察4次回绕。表中误差来自独立工程答案的有限导出点筛查。
100ps档另做一次诊断，仅查询80,748个原域内实际时刻，仍保留原80,749行分母与超域末行。
该诊断返回完整域内波形，第三中心普通相位差仍约`0.9999999974 cycle`；
原整批 `invalid_inputs` 没有被替换。Spectre末 token 为`8.000000000003679e-6`，
没有把它钳位到 `8e-6`。

收紧容差后圆周/正弦误差下降，但第一中心由接近0变为接近1。
这说明断点处的普通相位分歧不能只靠降低连续误差量消除；EVAS继续按自己的精确参考认证，
并把与Spectre的侧别差异作为未解决项报告。以上两次控制执行不改变paper状态。

## 回绕中心的逐点诊断与容差含义

[逐点补充](boundary-diagnostics.json)以 `d7034820` 的原生产代码重建内核，
复用同一批 Spectre 实际记录，在四个中心和各自的实际左右邻点分别查询。
本次共48次本地内核调用，没有新增 Spectre 运行。

| EVAS 设置：absolute / relative | 原模型中心拒绝 | 原模型左右邻点完成 | 常零 phase 输出诊断模型中心完成 |
| --- | ---: | ---: | ---: |
| 原配置：1e-7 / 1e-5 | 4/4 | 8/8 | 4/4 |
| 收紧：1e-8 / 1e-6 | 4/4 | 8/8 | 4/4 |
| 仅诊断的放宽：1e-6 / 1e-4 | 4/4 | 8/8 | 4/4 |

以上是调用结果计数，不是新增题目或正式达标数。所有原模型中心仍因普通 phase 的
前向误差界跨0/1而拒绝；不能靠这三档容差消除边界歧义。成功查询的各节点名义值在三档间相同。
诊断模型只把普通 `V(phase)` 贡献改为常零，保留原频率、`idtmod` 与正弦链，
用于区分相位节点认证和周期输出路径；它是不同源码，不能作为原模型通过证据。
原源码、刺激、时间、预算、失败和分母保留，paper 状态仍为 **I**。

独立精确分数计算还区分了“请求的中心”与数学边界：按原始 binary64 PWL 和编译后
binary64 IR 的精确实数解释，四个中心相对最近整圈的侧别为 **正、正、负、正**，
距离约为 `2.75e-16`、`1.90e-16`、`-4.91e-16`、`2.52e-16 cycle`。
第三点在该参考下应接近1，不能把所有中心强置为0。此计算不是十进制工程源的精确答案，
也不是源到 IR 等价证明或 Spectre 内部算法说明；前端倒数折叠等算术还须单独检查。

实际 Spectre 日志121–141行记录 `errpreset=conservative`、`reltol=1e-6`、
`vabstol=1e-7 V`、`lteratio=10`、`relref=alllocal`、`maxstep=200ps`、`method=traponly`；
deck 显式覆盖积分方法，不能仅从预设名推断方法。其相对误差参考可采用该节点历史最大幅值，
而 EVAS 当前瞬态包围检查使用本次返回值幅值。两者约束对象也不同，见
[容差解释](../../../evas/docs/math/solving.md#spectre-与-evas-的容差含义)。
本地三档诊断没有建立 Spectre 的容差收敛结论；新的 Spectre 扫描须另行冻结具体设置，
并保持外部物理验收预算不变。

当时提出的修复方向是保留原输入来源，在普通包围跨整圈时按需证明积分落在哪一侧，同时认证名义返回值。
只精确积分已舍入的派生 PWL，不能消除它与原输入之间的误差带。
这需要新的数值证书，按 [Spec A Q7](https://github.com/BucketSran/vaEVAS/issues/96)
先讨论具体设计；该历史诊断没有实现新方法。用户随后批准的实现及最新结果见本文首节。
