This fixed-history archive preserves the approved scope, canonical decision trail
and selected independent reports for PR #162. It is not a second support matrix.
The current result belongs to `evas/docs/COMPARISON.md`; compact scientific
receipts belong to `experiments/backends/support/`.

`MANIFEST.json` binds the exact copied report bytes. The archived decision trail is
append-only and includes corrections. Read superseding dispositions when an early
review found a defect or lacked context; an early clean review does not cover a
later source revision.

Relative paths inside the original reports refer to the original local task root
`runs/evas-overnight-20261012` unless the report states otherwise. Selected report
files are available here at this commit. Unselected raw waveforms, full CLI streams,
compiled models, binary dumps and commercial manuals remain local-only. A file
hash, path or review statement is not a public download or an independent execution.

actual Claude CLI calls to GLM-5.3, with invocation receipts and coverage limitations.
These are reviews, not substitutes for actual simulator results. No unapproved
open-backend mechanism draft grants a passing qualification.
