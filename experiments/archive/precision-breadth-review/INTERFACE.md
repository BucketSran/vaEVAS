# Shared case / reference API, breadth-v1

New files only; existing precision-v1/v2 cards and results remain immutable. This interface is a coordinator decision before implementation, not a scientific qualification. Raise necessary API changes promptly.

- precision_breadth_foundation.py and precision_breadth_composition.py each export cards() -> list[dict], reference(card, time_s, event_bounds) -> dict.
- Card keys compatible with existing deck generator: id (unique variant), group_id (F01..F20 or EC01..EC24), family (foundation/composition), title, source (complete common VA), top, ports, parameters, inputs {name:[[seconds,volts],...]}, outputs [names], scale_V, unit_s, stop_s. Add critical_times_s, events, counter_channels, input_gain_bound, output_slope_bound_V_s, reference_kind, and reference_parameters. JSON serializable, no callable metadata.
- events: ordered list of {id, counter, index, nominal_s, early_s, late_s, kind}; early_s and late_s are NONNEGATIVE TOLERANCE OFFSETS IN SECONDS, not absolute timestamps. Legal window is nominal_s-early_s through nominal_s+late_s. Cross additionally has input and slope_V_s / expression_tolerance_V when applicable. As already required by COMPARISON-METHODOLOGY.md (sample/hold derivation) and math/events.md (cross tolerance contract), a locally affine cross must satisfy both time and expression tolerance: its legal late bound is also limited by expression_tolerance_V/abs(slope_V_s). This defines the legal window before observing results; it never clips the measured callback bracket. Different counters may be used for independent sources. Each counter_channels entry maps name to {initial, final}. A counter increments by one per event. For unobservable events mark timing_evidence_required and do not claim qualified callback time.
- reference receives one globally consistent mapping event id -> [lower_s,upper_s], never per-point inferred values. With no events, {}. Return {outputs:{name:[lower_V,upper_V]}, numerical_uncertainty_V: nonnegative float, undefined:{name:reason}}. Bounds contain exact mathematical answer for the represented parameters, input PWL and supplied callback intervals. Include sensitivity to time serialization conservatively. Numerical uncertainty is arithmetic rounding, separate from event uncertainty already in the ranges.
- Reference may raise explicit NotImplementedError for unsettled semantics, accompanied by card qualification_note and support_probe_only=true. Still generate source/experiment slot and report unqualified; do not silently skip the group.
- Mathematical undefined points alone may omit a named output only with reason and explicit left/right critical obligations. Other missing outputs are evidence failures. Output count channels are graded by shared event logic; the reference can omit them.
- Defaults Q budgets and native observations are shared. Max interval between actual rows T/16; requested global T/32. For each critical point request center and +/-2ps, limited to run extent. Event window grids may be denser based on slope/uncertainty. Defaults preserve 100ps source tolerances; exact numbers must be in each card.
- Multiple DC variants or axis variants share group_id and all are required. Tests live in evas/tests/test_precision_breadth_{foundation,composition,core}.py as owner assigned. Family workers own models/references/tests, core worker owns precision_breadth.py and test_precision_breadth_core.py, root owns orchestration/docs/publication.

## Pre-freeze audit clarifications

- Input gain means the L1 combination over independent input uncertainties; 3u-2r needs coefficient sum 5 for a shared maximum input-error bound. Propagate dynamic amplification over the full frozen run.
- idtmod exact half-open wrap points are mathematically defined. Raw voltage error remains mandatory; circular error and sin cannot replace it.
- DC-sensitive outputs require actual phase evidence. A numeric timestamp of zero alone is insufficient. Missing phase or strict event-order evidence must produce evidence_insufficient, not behavior failure or pass.
- Reference intervals enclose complete event ranges, including internal extrema; endpoint enumeration is not generally sufficient. All future consumers use the same callback intervals.
- NP/ND paired exact equivalence uses represented dyadic parameters in new F15/F16, before formal freezing. Old non-dyadic records remain unchanged.

- The core passes reference_time_uncertainty_s=16*ulp(stop_s) in a copied card. A reference that already includes this full time box returns time_uncertainty_included=true; only voltage export rounding is added again.
- After counter history passes integer/count/order checks, core may pass reference_counter_stages and reference_event_stages from the same observed row. This establishes the current discrete state, never an inferred callback timestamp. The reference keeps the same global callback intervals for all continuous consumers. Missing/invalid counter evidence cannot become a trusted stage.
