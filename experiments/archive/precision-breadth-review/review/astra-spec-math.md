## 已确认问题

### [P1] F20 用圆周距离代替普通相位误差，会漏检错误的跳变侧

位置：`foundation-inventory.md:284`；对照 `SPEC.md:15-17` 和 `evas/docs/math/operators.md:588-599`。

该行把 ordinary phase 定义为圆周距离。真实相位接近 1 而输出接近 0 时，圆周误差很小，普通电压误差接近 1 V。相位越界整圈也可能被圆周距离消去。正弦输出正确不能证实 phase 电压正确。

修正为 raw/ordinary 相位按普通绝对电压误差验收，圆周误差只作独立附加诊断。时间不确定区间跨 wrap 时，应保留两侧集合；当前 API 的区间凸包也可保守实现，但其宽度应导致证据不足。不能挑选离实测最近的一侧。增加 phase 错侧、phase 整圈偏移但 sin 正确两个负例。

处理进展：已通知 foundation worker。其回复承诺 raw phase 使用普通区间，跨侧为 I。审查时未见最终实现，不能记作代码修复已验证。

### [P2] F16 的微秒时间单位与当前精确倒数准入冲突，ND/NP 也不是严格同一方程

位置：`foundation-inventory.md:230-233`；对照 `evas/docs/math/operators.md:444-464`。

原方案 T 为 binary64 的 `1e-6`，常量计算 `-1/T` 得到 `-1000000`。其精确倒数是实数 `1/1000000`，不等于 binary64 的 T。当前 EVAS NP 准入明确要求该倒数可精确表示，因此这个原方案应拒绝。不能将其描述为已有支持路径上的积分精度失败，也不能称 ND/NP 的精确参考方程完全相同。

独立 Fraction 检查得到 `Q(1e-6) - 1/1000000 = -4.525188817411374e-23 s`。该差本身远小于本批电压预算，问题在于准入和“精确等价”的表述。

冻结前可把 F15/F16 共同选为 T=`2^-20 s`，从而极点和倒数都精确，或保留原模型并明确报告转换准入缺口。不能运行后依据成绩改值。处理进展：foundation worker 转述 root 已选择共同 dyadic 时间单位。最终卡与源码仍需核查。

### [P2] EC02 把事件时间灵敏度等同当前边沿斜率，会低估中断历史的不确定度

位置：`composition-inventory.md:32`；对照 `evas/docs/math/operators.md:82-85,130-136`。

中断后的值同时依赖旧起点事件和反向事件。举例：初值 0，a 时刻开始向 1 上升，tr=10；b 时刻反向到 0，tf=20。下降期间

`y(t)=(b-a)/10-(t-b)/20`，

因此 `∂y/∂b=1/10+1/20=0.15`，是当前下降斜率绝对值 0.05 的三倍。只用当前斜率乘反向事件窗会遗漏旧上升段随 b 改变的面积/高度。对库存 EC02 的 tr=.2T、tf=.4T，同样是 `7.5/T` 对 `2.5/T`。

修正说明并对整条历史传播区间。中断参考需要保存历史起点 o、旧目标 p、当前值 yc、新目标 q；同向保留 o、反向使用 p；`m=(q-on)/D`，从 yc 连续延伸到 `tc+(q-yc)/m`。不能每次中断从 yc 重新走完整 D，也不能把 yc 替成旧目标。EC05 面积消费者还须累计已经发生的所有线段面积。

处理进展：composition worker 已承诺完整历史区间递推，EC05 保持 probe-only。最终实现未审查。

## 实现必须满足的数学义务

### 事件区间不能只枚举两个端点

`composition-inventory.md:44` 的 EC04 闭式解正确，但非线性 callback 依赖存在内部极值。令

`f(r)=5+4r+(2r+1)^2(x-r)`，则

`f'(r)=4+4(2r+1)(x-r)-(2r+1)^2`。

选择任意事件中心 r0，再令 `x=r0+((2r0+1)^2-4)/(4(2r0+1))`，即可使中心成为驻点。对 r0=7/5、x=793/380、半宽 1e-4 的独立有理数检查，中心值比左右端点分别高约 `1.24522316e-7`、`1.24530316e-7 V`。这已超过 A=1 的 Q3 预算。该数值例用来校准包围算法，不冒称是 EC04 的实际 sqrt(2) 根；同一驻点构造对 sqrt(2) 邻域也成立。

因此需要完整区间运算、可证明的全窗导数界，或解析包含驻点的极值计算。仅角点枚举不是一般包围方法。composition worker 已承诺完整 Decimal interval 传播。

所有输出、未来保持状态和面积消费者使用同一组全局 callback 括区间。即使一个区间参考保守，验收仍应使用误差上界 `max(abs(actual-lo),abs(actual-hi))+u`，不能用距区间最近距离判通过。旧 `precision_v2.py:68-69` 正确区分了这两个界，可复用该原则，不应更改旧文件。

### 绑定原始源码表达式，不把归一化公式默认为无舍入等式

F02 的 `y=r+3v+.125`、`z=r+2v+.125` 正确，必须保留贡献位置快照。EC04 的先采样、再 `q=2*q+1` 也正确，不能最终符号替换成不同求值时刻的 V(u)。

归一化公式中的 T、频率、速率、延迟必须对应实际模型字面量和常量表达式。不能把 `Q(.75/T)` 自动换成 `.75/Q(T)`，或把 `Q(.75*T)` 自动换成 `.75*Q(T)`，再声称得到源码的精确参考。可选择可精确表示的冻结常量、显式字面量，或把差异放入有证明的 uncertainty。此处只要求公开源码的数学/表示合同，不要求模仿 Spectre 私有中间舍入。

F20、EC17-19 的 `sin(c*p)` 中 c 来自实际 `2*M_PI`。严格地说，`sin(c*unwrapped_phase)` 与 `sin(c*wrapped_phase)` 并不完全相等，因为 c 不是精确实数 2π。若用数学 `sin(2πa)` 简化参考，应显式加上由 `|c-2π|`、圈数/相位幅度和 sin 的 Lipschitz 界导出的误差。当前短轨迹该差远低于 Q3，但不能声称零。对输入区间的正弦还需包含内部极值，不只是求两端 sin。

### 多输入增益和未来动态增益必须合成

`INTERFACE.md:6` 的 `input_gain_bound` 需要说明所乘的是哪种输入误差范数。F01 的 `y=3u-2r+.125` 在两个输入各自有误差 δ 时，总输入影响上界是 5δ，不是 3δ。F06 的 `y=6u-5r` 相应为 11δ。非线性根可用导数下界传播；动态积分/保持消费者应使用整个冻结时间域上的增益或直接区间传播，不只当前输出斜率。

事件不确定度已进入 reference range 后，不应把同一项再次作为确定误差重复添加；但输入、时间序列化和数值参考不确定度不可无说明地遗漏。Q1/Q2/Q3 的 B/100、B/10 子限额仍同时检查，不能仅看最终总界是否小于 B。

### 观察资格需要表达 DC 相位和真实事件顺序

F14 的 ddt 在 DC 为 0，正时间第一段为 .5；EC16 的 y 在 DC 为 0，右极限为 .5。这两个答案都正确。但一个标为 time=0 的原生行，可能是 DC 或 transient 初始行。`reference(card,time,event_bounds)` 没有 phase 入参；应由适配器/卡片合同传入可信的相位证据，或将初态资格标为 I。不能只凭 time=0 选择 DC 答案后判某后端错误。数学无定义的内部导数点也不能扩大成固定时间排除窗。

EC20 的 `3Q(2e-6)<2Q(3e-6)` 正确，两者差仅 `4.235164736271502e-22 s`。独立计数最终为 3/2 不能证明先后。`experiments/backends/ordered-event-history/README.md:5` 已记录这两个变化共用一个导出记录而顺序仍未知。不能因 reference 已按期望顺序排序就把顺序标为 pass。普通 native 行无法区分时，需独立 event identity/order 证据或保持 I。严格原始名义次序是该项目已选定的额外义务，不能从宽 timer 合法窗本身推导出来。

### 固定卡片之前仍需冻结的科学选择

EC22 OR 回调合并/计数语义、EC23 单 guard 自换向是否与双阈值模型等价，库存已经正确保留未决。不得以某后端输出反推期望答案。EC24 需要冻结 reset 的左右闭合约定、选定代数分支和满足 `1+2y` 远离零的 stop；其无 reset 与 release 后闭式解本身正确。EC05/24 当前拒绝是支持结果，不能被误记为数值通过。

“请求了中心与 ±2ps”不等于中心及两侧确实观测到。先按实际时间/误差证据判资格，再算参考。事件内密集请求可能改善后端行为，成绩必须绑定整个观察配置。近相位边界自然出现 I 不构成删边界或降标准的理由。

## 核对为正确的部分与覆盖限制

已逐式核对 F01-19 的理想实数关系、F20 的 modulo 结构，以及 EC01-21/24 给出的代数、分段面积和 ODE 解。除上列表示与验收问题外，未发现另一个错误闭式解。尤其 F18 的切换点 1.2/2.8、EC15 两级 slew 的折线、EC10 的 `2-4/(4+x-theta)`、EC11 的二阶 ramp 解、EC16 的 0+ 直接跳变、EC18 的负频率 half-open 点、EC21 的倒数解均相容。该结论不扩展到尚未给出的完整 PWL fixture 和源代码。

EC12 的首段还有便于人工校准的简式：当 u=x+.5 且 DC 初始化 X(0)=.125 时，`X=x²/2+.125`，故 `h=x²/2+x+.125`。首段齐次指数系数恰为零；若要验证折点后齐次尾波，应保留实际 PWL 折点并继续传播状态。

F12 的单调根满足 `g'(z)>=1`，因此绝对残差本身界定前向误差 `|z-z*|<=|g(z)-v|`。库存要求的“残差小而前向误差超预算”负例，若指同单位、同预算的绝对残差，则数学上不存在；只能针对错误归一化/缩放残差的检查器设计。保留独立前向根验收仍有价值，不必构造不可能的控制。

现有 `precision_reference.py` 的 Fraction PWL、80 位定向 Decimal 运算与 first-order 段解可作为新实现的独立基础。本次没有发现该文件上述有限用途的公式错误。其 `slope_bound` 和 `FirstOrder` 不能无证明地推广成任意组合的全局误差界。旧 `precision_v2.py` 的完整 callback 括区间合法性、误差上下界和缺观察 I 原则可以继承，新组合仍需独立校准。
