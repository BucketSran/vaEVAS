# 事件波形的共同历史重判

本目录记录 2026-09-28 对 v1 既有事件波形的重新分析，覆盖 V3、V4 C0/C1 和 V5。
问题是：**能否用同一组合法事件时刻解释整条输出？** 逐点挑选不同的事件时刻，
即使每个点都落入允许包络，也可能无法对应一条实际历史。

本轮没有新仿真或 EVAS 修改。原始输入、失败和冻结 v1 保持不变，
新判据与结果单独保存。

## 重判结果

32 条旧配置中有 24 份可用波形，另外 8 条保留原执行失败。
逐配置结论、共同事件见证与搜索状态在 [results.json](results.json)。

| 后端 | 旧配置 | 可用波形 | 相容 | 不相容 | 原执行失败 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Spectre | 8 | 8 | 8 | 0 | 0 |
| EVAS 0.8.7 | 8 | 6 | 3 | 3 | 2 |
| OpenVAF-R＋ngspice | 8 | 2 | 0 | 2 | 6 |
| Gnucap＋modelgen | 8 | 8 | 2 | 6 | 0 |

在 `ε=1 mV` 下，`B=0` 与候选 `B=0.25 mV` 两个条件性场景分类一致：
13 份相容、11 份不相容。第二个 B 是敏感性假设，尚非已证明的观察误差界。
真实运行的正式资格仍为 **I**，也未单独认证 V5 延迟/完整沿长的 1% 指标。

本轮没有发现改变旧筛查分类的新反例；方法改进的直接证据来自预定的共同历史矛盾控制。
这不能说明检查器已经检出所有错误。

## 判定覆盖什么

[history.py](history.py) 只处理互不重叠的线性有限边沿及其保持状态。
每个事件的时刻偏移属于事先规定的区间；采样目标随同一个偏移变化，后续保持和
下一边沿也使用这个目标。初态、沿长和延迟固定，不能通过任意拟合隐藏错误。

算法将输入数值转换为精确有理数。相同保持段上的所有约束取交集；沿内保留全部
观察约束。区间包围采用多仿射表达式的角点界，分支时完整覆盖原事件域。
候选时刻只是搜索建议，接受前仍对全部约束逐项精确核对。

- **P（相容）**：找到并核验同一组时刻满足所有 `|误差| + B ≤ ε`。
- **F（不相容）**：通过区间排除覆盖整个事件域，证明没有共同历史满足 `|误差| ≤ ε + B`。
- **I（未决）**：误差带无法裁决、搜索预算用尽，或输入/所需合同不合格。

这里的 P/F/I 是指定观察模型内的数学结论，**不是模拟器正式资格**。
区间过宽可能留下 I；找不到候选解不会自动变成 F。初版每条轨迹最多检查 256 个区间盒。
重复时标未经侧别解释时保留 I，不删除行；中断边沿、额外内部回调和未采样窄脉冲不在已实现范围。

## 检查器与证据

[history.py](history.py) 实现共同历史判断；[recheck.py](recheck.py) 在读取旧数据前
核对运行记录、条件、DUT、设置、网表与波形哈希，再生成新的分析。
它不调用旧逐点包络或 EVAS/Benchmark checker 来产生答案。

17 项校准/适配检查覆盖手算正例、共同历史矛盾、容差边界、错误沿形、
预算耗尽及非法观察输入。它们是方法控制，不计入仿真器条件数。
方法要求见 [METHOD_QUALIFICATION](../../../evas/validation/METHOD_QUALIFICATION.md)。

## 复现

在仓库根目录运行校准，不访问网络或模拟器：

```sh
python3 -B -m unittest discover -s experiments/archive/dvs2-history-validation -p 'test_*.py' -v
python3 -B scripts/verify_validation_version.py
```

已有获准原始证据的本地副本时，可重判到一个新的输出路径：

```sh
python3 -B experiments/archive/dvs2-history-validation/recheck.py \
  runs/dvs2-starter-20260927-01/evidence \
  --output runs/dvs2-history-reanalysis-new/analysis.json
```

脚本拒绝向证据目录内写入或覆盖已有分析文件。没有这份私有归档时只能运行公开的
构造控制，不能把它们当成对历史波形的复现。公开结果保留输入/分析器摘要及逐配置状态，
不分发原始日志、商业依赖或机器配置。
