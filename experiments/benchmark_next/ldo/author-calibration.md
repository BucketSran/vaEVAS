# LDO 作者校准

最终 r7 校准完成。17 个实现 × 3 个条件，共 51 条件全部实际编译并仿真成功；四个正确实现的 12 个条件全部通过，13 个语义错版各有至少一个条件被拒绝。最终结果为 16 条件通过、35 条件拒绝，其中四个错版在失败 DUT 上恰好报告正确。精简 JSON 共保留 80 个已完成执行位置，其中包括最终 51 个条件和另外 29 个历史尝试，模型试做为 0。实际后端为 Spectre `21.1.0.509.isr12`。

最终校准在真实 ADB OTA5 晶体管电路和固定 SKY130 TT 模型上运行，使用 Spectre 商业扩展后端。这里记录作者参考、不同正确写法和可编译语义错版的验收，不包含模型试做。候选代码、任务包、判据、波形和归档身份见 [author-calibration.json](author-calibration.json)。

## 验收范围

B1 覆盖 nominal、dropout-no-target 和 heavy-slow。B2 覆盖 healthy、slow-cap 和 offset-timeout。每题的原始 `solution/solve.sh` 在固定 Docker 镜像执行，取实际生成的 `/work/dut.va` 参与校准。不同正确实现改变资格计算方式、使用 3ns 报告边沿，并加入 1TΩ 输入负载。它检验 checker 接受公开合同允许的不同实现。

错误实现分别覆盖阈值时钟错误、把末端电压当目标、健康 DUT 永远报失败、理想指标、固定时间推进、跳过负载、跨阶段沿用恢复历史及抑制峰值。两题另各有主动驱动观测端与 1MΩ 额外负载负例。拒绝要求错版实际编译并完成仿真，至少一个工况被独立 checker 拒绝；某些错版在本来失败的 DUT 上恰好报告正确，计为该工况通过。

## 判据独立性和容差

checker 根据真实波形重新采样，不使用候选的 done、stage 或状态报告来选取实际阶段。独立算法校验包含有解析根的一阶响应、解析过冲的二阶振铃、末端单点入带以及资格重新开始。B2 验证 1ns、3ns、5ns 三种合法报告边沿和缺失实际负载的负例。

时间误差 75ns 是 50ns 采样格加波形插值余量；峰值和偏移允许 0.3mV。报告边沿前后 5ns 不做静态比较，窗口之外持续校验。固定零压探针保存输入支路电流，0.1nA 上限比正确替代实现最大实际 1.8pA 输入负载约大 56 倍，同时比 1MΩ 负载的约 1.2µA 小约一万倍。原参考观测电流为 0；两题的 drive/load 四个错版共 12 条件全部被拒绝。检查实际保存的电流，能够拒绝改变 DUT 物理行为后再正确报告的实现。

B2 健康与大电容条件的首阶段结束分别为 21.95µs 和 26.2µs；偏移 DUT 按 70/110/150/190/230µs 超时推进。B1 nominal 从实际波形重算的过冲为 10.9739249mV，低供电条件正确报告未达目标。指标来自实际 DUT，正常与不合格条件都按同一公开测量合同验收。

本地九项算法与波形接口测试通过，Python/JSON 语法、相对链接、可移植 checker 副本和冻结材料 SHA 检查通过。完整 `git diff --check` 保留格式例外：上游 PDK 两行 `+ ` 的尾空格（原始、适配模型及分发副本）与冻结题面的末尾空行。排除这些已固定字节的路径后，格式检查通过；没有为格式改动使校准身份失效。

## 来源适配和历史尝试

[源适配校准](source-calibration.json)记录六次 ngspice 完整启动运行：原始模型和适配模型各运行三种工况，峰值和终值一致。nominal 原电路峰值 1.21117343V，终值 1.20346707V，保留约 11.17mV 启动过冲。该检查只验证源模型格式适配，不能证明候选 VA 的开源执行等价性。

历史 r1 是旧部署范围拒绝；r2 与 r3 分别暴露 Spectre 对零随机表达式和花括号参数的导入差异。r4 的 B1 通过，B2 暴露报告切换保护窗比较缺陷。修正后 r5 四个正确实现的 12 条件通过。r6 已完成的部分错版校准保留；增加输入探针后，最终任务包与 checker 改变，最终全部工况使用 r7 重做。归档检验的 SSH 超时按原 job ID 恢复。所有已完成尝试保留在 JSON 的 `all_attempts`，原归档和波形留在忽略目录 `runs/ldo-calibration/`。

本组没有 EN、shutdown、PG 或保护控制任务。341、372、340 仅保留为后续素材。Spectre 是候选的唯一已校准后端；本报告不授予 ngspice 候选执行资格，也不宣称这些负例穷尽所有错误行为。
