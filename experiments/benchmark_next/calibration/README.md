# 分数闭环与校准扩展

本路线实现批准规格 #150 的三个独立工程目标。任务归属 `benchmark/tasks/v3-calibration-*/`，固定后端沿用 `v2_runtime.py` 和 circuit harness。当前作者校准尚待实际执行，不以文件存在或本地 checker 测试宣称通过。没有模型试做。

| 设计单元 | 任务 | 必须实际观察的行为 |
| --- | --- | --- |
| D1 | fractional-pll | 实际 DCO 上升沿组成 N/N+1 feedback，平均分频和输出频比、相位、复位及模式切换 |
| D2 | continuous-offset | 零输入窗口更新实际执行码，慢变差分失调残差与正常信号保留，停启、限幅与恢复 |
| D3 | common-mode-servo | 实际双路输出的共模误差和差模增益同时合格，停启、限幅与恢复 |

来源302提供分数闭环主题，但旧toggle计数合同不直接继承。306与369分别提供静态trim和有符号持续校准，已合并为D2的同一执行合同。390对应D3。现有v2 fine-TDC仍保留原身份。以上新环境均为自编行为合成前端，没有器件数据或开源同题复验资格。旧来源快照及许可边界随题保存，未复制其实现。

`build_tasks.py` 生成公开工程、私有台架、参考解、 不同的正确算法以及编译型语义错版；重新生成后必须重新校准身份。`manifest.json` 登记完整变体与预期，不把 pending 当作实际结果。`test_checker.py` 通过候选实际输出 seam 验证共模合格但差模损坏应被拒绝；它不运行仿真。

作者校准先执行原 `solution/solve.sh` 的产物。随后每个候选在两个固定台架执行，错版必须实际编译并获得 graded 行为失败，编译失败不能证明 checker 敏感。完整日志、波形和恢复状态留在忽略的runs；精简结论需要保留候选、checker、条件、后端与实际波形身份。总Spectre并发由主协调者分配，本路线最多一在途job。

阈值根据公开用途设定。差分残差12mV覆盖2mV量化步长、执行增益变化与校准间隔内慢变偏置；共模8mV覆盖相同量化与持续伺服建立。PLL窗口平均计数允许边界截断一个间隔，但逐间隔只能N/N+1；相位接受可预测分数波动，不要求参考序列逐位一致。最终数值裕量由真实正例及不同正确实现补齐，未校准前不称冻结。

当前科学资产 checkpoint 的最终作者矩阵仍在进行。固定台架版本、整数码检查与不同轨迹属于最后一轮身份；先前尝试用于诊断并完整保留，不能替代最终版校准。此 checkpoint 尚不能关闭 #150 或声明正式评分发布资格。
