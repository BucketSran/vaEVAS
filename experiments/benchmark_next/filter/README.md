# 连续滤波、RF变频与测量

本目录实现已批准规格 #149 的5道实际VA任务，覆盖C1至C4。C3拆成独立I/Q变频和包络动态。公开题面给出连续状态、频率单位、LO极性、窗口与容差，固定健康材料均可读。

[最终作者校准](calibration.json)完成26候选、58个实际Spectre条件：五参考及五种不同正确实现的22个条件全部通过；16种可编译语义错误实现全部被拒绝。负例的36个条件中32个失败、4个通过，每种错误至少在一个合法条件下被检出，未从分母移除通过条件。公开原码固定低通另有一个实际健康基线条件通过，不计入58个评分条件。原始 `solution/solve.sh` 在隔离Docker中实际生成参考产物，五题原始 `tests/test.sh --help` 在 `/tests` 挂载中导入成功，报告保留脚本、产物、镜像及执行身份。

早期[参考smoke](reference-smoke.json)保留为历史证据，最终矩阵额外检查测量报告在窗口结束前保持旧值。最终报告保留旧部署预检、保留字编译错误、未执行的准备包及SSH查询超时后原作业ID恢复。checkpoint独立审查没有新增Filter缺陷；最终证据仍待协调者独立复核，PR发布及规格关闭由协调者处理。本轮没有模型实验。

| 任务 | 工程动作 | 验收重点 |
| --- | --- | --- |
| `v3-filter-ctle` | 规格建模 | 单零双极归一化、完整幅相、非零初态 |
| `v3-filter-programmable-lp` | 扩展集成 | 原码基线、动态码频映射、连续状态和复位 |
| `v3-filter-iq-conversion` | 规格建模 | 实际输入与LO相乘、和频侧带、下变频低通、使能 |
| `v3-filter-envelope` | 规格建模 | 能量低通、瞬态、禁用衰减与复位 |
| `v3-filter-sweep-measurement` | 测试表征 | 实际扫频、实际输入输出同步积分、低幅及不足窗口无效 |

前四题各两个私有合法条件，测量题三个，其中一个窗口未稳态。每题有参考、不同正确实现和三个语义错误版本，测量题另有提前报告负例，共26候选、58个条件位置。完整分母由 `manifest.json` 与 `run-plan.json` 固定。计划中的pending表示生成时状态；实际验收以固定校准报告为准。不同参数与工况不增加题数。来源及所有334/364/400/336去向见 [SOURCES](SOURCES.md)。

正确替代实现检验的是等价行为，不要求复制参考源码：CTLE使用差状态d=x1-x2；可调低通积分z=y-initval；I/Q低通积分和、差状态后还原di/dq；包络积分e/2；测量器存储已归一化的正交系数，并通过复数乘积计算相位差。各错误版本只破坏已公开的一项语义，实际编译与完整条件判定随报告保存。

`build.py` 确定性生成题包和作者候选；不调用模拟器或模型API。`benchmark/checkers/v2_next_filter.py` 是唯一判据源，题包保存执行副本。独立checker从真实波形重建连续状态（分段线性输入与RK4）；CTLE额外计算解析复数频响，I/Q额外核对实际和频分量，测量题对真实波形同步检波。阈值按公开合同固定，随后用作者正负校准报告数值裕量。没有参考波形回放，也不解析候选源码选择评分。

参考和正确替代实现的最大输出误差分别为CTLE 0.00072 V、可调低通0.00037 V、I/Q低通0.00043 V和包络0.000077 V，均低于公开的0.006、0.008、0.008和0.01 V上限。实际扫频的有效报告相对波形同步积分结果，最大增益误差0.00067、最大相位误差0.00068 rad，均低于0.035上限；低幅、不足周期和未稳态窗口按合同报告无效。完整逐条件判据与波形身份见校准报告。

运行命令：

```sh
python3 -B experiments/benchmark_next/filter/build.py
python3 -B -m unittest discover -s experiments/benchmark_next/filter -p test_checker.py
```

实际运行由仓库现有 `experiments/benchmark_first_batch/runtime.py` prepare/execute 和 `batch.py --workers 1` 执行，协调者分配Spectre槽与私有配置。单个候选按条件串行，未知作业恢复原ID。`prepared_only`不算运行；编译、许可、传输或报告失败保留未知，不当成语义错误检出。原始运行放在忽略的 `runs/filter-next-*`，本目录只保留绑定身份的精简报告。

本轮是Spectre扩展集，尚无ngspice候选复验资格。没有模拟噪声、非线性限幅、相噪、镜像抑制或完整接收机性能。FFE/DFE训练、PAM4串并与完整CDR仍属后续方向，不计入本规格完成项。
