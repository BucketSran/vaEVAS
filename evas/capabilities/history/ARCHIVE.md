# 冻结审计与发现材料

本目录只保存原始审计、发现和有限检测器复查材料。113 份原审计/发现文件保持准备收据绑定的字节，另原样保留一份准备阶段生成的 source-manifest 作为路径与字节索引；归档不改变原裁决、执行成绩、来源可获得性或资格。归档代码是数据来源，不在登记加载时导入或执行。

主线方法审计分母为 3257。原裁决为 2785 项未发现具体问题、95 项缺证、359 项混合问题及 18 项测试问题。未发现问题不表示测试合格，已执行通过也不表示 EVAS 能力合格。

三组后续检测器复查涉及五个方法，保留原本地 3262 候选范围。两项 BoundStep 的模块字节匹配；两项 SourceMath 的原模块字节不同，DeferredRdist 未给完整 tested-module SHA，这三项当前模块对齐保持 pending，不覆盖原主线裁决。

发现材料分别保留 Python 主线、校准、维护入口和 Rust binary listing 的原始分母、导入限制与环境。旧材料中的绝对机器路径和旧源码身份属于原记录，不能当作当前路径或公开下载地址。

`archive-inventory.json` 列出本包原始文件及 SHA256，明确不列自身整文件 SHA。发布后的完整 Git 提交由外部索引固定，main 只保存紧凑索引和版本化 Git 对象定位。发布与重新取回验证由任务记录单独给出；此文本不自行证明发布已经完成。
