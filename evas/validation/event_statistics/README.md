# 隔离事件统计的独立控制

这四个模型检查测量器的事件算术，不给出 Q 精度等级，也不代替完整工程任务。
EVAS 与 Spectre 使用同一份 VA 和刺激。`tb.scs` 用于 Spectre，`tb-evas.scs` 只去掉其专用的
`method=gear2only`，其余设置保持；EVAS 使用自己的求解方法。固定输入及预期记录见 [INPUTS.json](INPUTS.json)。

| 模型 | 检查内容 | 预期记录 |
| --- | --- | --- |
| `fit-stop` | 停止时刻的第三次采样与最终拟合 | `fit 3 2 1 0` |
| `fit-interior` | 第三次采样后再停止 | `fit 3 2 1 0` |
| `ordered-math` | 乘积、平方根和限幅按语句顺序计算 | `math 3 2` |
| `guarded-empty` | 零样本时不执行未选分支的除零和负平方根 | `empty 0` |

拟合的三个样本为 `(-1,-1)`、`(0,1)`、`(1,3)`，都在 `y=2x+1` 上。
样本数为3，`Σx=0`、`Σy=3`、`Σx²=2`、`Σxy=4`、`Σy²=11`。
拟合分母为 `3×2−0²=6`，增益为 `12/6=2`，失调为1，残差 RMS 为0。
这些数可精确表示，因此这四项只要求打印记录与上述整数答案一致。
该要求不证明隐藏回调时刻、状态区间宽度或全时域误差。

已选的除零、负平方根、非法 IR、跨实例读取、物理状态依赖、失败回退和额外查询，
由 [事件统计回归](../../tests/test_event_statistics.py)及 Rust 回退测试分别检查。
新非仿射赋值与直接显示共享求值，避免同一表达式因消费者不同而返回不同值。
实现范围见[事件数学合同](../../docs/math/events.md#event-math)，实际结果与身份见
[事件统计证据](../../../experiments/backends/support/README.md#event-statistics)。
