# 论文比较的特性映射与首批条件

本目录定义新的电压域比较条件，供模型、观察适配器和检查器共同使用。
它交付 Spec A 的 A0。A1 仍需合法源审查、观察资格、检查器校准、四后端实际执行、
差异诊断及必要修复，当前没有新的后端成绩。

[特性候选清单](inventory-v1.json)是有限的工程候选目录，
[首批条件卡](core-v1.json)固定 12 条行为条件的源模板、刺激、初态和独立答案。
选择参考了已有开发契约和缺口，因此这批是 development-informed，不能称为未见确认集。
卡的结果状态目前全为 T。源码模板先于本批新结果固定，A1 冻结实际文件、deck、工具和设置身份。
A0 不是论文结果冻结，也不证明这些源已在任何后端执行。

## 特性分组与工程用途

论文主表按语言关系、算子和结构分组，工程场景是需求来源和次标签。
每条条件只计入一个主组，其他特性、场景和旧 V1–V7 只提供追溯。
组合条件另列，不重复加入参与算子的主组分母。

| 主组 | 工程问题 | 首批主条件 | 首批未覆盖的关键义务 |
| --- | --- | --- | --- |
| 电压关系 `voltage` | 差分访问及参考端贡献是否持续满足声明关系 | VR-01 | 多贡献累加、供电依赖、共模单因素不变性、唯一解反馈 |
| 表达式与控制流 `expression` | 连续输入变化是否驱动顺序赋值与分段表达式 | EX-01 | 逻辑/三元、参数默认和范围、函数/数组、循环和动态索引 |
| 初始化与事件 `event` | 首次事件前初态、方向、次数和状态更新是否正确 | EV-SH-01、EV-HC-01、EV-HC-02 | above/last_crossing、平台切触、动态 timer、分析限定初始化、同刻竞态 |
| 定时与历史算子 `history` | 状态变化后的延迟、上下沿和历史是否完整 | TM-01 | 中断边沿、延迟队列、absdelay、slew、动态参数与缺省边沿 |

| 组合行为 `combination` | 单项关系组成的数据链是否有一致状态和未来轨迹 | CO-SH-01、CO-HC-01、CO-VCO-01 | 同刻 reset/clock、快速重入边沿、VCO复位/门控、滤波采样与动态反馈 |

旧 31 条保持开发条件及其原执行身份，完全不进入新表分母。
V1–V7 对应[旧协议](../PROTOCOL.md#七组行为要求)，不再作为新表主行。

## 固定编码和独立答案

条件卡内 `source` 给出完整 VA 模板。所有电压贡献在连续 analog 求值路径；
动态算子调用在事件块和时变条件分支之外，事件体只更新离散标量状态。
`EX-01` 和 `CO-VCO-01` 的条件语句选择频率值，`idtmod` 本身持续求值。
`CO-SH-01` 的reset事件触发阈值为0.5 V，事件体谓词为reset>0.25 V。
本刺激所有reset回调处均有充分电平余量，所有时钟回调处reset为0或1，
避免把根时刻等号比较误当成确定reset优先；reset斜坡中的时钟另列未覆盖。
`EV-HC-02` 的初态明确来自 initial_step 时的输入比较，不能从 cross 自动推导启动高状态。
`SI-01` 使用两个真正模块实例及独立参数覆盖，不能改成同一实例的两个输出公式。

合法语言来源沿用 [范围协议](../PROTOCOL.md#来源与独立性) 固定的 LRM 2.4：
电压访问与贡献、模拟事件、初始化及模拟算子。
[定时与历史合同](../TIMED_OPERATOR_CONTRACTS.md#transition边沿历史起点与延迟队列)
给出未中断 `transition` 的线性完整边沿。
本轮读了LRM2.4 §5.10.3.1打印页122–123、§5.10.3.3打印页125，
核对cross单侧窗口与显式timer容差窗口，卡保留页码与标准链接。
[算子数学](../../docs/math/operators.md#transition)明确
`y=y0+(y1-y0)*clip((t-e-d)/D,0,1)`，其中 D 为完整沿长，10%至90%仅为0.8D。
这些数学/语言合同是判据依据；历史 checker 和某后端波形不是黄金答案。
源模板需要 A1 独立合法性核验，工具编译报错不能直接证明合法语言不支持。

单位固定为 T=1 µs、V、s、cycle。源中频率除以1 µs恢复 Hz。
频率和相位观察端口用电压数值编码，卡中明确其意义，不把 Hz 和 V混用。
所有刺激提供完整PWL节点或DC值，无重复时刻造成的瞬时源跳变。
每卡保留独立锚点，并要求检查全部合格导出样本和初态，而非只验若干终值。

采样值必须用同一个合法事件时刻对应的实际输入求值。
迟滞、采样和有限边沿必须允许一个共同事件序列解释状态、回调次数和所有输出。
仅有输出边沿不足以证明回调次数；因此事件卡固定不加载的状态/计数电压端口。
端口导出仍需观察资格，不把DUT自报 last_crossing 作为独立定位答案。

模相位使用圆周距离 `min_k |p_expected-p_actual+k|`，
普通绝对相位误差只在包裹窗口外计算。CP-02与CO-VCO-01同时固定连续未包裹解析相位、
正弦、包裹次数和左右极限。精确包裹时刻的端点输出另存，不丢弃异常，
也不拿相位从近1跳到近0造成的普通绝对误差冒充相位漂移。
未有合格包裹前后记录时，次数或窗口资格为 I，不能只凭正弦通过覆盖它。

## 误差预算与观察资格

卡内预算在新结果前固定：静态/保持电压1 mV、有限边沿/正弦3 mV、
相位0.001 cycle、计数观察1 mV。输入误差上界10 µV，导出电压不确定度50 µV，
导出时间不确定度10 ps。通常观察间隔最多0.2 ns；事件和包裹局部需要更密的括定，
每个预先解析事件/包裹根周围±2 ns窗口内，最大间隔20 ps，
并保留名义根时刻的单独端点记录。卡的 `observation_windows` 固定这些窗口，
实际接受点与插值导出分开记录；更密网格不能单独证明插值误差。

`cross` 使用显式1 ns和0.2 mV容差，孤立非零斜率根采用单侧窗口
`[root,root+min(time_tol,expr_tol/|slope|)]`，再传播独立的输入和导出不确定度。
例如EV-HC-01斜率0.4 V/T给出0.5 ns窗口，CO-SH-01斜率2.5 V/T给出80 ps窗口。
`timer` 使用显式1 ns容差及对称±1 ns窗口，不使用工具缺省值。
LRM2.4 §5.10.3.3打印页125对显式容差要求在窗口内，
“不早于事件”的文字只描述容差缺省情形；二者不能混用。
这是先定外部合同，后选工具设置；不要求各后端同名设置数值相同。

对每个性质保存原单位的误差和观察不确定度，误差上界在预算内才为P，
下界超预算为F，交叠或观察资格不足为I。事件容差允许同一历史内的时移，
不能作为随意扩大的额外电压容差，也不能逐点各选一个有利事件时刻。
这里报告固定观察集合上的最大误差，尚不宣称连续时间最大误差或隐藏窄脉冲检出。
校准必须包含锚点间短脉冲；不可分辨时如实记录观察限制或改善观察。

## 候选分类和后续边界

40个候选条目都有selected、deferred或outside分类、工程用途和理由。
JSON中的 `condition_ids` 是特性到条件的关联，可以一对多，不能据此重复计数。
候选所有权链接现有能力ID和已知Issue/PR，仅指当前关联边界，不预先认定故障或修复归属。
PR #93的执行身份工作由A1检查并复用；PR #79的精确事件差异仍未接受例外。
Spec B只有在实际修复依赖共同生命周期时成为阻塞，独立数学与卡不依赖它。

首批明确延期同刻reset/clock、reset初始高、快速重穿越、负频率和长时VCO，
并保留动态timer、absdelay/slew、滤波、导数、反馈和其他合法结构候选。
一般电流/KCL、晶体管网络、任意负载、AC/PSS/RF、噪声、一般多稳态、
完整数字AMS以及性能比较在接受范围外。当前不支持的合法电压域特性仍可为deferred，
不能仅因EVAS拒绝而归入outside。

运行 `python3 -B evas/validation/paper/check_design.py` 检查卡/清单对应、唯一计数、
有限数值/PWL、源码存在、全部后端状态以及独立锚点的代数一致性。
它不编译VA、不执行后端，也不代替检查器校准或观察资格。

## 独立检查器和本地校准

`criteria.assess(condition_id, rows, qualification, execution_state="completed")`
接受归一化记录。每行有 `time_s` 和条件卡的全部端口名，时间为秒、电压为V。
`assess_observation`接受实验工具的envelope并把行内 `time` 转为 `time_s`。
T、U、X属于执行状态，直接保留且不产生行为性质成绩。
completed记录才进入观察资格和独立性质评估。
卡内的全T字段永久保存A0设计身份，实际执行状态在独立结果记录中，不回写条件卡。

`qualification`明确单位、时间/电压不确定度、实际输入界、源合法性及原生计数/相位资格。
`qualification_evidence`按source、time、voltage、inputs及适用的native_counters/native_phase
提供method、artifact_path和sha256；全部条件还需native_initial角色证明原生已初始化首行。检查器核验文件可读取且哈希匹配，并保留原证据。
这只是证据绑定，数值资格还须由对应方法报告证明，文件存在不能单独证明其结论正确。
缺证据、单位错、非有限值、截断、稀疏窗口或未经资格的插值均为I。
实际执行表不能以调用者布尔值代替资格证据。

输入源的10 µV独立资格与保存电压的50 µV导出误差分开。
检查器要求独立输入界证据，保存输入列仅做与刺激、时间及导出误差的相容性检查。
后者不能证明前者；相容性通过不得写成输入数值误差已由粗保存波形独立测得。
保存输入不相容时保留具体最大差值和超预算量，将观察资格判为I并停止DUT行为判定，
不把deck或导出问题计作DUT行为F。

原生计数阶梯提供每个回调的左右括定，与固定合法窗口相交后得到一个共同潜在事件历史。
所有保持值及有限边沿用这一组区间的中点计算，并用保守Lipschitz界传播区间宽度。
这不是要求波形同时匹配整个语言容差窗口，合法timer±0.5 ns或正向cross时移
在原生观测收窄历史后可以通过。
精确名义timer/cross中心记录保留原值和不确定度，不按名义时间强制事件前/后。
显式timer可能合法提前或延后；cross根也需传播实际输入/时刻不确定度。
原生t0首行必须在initial_step稳定后、首次采样/阈值回调前，缺资格时初态为I。
只有所有依赖性质的误差上界均达标才为P，预算交叠为I，已证实超界为F。
计数不插值，也不为每个输出点重选事件时刻。
报告同时保留原始相邻保存时刻、传播时刻不确定度后的原生括定、合法窗口及相交历史。
event_history的P仅表示存在一条合法共同历史能解释有限合格记录；
原生括定可能还容纳不合法时刻，因此这个P不能宣称实际回调时间上界已独立证明。
运行时cross窗口从固定VA的time/expr参数、阈值、方向及实际PWL斜率重算，
并核对卡窗口与计数日程；不使用另一份手写窗常数。
逐性质的误差界先在同一行配对：lower=max(0,error-uncertainty)，upper=error+uncertainty；
再分别取全部观察行的最大lower和upper。任一行lower超预算为F，全部upper达标才为P。
单独的最大error和最大uncertainty只作描述，不能跨行配对用于判定。

包裹卡的必检性质包括圆周相位、窗口外普通相位、正弦、模数值范围、
由原生相位记录确定的包裹次数和左右括定窗口。
精确名义根记录保留原始相位、普通端点误差和圆周误差。
边界行必须来自明确请求的名义中心，不能用最近普通点补齐。
qualification.boundary_cohort含serialization_error_s和records；每条记录含nominal_time_s、
row_index、request_id。boundary_cohort角色提供method、artifact_path、sha256来源证明。
名义请求匹配只允许浮点表示舍入，导出行允许经证明的序列化误差；该误差不得大于时刻误差。
缺来源、中心缺行或精度超界时记录missing_boundary_observations，boundary_cohort为I，
保留其余可判性质；缺失端点没有raw_phase/raw_values，不冒充已请求端点。
这种来源资格证明请求与行身份，不证明端点事件次序。
有限时刻不确定度横跨模端点时，端点语义单列I诊断，不冒称已验证精确tie。
这种诊断不覆盖必检包裹性质；缺少左右资格时，整个相关必检性质仍为I。
CP-01只验未包裹积分，不套模数范围或圆周距离。

`oracle.py`按独立分段方程求值，不读取后端成绩，不调用旧checker判分。
`identity()`绑定criteria.py、oracle.py及core-v1.json的SHA256，并记录Python版本与math二进制哈希。
导入后文件改变时拒绝混用内存答案与新的文件身份。
`freeze_checker(path)`创建固定清单，已存在不同清单时拒绝覆盖。
模型、卡、预算或检查器改变后需要新身份及相应校准，不改写旧判定。

本地校准命令如下，不执行仿真器：

```sh
python3 -B -m unittest discover -s evas/validation/paper -p 'test_criteria.py' -v
```

控制包含12条解析正确轨迹、合法统一时移、源卡的区别性工程错误、
重复回调、共同历史不相容、预算交叠、缺列/单位/证据与观察稀疏、
两后端同错及固定依赖身份不可覆盖。
短脉冲控制明确构造两个相邻记录间的连续脉冲，保存记录完全不变。
检查器无法辨别它，因此结论限于规定观察集合，不声称连续时间全覆盖。
所有控制都是synthetic calibration，不能计入实际后端N或论文通过数。
