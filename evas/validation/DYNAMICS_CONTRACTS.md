# 连续动态的独立契约与语义回归

<a id="shared-lifecycle-contract"></a>

## 共同生命周期契约：第一批审查

本节第一批固定共同约束与待审查选择；0.12.1 的实施范围另列于下方，历史提案不自动成为支持声明。
当前实现身份、拒绝和兼容差异仍由[能力表](../docs/CAPABILITIES.md)登记。
目标是保留电压域行为模型，并统一不同算子、线性传播和非线性传播的语义。
不增加电流网络、真实器件或完整数字事件引擎。

### 数学对象与五种操作

模型关系记为 `R(t,V,z,z',u,q;H)=0`：V 为节点电压，z 为调用点连续状态，
q 为事件保持变量，H 为已接受历史和队列。延迟关系依赖 H，不能一律压成有限维 ODE。
数值方法按结构选择；方法不能各自定义初始化、事件观察和提交规则。

| 操作 | 输入及必须满足的义务 | 禁止的替代行为 |
| --- | --- | --- |
| 首次初始化 | 绑定 q 的初值；显式 idt IC、ddt 的 DC 输出、滤波 DC 关系和电压约束共同成立 | 把所有连续状态都设零，或要求带显式 IC 的积分输入也必须为零 |
| 已知历史续算 | 接收已接受的物理状态和完整误差；新输入/保持参数只改变未来关系 | 重跑 DC 并覆盖原滤波/积分状态 |
| 同刻复位与事件求解 | 从同一事件基准状态执行有序赋值；识别实际复位调用点；确定采样阶段后共同求解候选电压和状态 | 每次迭代从前一次试算的赋值结果继续，或复位整个连续网络 |
| 只读观察 | 根据接受历史求值、包围并报告；不同查询顺序/额外输出点保持共同物理轨迹 | 用输出网格建立积分历史，或查询时消费事件/修改队列 |
| 验收与提交 | 电压、状态、误差、历史、队列、事件记录及实际持有的日程游标整批更新 | 验收前写正式历史，或只回退数值而保留半提交事件 |

首次初始化的算子规则依据 [LRM 2.4 §4.5.3–4.5.4](https://www.accellera.org/images/downloads/standards/v-ams/VAMS-LRM-2-4.pdf#page=80)。
无显式 IC 的 idt 仍是能力缺口；这里没有将其默认为零。
候选/接受分离是 EVAS 的接口约束；[ngspice 固定源码](https://github.com/imr/ngspice/blob/aaba50ba3f49d8cf2312ffaa8fe0a222754c5a8e/src/spicelib/analysis/dctran.c)
中的状态层、Newton 失败及截断误差后的重试可作架构参考，不证明 EVAS 已覆盖其流程。
LRM §8.4.7 的模拟解/关联事件拒绝规则属于混合信号上下文，不能据此声称实现了完整 VAMS 调度器。

### 根、触发和代表时刻

分别记录三个对象：数学根 `tau`，模型实际触发时刻 `te`，数值存储/重启使用的代表时刻 `b`。
根区间 `W_root` 是 tau 的证据，不自动成为 te 的取值范围，也不是一次回调发生于多个时间。
对本轮单调仿射 guard，`tau <= te <= tau+min(ttol,etol/|g'|)`；依据
[LRM 2.4 §5.10.3.1](https://www.accellera.org/images/downloads/standards/v-ams/VAMS-LRM-2-4.pdf#page=137)。
timer 的显式容差按 §5.10.3.3 单独处理，不沿用 cross 的单侧窗口。

后续共同接口应先固定一次实际 te，让采样、条件、复位和未来关系共用这次事件历史。
若 b 与 te 不同，误差包围必须同时覆盖到 te 的旧流和 te 到 b 的新流；不能在 b 重采样，
也不能把 `g(tau)=0` 用作 `g(te)=0` 的证明。严格比较尤其不能以连续量误差很小为由选另一分支。

**第一批检查点的已知选择**：非点 cross 的部分条件使用数学根 tau，并利用触发 guard 的零集证明等号；
相关实现/测试暂保留，见[连续动态](../docs/math/continuous.md#事件修改的联合积分与复位)。
它是 EVAS 当前约定，不能从 LRM 推导出“所有事件回调都应在真根采样”。
0.12.1 显式选择 te=tau 并共用观测对象；可选晚触发策略和更广历史认证仍须另行实现及回归。

### 复位与采样：义务和待审查选择

`idt(q/T,1,rst)` 在 rst 非零时输出/状态为 1；释放后从保持的 IC 继续。
滤波 `T*y'+y=z` 的物理状态在积分复位时保持连续，不重做滤波 DC。
这两项给出独立数学义务。对于同一事件中的 `rst=1; q=V(z)`，还必须说明 V(z) 的观察阶段。

本批把两个候选解释分别保留：读取 `z(te-)`，或读取与复位共同求解的 `z(te+)`。
若选择当前 EVAS 同刻联立思想的后者，则 `rst+=1, z+=1, q+=z+` 唯一给出 q+=1；
把两个赋值语句交换也不改变这一闭包，因为 q 不参与 reset 谓词。
这项交换仅适用于本反例，不能推广到依赖赋值的任意交换。
LRM 的积分复位规则本身不足以代替对事件体节点读取阶段的说明；Spectre 观察须单独分类。

本轮 Spectre 的正序、交换赋值顺序和非线性 cross 三组各两档，均在本实验 1e-6 V
观察 allowance 内落入复位后初值采样类；EVAS 六配置均在历史重放一致性检查拒绝。
这支持下一批采用复位后共同闭包的设计方向，不构成任意事件体的规范证明。
实验也显示 Spectre 的严格条件为真而 EVAS 为假，二者采样时刻分别位于晚触发点和根附近。
完整配置、失败与精度限制见[实验收据](../../experiments/runs/parallel-gap-integration/results/shared-lifecycle-review.json)。

### 独立组合反例与误差

所有新反例使用 `T=2^-20 s`、x=t/T，使时间尺度和导数倍率精确互逆。
原始 VA、刺激、两档设置、分析程序和依赖在执行前冻结，原 31 条件分母不变。

| 反例 | 独立答案或区分义务 |
| --- | --- |
| 首次 idt+proper 滤波 | z=3+x，y=2+x+exp(-x)，z(0)=y(0)=3；不可把积分 IC 置零 |
| 零复位并采样积分 | 事件 e 前 z=1+x；q=1+e 后 z=1+e+(1+e)(x-e)；同刻不能读入后续新流 |
| 实际复位/采样/释放 | e=1/2 复位，r=3/4 释放；q=1 时 z(1)=5/4，q=3/2 时 z(1)=11/8；两答案保持分类 |
| 单独复位、释放采样 | 保持 IC；未复位滤波使用旧物理 y(e)，不用新的 DC 值替代 |
| 已知历史上的非线性重启 | e=1/4 后 y'=(y-2)^2/4，y(e)=1，故 y=2-4/(4+x-e)；冷 DC 方程不能代替这条初值轨迹 |
| cross 条件与采样 | 精确 binary64 端点 .2/.8 的根由 Fraction 求得；根处严格 `>` 与晚触发处 `>` 可以不同；stamp 与 data 必须承认一个共同 te |
| 错误答案控制 | 错历史仍可有零代数残差；两个各自位于合法窗口的采样，若不能共享一个 te，仍须检出 |

误差链分别包含代数解、历史传播、事件定位/复位和观察误差。在可微且代数 Jacobian 可逆的局部，
`delta V ≈ -R_V^-1*(R_z*delta z + r)` 解释历史误差的放大；这只是局部一阶说明，
实际接受需要相应可证明的界。误差不能只检查 r，也不能把任意量纲的状态都套上电压绝对容差。
暂时未知的状态绝对预算、条件相关性及全时域误差义务继续登记为缺口。

纯数学校准：[check_lifecycle_math.py](check_lifecycle_math.py)；有限观测的正反校准与双后端生成器：
[lifecycle_contract.py](../../experiments/runs/parallel-gap-integration/lifecycle_contract.py)、
[test_lifecycle_contract.py](../../experiments/runs/parallel-gap-integration/test_lifecycle_contract.py)。
它们不访问算子内部实现来生成答案。综合收据从[实验入口](https://github.com/BucketSran/vaEVAS/blob/f3440b214e10294de2135415fac4ac72d121d6d6/experiments/parallel-gap-integration/README.md#shared-lifecycle-review)进入。
本批有限观测采用明确的观察 allowance，尚没有物理误差上界；事件边界原始导出保留，
平滑轨迹误差统计排除边界附近点。模型状态、时间见证和复位采样另行检查。
这些实验不证明真实引擎的回退；已覆盖及仍缺的回退义务见本页后面的历史证据映射。

共同控制流程的下一批验收为：对同一接受快照进行失败/丢弃/重试，检查实际拥有的历史、误差、
队列和游标；修复实际复位与采样闭包；不同传播方法共享相同阶段定义。
不能通过放松 `same_reset_history` 或固定增加一次重放来替代这份共同契约。

下一批按三项验收迁移现有控制流程，而不是让每个算子新增一套事件执行器：

1. 以六个实际复位/采样配置作 RED；从同一接受快照重建事件体，闭包输出、实际 reset
   掩码和未来流共同稳定后才能验收。保持有序局部赋值，未复位的滤波状态连续。
2. 记录一次共同 te；条件、采样、复位和未来历史绑定于它。允许已选择的精确根触发，
   也允许合法晚触发；证明的是实际 te 的结果，不能仅为匹配 Spectre 改一个条件位。
3. 在实际控制流程中强制拒绝候选，再丢弃、重试；接受历史、误差、队列、记录和持有的
   游标均与未试算过的控制组一致。加密输出查询和交换独立贡献不改变共同轨迹。

冷初始化/已知历史续算先保持这里的控制组，再把线性、非线性、DAE 传播逐个接入。
只有这些组合验收通过后，才扩展非线性滤波 DC、事件修改 DAE 和更广根重定位。

### 第二批实施与验收（0.12.1）

观察闭包与未来传播分开，事件体每轮从同一接受状态重放，保持局部顺序赋值。
原六配置同一 IR 回放均从拒绝变为有限轨迹一致；更密输出、线性/非线性方法与独立赋值交换均验证。

该结构环现明确拒绝；无节点反馈的局部顺序更新、经过严格 proper 物理状态的控制组均通过。
保守结构拒绝还不等于一般直接项事件反馈的联合认证。

一次 `EventMoment` 绑定 te 的共同包围、代表时刻与触发证书；本轮保留 te=tau 的实现策略。
新增 trace 区间由 Fraction 根检查，并结合时钟采样、reset IC 及释放后轨迹验证。
这满足精确根策略下的共同观察义务；尚未交付晚触发模式、全算子历史认证或连续时间资格。

与从未试算过的控制组一致，释放后积分为 5/4。此为明确 fixture 的回退证据，不是完整引擎的形式证明。

## 首版边界与数学

首版直接 PWL 路径接受 `idt(u,z0)`：显式有限常量初值 `z0`，输入为直接驱动的连续 PWL 或其固定仿射组合；
IR v11 另接受 `idt(u,z0,reset)`，其中 reset 是同实例状态/常数仿射表达式，
每次事件后必须能证明为零或非零；非零保持 `z0`，归零后从 reset 保持解除/释放时刻重新积分。
输入拐点取各源的并集。输出可参与现有可解的仿射电压网络；多个调用点、实例分别积分。
禁止电压或状态反馈进入积分输入；输出侧的静态电压反馈沿用现有联立求解与误差放大验收。
这是本轮选择的子集，前端与原始 IR 入口均有准入检查。
三参数实现拒绝复位反馈环：积分输出经电压网络、事件赋值及其他算子中转返回 reset。
无解/多解示例必须拒绝；无反馈的积分采样仍支持。每次同刻试算从已接受历史重建，
最终认证复位模式、释放时刻/区间与输出误差；失败后重试与从未发生失败的结果一致。
缺省初值、状态/内部未知节点输入、动态参数、不连续输入、嵌套、反馈进入积分输入、
算子输出直接或间接驱动 `cross`，以及导数、滤波、高阶/其他动态算子均不在首版。
不支持的合法 VA 写法应标能力缺口；不能把本轮拒绝边界写成语言标准的限制。

令 `u` 的单位为 U/s，`z` 为 U。若 `u` 是电压，积分结果单位为 V·s，映射到电压贡献时
须显式说明换算系数。在单段 `[t0,t1]` 上，`u(t0+h)=u0+m h`，`0≤h≤t1−t0`，则

\[
z(t_0+h)=z_0+\int_0^h(u_0+ms)\,ds=z_0+u_0h+\tfrac12mh^2.
\]

下一段初值必须是本段完整积分后的端值。连续 PWL 积分后是连续、分段二次的函数，
导数在拐点连续；不能把输出当 PWL 插值。例如 `u=t,z(0)=0` 时，`z(1/2)=1/8`，
用 `z(0)=0,z(1)=1/2` 做线性插值会得到错误的 `1/4`。
首版不支持由该二次轨迹驱动 `cross`；已有线性根定位不能自动继承为二次轨迹的事件证明。

以下时间/幅度先用无量纲有理数表达，仿真时另固定尺度与单位。锚点同时覆盖区间内部和拐点。

| 输入与初值 | 观察时间 | 独立 z 答案 |
| --- | --- | --- |
| `u=−3/2,z0=5/4` | `0,1/2,2` | `5/4,1/2,−7/4` |
| `u=−1+2t,z0=1/4` | `0,1/2,1,2` | `1/4,0,1/4,9/4` |
| `u=2−3t/2,z0=−1/2` | `0,1,2,4` | `−1/2,3/4,1/2,−9/2` |
| PWL `(t,u)=(0,0),(1,2),(3,−2),(4,−2),(5,0)`，`z0=3/4` | `0,1/2,1,2,3,4,5` | `3/4,1,7/4,11/4,7/4,−1/4,−5/4` |
| 同实例调用 A：`u=t,z0=1/4`；B：`u=2−t,z0=−1/2` | `0≤t≤2` | `zA=1/4+t²/2`；`zB=−1/2+2t−t²/2`；同一贡献目标上的和为 `−1/4+2t` |
| 另一实例的 A：`u=−2t,z0=3/4` | `0≤t≤2` | `3/4−t²`，不得共享前一实例初值/历史 |

独立关系还包括：

- 时间尺度 T>0、幅度尺度 S：`u'(t')=(S/T)u(t'/T)`、`z0'=S z0`，则 `z'(Tt)=S z(t)`。
  校准取 T 为 `10⁻⁹,2⁻²⁰,1,2²⁰`，S 为 `1,−3/2`；不是相同裸输入在不同单位下给出相同输出。
- 任意合法分段点 a：`I(z0,u0,m,h)=I(I(z0,u0,m,a),u0+ma,m,h−a)`。
  插入共线输入拐点、增加输出查询时刻或丢弃候选再试算不得改变积分关系。
- 同一接受点发起同刻不同输入试算须有不同答案：`z0=1/4,h=1` 时，
  `u=−1+2t` 给 `1/4`，只改未来斜率为 `u=−1+8t` 给 `13/4`；二者起点输入均为 −1。
  时间相同不代表候选值可复用，已接受区间不随这次试算更改。
- `u=1−t` 在 `[0,2]` 的净积分为零；非零初值仍保留。若输入误差恒为 ε，
  积分误差为 `2ε`，不能因名义积分抵消或末端方程残差为零而删除历史误差。

`check_dynamics_math.py` 用 Fraction 的分段梯形面积与上述多项式及固定锚点交叉校准，
包含漏乘 1/2、矩形积分和输出直线插值的错误控制。大绝对起点 `2⁵⁴` 的有理数平移关系
仅验证数学；其部分时刻不能表示为 binary64，不能据此要求当前仿真器接受相同浮点请求。

## 身份、误差与生命周期

历史身份为实例展开后规范化 IR 中的调用点 ID。两个积分出现在同一贡献目标仍是两个历史；
同一模块被实例化两次，即使源码坐标相同也各有历史。重命名不改变绑定关系，调用点编号可变化，
所以不变性比较应按语义映射对齐，不能要求内部编号或诊断坐标逐字一致。

接受帧是全部历史、误差界、离散状态、电压和调度信息的共同起点。试算只改变候选；
计算及方程、历史精度、事件次序全部验收后才共同提交。取消或失败后重新从原接受帧求值，
不得重复累计积分、消费期限、提前写入事件/输出记录。相同时间而输入不同必须重新计算；
只有证明其依赖未变的矩阵/系数等才可复用。

未来仿真比较以实际传入的 binary64 时间、PWL 值、参数和初值的精确实数解释为参考，
用 `Fraction(float_value)` 固定它们；名义十进制答案与实际输入的舍入差另行计入。
校准表的有理数不是对所有缩放后 binary64 请求直接可用的黄金数组。
若固定段/时间下初值、输入截距、斜率分别有误差界 `Bz,Bu,Bm`，则
`Bnext≤Bz+h Bu+h² Bm/2`；浮点运算、输入插值与时间误差需另加可证上界并跨段保留。
网络 `v=A z+b` 还需传播 `|A| Bz` 及求解误差，不能只检验代入近似 z 后的方程残差。
误差预算应分别覆盖输出 U、状态 U 和时间 s；不得拿残差预算代替积分精度。

独立观测误差 E、不确定度 B、目标 ε 的判据沿用[验证协议](PROTOCOL.md#精度方案候选指标不冻结统一阈值)：
`E+B≤ε` 才通过，`E−B>ε` 才失败，其余未决。纯数学校准使用精确有理数，B=0；
未来执行必须说明 B 来源及有效设置。首版解析法没有一般步长收敛主张，有限观察也不构成连续时间资格。

| 同一引擎失败后完整性 | [transient.rs 私有测试](../rust_core/src/transient.rs) 的事件、transition 和 idt 初始帧检查；[idt 非零历史测试](../rust_core/src/transient_idt_tests.rs) 的四调用点/两实例精度失败、丢弃与较早候选重试、仅修正未来输入 | 检查接受帧及返回的批次记录；不构成完整调度器持久游标/已提交记录的失败恢复证明 |

公共 [runtime.py](../src/evas/runtime.py) 的 `_invoke` 每次运行新进程，内核 CLI 也只接收一次请求。
因此失败请求之后再成功请求只能证明请求隔离，不能证明同一引擎的候选回退。
`absdelay.rs` 的只读历史克隆/查询顺序测试，以及 `operator_queue_and_edges_commit_with_the_whole_frame`
中成功但丢弃的候选，也必须与真实数值失败区分；测试里的注释不能替代实际触发的错误路径。

idt 的生命周期验收断言如下，实现与覆盖分别说明：

1. 从非零初值及至少一段已接受历史出发，准备未来候选后丢弃，再试算同一时间，逐调用点核对解析值和误差界；
   继续到下一段，确认没有重复积分。两个调用点位于同一目标，两个实例复用同一源码坐标。
2. 至少一个候选历史已算出后，在另一调用点或后续网络验收处触发真实 `waveform_accuracy`/残差失败；
   比较原接受帧的时间、所有历史值/界、状态/界、电压、下个断点，以及已提交记录/游标（若该入口持有）。
   不能只检查报错或重新构造一个引擎。随后以原接受帧试算可接受的更早时刻，必须符合独立答案。
3. 保留同一模型/缓存和接受帧，替换候选输入轨迹后在相同时间重试，核对 `1/4` 与 `13/4` 的区分关系；
   输入更改限于未接受区间，不能重写已接受物理历史。重复失败不能消费事件或保留半提交历史。

`transient_idt_tests.rs` 通过真实 `prepare_event` / `prepare_batch` 接受到 t=1，再准备 t=2 候选并丢弃。
两个实例各自向同一支路贡献两个积分调用，初值均非零；共用源码坐标仍逐调用点核对。
固定预算下 t=2.1 的历史查询成功，随后电压网络认证产生 `waveform_accuracy`；两次失败后，
接受帧的时间、状态/界、电压/残差、历史值/界、断点及电路重解结果保持一致。
t=2 的较早候选重试与失败前候选一致，继续到 t=3 不重复积分。返回的事件批次记录也逐项核对。
另一检查保留已接受的 [0,1]，仅把之后输入从 `-1+2h` 改为 `-1+8h`，沿用同一模型缓存和
接受帧，在 t=2 得到 `1/4` 与 `13/4`；再次失败与重试也不得改写接受帧。
这些私有入口不持有 `run` 循环的调度游标和已提交 trace，未以测试自建的游标代替实际调度器。
完整循环在真实失败后的继续执行仍是证据缺口；本轮没有扩展公开 API 的失败恢复或在线改源能力。

```sh
python3 -B evas/validation/check_dynamics_math.py
cargo build --locked --offline --manifest-path evas/rust_core/Cargo.toml
PYTHONPATH=evas/src:evas/tests python3 -B -m unittest -v test_semantic_invariants test_affine test_transition test_settlement test_timed_composition
cargo test --locked --offline --manifest-path evas/rust_core/Cargo.toml transient::tests
```

第一条仅是纯数学校准。其余检查作用于实际 checkout 中的既有实现及本轮新增回归；
输出需绑定当前提交、内核和测试身份，不能自动继承为其他分支或 idt 实现的证据。

### 共同观察入口的追加回归

[审查修复](../docs/math/continuous.md#lifecycle-observation-review-fixes)增加两条跨算子义务：

- 所有在非点事件中使用的历史观察覆盖同一个 W；“历史不可修改”不能代替“时间函数恒定”的证明。
  恒等包装、断开恒零组件不改变误差验收。宽盒须拒绝超预算结果，缩窄根盒后解析答案可通过。
- 瞬时依赖按值/导数传播。`ddt(idt(q))` 恢复输入依赖；双重积分或相对阶至少为 2 的滤波
  保留状态。非唯一 `q+=q+` 事件环明确拒绝，普通 `q=q+1` 和保留状态的控制组须通过。

直接积分释放与已激活 transition 斜坡各有解析采样控制；缺少区间观察的 absdelay/slew/idtmod
在非点事件上明确拒绝，并配套精确 timer 的通过控制。测试位于
[test_lifecycle_closure.py](../tests/test_lifecycle_closure.py)，不改变原 31 条件分母或阈值。

### 已知事件截止点的独立义务

0.12.2 仅将固定 timer / 仿射源 cross 日程用于限定非线性历史认证；
数学与未支持组合见[截止点说明](../docs/math/continuous.md#known-event-horizons)。
答案来自分段初值问题，不以另一份 EVAS 输出作为 oracle。

| 义务 | 独立答案或完整性检查 |
| --- | --- |
| 未来事件使关系失效 | `y'=q*y²,y(0)=1`，q 在 .5 从 1 切成 -1：事件前 `1/(1-t)`，事件后 `1/t`；到 t=2 应为 .5 |
| 初始事件与无变化事件 | timer(0) 切成 q=-1 后为 `1/(1+t)`；.25 写同一 q 值只延长认证前缀，不能重新初始化 |
| 周期事件与独立事件 | q 每 .25 翻转时 `1/y=1-integral(q)`，以 Fraction 求面积；断开的计数器事件不改变 `y'=-y²` 的物理轨迹 |
| 非点根的误差保留 | `cross(3u-1),u=t`，tau=1/3；事件后 `y=1/(t+1/3)`，观测盒必须包含精确有理根 |
| 组合与观察不变性 | 独立 ramp 低通保持 `t-1+exp(-t)`；加密输出、改变 max_step 不改变共同采样值和事件记录 |
| 认证域与原子提交 | 未认证未来查询拒绝；追加历史不改前缀；真实 Controller 的严格预算失败不改变接受帧/游标/记录，丢弃后重试与干净运行一致 |

公共检查位于 [test_event_horizons.py](../tests/test_event_horizons.py)，两个 Rust 私有检查分别位于
[nonlinear_dynamics.rs](../rust_core/src/nonlinear_dynamics.rs) 和
[transient_lifecycle_tests.rs](../rust_core/src/transient_lifecycle_tests.rs)。
该开发回归不增加原 31 条件分母；未新增跨后端或性能结论。

### 候选 DAE 与滤波一致初值的组合义务

本分支允许无事件 index-one 多项式 DAE 搭配 proper 滤波。输入可来自内部节点或其他算子；
严格 proper 可使用多项式输入。原电压关系、积分 IC 与 `d0*h=n0*input` 须联合认证初始根。
滤波全部物理状态以根盒包围的输入求 `A*x(0)=-B*input(0)`；后续与代数电压一起延续。
直接通路的算子耦合须先证明可逆；奇异初始根不能因残差为零而通过。

[test_implicit_filters.py](../tests/test_implicit_filters.py) 的独立义务包括：

- `f'=u-f` 与 `y+y²=z+f` 给出 `y=t`，滤波 DC 与积分 IC 不互相覆盖。
- 内部反馈 `f'=u+.5y-f`，`u=.5+t`，`z'=1+2y-f'` 给出 `y=.5+t`，
  `f=.75+1.5*(t-1+exp(-t))`；增加内部 relay、交换独立贡献次序仍成立。
- 多项式输入 `f'=y²-f` 与 `z(0)=.5` 给出 `y=.5+t`、`f=t²-t+1.25-exp(-t)`。
- 积分驱动的嵌套 proper 滤波给出 `f=.5+t-t*exp(-t)`；保留直接通路、加密输出不改变历史。
- 两极点 ramp 保留全部状态；奇异 DC、非线性直接通路和不可能电压预算拒绝。

共同多项式 ODE 的非线性 DC 使用同一根证明。[test_mixed_dynamics.py](../tests/test_mixed_dynamics.py)
以 `y=.75+.25y²` 的局部根 y=1 启动，e=.25 移去平方项后得到
`y=.75+.25*exp(-(t-e))`。同时复位/释放另一积分器，滤波状态不得重做 DC。
Rust 检查保持参数的整个不确定盒、失败候选后的原历史和相同控制过程的重试。
这些是开发回归，不改变原 31 条件或升级正式资格。隐式 DAE 的事件/复位/ddt 仍未接入。
