# 功能组合确认集

本批次在候选功能实现后、首次执行前固定模型、刺激、数学答案、目标和检查器身份。
七个模型各运行稀疏、加密两种观察网格。它们没有用于本轮功能实现；若首次执行失败并用于修复，
该条件须改记为开发证据，保留原失败，不再声称未见确认。原 31 条件的分母保持不变。

| 模型 | 独立答案与检查内容 |
| --- | --- |
| language | 子块循环求和为 `6(.5+offset)u`；两块总和为 `12u`，父反馈 `y=.25y+12u`，所以 `y=16t`。检查宏、函数、循环、数组和层次共同展开。 |
| histories | 两块积分初值和为 `−.25`，增益和为 2；`u=1+t`，所以 `y=−.25+2t+t²`。检查层次历史隔离。 |
| calendar | `y′=qy², y(0)=3/4`，next 从 `5/8` 改为 `3/8`；该时刻 q 变号。之前 `y=1/(4/3−t)`，之后 `y=1/(7/12+t)`。检查新日程截止点与积分历史。 |
| projected | 内部反馈给出 `z=5u/6`。delay 输出为 `z(max(t−1/8,0))`。slew 在 `[0,3/4]` 以 2 上升，在 `5/6` 追上平台；`5/4` 后以 `−3/2` 下降，在 `125/36` 到 `−5/6`。 |
| roots | q 在 `3/16` 从 `9/16` 改为 `1/4`；`t²−q` 的新根为 `1/2`。同一 OR 事件在 `3/4` 再由 timer 触发。检查记录身份、根窗口及次数。 |
| implicit | `y+y²=z, z′=(1+2y)(1−t), y(0)=1/4`；因此 `y=1/4+t−t²/2`。检查原关系和隐式历史的共同解。 |
| reset_filter | reset 在 `3/8` 断言、`5/8` 释放；积分为 `1/8+t`、保持 `1/8`、再为 `1/8+t−5/8`。独立滤波为 `t−1+exp(−t)`，不应被复位改写。 |

`suite.json` 固定输入和电压目标 `10⁻⁸ V`；运行精度为 `vabstol=10⁻⁹ V, reltol=0`。
有理式使用 Fraction 独立求值，指数使用 80 位 Decimal 并预留 `10⁻⁶⁰ V` 的计算界。
检查器拒绝 NaN、缺失/多余观察点、错误事件身份/次数和无法包围名义根的时间窗口。
加密观察网格须满足同一答案，并与稀疏结果在共同点的目标内一致。

```sh
python3 -B evas/validation/confirmation/run_confirmation.py --calibrate
python3 -B evas/validation/confirmation/run_confirmation.py --kernel evas/rust_core/target/release/evas-kernel --out runs/confirmation-NEW
```

每次执行创建新目录，先写输入/检查器/源码/二进制身份，最多执行 14 次；失败保留在分母中。
结果是这些有限观察条件的确认，不证明一般连续时间精度、完整 LRM 支持或 Spectre 一致性。
大结果只保存在忽略的 `runs/`；精简收据可按仓库资产规则保存。
