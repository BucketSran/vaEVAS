# 一阶 laplace_nd 的独立契约

本页固定 EVAS 首版 `laplace_nd` 的受限子集。实现说明见
[算子手册](../docs/OPERATORS.md#laplace_nd)。这些开发回归不扩大原 31 条件分母；
原条件通过与否必须由对应矩阵执行记录给出。

## 支持边界

接受 `laplace_nd(u, '{b0}, '{d0,d1})`，系数按 Verilog-A 的升幂多项式顺序解释：
分子为常数 `b0`，分母为 `d0 + d1*s`。本版要求 `d0,d1` 为有限正数，`b0` 为有限常数；
输入 `u` 为直接驱动连续 PWL 节点及常数的仿射组合。输出可以参与现有可解的仿射电压网络。

拒绝高阶分子或分母、空数组、非标准 `{...}` 数组写法、动态系数、内部节点或状态输入、
反馈输入、嵌套算子、算子输出乘以电压、静态 `solve` 入口，以及算子输出直接或间接驱动 `cross`。
拒绝是当前能力边界，不是语言标准限制。前端保留完整系数列表，不能悄悄丢弃额外极点。

## 数学参考

令 `tau = d1/d0`，`gain = b0/d0`。受限模型满足一阶线性方程：

`tau*y'(t) + y(t) = gain*u(t)`。

初始化采用编译后 binary64 输入在仿真起点的 DC 平衡：

`y(0) = gain*u(0)`。

这个选择与一阶滤波器的初始工作点一致；不会因为原 V6 条件的输入从 0 开始而隐藏成零初值。
若某个未来模型需要显式初始状态，那是另一个能力边界。

在源语义段 `[t0,t1]` 上，设 `h=t-t0`，`D=t1-t0`，
`u(t0)=u0`，`u(t1)=u1`，`m=(u1-u0)/D`，段起点输出为 `y0`。解析解为：

`y(t0+h) = gain*(u0 + m*(h-tau)) + (y0 - gain*(u0 - m*tau))*exp(-h/tau)`。

代表值使用等价端点式：

`y = e*y0 + gain*((1-e-q)*u0 + q*u1)`，
其中 `e=exp(-h/tau)`，`q=(h - tau*(1-e))/D`。`1-e` 由 `expm1` 计算；
当 `h/tau` 很小时，`h - tau*(1-e)` 使用级数近似，避免小量相减直接消成 0。

验收区间使用同一个解析关系的权重形式。令 `x=h/tau`、`g=1-exp(-x)`、`b=x-g`，
则

`y = y0 + (gain*u0-y0)*g + gain*m*tau*b`。

输出采样时间、`max_step` 和候选重试不定义历史。历史由直接源 PWL 的语义拐点和上述解析递推决定；
查询是只读的，换一条输入轨迹必须重建历史。

## 误差边界

验收参考为编译后 IR 中的原始 binary64 系数 `b0,d0,d1` 与原始 binary64 PWL 点在实数算术下的解析解。
`gain=b0/d0`、`tau=d1/d0` 在证书路径中用区间除法外向包围；段长 `D=end-start`、
局部时间 `h=query-start` 也由 binary64 时间点先做区间相减，不能把已舍入的 f64 差值当成精确实数。
输入端点区间复用现有直接 PWL 仿射准入；输出区间随段递推并传入电压网络验收。
本分支不把 `libm exp` 当成证书。对 `x>=0`，先把区间 `x=h/tau` 连续二分到 `r<=1/16`，
分别用 `g(r)=r-r²/2!+r³/3!-...` 与 `b(r)=r²/2!-r³/3!+...` 的区间交错级数求值，
并加入下一项大小作为显式余项包围；再用
`g(2r)=g(r)*(2-g(r))`、`b(2r)=2*b(r)+g(r)^2` 恢复到原尺度。
当 `x>=1024` 时使用 `exp(-x)<2^-1022` 的粗包围，得到 `g≈1` 与 `b≈x-1` 的保守区间。
不能形成有限区间时拒绝。
