## 1. 本轮要交付什么

在任何新成绩进入论文前，先建立以下对应关系：需求 → 模型与刺激 → 独立答案 → 可观察性质 → 判据校准 → 固定后端结果。Spectre 是主要对标后端，也接受独立答案检查。

每条条件固定 `condition_id / contract_revision / dut_hash / stimulus_hash / initial_state / observation_revision / target_revision`；每次执行另固定工具及编译器身份、网表、请求/实际设置、命令、输出哈希；每次重判固定分析器版本与原执行 ID。分母只由获审查的条件列表确定，不能由成功生成波形的数量决定。

下面的阈值和观察预算是待审查设计，不是已达到的测量能力。新案例先完成 [Spectre 执行](../../experiments/dvs2-spectre-validation/README.md)，再完成 [四后端补测与设置审计](../../experiments/dvs2-four-backend-validation/README.md)；不能把数学检查或仿真完成写成正式资格 P。

## 3. 一组事件历史解释整条输出

令 θ 包含本条件全部合法事件时刻；由同一 θ 计算采样值、保持状态和规定的输出边沿，记为 F(t;θ)。θ 的范围来自输入根、方向、模型容差和独立输入误差，不能来自“把输出拟合得最好”。边沿长度及传播延迟固定为合同值，不能作为无限制拟合参数。

对于已导出的观察点 j，测量值为 y_j，目标误差为 ε_j，独立计算的参考/输入/导出误差上界合计为 B_j。对非空合法事件域 E 定义：

- **保守接受域** K_in = {θ∈E：所有 j 均有 |y_j−F(t_j;θ)|+B_j≤ε_j}。
- **可能相容域** K_out = {θ∈E：所有 j 均有 |y_j−F(t_j;θ)|≤ε_j+B_j}。
- 找到并核验 K_in 中的共同见证，说明观察轨迹与合同相容；证明 K_out 为空，说明这些观察与合同不相容；其余为 I。

每条 θ 还须满足离散状态/次序规则。前一步采样值不可到下一保持段重新选择；组合电路的采样源也不可为每个点选另一条参考轨迹。不得把局部优化器“找不到解”当成空集证明。实现候选为单调区间收缩及有界分支；达到预算仍无法判断时返回 I。分支边界、数值舍入与停止精度须纳入校准。

这是**有限观察下的行为相容性**，并非内部事件时刻被直接测出，也不证明样点之间不存在任意短脉冲。如果多个 θ 都能解释波形，不选其中最接近理想值者冒充实测事件时间。缺少独立事件证据时，只报告事件到输出的联合行为。

### 一个确实需要共同历史的校准例

使用无量纲人工轨迹 F(t;e)=clip(t−e,0,1)，e∈[0,0.1]。在 t=0.25 给出 y=0.25，在 t=0.75 给出 y=0.65。两点各自落在允许包络内，却分别要求 e=0 与 e=0.1；取 ε=0.01、B=0 后，可行区间不相交。旧式逐点包络会漏过该反例，新方法必须拒绝。

这不是一张仿真器案例卡，只检验判定逻辑。另使用 e=0.05 的整条合法轨迹作接受对照，确保没有把合法事件偏移也拒绝。

## 4. 边沿、延迟与观察预算

1. 保留全部输出，不仅检查少数数学锚点。稳定区默认候选 ε_V=1 mV，参考/刺激/导出总预算 B_V≤0.25 mV；V6 原低通仍为 ε_V=0.6 mV、B_V≤0.15 mV。B 必须逐项计算，不能直接取预算当作已知误差界。
2. 导出点间隔候选上限 T/1000=1 ns；这只约束导出密度，不证明内部步长或连续时间精度。处理跳变时保留左右侧信息，不跨跳变插值；时标重复不能一律删除或一律判为错误。
3. 对孤立边沿分别给出 10%、50%、90% 阈值穿越的时间区间，传播平台幅值误差。只有先验证规定的线性边沿形状，才用 (t90−t10)/0.8 推导完整 tr/tf；非单调、缺点或多次穿越单独报告。
4. V5 目标沿用 delay/tr/tf 各自标称值的 1%。以完整沿长 τ 为例，若两个阈值各只能定位在宽 h 的区间，推导完整沿长的区间宽至多为 2h/0.8=2.5h；1 ns 密度并不自动足以认证 100 ns 边沿的 1% 目标。需利用已证明的更窄定位信息，或新配置改善观察；否则 I。
5. 延迟相对真实事件定义。无独立事件记录时，把事件合法窗口与输出起沿区间联合传播；不能同时声称分别验证了事件定位和传播延迟。
6. 额外事件计数端口、强制断点或更密导出可能影响执行。新增端口是新 DUT 身份；输出观察有干预时保留前后对照，不能把旧波形自动升级为该条件结果。

离散计数平台以 0.1 V/次编码时，1 mV 电压目标足以区分相邻整数，但仍须按每段预期整数分别核对；最终计数相同不能排除中间的漏/多事件。直接内部日志只作为补充，不优先于独立刺激与可观察输出。

## 5. 判定器校准清单

| 控制 | 应有结论 | 检验目的 |
| --- | --- | --- |
| 名义答案；同一合法 θ 的整体偏移 | 接受 | 避免将规范允许的偏移误判 |
| 同一点 ε=1 mV、B=0.2 mV，误差 0.7/0.9/1.3 mV | P / I / F | 误差与观察不确定度分开 |
| 上述逐点合法而共同历史不可能的轨迹 | 拒绝 | 约束整条轨迹 |
| 采样值来自 e1，输出沿来自不相容的 e2 | 拒绝（校准量需大于目标与不确定度） | 检查采样与输出共享历史 |
| 漏一次、重复一次、方向错、复位后继续旧状态 | 拒绝 | 状态/次数错误不被幅值平均掩盖 |
| 2% 的沿长误差、错误斜率或非单调边沿 | 有足够观测预算时拒绝，否则 I | 完整沿与形状，而非仅 50% 点 |
| 缺信号、单位错误、NaN、截断、未知时间语义 | 观察不合格/I，注明原因 | 不伪装成正常数值误差 |
| 同一错误轨迹作为两个后端的输出 | 拒绝 | 跨后端一致不代替独立答案 |
| 两个采样点之间不可见的短脉冲 | 对连续时间无脉冲主张保持 I/不可认证 | 公开观察边界，不声称已检出 |
| 区间求解达到预算、边界相交或浮点舍入不确定 | I | 不把算法能力不足写成电路失败 |

每类控制使用独立构造轨迹和预定答案；校准器不调用被测 EVAS，也不以自身生成并重读的数据作为唯一检查。控制数独立报告，不计入仿真器 p/N。当前已实现互不重叠线性边沿、采样目标与保持状态的精确有理数共同历史检查，覆盖表中若干接受/矛盾/误差带/无效观察/预算控制，详见上述实现入口。它不是整套新判定器；中断边沿、完整事件计数、单独时间测量及真实误差界仍待实现或资格验证。
