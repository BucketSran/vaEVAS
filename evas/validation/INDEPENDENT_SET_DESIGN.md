# DAC 2027 独立仿真器验证集：DVS-2 设计草案

2026-09-27。**当前交付是测试集设计，不是仿真结果。** 面向 DAC 2027，研究范围与展示形式由本设计和 Table 3 共同说明。当前包含七组行为要求、八张起步契约及候选精度方案；没有正式测试分母、编译资格、方法校准或后端成绩。

入口：[验证集说明](README.md) · [起步契约](CASE_CARDS.md) · [论文 Table 3](COMPARISON_TABLE.md)。DVS-2 是当前设计修订号，不代表已发布的可运行数据集版本。

## 1. 研究问题与已确定的设计方向

- C1：在明确声明的电压域行为范围和有限条件下，仿真器能否正确执行静态、时序、状态与连续动态关系？
- C2：独立预期结果、刺激、观察和判定规则是否足以识别这些行为的错误，并支持同等外部精度下的成本比较？
- V7 纳入少量有唯一答案的电压隐式反馈关系，不把“电压域”自动等同于可顺序赋值。
- 目前尚无固定的 ADC/DAC 位数、最高频率或统一工程精度要求；本设计先提出按行为区分的指标，供后续审查。
- 按先设计与验证方法、再 Spectre、再其他固定后端、最后根据基线修复 EVAS 的顺序推进。当前仅有设计及局部公式检查，尚未形成可运行验证集。
- 400 个 VABench 家族属于应用/回归层。既有语义探针、家族和参数变体均不自动进入本版分母。

希望排除的替代解释：案例只覆盖 EVAS 已实现的功能；使用 EVAS 或同一个错误 checker 给自己定义答案；大量参数副本制造覆盖规模；用错误但很快的执行建立速度优势。

## 2. 范围、编码与可比性

### 纳入

电压接口的确定性行为级瞬态模型及必要的初始状态：静态传递、差分/共模/参考、规定的供电依赖、阈值事件、采样/保持/复位、有限边沿/延迟、连续动态、相位、级联、多实例以及有限的唯一解反馈。保留负电压、非零参考、非零初值及不同时间尺度等有用途的条件。

采用已声明连接的理想电压接口，无负载耦合或冲突理想驱动器。`electrical` 不自动变成 signal-flow discipline；电压贡献仍是必须满足的关系。共同模型中的输入/输出方向、参考节点和初值须经过合法性审查。没有电流贡献不等于没有隐式方程。

### 本版范围之外

通用器件/晶体管网络、有限输出阻抗与任意负载耦合、通用电流/电荷模型、功耗/工艺真实性、AC/PSS/RF 分析、噪声统计、完整数字 AMS 协同、一般多稳态/奇异/不适定系统及任意跨过程同刻竞态。这些是声明限制，不是“所有电压接口模型都不需要”。

### 公平编码

同一正式条件使用相同 DUT 源码和数学刺激。仅适配网表外壳、工具调用和结果格式；必要语法差异单列并记录。把隐式模型改成显式公式、把 cross 改成外部预定时刻、把算子换成另一实现，属于新的编码条件，不能覆盖原条件失败。OpenVAF 的实际分支/版本必须单独固定，不能把 OpenVAF-R 的结果泛称所有 OpenVAF。

## 5. 精度方案：候选指标，不冻结统一阈值

起步卡用 S=1 V、T=1 us 方便手算。S/T 是演示尺度，不是工业分布、位数或最高频率要求。电压、时间、相位和离散状态分别规定目标；旧 1/4096 不再作为当前默认判据。

| 对象 | 起步候选目标 | 设计用途与后续论证 |
| --- | --- | --- |
| V1 电压传递 | 输出误差 ≤0.001 S | 起步希望分辨 0.005 S 级失调/限幅变化；增益误差在非饱和点单独推导，不能用饱和点证明增益 |
| V2 差模/共模 | 差模误差 ≤0.002 S，共模误差 ≤0.001 S | 两个观测量分别判；还须按关系传播原始端电压观测误差；只有“相对一致”不足以通过绝对答案 |
| V3 阈值状态 | 状态/次序准确；稳定电平误差 ≤0.001 S | 事件容差采用显式 cross 参数及规范允许集合；初步参数 time_tol=T/1000、expr_tol=S/5000，非所有用例统一上限 |
| V4 采样保持 | 稳定输出的数值误差 ≤0.001 S；采样/复位时序独立判 | 按数据输入斜率传播合法采样偏移；本卡显式双容差与时钟斜率给出 T/25000，理想数据输入变化上界为 0.000006 S；实际输入误差另计 |
| V5 波形时序 | delay、完整 tr/tf 的测量误差候选为各自标称值的 1%；稳定电平误差 ≤0.001 S | 明确完整边沿与 10–90% 时间的区别；timer time_tol 初取 T/10000；时间不确定性需传播到沿内电压 |
| V6 连续响应 | 误差 ≤阶跃幅度 A 的 0.1%，起步 A=0.6 S | 依据本卡响应分辨率提出，不声称工业精度；用解析误差及设置细化检验。相位、导数、采样滤波另定指标 |
| V7 反馈关系 | 解的电压误差 ≤0.001 S，残差另外记录 | 以独立唯一解为主；残差与解误差关系用已知导数/系数解释，不把小残差自动当成正确输出 |

以上数值是预先提出的工程分辨目标，尚非经外部应用指标确认的“足够精确”。给出 0.5×/1×/2×目标敏感性设计；主目标在看到后端成绩前冻结，不能择优报告。未获得用途支持时论文只能说满足所声明的分辨目标，不外推某位数 ADC 或一般工业精度。

参考、刺激、导出与时间定位的不确定度应有逐项上界。暂以其合计不超过目标的 1/4 作为观察预算候选；这是设计分配，不是既有误差证明。区间完全在允许域内才通过，完全分离才失败，跨边界为未决。离散整数/事件次序不使用电压容差模糊放行。

具体地，对独立答案唯一且已固定的标量性质，令测得误差为 E≥0，参考、输入传播和观察的合计绝对不确定度界为 B，则真实误差在 `[max(0,E-B), E+B]` 中。给定候选阈值 ε，`E+B ≤ ε` 才通过，`E-B > ε` 才失败，其余为未决。例如 ε=0.001 S、B=0.0002 S 时，E=0.0007 S 可通过，E=0.0013 S 可失败，E=0.0009 S 为未决。B 的上界必须有证据，不能用两后端接近或重复运行的标准差替代。

上述标量式不允许对事件逐点挑选答案。含事件的条件仍须用一组共同的实际事件时刻解释整条状态/波形轨迹，并对该轨迹传播观察误差；逐点落入某个包络只是必要检查，不能独自取得通过资格。

## 6. 刺激、事件与观察合同

- 优先外部常量/PWL。每张卡明确参考节点、初值、单位、分段点和时域，不在 DUT 内用被测算子生成“标准刺激”。
- 事件包含合法定位窗口。按 [LRM 2.4 §5.10.3.1/§5.10.3.3](https://www.accellera.org/images/downloads/standards/v-ams/VAMS-LRM-2-4.pdf#page=137)，孤立线性 cross 在穿越后的单侧窗口同时满足时间/表达式容差，显式 timer 时间容差另按其规范；不能统一使用对称窗口或把默认容差冒充预定精度。各卡给出本刺激下的具体推导。
- 同一事件时刻必须一致解释采样值、输出边沿和后续状态；不能逐点任取最有利时间使每点分别通过。
- 样点误差不是连续时间最大误差的证明。每卡指定稳定区/边界区、最大可接受观测间隔及输入/输出误差传播，尚未确定的观察资格显式标缺口。
- 事件日志、内部变量及观察端口都需声明证据含义。不能仅由输出翻转证明回调次数；不能以被测 last_crossing 的自报值证明定位正确。
- 实际接受点与插值输出分开。事件附近主动强制断点可能改变求解；观察配置在四后端公平固定，并在资格阶段检查干预。无资格结果留未决。
- 设置名称和值相同不代表精度相同。逐后端记录参数请求、实际生效配置、模型步长请求和导出语义；不要求 EVAS 采用牛顿法。

## 7. 方法校准与计数

校准材料独立于行为分母：已知正确波形、每卡明确错误、阈值内外/交叠、缺列/非有限/单位错/时间倒退/截断、事件遗漏/重复/顺序错、合法定位引起的波形差、无法由同一事件历史解释的逐点包络。还要有两后端同错控制，防止一致性取代独立答案。

最小样本单位：冻结的模型编码＋参数＋刺激/初态＋观察合同＋预先列明性质。一个条件只分配 V1–V7 中一组；所有预定性质满足才计 P。同一波形的多个锚点、重复计时、状态端口及显式 oracle 对照不增加独立样本数。尺度/编码变体另注明相关性，不把 p/N 当工业总体概率。

状态沿用 P=通过、F=性质失败、U=确认不支持、X=执行失败（timeout 子类）、I=未决、T=未运行。N=P+F+U+X+I+T。设计阶段条件列表未冻结，N=null；不把八张卡的数目当 N，不预填任何后端支持格。

原始错误类别和失败阶段须另行记录：不能仅凭解析器报错断定语言特性不支持，也不能把导出缺列、单位不明或实际输入不符直接归因于 DUT 语义错误。没有足够证据判断对应性质时为 I；执行中止为 X 并注明阶段；一项已有合格证据的性质违反可判 F，但不能因此声称其他性质也完成了验证。

误差同时保留原单位和目标归一化值。明确有效案例数和排除原因；后端间误差对比需同案例子集。事件遗漏/次数错不是可用一个时间误差数字替代的失败。每条性质先在固定的观察集合上计算观测误差及其不确定度，再按预先定义的规则汇总；Table 3 只能将这种结果称为最大观测误差。若要声称连续时间最大误差，须另有样点之间的误差界；不能把插值值或正确参考曲线的平滑性当作被测输出的误差界。

判定器校准至少包含两种针对观察方式的反例：在既定锚点之间插入短脉冲，以及每个点分别合法但无法由同一事件历史解释的波形。前者若无法被当前观察过程分辨，应收窄可验证主张或改善观察过程；不能报告其已被检出。正常、错误与边界控制的通过/拒绝/未决计数单独报告，不与仿真器行为条件数混合。

计时分独立集和应用层，分别取四后端共同正确且达标子集并报告 n。当前 Table 3 主成本建议是新模型完整执行（编译/加载、启动含许可证等待、求解、导出）；判定器耗时另记，若未来纳入则全后端一致纳入并修改定义。缓存/重复启动作为分开的辅助条件。硬件、并发、配置、观察负担一致；共同子集为空则不计算四方速度比。P95 在重复数足够前不输出虚假精确统计。

## 8. 历史证据的复用

已有模型、探针和运行结果可以减少重复实验，但不直接继承其通过结论。只有原始模型、刺激、初值、实际生效设置、观察精度、工具版本和输出均可绑定，且满足新契约时，历史证据才可按新判据重判。缺失身份或采样信息时，只复用环境配置与分析经验，不把旧分数填入新表。

用于方法开发的案例须记录其用途与修订，不能随后声称为未见测试。历史 checker 的通过记录不替代独立答案、观察资格或当前判定器校准。
