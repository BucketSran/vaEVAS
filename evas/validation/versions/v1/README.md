# 电压域独立验证集 v1

**冻结的首轮试点快照，2026-09-27。** v1 是验证集版本；`DVS-2` 是历史设计修订标识，`0.8.7` 是被测 EVAS 版本，三者不同。对应 Git 标签为 `validation-v1`。冻结表示输入、结果及已知问题可追溯，不表示验证集完备或仿真器已通过认证。

## 快照包含什么

| 内容 | v1 身份与规模 |
| --- | --- |
| 共同模型 | V1–V7 七组、八张卡及八个 DUT |
| 固定条件 | 15 个；见 [conditions.json](conditions.json)，PWL 横坐标按 `time_scale_s` 转成秒 |
| 数值设置 | 基础/细化两档请求；实际生效范围见冻结结果报告 |
| 原试点 | 四后端共 120 条配置记录，114 次实际电路启动 |
| 后端 | Spectre 21.1；EVAS 0.8.7；OpenVAF-R v24.0.2mob＋ngspice 46；Gnucap＋modelgen 2026.07.29 |
| 后续诊断 | 20 个单独探针，含 16 次电路启动；不混入原始 120 条记录 |
| 原始证据 | 两份私有归档的公开收据及 SHA-256；原始日志、商业依赖和机器配置不在 Git |

[manifest.json](manifest.json) 将模型、参考/分析代码、报告、整理结果、工具身份和诊断固定到 Git 提交 `b28a476ac0f5ccc063c41a93a59acb7f956d7e1d` 的 36 个文件，并逐项记录 SHA-256。以后当前分支修改这些路径，不会改变这里引用的历史 Git 对象；不再复制一套相同代码。

实际运行前的 13 项输入由 [input-manifest.json](input-manifest.json) 固定。12 项模型/程序与上述提交相同；运行前协议早于结果撰写，原字节另存为 [run-protocol.original.md](run-protocol.original.md)，不能拿更新后的结果入口冒充运行前协议。

## 已知问题随版本保留

- V6 原始匿名数组使用旧 `{…}` 写法，不符合本验证声明采用的 LRM 2.4 写法；标准 `'{…}` 修订只属于诊断变体。原始 V6 拒绝不能直接计为后端滤波能力缺失。
- Gnucap 原网表使用数字接地端口产生警告；具名参考对照不能消除 V4 漏事件。标准 V6 还受到默认 `short` 选项截断系数的影响；调整选项的诊断结果不覆盖历史配置。
- 当前分析器给出有限观测筛查；联合事件历史、完整边沿门槛和观察不确定度尚未全部完成资格验证。正式资格均保持 `I`，不将历史筛查数当作论文正式 p/N。
- 原始 EVAS 及其他后端的失败完整保留；诊断成功不代表已修复仿真器。没有速度排名。
- 现有证据可复核，但依赖既有私有环境启动器；尚不是公开环境从零安装即可重跑的发行包。

## 查看与核验

从仓库根目录执行，只读 Git 对象，不调用模拟器：

```sh
python3 -B scripts/verify_validation_version.py
git show b28a476ac0f5ccc063c41a93a59acb7f956d7e1d:experiments/dvs2-starter-pilot/DIAGNOSIS.md
```

需要整个版本的独立文件副本时，可在新目录解包 `git archive validation-v1`；无需切换或覆盖当前工作区。浅克隆缺少历史对象时需先取得对应标签及历史。哈希校验只证明工件身份，不能代替仿真正确性或私有原始证据校验。

当前分支的便捷入口：[历史结果](../../../../experiments/dvs2-starter-pilot/RESULTS.md)、[故障归因](../../../../experiments/dvs2-starter-pilot/DIAGNOSIS.md)、[后续设计](../../INDEPENDENT_SET_DESIGN.md)。这些链接会随分支演进；精确历史以清单中的提交与哈希为准。

## 后续版本规则

v1 的模型、设置、判据或结果发生变化时，使用新的版本标识与清单，不覆盖本目录或重置 `validation-v1` 标签。v1 可以继续保留失败；未来新增条件须说明独立需求与能区分的错误。修正 V6、外壳和配置后得到的成绩必须绑定新输入；单独重判旧波形也须记录新判据身份和复用理由。
