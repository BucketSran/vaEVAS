# SCS 标量列表连接静态 VA 向量端口

这是受限输入适配契约，复用已有 VA 编译器和 Rust 电压内核。
它不定义新的总线语法或向量求解器。

每个实例先用 `parameters.py::bind_parameters` 绑定默认值和覆盖值，
再用 `node_elaboration.py::scalarize_nodes` 得到标量端口序列。
模块端口保持声明顺序；每个向量从声明的第一个索引走到最后一个索引，
包含递增、递减、负索引、非零起点和单元素范围。
`scs.py::load_scs` 将该序列逐项配对标量节点列表，连接数须完全相等。
实例参数、向量声明一致性和既有 4096 元素/节点预算继续生效。
保存与电压源仍只使用标量节点；总线名、范围、拼接、切片及动态索引不属于此切片。

例如 `input [1:0] u; output [0:1] y;` 的 `DUT (a b c d) bus`
映射为 `u[1]=a,u[0]=b,y[0]=c,y[1]=d`。
对 `y[0]=u[0]+1,y[1]=2*u[1]`，输入 `a=2,b=5` 得到 `c=6,d=4 V`。
将输入范围改为 `[0:1]`，输入 `a=3,b=5` 则得到 `c=4,d=10 V`。
这些常量答案独立于 EVAS 编译与映射实现。

[test_scs_vectors.py](../tests/test_scs_vectors.py) 从公共 SCS API 和 CLI 检查
独立答案、显式逐位 manifest 等价性、混合端口、参数宽度和实例交换，
并检查连接数、声明、参数、预算及不支持的总线文本拒绝。
PWL 三角输入在两种 maxstep 网格下检查每个保存值和共同时间值，
采用 `reltol=0,vabstol=1e-9`，外部绝对电压容差为 `1e-9 V`。
这属于步长与输出网格细化检查，不独立证明连续误差或只改变查询网格的性质。

2026-10-06 的本地开发准入证据使用既有 Spectre 21.1 热修补版，
固定降序、升序和默认 N=2/覆盖 N=3 三个标量列表网表。
三个配置均执行成功，所有保存点符合上述独立映射答案，
Spectre 设置为 `reltol=1e-6,vabstol=1e-9`，观察容差为 `1e-9 V`。
原始输入、PSF、日志及身份暂存于任务本地 `runs/s1/`，未纳入公共资格矩阵；
公开可复现性与审查/发布状态须由对应交付记录另行说明。
该切片只解决标量列表到静态向量端口的连接，不完成 #63 的其他源或总线语法要求。
