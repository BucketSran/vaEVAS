# 连续动态联合求解与动态 cross

此页描述 `feat/evas-continuous-dynamics` 的开发能力（EVAS 0.10.0 / IR16），尚未合并或发布。
能力 ID：DYNAMICS、CROSS、COMPOSE、LANG。旧 IR15 检查点和实验收据保留原身份。

## 行为与边界

| 功能 | 接受范围 | 明确拒绝或保守失败 |
| --- | --- | --- |
| `idt(u,ic)` | 常数显式 IC；仿射电压关系、内部 relay、线性算子嵌套和积分电压反馈 | 事件状态输入、非线性动态反馈、缺省 IC；联合网络内 reset |
| `laplace_nd` | 固定有限常量数组；分母 1–8 阶、常数项和最高阶系数非零，分子阶数不超过分母；仿射输入及电压反馈；完整分子和直接通路 | 动态系数、非 proper 传递函数、不可唯一确定的 DC 初值；数值范围/包围预算不足 |
| `ddt(u)` | 直接驱动/地/常数的仿射连续 PWL 输入；DC 初值为 0 | 内部节点、状态或算子输入；作为连续 cross 轨迹 |
| 动态 `cross` | 状态独立的多项式 guard，及已认证连续 `idt`、滤波、受限 `sin` 输出；方向与两项容差保留 | 事件修改的历史、状态反馈、切线/平台或无法证明唯一穿越、无法认证事件排序 |

旧直接 PWL 积分和一阶低通路径继续使用各自解析实现；需要联合关系或更高阶时进入共同连续网络。
`ddt` 在内部 PWL 断点取右导数，stop 取左导数；这项观察约定是 EVAS 的选择，
折点的经典导数本身不存在。连续源不包含重复时间/理想跳变，因此此范围没有冲激表示。
稳定性不是一般高阶滤波的准入条件；不稳定系统也只能在有限且可认证的时间范围内计算。
保留的直接输入一阶旧路径仍要求正时间常数；这一兼容边界不推广到高阶网络。
矩阵维度（动态状态、驱动和常数的增广维度）最多 32；超过预算明确失败。

规范依据为 [Verilog-AMS LRM 2.4](https://www.accellera.org/images/downloads/standards/v-ams/VAMS-LRM-2-4.pdf)
的 analog operators、`ddt`/`idt`/`laplace_nd` 及 §5.10.3.1 `cross`。
阶数、维度、函数/组合范围和 PWL 观察约定属于本实现，不是 LRM 的一般限制。
以下状态空间和区间证明是 EVAS 的算法选择，不声称复现 Spectre 的内部算法。

## 电压关系与积分反馈

同一支路上的贡献先累加，再形成电压约束。对连续网络写成

`A_v v + A_z z + A_u u + a = 0`。

积分调用点的状态满足 `z'=B_v v+B_z z+B_u u+b`、`z(0)=ic`。
代数子系统必须有唯一可认证解；消去 v 后得到 `z'=M z+N u+c`。
在消元接口中必须把残差形式 `A_v v+F=0` 转成 `A_v v=-F`，不能改变输入表达式自身的符号。

例如 `y=idt(1-y,0)` 给出 `y'=1-y`，解为 `y=1-exp(-t)`；
`y=.25+idt(1-y,0)` 给出 `y(0)=.25` 和 `y=.25+.75(1-exp(-t))`。
`y=idt(y,3)` 则为 `3 exp(t)`。这些答案同时检验 IC、贡献求和和代数消元符号。

每个状态仍归属于实例展开后的算子调用点；接收值的局部变量不决定历史身份。
动态网络的依赖闭包同时经过电压关系和算子输入，不能因中间节点或改写而漏掉前级历史。
结构状态/算子依赖检查先于数值消去，零系数和相消不能绕过组合边界。

## 高阶滤波的完整状态空间

系数按 s 的升幂排列。设

`H(s)=(b0+b1*s+...+bn*s^n)/(d0+d1*s+...+dn*s^n)`，`dn != 0`。

不足 n 阶的分子补零。伴随实现为 `x_i'=x_(i+1)`（i<n-1），
`x_(n-1)'=u/dn - sum_i(di/dn*x_i)`。输出是

`y=D*u+sum_i(C_i*x_i)`，`D=bn/dn`、`C_i=bi-D*di`。

因此分子每一项都会进入输出；等阶分子还有 D 的直接通路，不能降阶或只保留 b0。
初始滤波状态由 `x'=0` 的 DC 关系与电压网络联立确定；积分状态采用显式 IC。
例如 `y=laplace_nd(1-.5*y,{1},{1,2,1})` 的 DC 解为 2/3。
没有唯一 DC 解时失败，不以零状态替代。

高阶伴随状态的不同量纲容易造成矩阵元素差异。实现取分母末项/常数项所给特征时间
的最近 2 的幂，构造对角尺度 S；以 `x=S*q` 变换为 `A_q=S^-1*A*S`、
`B_q=S^-1*B`、`C_q=C*S`，D 不变。尺度只是坐标选择，所有系数转换仍向外包围；
它避免微秒二阶滤波的未缩放 `1/tau²` 项主导矩阵范数，但不是一般病态系统的解法。

## PWL 段的解析传播与误差

一段输入是 `u'=m`，因此增广量 `w=[z,u,1]` 满足常系数 `w'=G*w`，
解为 `w(t)=exp(G*(t-ta))*w(ta)`。输入断点更换斜率；上一段终点的完整区间进入下一段。
输出网格与 max_step 不定义积分历史，也不改变分段初值。

`state_space.rs` 使用向外舍入区间 Taylor、缩放和平方。把 `G*h` 缩放到无穷范数
不超过 1/16，累加至 40 阶；第一遗漏项以其后项比上界形成几何级数尾界，
再逐次区间平方。Taylor 除数、范数求和、尾项与时间差也必须向外包围，不能把
已舍入的倒数或 `t-ta` 当精确数值。最多 48 次缩放；溢出、非有限或倒序区间明确失败。

计算既返回代表值，也返回历史区间。原 IR 的电压映射继续传播该区间，
验收前向误差 `sup|v_hat-V| <= vabstol+reltol*|v_hat|`，并检查原贡献残差。
小残差不替代历史误差。区间相关性丢失、病态消元或长时间增长可能造成保守拒绝；
这版没有通用自适应积分器、自动高精度重算或任意非线性 DAE 控制。

连续网络不可变，观察/定位查询没有推进或提交副作用。候选只引用同一份轨迹；
事件状态仍通过原有 Frame 整批验收和提交，失败不会消费历史或事件。
因为本范围的连续轨迹不受事件状态修改，允许提前定位；需要事件后重新积分/重定位的模型仍拒绝。

## 非线性 guard 的根证明

非线性 guard 不能套用仿射根公式。对每个输入物理分段建立值包围 `g(I)` 和链式法则导数包围 `g'(I)`：

1. 若 `0` 不在 `g(I)` 内，证明此盒无根。
2. 导数严格同号、端点严格异号时，证明唯一穿越；二分缩小根盒。
3. 未能证明单调时细分；同号端点本身不能排除两个根。
4. 末端恰为零也先证明横截性，并继续搜索此前可能存在的根。

最终根盒 `[lo,hi]` 的代表时刻取 hi；验收盒宽不超过 ttol，且导数绝对上界乘定位宽度
不超过 expr_tol。实际 guard 求值仍独立验收。切线、恒零平台、预算耗尽、无法证明符号或次序
返回 `event_resolution`，不能静默变成“没有事件”。初始零点不触发。
每段最多 4096 搜索盒、深度 128、每个已括根最多 256 次二分。
同根/排序仍经过共同日程检查，不用容差把不同事件合并。

连续轨迹、根盒和接受的输出点认证不等于整个模拟器已有全时域物理误差资格。
尤其事件反馈、非线性电压轨迹驱动 guard、理想跳变和一般切线事件仍需要新的契约。
