# EVAS technical handbook

本手册说明电压域行为如何被编译、求解和验证，供使用者与贡献者复核。当前已合并基线、
开发分支及其证据分别记录在[能力与缺口总表](CAPABILITIES.md)，不通过 PR 编号推断支持范围。
构建、API 和 CLI 从 [EVAS 入口](../README.md) 开始。

## 阅读入口

| 需要了解什么 | 唯一维护入口 |
| --- | --- |
| 当前能力、分支实现、已知差异和后续工作 | [CAPABILITIES](CAPABILITIES.md) |
| 电压方程、稠密/稀疏线性代数、Newton、精度 | [NUMERICS](NUMERICS.md) |
| cross、timer、同刻事件与提交/回退 | [EVENTS](EVENTS.md) |
| transition、absdelay、slew、idt，以及候选滤波/相位的数学与实现 | [OPERATORS](OPERATORS.md) |
| 独立需求、模型及观察判据 | [验证集](../validation/README.md)、[观察资格协议](../validation/METHOD_QUALIFICATION.md) |
| 执行身份、复现实验及公开资产 | [实验入口](../../experiments/README.md) |
| 分支、责任归属、发布与清理 | [CONTRIBUTING](../../CONTRIBUTING.md)；agent 快速入口为 [AGENTS.md](../../AGENTS.md) |

数据路径为：源码 → 语法/绑定 → 有版本的 IR → 支路方程 → 电压求解。
瞬态入口在此基础上推进输入、事件和历史，验收后才接受候选状态；静态样本不推进物理历史。
模块/API 的唯一清单仍在 [EVAS README](../README.md#模块与接口)，这里不复制。

## Feature documentation contract

新增或修改语义/数值能力时，在对应章节更新以下内容；一个小改动可以只修改相关段落。
无需为每次任务新建设计、计划、KPI 或 review 日志文件。接口/工具类改动只说明适用部分。

1. **行为与组合边界**：能力 ID、合法输入、输出、单位、初值；逐项注明支持/拒绝的阶数、参数、
   输入依赖、嵌套、事件和反馈组合。入口不支持的合法语言写法是能力缺口，不是标准要求拒绝。
2. **依据**：规范版本/章节、论文或固定源码提交；区分规范要求、数学推导、EVAS 选择与后端观测。
   开放网页/主分支链接可作导航，算法或兼容性主张需要固定版本，未固定时注明。
3. **数学与误差参考**：方程/状态转移、历史依赖、假设与边界反例；固定精确参考所指的输入
   （例如 binary64 PWL 的实数解释）、初值、时间与单位。分别报告解/历史误差、残差和观察误差，
   计入累计误差及网络放大；小残差不能替代历史精度，有限样点不能证明连续时间误差界。
4. **数值方法与生命周期**：算法、误差/终止判据、不可判定和失败处理。历史属于实例展开后的
   调用点 ID，不能按赋值目标或仅按源码坐标分槽。每次试算从已接受历史出发；值、误差界、队列、
   状态、电压与事件记录全部验收后原子提交；取消/失败不消费历史。同刻输入改变必须重新试算，
   候选值缓存不能只以时间为键；矩阵等复用也须说明依赖。
5. **实现**：源码入口、数据责任及可检查的规范化 IR；不同等价语法落到共同语义，贡献进入统一
   方程，程序赋值保留顺序。说明必要复杂度/成本；只对实测范围报告性能。
6. **三类独立验证**：链接数学答案与正反校准、适用的语义不变性、同一引擎的失败后完整性证据。
   独立贡献可交换，依赖赋值不可交换；重命名须保持绑定，增加观察点须保持原模型关系。
   回退检查须在实际取消/失败后比较已接受历史并重试，重启进程成功不能替代它。
   固定输入/构建/检查器身份，区分纯数学校准、仿真执行、新执行、复用和重判；缺项明确留作缺口。
7. **限制与贡献入口**：已知差异、未完成证据、相关 Issue/PR。给出能复现问题的最小输入或定位方式。

受限积分的独立样例和待补生命周期断言见 [DYNAMICS_CONTRACTS](../validation/DYNAMICS_CONTRACTS.md)；
已有与新增不变性回归的覆盖映射也在该页。它们不改变能力总表的实现状态或原验证集分母。

## 状态与文档维护

能力总表维护实现、证据、审阅/发布三类状态；Issue 保存具体待办，PR 保存迭代与 review。
手册与相关代码在同一批可 review 的改动中更新。父分支或检查器变化后，只重新验证受影响的结论，
旧记录继续绑定其原始身份。发布文档随 tag 保存，开发中的能力明确链接分支的固定提交。

独立契约保存在 validation，手册解释实现如何满足它；实验结果保存在 experiments，手册引用结果。
已公开参与开发的样例不是未见确认集。正文没有复制原始大波形，公开可复核性取决于真实可取得的归档。

贡献者可以按能力 ID 提交 Issue：注明版本、最小模型/刺激、期望及依据、实际结果和复现命令。
数学反例、检查器问题、规范解释和性能回退都可以独立提出，不要求先修改仿真器。

文档组织参考 [ngspice 用户手册与内部实现说明](https://ngspice.sourceforge.io/docs.html)，
以及 [Xyce 用户/参考指南、回归说明和数学表述](https://xyce.sandia.gov/documentation-tutorials/)。
这属于文档组织参考，不是 EVAS 正确性或兼容性的证据。
