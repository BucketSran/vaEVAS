# EVAS 能力概览

**当前版本：0.14.0 / IR18。可运行受限的电压域模型，尚未全面对齐 Spectre。**

本页描述已合入的开发基线。表中“支持”限于所列范围；单项支持不代表任意组合可用。
晶体管、电流与电荷方程、真实负载和完整 SPICE 网表不在实现范围内。

## 能力矩阵

| 能力 | 结论 | 关键限制 |
| --- | --- | --- |
| 线性电压关系 | 支持 | 联立求解、贡献累加、参考节点；奇异系统拒绝 |
| 非线性电压关系 | 部分支持 | 主要限多项式；不保证找到全局唯一解 |
| 模块、参数与控制流 | 部分支持 | 支持静态层次、循环、数组与有限分支；运行时循环、动态索引不支持 |
| 初始化与状态 | 部分支持 | 常量及受限输入比较初值；不支持一般电路派生初值 |
| `cross` 阈值事件 | 部分支持 | 仿射及部分连续动态阈值；极近事件、切线和跳变反馈仍有限制 |
| `timer` 定时事件 | 部分支持 | 固定或保持状态控制的日程；连续电压参数不支持 |
| `transition` 有限边沿 | 部分支持 | 固定参数、正上升时间；动态参数和零上升时间不支持 |
| `absdelay` 延迟 | 部分支持 | 固定延迟、受限输入；仅支持受限两级串联 |
| `slew` 斜率限制 | 部分支持 | 固定速率、受限连续输入；不能任意嵌套 |
| 积分、滤波与 VCO | 部分支持 | 支持 `idt`、`idtmod`、受限 `laplace` 和 `ddt`；环回与复杂反馈仍有限制 |
| 事件与连续状态组合 | 部分支持 | 支持部分采样保持等组合；事件改变隐式动态方程仍不支持 |
| Spectre 风格 `.scs` 输入 | 部分支持 | VA 实例、电压源、瞬态及部分选项；不是完整 Spectre 网表 |
| strobe 强制求解点 | 部分支持 | API、JSON、`.scs` 已接入；缺 `strobeoutput`，部分事件组合仍拒绝 |
| 诊断与结果导出 | 已实现 | 编译预检、身份查询、JSON/CSV、只读查询；部分错误仍为 `unknown` |

具体语法见 [使用说明](../README.md#实现范围)；算子和组合限制见 [数学手册](math/README.md)；
输入、观测与输出选项见 [接口参考](README.md#接口参考)。

## 精度与 Spectre 对齐

| 问题 | 当前结论 |
| --- | --- |
| 能否控制数值误差？ | 能。支持容差和部分瞬态误差包围；超预算或无法认证时拒绝 |
| 所有输出都是精确解吗？ | 不是。静态收敛、瞬态误差包围和全时域证明是不同保证 |
| 已全面对齐 Spectre 吗？ | 没有。部分固定模型通过实际对照，事件边界仍有已知差异 |
| 论文四后端表已最终验收吗？ | 没有。参考观察资格与同一最终版本验收仍未完成 |
| 已证明比 Spectre 更快吗？ | 没有。已有局部性能实验，不能外推为整体优势 |

当前主要差异是事件边界的前后态、停止时刻计数和 VCO 环回。
验收范围见 [#96](https://github.com/BucketSran/vaEVAS/issues/96)，精度控制改进见
[#119](https://github.com/BucketSran/vaEVAS/issues/119)。
