# 架构决策

本页保留影响产品边界和兼容性的决定。数学推导仍在 [math/](../math/README.md)，
具体支持范围仍在 [四后端支持范围](../COMPARISON.md)。

## ADR-001：保持电压域定位

状态：采用。依据是项目既定目标与 [#46](https://github.com/BucketSran/vaEVAS/issues/46) 的架构核查。

当前 EVAS 求解行为级电压关系，以及这些关系中的连续状态和离散事件。
这条路线不引入 `I()` 贡献、KCL、器件电荷或完整电路网表求解。
`idt`、滤波和 `ddt` 表达时间关系；它们的存在不要求引入电流未知量。

每个电压支路贡献进入统一关系，程序赋值保留顺序语义。这个区别、算子调用点身份、
候选状态与一次提交、历史误差向输出传播，是继续扩展时必须保持的约束。
集中精力完成已声明的电压域组合，比增加一套未经验证的电流语义更符合当前目标。

### 为什么不把受限电流当作小补丁

仅增加线性电流源也需要定义节点电流平衡。一般 MNA 系统的未知量包含节点电压和部分支路电流，
方程会同时包含 KCL 与电压约束。组装、拓扑检查、初值、动态状态和误差预算都需要新契约；
电压残差的伏特容差不能直接用于以安培计的 KCL 残差。
矩阵也不能统一假定为对称：受控源及非互易关系可以破坏对称性。
因此当前不做受限电流过渡层，不把电流悄悄编码为电压节点。

### 兼容性与将来的重新决策

这不是对项目永久用途的限制。若以后出现具体电流域任务，应先通过独立设计明确需求、
MNA 未知量与方程、混合量纲容差、状态生命周期和独立参考，再决定是否形成新内核或扩展。
已有电压模型继续保持其语义，不能在解码时自动换成另一套方程。

当前不改变 IR16。若未来的语义需要不兼容 IR，须分配新版本，拒绝旧可执行 IR，
用原始 VA/manifest 重编译并保留迁移溯源。不能预先声称下一版本一定是 IR17，
也不能仅改版本字段就称完成迁移。

## ADR-002：电压域扩展共用状态、事件与误差事务

状态：设计已独立审查，并由 [PR109](https://github.com/BucketSran/vaEVAS/pull/109) 合入。
[#62](https://github.com/BucketSran/vaEVAS/issues/62)记录设计验收；未完成实施已按下表移交，
由对应 Issue 持续验收。设计关闭不表示 C1–C5 已实现。
设计时核对基线为 reviewed main `fbf896bbbb6f66a85f2d8be159eb2657ea17f972`，
[PR108 候选](https://github.com/BucketSran/vaEVAS/tree/739d961c9894715d5be3c19dec9441eaecec6369)
只作接口核对，尚未合并。两者的源码元数据均为 EVAS 0.14.0 / IR18，依据 `evas/pyproject.toml`、
`evas/rust_core/Cargo.toml` 和 Python/Rust 的 `SCHEMA_VERSION`；旧 README 版本描述未作为身份依据。

### 决定与依据

继续扩展现有 Python 编译、共同 IR 和 Rust 电压域执行路径。
前端把等价静态表达展开到共同 IR；运行时条件、索引和状态依赖须保留或明确拒绝。
当前 `Operators` 已同时管理解析算子和连续历史，`Frame` 保存电压解、离散状态及状态区间，并通过 `Operators` 持有连续历史，
`Controller` 管理事件游标和记录。`implicit_dynamics` 另有受限 DAE 数值方法，
但仍验收原电压关系。不同数值方法不是不同语言语义。

本轮不建立 Rust `behavior/` 第二执行器。没有具体模型和当前方法无法表达的证据，
第二执行器会要求重新定义初始化、事件读取和回退，也不能解决误差依赖问题。
今后若实际模型证明需要新数值方法，应先给出反例，再比较对当前方法的扩展与新增方法；
它们均须实现下列共同契约。诊断、受限前端和输入入口可独立推进，不等待新引擎。

不引入逐信号 `certified` 布尔标志，也不在默认执行中自动切换到未认证模式。
若历史量 b 没有误差界，`y=2*b` 的零残差不足以认证 y。
反馈中必须证明联合解与全体依赖的包围，不能按算子名称授予认证。
未来若有实际需求提出未认证模式，须另立决定，先定义显式启用、依赖传播、
反馈/事件/历史范围、输出标记、失败含义和独立验收；#44 的关闭不是该模式的实现。

## ADR-003：ngspice 负责托管模型的电路求解，Rust 保持电压域

状态：2026-10-18 用户在[兼容设计讨论](codex://threads/01a14f48-7c27-7133-9e17-b85f9e871e94)中接受的设计边界，新增能力尚未实施。

时钟控制和采样开关都属于后续模块替换目标。电路节点电压、电流平衡和外围器件由ngspice联立求解，EVAS独立Rust内核继续保持ADR-001规定的电压域定位。这样可以使用宿主已有的器件和网表能力，不把增加电流贡献的编译支持扩大为开发另一套电路求解器。

用户在Q5接受共享语义表示的分层。解析和实例绑定共用，在电压专用转换之前保留贡献种类、两端节点、表达式、事件及来源；随后分别做后端准入，转换到Rust电压域表示或ngspice模型计划。这样避免电流模型提前受到电压专用规则限制，代价是增加表示与转换映射的维护。共享层只承载所选模型需要的语义，不要求完整Verilog-A IR。本决定没有选择持久化格式或分配版本号。

不要求每个VA模块都含电流贡献。纯电压模型可以作为联合仿真的目标模块，与具有电流关系的模块组合；各后端仍须分别声明和验收实际支持范围。未来若编译入口接受受控电导，不能据此让Rust路径默认接受电流关系，也不向ngspice路径转移Rust的区间证明结论。

首阶段采样开关采用受控电导模型，覆盖有限导通、关断泄漏和双向导电，与外部电容共同演化。用户在Q6接受连续控制的G(Vctrl)与事件保持状态控制的G(q)均纳入，支路关系为I(p,n)=G*V(p,n)。电荷注入和时钟馈通暂不纳入。具体控制表达式、端口、时序及事件组合合同尚待讨论；该范围不自动包含任意电流函数、支路电流读取或电荷关系。

各后端使用同一份原始VA模型，沿用[同源VA](../../../GLOSSARY.md#同源-va)约定。验收继续区分模型语义、独立物理判据、宿主状态回退和有限Spectre配对；本设计决定不增加已有验证结果或支持计数。后续待决项见[讨论底稿](ngspice-compatibility-discussion.md)。

### Q7至Q9确定的首批模型和事件范围

时钟采用三输出功能模型，保留外围bootstrap驱动。正常上升沿关闭phi2，经过死区打开clkse/clks；下降沿先关clkse，再延迟关clks，之后经过死区打开phi2。首批纳入可改期和取消的一次性timer，以及初始高/低电平处理。时钟仍为理想电压驱动，不模拟自身供电电流和输出电阻，代价是该模型不能独立证明原时钟电路的功耗或负载相关延迟。

连续开关采用tanh电导，事件开关采用单阈值保持状态和瞬时G切换，首个电路夹具的控制参考ref接vss。各后端使用同一份选定VA。参考地平移、导电方向和外部电容连续性分别验收，不把控制参考端解释为体效应模型。

事件首批覆盖多个cross及上下沿、同块OR合并同一次发生、无状态读写及即时电气因果依赖的不同块同刻执行。共同写入和跨块读写依赖明确拒绝；跨实例先验收具有正延迟、可分离的新事件，一般即时电气反馈闭包暂不纳入。这个边界减少了需要同时解决的因果组合，但也限制了能够接受的VA及连接电路。碰撞优先级必须能由同源VA表达，不能由生成的C另加一套行为。后续若为同模块源码顺序处理而扩大读写范围，须作为具名扩展另行决定，不能将Q9解释成已经允许。

### Q10至Q12确定的行为与首轮预算

新边沿撤销尚未执行的旧开通，已启动的clks关断必须完成且不能被后续边沿推迟。真正同刻时先落实到期关断，再更新输入请求并取消旧开通，最后检查开通资格。已经执行的变化不能事后撤销，近而不同刻的事件保留真实先后。代价是短脉冲可能缩短或丢失采样窗口。普通取消和数值拒步回退是不同操作。

初始化依已收敛输入建立高相或低相稳态，无待办timer，不制造启动边沿。初态恰在阈值上或无法确定侧别时，首批暂不准入。用户同意先用200ps的采样关断延迟和死区、50ps输出边沿，以及[第五轮预算](ngspice-compatibility-discussion.md#第五轮窄脉冲碰撞参数与误差预算)。参数没有由原时钟电路校准，预算也未通过新仿真验证。各后端分别过独立答案后再配对；功耗不作等价结论。

精确碰撞的标准VA编码和原生后端准入尚未解决。上述行为决定不等于已有前端/IR或运行时能够执行，也不授权实施。

### Q14至Q16确定的参数化时钟阶段

2026-10-19用户接受第2步范围及验收。以tangxy恢复原件的标准整理版为候选，保留原参数、时序算式和六路输出，首阶段限定固定周期timer。初始化先应用常量初态和零起点timer，再用最终状态建立transition种子；正延迟才产生启动边沿。

有限边沿时钟中完全独立的近邻事件可共用宿主执行点，但保留各自名义身份和周期序号，并分别满足合法时间窗口与输出预算。它不是精确同刻证据，不适用于共享状态、可观察中间离散状态、取消优先级或跨实例即时闭包。代价是本阶段的准入和证据依赖消费者边界，不能作为一般电路的无条件许可。细节见[第2步合同](ngspice-compatibility-discussion.md#step-2-parameterized-timer-clock)。Q13有序共享状态仍待决定，尚未实施。
