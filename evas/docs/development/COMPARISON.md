### 数值判分与预算

对每项电压性质，条件卡先固定下面的预算形式及数值：

```text
B_V(t) = A_V + R_V * S(t)
```

`A_V` 是绝对电压预算，保证近零处仍有明确门槛；`R_V` 是无量纲相对预算。
`S(t)` 是预先定义的独立参考幅值或模型尺度，不得由待测后端的输出决定。
其他物理量使用自己的单位和预算，不能给所有内部 real 状态套用电压容差。
这些是外部验收量，不等于任何后端同名的 `abstol` 或 `reltol` 设置。

设原生输出与独立参考的可比值之差为 `d`，尚未包含的参考、导出及时间换算不确定度合计为 `U`：

```text
E_upper = abs(d) + U
E_lower = max(0, abs(d) - U)
```

- `E_upper <= B_V`：该数值检查通过。
- `E_lower > B_V`：已有证据证明超差。
- 其余情况：证据不足，需要更精确的参考或观察，不能当作通过或已证实超差。

上述标量式适用于已确认同一阶段、同一性质的连续值比较。事件窗口内先核验阶段和时刻，
不能跨跳变插值后套用此式。无法给出有限 `U` 时，该误差结论保持未决。
输入发生了什么也须从原始记录核对；输入异常单列，不用扩大输出预算吸收。

预算制定依次完成以下工作：

1. 写出应实现的数学关系和事件语义，确定输入域、幅度、时间尺度及边界。
2. 建立独立答案。简单条件优先使用精确可表示值或解析式；复杂条件使用有误差说明的独立高精度参考。
3. 分清输入、定位、读取、传播和观察误差。需要传播时说明增益、斜率或其他敏感性依据。
4. 冻结外部 `A_V`、`R_V`、`S(t)` 和各事件预算，并说明为何足以检验这项数值能力。
   不能将待测实现当前的误差作为它自己的允许误差。
5. 校准检查器，再执行正式评价。探索结果可用于设计新条件，不能事后放宽原条件使其通过。

分项预算按各自依据设定，不采用统一比例分配，也不假设误差会抵消。
总偏差已包含的误差不能再次累加。报告实际误差及其不确定度，不能只报告是否越过门槛。
误差低于可辨识范围时报告可确认的上界，不报告为数学零或已测得的精度极限。

### 旧采样保持用例的误差分解

以 [EV-SH-01](../../validation/paper/core-v1.json) 的模型说明分解方法，不修改其历史判据。
它与[评测标准中的 SH-T-RAMP 示例](../COMPARISON-METHODOLOGY.md#sample-hold)是不同条件，
采样周期、初值和事件容差不能混用。
初始保持值为 −0.25 V；名义采样时刻为 2、4、6、8 µs。
输入从 −0.4 V 在 6 µs 内升至 0.8 V，再在 3 µs 内降至 −0.1 V。
名义采样值依次为 0、0.4、0.8、0.2 V，最大绝对斜率为 0.3 V/µs。

令 `t_k` 为名义时刻，`e_k` 为实际回调时刻，`u_0` 为独立定义的输入，`u_b` 为后端实际输入。
`q_k` 是事件后共同规定的保持参考点输出，位于最晚允许回调之后、下一事件之前。
在同一次保持阶段的观察点，输出 `y_b(t)` 满足下列误差分解：

```text
y_b(t) - u_0(t_k)
  = [y_b(t) - q_k]           保持过程的变化
  + [q_k - u_b(e_k)]         读取到规定输出点的误差
  + [u_b(e_k) - u_0(e_k)]    输入偏差
  + [u_0(e_k) - u_0(t_k)]    采样时移的影响
```

各后端均使用外部输出检查，不要求导出内部 real 状态。保持参考点的实际时间与阶段必须已确认，
同阶段的其他规定点均须检查，包括该参考点之前已确认更新的点。参考点与观察不确定度纳入误差分析。

原源码的显式 timer 容差为 1 ns。在这个连续 PWL 输入上，合法时移引入的电压变化最多为
`0.3 V/µs × 1 ns = 0.3 mV`。这项来源不能豁免读取旧值或保持漂移。
显式 timer 容差约束回调时刻；cross 还须满足其适用的方向与表达式约束。
[LRM 2.4 §5.10.3](https://www.accellera.org/images/downloads/standards/v-ams/VAMS-LRM-2-4.pdf#page=137)

若源码允许的时间偏移为 `T`，则本例可用下式建立名义误差上界：

```text
E_nominal <= S_max * T + E_sample + E_hold + E_input_obs
```

这里的后三项分别是读取误差、保持变化及输入与观测不确定度的上限，须另有数值依据。
在输入跳变处不能使用有限斜率公式，必须定义采样侧；在 6 µs 连续折点仍须检查两侧。

每个条件至少检查初态、完整回调次数、时间与顺序、实际采样值、保持平台以及采样边界。
计数已更新而输出仍旧、超过允许时刻未更新、采样后继续跟踪输入均判错。
无法观测精确回调时，使用原生记录括定的整个时间区间判断；不能仅由输出反推一个有利时刻，
也不能为每个观察点各选一个回调时间。区间不足以证明满足要求时补充观察。

这一例没有积分或滤波状态，不能证明积分精度。完整采样保持行还须覆盖 cross 时钟、
常量与变化输入、近零值、不同斜率及长期计数，按[必测清单](../../validation/paper/README.md#next-engineering-suite)形成新条件。

### 采样保持 checker 核对记录（2026-10-11）

核对对象是提交 `826fefb12b5b068544be9de97e68f21e3c60e76f` 的
[precision_checker.py](../../validation/paper/precision_checker.py)及
[precision-v1.json](../../validation/paper/precision-v1.json)。依据是
[采样保持推导](../COMPARISON-METHODOLOGY.md#sample-hold)。旧 `core-v1` 和其他组合的检查器
不在这次核对范围内。本次只补文档和运行人工轨迹诊断，没有修改检查器、条件卡或历史成绩，也没有运行仿真器。

现有 12 项校准测试全部通过；另外构造了 9 条轨迹，复现以下两处与本轮规则不一致的地方。
**这些反例说明检查器会漏查，不能据此认定某个后端的历史输出已经出错。**

| 待补检查 | 复现结果 | 原因与后续处理要求 |
| --- | --- | --- |
| 整个回调区间是否在合法窗口内 | `timer` 真正提前或延后 100.5 ps，超过 100 ps 限制，却返回 `pass`；`cross` 提前 0.5 ps 也通过 | `assess()` 用观测区间与合法窗口的交集计算参考值，只在交集为空时拒绝。部分相交只能证明“可能合法”；没有更精确的时刻证据时，应为证据不足，不能直接通过 |
| 首次采样前的保持漂移 | 把两个初始阶段观察值改为 `Q0 − 0.7B`、`Q0 + 0.7B`，峰峰变化为 1.414 µV，仍返回 `pass` | 初态只检查各点距 Q0 的误差；峰峰变化只检查第 1～8 次事件后的阶段。按本轮规则，初始保持阶段也需要检查；这不是对旧成绩的追溯改判 |

第一项的观测间隔约 1 ps，满足原 2.1 ps 宽度限制。检查器删去可能非法的时刻后，
剩余参考范围与错误读值只差约 0.1 µV，因而被数值预算放过。需要分别判断时间资格和电压误差，
不能让电压预算替时间越界兜底。区间完全在窗口外才可由这些观察确认越界；部分相交时需补证。

第二项中，各点距 Q0 的误差只有 0.707 µV，确实满足原初态逐点检查。
“逐点误差不超过 B”最多保证峰峰变化不超过 2B，不能代替“保持变化不超过 B”的独立要求。
后者已用于采样后的阶段；把它覆盖到初始阶段属于待补的检查范围，尚未改入原判据。

已符合的部分包括：固定参考刻度计算数值预算、独立 PWL 答案及折点极值、
同一保持阶段共用回调区间、输入独立验收、完整计数和顺序、采样后漂移以及关键边界观察覆盖。
正反例确认：合法晚采样 50 ps 及额外偏差 0.5 µV 可通过；额外偏差 2 µV 被判数值超差；
晚采样 400 ps 被判事件越界。不能把上述两处缺口解释为所有现有检查均无效。

另有两项依据需要补齐，不属于此次已复现的漏查：

- 原 2.1 ps 观测区间对应最多 0.42 µV 的参考值范围宽度，占 1.01 µV 门槛约 42%。
  它可能使临界结果无法判定。约 0.5 ps 是降低该不确定度的建议，未替换原观察要求。
- 10 nV 绝对下限使 1 mV 刻度用例的门槛成为 11 ppm；小信号条件的阈值依据仍需独立说明。

#### 复现方法

在仓库根目录运行现有校准，不修改测试文件：

```sh
python3 -B -m unittest discover -s evas/validation/paper -p 'test_precision.py' -v
```

以下代码复现本次的 9 条人工轨迹。它复用测试辅助函数生成分段答案，事件真实时移由输入直接指定，
不根据检查器返回的区间反推。输出是检查器诊断，不是四后端成绩。

```sh
PYTHONPATH=evas/validation/paper python3 -B - <<'PY'
from precision_checker import assess
from test_precision import BUDGETS, CARDS, sample_rows

cases = [
    ('timer_valid', 'SH-T-RAMP', 50e-12, 0),
    ('timer_valid_small_error', 'SH-T-RAMP', 50e-12, 0.5e-6),
    ('timer_2uV_error', 'SH-T-RAMP', 50e-12, 2e-6),
    ('timer_outside_late_0.5ps', 'SH-T-RAMP', 100.5e-12, 0),
    ('timer_outside_early_0.5ps', 'SH-T-RAMP', -100.5e-12, 0),
    ('timer_outside_late_400ps', 'SH-T-RAMP', 400e-12, 0),
    ('cross_valid', 'SH-X-RAMP', 50e-12, 0),
    ('cross_early_0.5ps', 'SH-X-RAMP', -0.5e-12, 0),
]
for name, card_id, shift, extra in cases:
    card = CARDS[card_id]
    rows = sample_rows(card, shift=shift)
    for row in rows:
        if row['count'] > 0:
            row['y'] += extra
    print(name, assess(card, rows, BUDGETS)['status'])

card = CARDS['SH-T-RAMP']
rows = sample_rows(card, shift=50e-12)
budget = BUDGETS['absolute_V'] + BUDGETS['relative'] * card['scale_V']
initial = [row for row in rows if row['count'] == 0]
initial[1]['y'] = card['initial_V'] - 0.7 * budget
initial[2]['y'] = card['initial_V'] + 0.7 * budget
print('initial_hold_drift_1.4B', assess(card, rows, BUDGETS)['status'])
PY
```

### v2：统一采样保持与一阶滤波 checker

对应[三档验收要求](../COMPARISON-METHODOLOGY.md#precision-tiers-proposal)和
[五个候选配置](../COMPARISON-METHODOLOGY.md#profile-proposal)。本节是已实现的验收契约。新入口是 `precision_v2.py`，
独立参考在 `precision_reference.py`，配置扫描在 `precision_v2_run.py`，报告在 `precision_v2_report.py`。
首轮只处理 `precision-v1` 中的 4 个采样保持和 4 个一阶滤波模型，沿用原源码、输入、初态及事件容差。
旧基础、旧 core 和后续工程组合的 checker 作为后续迁移对象，不自动换成这版规则。

| 修改范围 | 具体要求 | 实施后的验收 |
| --- | --- | --- |
| 条件与版本 | 增加独立的新版本定义，分开保存模型、Q1～Q3 目标、运行配置和观察计划；不能原地改写 `precision-v1.json` | 模型及刺激与旧八条件逐项一致；档位和配置变化有独立身份；旧检查仍可按原身份运行 |
| 数学参考 | 从 `precision_checker.py` 分离独立参考求值；PWL 使用精确十进制或有理数，滤波使用逐段解析式及明确的运算误差界 | 不读取后端输出生成数学答案，不调用 EVAS 求解器；计入输入数值表示、参考求值及浮点转换误差，不能只凭 80 位与 120 位结果相同声称证明 |
| 事件与保持 | 对完整原生计数区间检查合法时刻，删除“有交集即合格”的推断；检查初始阶段的峰峰变化 | 前述 ±100.5 ps timer、提前 0.5 ps cross 反例不能通过；时间不确定时为证据不足；初始 1.414 µV 漂移不能通过 Q2 |
| 数值判定 | 一次计算各性质的误差上下界，再按三个目标独立判分；参考和观测资格也随 Q 档检查 | 同一轨迹可通过 Q1 而不通过 Q2；不会因换档重建更有利的参考或时移；窗口内错误与旧值不能被豁免 |
| 观察生成 | 在新入口 `precision_v2_run.py` 生成观察计划，覆盖合法窗口两端及内部，保留关键点身份；使用同一计划运行五档 | 所有后端实际记录满足目标档位的区间、全局间隔和边界覆盖；不插值补边界，不混入另一轮更细运行的数据 |
| 后端资格 | 扩展配置生成和 `precision_report.py` 的读回核对，包括 deep、积分控制及步长依据 | 每项标明请求、生效、来源、未知或不适用；有效参数被钳位、观察请求未落实时不能取得该具名配置资格 |
| 报告与选择 | 按条件、后端、运行配置、Q 档保存结论及原因；每档按固定顺序选择完整通过的运行 | 原失败和未运行组合保留；额外报告收紧配置后退化；支持行只有全部预定条件满足该 Q 档才可注明通过 |
| 历史迁移 | 原 checker、卡、收据和成绩保持原身份。新分析另存并指向原执行资料 | 没有足够原始观察就标缺证并补测，不能根据旧 `pass` 推断 Q2，也不能覆盖原判定 |

#### 档位数据与判定顺序

令 `B0(A) = 1e-8 V + 1e-6 × A`，Q1、Q2、Q3 分别使用 `10B0`、`B0`、`B0/10`。
输入门槛为该信号自身刻度下的 `B/100`；时钟刻度固定 1 V。
计数信号仍按原 1 µV 检查整数，不把它作为精度档位的电压输出。

先核验工具与配置、输入和观察来源，再检查初态、计数、顺序和实际事件合法性。
这些行为要求不能被宽档豁免。最后逐档核验参考计算、观察能力、输出误差和保持变化。
若已能确认超差，保留该事实；缺少资格时不能进一步把波形结论升级为配置达标。

输出参考为区间 `[L,H]` 时，使用以下误差界。U 仅包含尚未纳入该区间的参考计算或电压读取不确定度。

```text
E_lower = max(0, L − y − U, y − H − U)
E_upper = max(abs(y − L), abs(y − H)) + U
```

`E_upper ≤ B` 才可通过，`E_lower > B` 确认超差，其余为证据不足。
本轮另以 `(H − L) + U ≤ B/10` 约束观察能力，参考运算误差单独要求不超过 `B/100`。
这是两类用例的保守分辨能力要求，不把区间宽度再次加到 `E_upper` 上。
初态用固定参考值；保持峰峰变化同时计入两端读取误差，并使用同一个 B 检查。

采样保持的 `[L,H]` 必须由完整、已确认合法的回调区间求得，包含其中的 PWL 折点。
时间序列化误差先扩入回调区间，不能再重复计入 U。
原生回调区间完全在合法窗内才确认时间合格；完全在窗外确认越界，部分相交则需更精确的独立时刻证据。
`cross` 另核对方向及表达式条件，时钟输入误差引起的根不确定度须有依据并参与时间资格检查。
精确落在边界的记录可由独立的时刻或事件证据确认，不能靠裁掉区间外侧确认。

滤波的 `[L,H]` 来自同一解析解在实际记录时刻不确定区间内的范围。
本批初值与输入均在 `[-A,A]` 内，稳定一阶系统的输出也在该区间内，故
`|dy/dt| ≤ 2A/τ` 可保守限制时间读写误差的影响。解析参考的初值必须沿原输入历史逐段传播，
不能每段从后端输出重新起算。报告仅限实际观察点和具名边界。

#### 观察计划与运行身份

首次五档扫描全部使用目标 Q3 的观察计划，观察方式作为配置身份的一部分。
普通请求间隔为 `T/32 = 31.25 ns`，原生导出最大间隔为 `T/16 = 62.5 ns`。
`T=τ=1 µs`；采样条件的停止时刻保持 8.5 µs 或 32.5 µs，滤波条件保持 8 µs。

每个 timer 以名义时刻前后 100 ps 为合法窗口；cross 使用名义穿越到其后 100 ps 的窗口，
实际时钟偏差另作检查，不能由窗口代替。对窗口及前后各 2 ps 连续生成请求点：
1 V 斜坡间隔 0.04 ps，小信号斜坡 0.4 ps，常量条件 2 ps。
另外保留窗口端点、名义时刻、全部输入折点及其左右观察点；不可用去重规则删掉不同来源的必要边界。
实际回调区间上限按主文表检查，全宽包含已计入的时间读写不确定度。
即使全宽达标，仍须满足本档总观察不确定度要求。

Spectre、EVAS 的 strobe 与另两后端的隔离 PWL 观察源沿用原入口，均导出原生时间和值。
普通查询是另一种观察模式，不能替代 strobe 的通过。
新计划比旧计划更密，可能改变接受网格，因此旧四档结果不是新计划的实测。
新增观察点的预检须确认文件和点数预算；若需变更计划或执行限额，先形成新计划身份，不能删点后仍冒用原身份。

候选配置固定顺序为 `base, tol, step, both, deep`。
`deep` 的请求值是 `reltol=1e-10`、电压绝对容差 `1e-14 V`、电流绝对容差 `1e-17 A`、
最大步长 `4.8828125e-10 s`；EVAS 不接收电流容差或 SPICE 方法。
ngspice 的 `trtol/chgtol/itl4`、Gnucap 的 `trtol/dtratio/dtmin` 在新网表中显式写入并核验，
不能依赖未记录的默认值。Spectre 的预设覆盖按原版本验证；本轮 deep 已取得新的读回，详见新收据。
初始化方式、源缩放、额外电导和模型参数不得作为未声明的精度调节手段。

#### 实施校准

- 已知精确的 PWL 常量、斜坡及峰谷采样；滤波恒定输入、单位斜坡闭式解、非零初态和跨折点连续性。
- 每档门槛内、门槛外、误差范围跨门槛的轨迹；近零与 1 mV 条件；输入错误、参考不够准和导出不够准。
- 回调区间完整在窗内、完整在窗外、跨越窗边三种情况；边界同刻但有确切阶段证据；提前 cross、漏事件、旧值、输出与计数不同步。
- 所有保持阶段，包括初始阶段，分别注入漂移；不得以逐点接近初值代替平台稳定性。
- 只改变求解配置时数学基准和 Q 门槛不变；较严档通过必须同时满足较宽档，行为失败不能降档变通过。
- 设置未应用、读回缺失、观察点缺失、配置中途失败与整批中止；报告保留原因和完整预定条件。

这些校准之后才能按新身份执行四后端对照。三档是同一输出的三次判定，不是三倍仿真次数。
实现及新成绩以[本轮记录](../../../experiments/backends/support/README.md#precision-v2)为准，
原 `precision_checker.py`、`precision-v1.json` 和历史收据未改写。独立回调证据必须绑定同次波形及
实际测量工件；哈希只证明身份，适配器审查还需证明其测得实际回调时刻。
当前没有后端因自报数学根或请求时刻而取得这项资格。报告另核对执行条件卡、设置、观察计划、
模型及网表与冻结输入的身份，缺少实际配置或已审版本传递路径时不授予配置达标。

#### 校准后的 Q 档绑定

`precision_binding.py` 从 `precision-bindings-v1.json` 解析条件、后端和 Q 档。
注册表锁定模型卡、参考、检查器、生成器、EVAS 前端及内核源码依赖，并引用独立的新收据。
准备运行还要比较当前工具身份，逐文件检查重建输入的哈希；变化后不能沿用原资格。
这是八个具名条件的复用入口，不承诺任意模型或任意严格内部容差都能执行。

补充证据由 `precision_binding_evidence.py` 处理，原 v1/v2 文件保持不变：

- Spectre 单实例采样记录必须逐条对应同次原生波形，不允许去重后掩盖试探回调。
  17 位规范格式恢复实际 binary64 时间；数学根误差继续保留。合法端点通过，早一 ULP 的负例仍失败。
- 原两侧观察规则仍采用 2.1 ps 距离与原序列化不确定度，但在全部记录中寻找有效左右点。
  找不到、超出距离、仅有落在不确定区间内的点都不能补成通过。全部原生记录继续参与误差评分。
- ngspice 的显式 TMAX/stop 使用经过独立审查的安装二进制路径证明，核验镜像、程序和审查附件哈希。
  只消除对应参数缺证，不消除其他配置问题，不把参数传递当成运行时回显。

每个尝试分别保存 `numerical`、`behavior`、`evidence`。计数错误使输出未进入数值评分时，
必须写 `unavailable`，不能把尚未计算的零误差字段说成数值通过。
只有同一次运行在当前 Q 档完整通过才进入注册表；失败尝试保留在新收据中。
`precision_binding_report.py` 在分析前后核对源码身份，变化时终止并要求新分析目录。
分析完成后运行校准、独立审查，再用 `precision_binding.py --freeze-analysis` 固定收据和注册表。
该操作只创建新文件，不覆盖历史结果。命令见[复验入口](../../validation/paper/README.md#运行前选择已校准配置)。

### 后端配置与选择规则

共同的是模型、刺激、初态和外部目标，各后端用自己的控制达到目标。
下表列控制入口，不声明当前适配器全部接通，也不构成已验证的参数配方。

| 后端 | 需要核对的精度控制 | 需要保存的实际信息 |
| --- | --- | --- |
| Spectre | reltol、vabstol、iabstol；积分方法、步长；精度预设及 strobe | 预设覆盖后的有效值、原生求解与保存时刻、实际事件记录 |
| ngspice + OpenVAF-R | ngspice 的 reltol、vntol、abstol、trtol、积分方法及瞬态最大步长；OpenVAF-R 负责编译模型 | loaded-circuit 设置、原生时间列和导出方式；编译成功与瞬态成功分别记录 |

控制依据见 [EVAS 精度说明](../math/solving.md#spectre-与-evas-的容差含义)、[ngspice 46 手册](https://ngspice.sourceforge.io/docs/ngspice-46-manual.pdf)、

打印位数、输出采样间隔、最大求解步长和事件定位精度不是同一个量。
EVAS 的解析与数值路径对控制细化的响应不同，未应用的设置必须如实记录。

每个后端的候选档位、选择顺序及允许的调节范围须在评价前固定。
可以按预定规则选择达到共同目标的档位；保存所有尝试和失败，不另改模型、观察或外部门槛。
不强制整张表使用同一档位。不能事后为每个输出点选择一份最有利的运行结果。

对精度敏感的条件，分别检查基础配置、仅收紧求解容差、仅减小步长，必要时增加组合或积分方法诊断。
扫描时保持源码事件容差不变；更改 time_tol 属于新模型条件，不能混入求解器收敛扫描。
增加 strobe 或强制求解点可能改变网格，须作为具名配置；它们与普通输出查询分开记录。
实际误差不必逐点单调下降，但平台、反常放大或事件序列变化须解释。
相邻档位接近本身不能证明正确，仍须对独立答案验收。

### 独立参考与配对比较

每项要求注明来自语言语义、模型显式约束或项目数值质量目标。
数学函数按合法定义域、已表示输入和运算关系建立独立答案，分析浮点表示与舍入；
不能给所有函数假定统一 ULP 上限。边界没有唯一数学点值时，写明可验证性质。

分别记录后端独立正确性、与 Spectre 的工程对照及严格同刻差值。
同刻同阶段，两方各自误差不超过 `B_a`、`B_b`，只能推出差值不超过 `B_a+B_b`。
更严的后端间预算须预先定义。相邻配置结果接近不能代替独立答案。
没有解析答案时说明高精度参考的误差，或以不变量限定可证性质；
无法界定的不确定度不能支持数值达标结论。
Spectre 参考也须满足上述独立判据，精度不足时按[配置选择规则](#backend-profiles)复核。
工程对照的范围与证据要求遵循[对齐验收](../../../docs/contributing/validation.md#spectre-alignment-acceptance)。

事件窗口内保留边界及两侧检查，用同一已证实的事件历史解释读值、顺序及全部下游消费者。
最终码值、事件序列或反馈轨迹改变时，调查是否满足原条件，不自动接受。
[SEF-TIMER-18](../../../experiments/backends/sample-edge-filter/BOUNDARY.md#accepted-timer-18)
仅适用于所记录模型、设置、版本与消费者，保留严格失败，不扩大到 C1、#79、VCO 或新条件。
新范围的重判须有独立证据及相应范围决定。

### 判分记录与检查器校准

N 是预先固定的行为条件数，不是输出点、配置档位或重试次数。全部 N 条件通过才标整行通过。
基础与组合分别验收。配置通过率另报，多行复用证据时说明总数去重规则。
只有独立检查而无 Spectre 对照时，可以报告独立结果，不能宣称工程对齐。

证据页保留以下内容，主表只链接相应记录：

- 条件清单、源码与刺激身份、初态、参数、观察点和判据版本。
- 数值门槛的单位、尺度、依据及不确定度，关键边界与事件历史。
- 实际误差及上下界、独立判定、配对结论、失败阶段、完整分母及原始资料可用性。
- 检查器正反例校准，包括错分支、旧值、漏事件、超时窗及超差轨迹。校准不计为仿真成绩。

工具、命令、参数和文件身份按下文[身份与复验](#身份与复验)保存。
正式运行前完成独立答案审查、具体阈值与配置定稿、检查器校准；缺项时标“判据未冻结”。

## 身份与复验

### 容差选择与边界比较

两后端的[内部容差含义](../math/solving.md#spectre-与-evas-的容差含义)不同。
容差与步长扫描遵循[配置选择规则](#backend-profiles)，同时保留 requested 与 effective。
各配置固定模型、输入、初值、观察请求和外部预算，保存全部失败。
不同配置的实际时间网格不能用跨跳变插值强行配对。

对 `idtmod` 输出，同时检查圆周相位、原始普通电压、回绕次数和时间括定。
