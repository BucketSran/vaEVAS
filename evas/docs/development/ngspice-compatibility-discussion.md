### 时钟模型的替换边界

[原网表](../../../experiments/backends/xyce-va-pilot/netlists/circuit_va_tt_ngspice.spi)的clkse驱动共模bootstrap，clks驱动两路输入bootstrap。两条NAND、反相器和延迟链通过反馈互锁。phi2输出没有下游负载，但第二条链的内部反馈参与第一条链的控制，不能把整条第二链删作无用逻辑。

从连接关系可推断设计意图是共模开关先关、输入开关随后关；具体延迟及器件波形仍须原电路证据，不能从级数直接换算。建议首批采用参数化功能模型clk_ctl(clk,vdd,vss,clkse,clks,phi2)，保留原bootstrap、采样电容和其余MOS。时序建议如下，时间指逻辑目标改变时刻，输出另有有限上升/下降时间。

| 输入变化 | 建议逻辑动作 |
| --- | --- |
| clk上升 | phi2关；经过t_dead后clkse与clks开 |
| clk下降 | clkse关；经过t_sample后clks关；再经过t_dead后phi2开 |
| clk停止 | 执行仍有效的待办动作，此后保持；不能因固定周期timer继续自振 |

这张表已随Q7选为功能规格，不声称复现晶体管全部时序。输出采用相对vss的理想电压驱动，幅度由V(vdd,vss)确定，transition仅作用于保持的逻辑目标。首批不模拟时钟块的供电电流和输出电阻；若要求这些效应，需另扩电气关系。输入初始高/低的状态仍须定义，不依靠第一次cross才初始化。原电路没有reset端，首批不凭空增加reset需求。

保留上述关断顺序和重入行为，需要状态控制的一次性timer，例如timer(next_deadline,0,ttol,enabled)，并用阶段状态逐项安排动作。公共[前端](../../src/evas/instance_compiler.py)和Rust已有held_timer及输入仿射条件选择常数初值的有限表达；[XSPICE入口](../../src/evas/xspice/compiler.py)尚不接受这些初始化与timer。transition延迟只安排输出目标，不能代替取消旧动作、选择新阶段的控制语义。标准timer与OR语法见[Verilog-AMS 2.4第5.10节](https://accellera.org/images/downloads/standards/v-ams/VAMS-LRM-2-4.pdf)。

短脉冲、新边沿先于旧deadline及恰好撞上deadline时的规则还未决定。建议采用新有效边沿撤销过期待办、重新建立符合死区要求的动作，但是否采用须在时钟功能范围确定后回答。不能用C回调顺序或根处一次严格电压比较隐式决定优先级，也不能因撤销动作而跳过死区。

### 两份开关模型

建议统一接口sw(p,n,ctrl,ref)，p/n是导电两端，ctrl/ref定义控制电压。ref只作控制参考，不声称具有MOS体效应。电流关系始终为I(p,n)<+G*V(p,n)。

| 模型 | 建议关系与状态 |
| --- | --- |
| sw_cont | G=Goff+(Gon-Goff)*(1+tanh(k*(V(ctrl,ref)-Vth)))/2；Gon=1/Ron，Goff=1/Roff |
| sw_event | 上穿阈值进入开态，下穿进入关态；q保持为0或1，G=Goff+(Gon-Goff)*q |

连续形式来自已有[ideal_sw.va](../../../experiments/backends/xyce-va-pilot/va/ideal_sw.va)，其中Ron=500Ω、Roff=1GΩ、Vth=0.9V、k=20/V可作为第一组名义参数。旧文件读取V(g)，这里改成显式参考端是统一新模型草案；ref接原地节点时才与旧控制电压相同。所有后端须使用选定后的同一份新VA，不分别改写。若ref接导电端n，则模型变成按Vgs类电压控制，行为和偏导均不同，需要明确选择。

建议事件版先采用单阈值、无迟滞、G瞬时切换，电容电压由宿主连续演化。G的平滑过渡不是电荷注入，可另选，但不能为了求解收敛偷偷加入。最小VA可以在上/下cross的同一OR块里更新逻辑状态；若采用q=1-q，合同须限定已初始化且严格交替的横穿事件，不能泛化到任意触零、漏沿或抖振。根处通过V(ctrl,ref)>Vth猜测触发方向可能受回调偏移影响，不把该写法作为已定方案。

### 多cross、OR与同刻的建议边界

| 组合 | 建议首批范围 | 最小验收与拒绝边界 |
| --- | --- | --- |
| 多cross | 多个独立叶，支持上/下沿；direction=0可由同一guard双向合同覆盖 | 两周期上下穿、两个不同guard、初始高/低；每叶独立arming，漏沿/重沿负控。平台触零需单独合同，不能从横穿外推 |
| 同块OR | cross OR cross、cross OR held timer；同一次发生执行body一次，保留全部触发叶 | 同根的cross(u-a)与cross(2u-2a)、cross/timer同刻；两个可分离但很近的根分别执行，不能按ttol直接合并 |
| 不同块同刻 | 只接受写集不冲突、互不读取对方本批更新且无即时电气因果依赖的组合 | 两块各更新一状态，交换声明顺序不改变结果；共同写入或读写依赖明确诊断，不用声明顺序裁决 |
| 同块内优先级 | 可由同一事件体显式编码；具体时钟碰撞规则待选 | 新边沿与deadline同刻，及其前后偏移分别验收；块内顺序赋值不等于跨块优先级 |
| 跨实例电气反馈 | 先覆盖正RC延迟后可分离的新cross | 即时跳变触发新事件、往返抖振、无解/多解的零时刻循环暂不准入；不能因实例状态不同就认定独立 |

OR同刻一次执行和跨块共同观察来自现有[EVAS事件合同](../../validation/EVENT_CONDITIONS_CONTRACT.md)与[事件手册](../math/events.md)，不是对所有Verilog-A模拟器回调行为的泛化声明。宿主数值时间接近不能直接证明两个根相同，实施时须给出可验证的识别规则；近根若无法分辨应报告限制，不静默吞并事件。原生Spectre对同源模型的实际行为仍是独立准入条件。

XSPICE需要新增逐叶guard/arming、OR发生集合、有限同刻事件批次、held timer重建与取消、所选条件体和初始化能力。可延续既有帧事务、状态赋值及transition框架，但新增状态、已消费事件和取消动作全部须受拒步回退保护。纯电压时钟与电流开关均不得在Newton重复调用时重复消费事件。

### 验收顺序与独立答案

1. 分别验收每份VA，再验时钟与开关组合。固定输入经G驱动外部C且无其他负载时，Vc(t)=Vin+(Vc(0)-Vin)*exp(-integral(G dt)/C)。连续G用独立积分答案；事件G用分段指数。检验开、关、反向端电压、泄漏、端口电流守恒与电容电压连续。实际夹具若加入源电阻或其他负载，须重推答案。
2. 事件微例验证上/下沿次数、全部触发叶、同块一次/跨块分别执行、deadline改期和取消、初始状态、停止时钟、短脉冲及同刻前后偏移。瞬时G切换附近以事件窗、窗外电流和净电荷误差分别验收，不能要求错时窗口内逐点电流始终接近。
3. 真实ngspice内验证重复Newton调用和实际拒步。对q、逐叶arming、timer启用/期限、消费记录及输出队列检查同进程回退；设置共享arming、OR重复执行、漏关、旧timer未撤销、候选状态泄漏等负控，证明检查器会拒绝。
4. 选定VA以完全相同源码分别进入ngspice和原生Spectre。先各自过独立答案，再比较状态序列、时刻、支路关系与响应，不将任一引擎波形当作全部真值。近根和同刻行为不一致须保留为未对齐，不能只看最终波形。
5. 最后在原采样器上分别替换时钟、连续开关、事件开关，再验组合。首轮建议先做同源TT，观察关断顺序、保持误差与原电路指标；PVT和速度另定，旧TT/性能结论不沿用为新能力。

## 第五轮：窄脉冲、碰撞、参数与误差预算

### Q10：待开通可撤销，已启动的采样关断必须完成

建议区分开通请求与关断义务。新边沿可以取消尚未执行的开通，但不能取消已经启动的clks延迟关断。否则clkse已经关而clks仍导通时，新上升删除关断deadline会让原采样阶段继续延长。允许这种延长是另一种模型，不能隐含在“新边沿优先”里。

建议规则如下，时间均指逻辑目标变化时刻。

1. 每个有效输入边沿更新最新请求相位，并撤销旧的待开通请求。已经执行的目标变化和开始的输出边沿不倒退；拒步回退另按事务合同处理。
2. 上升沿立即将phi2目标置零；下降沿立即将clkse目标置零。如果clks仍开，下降沿建立t_sample后的关断义务；已有更早期限则保留，后续边沿不推迟它。
3. 开通必须同时满足最新请求未变、已完成所有关断义务、已等待死区。建议开通时刻不早于max(最新边沿时刻,尚欠关断的目标时刻)+t_dead；没有尚欠关断时，从最新边沿计时。对已关的clks不额外虚构一次t_sample等待。
4. 真正同刻时，先落实到期关断，再处理新边沿及其取消请求，最后检查是否还允许开通。旧开通与新边沿同刻时，旧开通不发生。这个次序是模型要求，不能用宿主回调顺序实现另一套隐含行为。
5. 多个边沿只更新最新请求和有限待办，不积累无界开通队列。连续短脉冲可能使三路一直关断；允许丢失采样机会，不允许迟来的旧相开通。

以待选的t_sample=t_dead=200ps为例：

| 场景 | 建议结果 |
| --- | --- |
| 低相中0ps上升，100ps下降 | 取消200ps的clkse/clks开通，phi2在300ps重新开；输出仍会有关闭区间，不能说脉冲被过滤后所有输出均不变化 |
| 高相中0ps下降，100ps上升 | clkse在0ps关，clks仍在200ps关；phi2不开，clkse/clks最早400ps重新开 |
| 新边沿恰逢clks的200ps关断 | 关断仍发生，再按最新请求安排后续相位 |
| 新边沿恰逢旧开通 | 旧开通不产生零宽或短毛刺；从新边沿及未完关断重新计算可开时刻 |
| 新边沿在deadline前后0.5ps或5ps | 分别执行真实先后，不套用同刻优先级；已经发生的短开通不能事后抹掉 |

取消仅作用于未执行动作，不撤销已开始的transition。首批建议transition的delay=0，逻辑延迟全部由timer负责，输出形状用有限tr/tf。沿用Q7的目标间死区定义，不另悄悄增加tf延迟；选t_dead大于最大下降时间，为物理边沿留出余量。名义200ps死区与50ps下降时间留下约150ps全关间隔，含时刻误差时应扣除相应预算。这仅约束功能模型输出，不能当作bootstrap内部MOS的实际关断证明。

Q10建议采用上述“完成关断后按最新请求重开”规则。代价是短低脉冲会造成一次完整关断，下一采样窗口可能变短或被吞掉。备选是允许中止当前采样并立即关clks，再等死区，但这改变原t_sample等待，应另行选择；不建议简单撤销关断并保持clks导通。

| 状态、事件次数、取消记录与触发集合 | 完全符合预期 | 完全一致 |

0.1ps是相对理想事件日程的总误差，不能让每级timer再无条件增加0.1ps。输出电压的全波形比较包括事件窗口；瞬时G电流的跳变窗口则单独检查事件时刻和净电荷，不能要求其中逐点电流很接近。固定端电压电流门槛不直接用于含RC电压误差的动态电流，后者须传播G和V的误差。泄漏门槛单列，因为最大关断电流1.8nA小于导通档10nA的绝对项。

算术依据：Ron*C=500ps，Roff*C=1ms。每条边错0.1ps时，1.8V充电初段的单边影响约0.36mV；窄脉冲两边最坏合计约0.72mV，因此建议全波形1mV而不是只算单边的0.5mV。时钟斜率为1.8V/50ps，同样错时约3.6mV。5MHz、0.4V正弦的采样斜率预算仅约1.26µV/0.1ps，不能拿它代替开关充电预算。3.6mA最大导通电流下两边错时对应至多约0.72fC，1fC还要求积分和数值误差单独达标；点电流门槛不能证明这项电荷预算。

多个短脉冲、跨周期历史及新负载须按事件灵敏度和稳定性另推预算，不直接复制单周期1mV。避开事件窗口不会消除RC中已传播的错时误差。可增加已测事件日程下的解析残差诊断，但不能因此移动原答案、取消总时刻及全波形门槛。

初始RC夹具应由DC一致的零输入建立初态，再在正时间施加已知PWL激励，并按完整刺激建立分段答案；不为套用指数公式偷偷使用未准入的.tran uic。时序精度和求解器容差也不是同一量。未来需要分别记录两引擎实际设置、原生导出时间精度和检查器插值/积分误差，再证明达到上述门槛。

语义微例以deadline±0.5ps、±5ps和精确同刻为首组。更近的根必须缩小数值不确定性或明确报告无法分辨，不能自动套用同刻优先级。初始高/低、停钟、反复窄脉冲、输出过渡中改相、参考地平移及拒步后重试均列入独立条件；不按观察点数增加通过计数。

真实TT电路建议沿用原精度指标：采集/保持/反向再采集误差各≤5mV、SFDR≥80dB、增益误差≤0.5%、存储共模绝对值≤25mV。原FFT为900ns，80个保持样本位于89ns至879ns、间隔10ns；原保持台在7.8ns、11.5ns、19.5ns观察，来源见[原checker](/Users/bucketsran/Documents/TsingProject/research/vaEVAS/current/runs/xyce-va-pilot-20261017/bench/analog_arena_tests/verify.py)。这些是模型替换的功能要求，不是由上述RC误差推出的系统保证，整电路配对数值预算仍需单独确定。

## 第六轮：标准VA中的顺序、取消与碰撞

状态：Q1至Q12已接受。Q13的同一analog过程有序事件扩展仍待回答。以下为源码与规范核对、表达骨架和设计建议；没有生成模型源文件、编译、运行或新增支持结论。

### 修正：标准VA允许同模块内的源码顺序

[Verilog-AMS 2.4](https://www.accellera.org/images/downloads/standards/v-ams/VAMS-LRM-2-4.pdf)第5.3节规定顺序块的语句按源码先后执行，第6.9.1节规定同模块多个analog块按声明顺序合并。第5.10节规定模拟事件不阻塞过程且不携带数据。因此，不必把全部控制塞入一个OR再推测来源；可以把不可取消的关断timer、上/下cross、开通timer写成同一过程内有明确先后的事件语句。

这里修正的是上一轮对可用写法的判断。当前EVAS按事件块拒绝同刻共同写和跨块读写，属于自身受限合同，不能解释成标准VA禁止这些程序。Q9已接受该有限边界，所以采用有序写法须明确增加一个例外：同一analog过程内部允许保留源码顺序的状态依赖。不能声称用户已经批准，也不能据此取消跨实例即时电气闭包的限制。

### 推荐候选：保留一个模拟过程的执行顺序

下面只说明候选控制结构。注释处尚未展开完整状态转移，不是已可运行或已验证的模型。

```verilog
analog begin
  @(initial_step) begin
    // 按Q11设置输出、requested、on_en/off_en、期限与on_gen
  end

  // 本次求值入口的值副本，不是随后重新读取on_*的别名
  entry_on_gen = on_gen;
  entry_on_due = on_due;
  entry_on_en  = on_en;

  @(timer(off_due, 0, TTOL, off_en)) begin
    // 完成不可取消的clks关断，消费off请求
    // 如替换待开通，更新on_gen及其期限
  end

  @(cross(V(clk,vss)-VTH, +1, TTOL, VTOL)) begin
    on_gen = on_gen + 1;
    on_en = 0;
    // 上升处理：关phi2，保留off义务，安排最新高相请求
  end

  @(cross(V(clk,vss)-VTH, -1, TTOL, VTOL)) begin
    on_gen = on_gen + 1;
    on_en = 0;
    // 下降处理：关clkse，建立或保留off义务，安排低相请求
  end

  @(timer(on_due, 0, TTOL, on_en)) begin
    if (entry_on_en && on_en &&
        on_gen == entry_on_gen && on_due == entry_on_due) begin
      // 执行本次入口已存在且未被替换的开通
      on_en = 0;
      on_gen = on_gen + 1;
    end
  end

  // 三路电压贡献与transition位于事件体外，delay=0
end
```

取消是源码可见的状态变化：旧开通失效；替换时安装新的未来期限；off请求不随其取消。每次取消、改期、替换或消费须一致更新请求代次，并遵守整数范围。入口快照中的实数相等检查比较的是同一个请求字段的副本，不是把两个独立估计的根时间判成相同。模型初始输入不在阈值上，上下cross具有已约定的横穿合同。

不能只在末尾写if(on_en)。同一次求值中，新边沿可能撤销旧开通后，又令on_en=1安排未来开通；旧timer若仍触发，就会错误执行新请求。快照与代次用于阻止这个错误。普通复制必须捕获当时的值，不能将entry_on_gen优化为后续读取on_gen的别名。

此源码守卫只处理本次求值内的请求替换。它不为宿主的旧唤醒提供身份，也不保证下一次求值不会发生错误；后端仍须正确维护timer代次、到期和消费，并在重复Newton求值及拒步中验收。源码on_gen与宿主调度用的代次是不同对象，不能互相替代。

第5.10.3.3节允许显式time_tol的timer在名义时间两侧容差内取点，并按最新参数安排后续事件。因此不能额外要求$abstime>=on_due才消费timer：这可能吞掉一次合法的提前触发。时刻检查应遵循声明的允许范围，越界应报错，不能静默跳过。timer保持在持续求值的过程位置，以enable参数控制；不把timer调用藏进cross事件体中。

### 精确同刻、可分离近碰撞和未知先后

必须分开三个时间：模型关系给出的目标时刻、后端实际触发时刻、检查器观察或输出的时刻。源码顺序只规定同一次模拟求值中已触发语句的先后，不能把数学同刻的两个独立触发强制送入同一求值。

| 情况 | 判定依据与要求 |
| --- | --- |
| 模型关系或独立解析刺激证明同刻 | 保留Q10的关断、输入、开通顺序，原生后端也须实际通过无旧开通毛刺的用例 |
| 时间误差范围可分离 | 按真实先后处理；先前已经发生的开通不能取消成从未发生 |
| 两个估计接近且误差范围重叠 | 只能说明尚不知先后；继续定位或报告无法确定，不能推导为精确同刻 |

以输入根相对deadline的δ为例，δ=-0.5ps时输入先到，δ=+0.5ps时期限先到；若每个时刻均满足0.1ps的独立误差上界，这两种次序能够分开。δ=0的身份须由模型时间来源或独立解析刺激给出，不能由浮点相等、同一输出采样点或abs(δ)<TTOL代替。0.1ps是验收预算，未实测前不能拿它当作后端已具备的定位证据。

重要反例：数学上输入根等于on_due，但timer先触发，cross稍后才触发。即使VA源码顺序正确，也可能先开再取消。若旧开通已经被接受，后来的源码执行不能把它抹去。该情况是Q10精确碰撞验收失败，不能因时间差小于预算而豁免离散状态错误。

对于任意黑箱模拟网表，当前材料不能保证获得足够的根时间证据。EVAS出口应对可检测的未分辨情况给明确诊断；Spectre不承诺提供这套证书或同样拒绝，故其原生结果需由独立checker判定。证据不足或序列不符的参考条件保留为未对齐，不用“代码符合标准”替代支持结论。Q10要求保留，不擅自改成容差内都算同刻。

### 为什么暂不以last_crossing为主方案

last_crossing是标准算子，但第4.5.10节只规定线性插值估计，且它本身不控制步长。它既不是事件来源标签，也没有规范统一的误差上界。当前候选的公共前端、IR和Rust均未实现它。

单OR加last_crossing及seen时间仍有几个缺口：同一根的估计值在候选迭代中变化会被重复处理；宽容差去重可能吞近根；仅保存最近根可能遗漏多次发生；用发现时的$abstime固定排序可能抹掉本应先发生的开通。把两个估计排序也不能补回宿主已经接受、但没有执行的历史动作。

建议首先采用能直接表明来源的独立cross事件语句。last_crossing仅在后续证明必须用根历史锚定deadline或诊断误差时再单列能力；$abstime仍只表示实际求值时间。若用它安排deadline，回调偏移会进入时间预算，不能冒充精确根来源或不受限制地串联累积。

### 前端应补绑定与准入，运行时IR先保持不变

1. 扫描普通、初始化和事件写者；逐语句建立已定义的合格别名环境，检查类型、唯一写者、依赖方向和纯输入仿射结构。保留实际展开顺序，不按行号重新排序。

3. 继续走现有表达式lowering和后端准入。建议优先在源表达式层完成窄展开，让其余局部读取继续走原拒绝路径；按事件携带绑定环境也可实现同一合同，但不新增运行时变量。
4. 补编译期诊断旁表，关联读取位置、定义链、实例和展开来源。现有Origin有source/line/column/instance/expansion，但Affine与Assignment没有完整定义链，不能宣称已有这些诊断信息。
5. 别名展开采用实例私有环境、共享子表达式和有界遍历。沿用[limits.py](../../src/evas/limits.py)的表达式深度80、IR容器深度96及展开规模100000等资源边界，并在分配大展开树前检查；循环依赖和资源超限必须明确失败。

可复用local_symbol、lower_local的表达式解析和已有环境模式，但不能整体开放lower_local所接受的条件、历史或状态形式。无需新增语法关键字；不得删除symbol中所有局部量拒绝来替代准入。

现有[ir.py](../../src/evas/ir.py)的Affine及Binary足以表达本子集，采样结果仍由原Assignment写入State。当前树没有EventAffine或event_ir.py。本步原则上不新增运行时IR节点或schema版本；若最终设计改变序列化字段，再单独评估兼容，不能在设计阶段假定字段变化免费。

### 一个具有独立答案的首批微例

下面借用DFF原件的阈值链，加入模拟采样量以隔离局部量读取。它是待物化的标准VA片段，不是原件或已运行模型；完整夹具的电压输入均明确声明为input，输出沿用现有对地电压路径。

```verilog
analog begin
  @(initial_step) held = 0;
  vh = V(vdd);
  vl = V(vss);
  vth = (vh + vl) / 2;
  sample_value = 2 * V(vin, vss) + 0.1;
  @(cross(V(clk) - vth, +1, 5f, 1n)) held = sample_value;
  V(out) <+ transition(held, 0, 50p, 50p);
end
```

令x=t/ns，在0至4ns内使用独立PWL输入：V(vdd)=1.2+0.05x V，V(vss)=0.2 V，V(clk)=0.3x V。在触发附近令V(vin,vss)=0.1+0.02x V。由`0.3x=0.7+0.025x`直接得到事件时刻为28/11 ns，保持值为221/550 V，约0.4018181818 V。在3ns至3.02ns将V(vin,vss)从0.16V线性改为0.6V，此后保持，输出保持值仍不变。

再设一例CLK恒为0.8V、vss=0.2V、vdd=1.6-0.2x V，供电下降独自使守卫在1ns上穿；它检出只监视clk或冻结阈值的错误。每个输入在指定区间后按公开夹具保持或结束，避免额外未声明边沿。

这些有限1.8V范围、50ps输出边沿微例建议沿用首轮时间预算：每后端事件误差不超过0.1ps、配对不超过0.2ps；保持平台误差不超过0.1mV、边沿区不超过5mV，配对电压预算加倍。第一例的采样量斜率为0.04V/ns，0.1ps定位误差对应4µV采样误差，需和其余电压误差共同计入预算。这是解析推导与拟定验收，不是精度已达标；更大增益或不同输入域另定消费者误差合同。

## 第十二轮：第2步的参数化多路timer时钟

### 原件决定首个完整候选的形状

主要来源是从tangxy服务器目录恢复的[CLOCK_VA_SAMPLE_1800n原件](/Users/bucketsran/Documents/TsingProject/research/vaEVAS/legacy/output/veriloga-source-recovery-20261003/originals/research-group/tangxy/Documents/Design_2021/2021_ZOOM_NSSAR/CLOCK_VA_SAMPLE_1800n/veriloga/veriloga.va)。本轮SHA256再次与恢复catalog匹配。保留其1.1V电平、1800ns周期、20ps上下沿、五个参数化genvar循环及全部六路输出，不用v3中缩短并展开的solution替代。

默认展开为32个周期timer调用点。下表是原十进制定时算式的设计日程，单位ns，所有时刻还可加1800m，m为非负整数；它不是实际后端落点记录。

| 状态 | 置高起点 | 置低起点 |
| --- | --- | --- |
| rst | 0 | 20 |
| s | 20、620、1220 | 56、656、1256 |
| ss | 20、620、1220 | 70、670、1270 |
| nc_az | 52、652、1252 | 56、656、1256 |
| nc | 58、658、1258 | 68、668、1268 |
| conv | 72、672、1272 | 610、1210、1810 |

20ns处rst置低、s/ss置高，是不同状态的同时更新。最后一个conv脉冲跨到1810ns；不能把1810取模为10后在首次周期制造一次关断，也不能在1800ns重置全体状态。

原件有两项须公开处理的来源兼容问题。其initial_step体内对五个端口作零电压贡献，既没有给六个状态显式赋值，也未包含CONV；[LRM 2.4 §5.6.5](https://www.accellera.org/images/downloads/standards/v-ams/VAMS-LRM-2-4.pdf)不允许事件控制体内贡献。其voltage声明也不是electrical的拼写别名：恢复的[disciplines.vams](/Users/bucketsran/Documents/TsingProject/research/vaEVAS/legacy/output/veriloga-source-recovery-20261003/originals/cadence-support/SPECTRE211Hotfix/ahdl/disciplines.vams)将前者定义为只有potential的signal-flow discipline，后者同时有potential和flow。该头文件是恢复环境旁证，不证明原作者当时加载的确切版本。

建议首个完整候选采用明确标注的标准整理版：保留原件与差异记录，改为六个状态的显式零初始化，贡献保留在事件外；对本阶段的六个对地理想电压输出使用electrical接口。后一项是接口适配，不宣称普遍等价或已经支持voltage discipline。所有后端使用同一整理文件，所有时序参数及表达式保持；完整原件原样支持继续单列。此处仅提出整理方案，尚未生成VA文件。

### 首版支持子集

建议新增纯timer、无输入cross的平坦标量时钟入口。起点、正周期、容差和启用设置由实例参数在编译时绑定；genvar有限展开，不引入运行时循环。状态及transition目标使用现有保持量路径，输出为对地电压，延迟为0、边沿为有限正常数。动态改期、取消、事件OR、冲突写者和跨事件读写依赖留在后续步骤。

原件需要的是`timer(0,P)`且P>0，代表零起点周期日程；单参数`timer(0)`或`timer(0,0)`是单次日程。本步建议以周期形式为完成线，单次形式作为既有Rust/参考后端的初始化旁证，不因此宣布XSPICE已支持单次。不能只移除period>0检查，否则游标递增后仍会反复得到同一单次期限。

建议后端展开后的事件调用点上限为64，保留现有更严格的共享展开资源限制。验收包含默认32路，以及每组4脉冲、周期2400ns的42路变体，用来检查参数生效及跨32位的事件身份。零次循环、每组1脉冲以及实例间不同参数另设小例。超过上限明确拒绝，不截断或复用事件位。该容量不自动放开64路timer与cross/OR的任意混合；原有cross子集继续单列回归。

同一路的置高、置低事件在不同时刻写同一状态是必要能力。只有同一批次中冲突或有读写依赖时才拒绝，不能把“一个状态有多个timer写者”整体禁止。参数变化后重新检查日程与依赖；默认配置无冲突不证明所有width、interval、num和period组合都安全。允许start大于period，不能为简化日程要求所有起点落在首周期内。

### 零时刻应构造最终初态，不补造启动边沿

建议限定常量初始化前缀，再放各个timer。先安装初始化状态，再执行精确零起点的独立timer批次，最后用最终状态建立transition种子和首个接受帧。若采用默认原件参数，初始RST就是1.1V，其余五路为0；RST在20ns才开始下降。需要观察启动上升沿时使用正init_delay，不能把零起点偷偷改成一个极小正数。

这与现有Rust合同一致。[test_transition_initialization.py](../../tests/test_transition_initialization.py)和[历史Spectre精简收据](../../../experiments/backends/support/20261014-initial-transition-seed.json)保存了initial_step赋0、固定timer(0)赋1、transition直接从1开始的有限例子。该收据没有验收本轮32路时钟或ngspice入口。LRM的initial_step会在首点求解阶段活动，不能把“物理上一次初始化”理解为“求解器只调用一次”；transition在DC直接传递目标值，见§5.10.2及§4.5.8。

每次DC/Newton试算可以重建候选初态，但接受的零timer效果只能出现一次。首个瞬态调用必须继承正确状态、已消费的零周期序号和transition种子，不能再次执行零timer或重新归零。初始化候选失败后允许重算，不得由静态诊断标志记住“已经启动”。正起点即使很小，也不能仅因落入timer容差而归入初始化批次。`.tran uic`和分析类型过滤的initial_step继续不在本步内。

### 同刻、浮点近邻与宿主共点分别记录

独立性至少要求两个事件的写集互不相交，且任一事件的写集不与另一事件的读集相交；定时参数也必须固定。一个块内已有顺序赋值照常执行。对本时钟中只赋常量/参数的独立块，先取得整批待执行身份，分别计算更新，再发布整批状态及六路transition更新。不能先发布半批输出给电路，也不能依靠源码顺序给冲突写者选赢家。初始化前缀与零timer之间的已定阶段顺序不等于放开任意跨块优先级。

还需区分三种时间概念：原定时算式的设计日程、编译后start+k*period的名义日程、实际宿主执行点。当前[syntax.py](../../src/evas/syntax.py)把字面量先转换为float再乘单位后缀，[lowering.py](../../src/evas/lowering.py)逐次折叠常量；TimerTrigger只保留float字段。按该换算方式，56ns的两式相等，但656ns分别为6.560000000000002e-7s与6.56e-7s，相差约1.059e-22s；1256ns也出现约2.118e-22s差异。本轮最初用Python科学计数法得到的56ns示意差异没有遵循词法换算，已更正，不作为编译结果引用。没有执行编译，数值是依源码运算规则作的独立算术核对。

因此，不能通过`abs(t1-t2)<ttol`宣称两个名义日程精确相同。真正相等的名义日程共享一次批次，但每个独立事件体仍各执行一次，不能按OR去重。数学上相等而经折叠变成近邻的源码不在本步改写为新的精确十进制数值合同。

允许一个有限例外作为宿主适配：完全独立、只驱动本阶段有限边沿时钟输出的近邻事件，可以在同一宿主点分别执行，只要该点满足每个事件自身的合法时间窗口及本轮误差预算。记录保留各自名义时刻、调用点和周期序号，明确标为独立近邻共点，不计为精确同刻证明。正容差窗口重叠是必要条件，不足以独自证明独立性或输出误差合格。缺省容差仍按原写法的非提前要求检查。存在状态读写依赖、可观测的中间离散状态或无法满足消费者预算时，必须分开；宿主无法分辨则明确失败。这项许可已由Q16接受，不扩展到Q10的取消优先级或未来真实电路的即时反馈闭包。

## 第十三轮：第3步的多cross、事件OR与共享状态

状态：第2步Q14至Q16及其范围、验收已接受。本节细化Q13，仍是待讨论的第3步合同，不实施。事实基于恢复工作树IR23和两份课题组恢复原件；原件哈希与恢复catalog匹配，不外推作者身份或历史v3汇总包的字节身份。

### 原件中的顺序有可观察含义

[PFD原件](/Users/bucketsran/Documents/TsingProject/research/vaEVAS/legacy/output/veriloga-source-recovery-20261003/originals/research-group/zhangsh/VerilogA/PFD/veriloga/veriloga.va:35)先处理IN1上升，再处理IN2上升，两个块共同读写state、hide_state和Toff。假设初态state=0、hide_state=0，两路cross在同一次过程求值中发生，按原顺序，第一个块令state=1，第二个块读到1，令hide_state=1并安排Toff。交换块顺序会得到state=-1、hide_state=1。两种情况下UP和DN都可能为高，所以只看这两个输出不足以验收状态可见性。这是依据源码的推导，本轮没有运行PFD。

[DFFRSHQ原件](/Users/bucketsran/Documents/TsingProject/research/vaEVAS/legacy/output/veriloga-source-recovery-20261003/originals/research-group/zhangm/TED/ted-release/ted/tools/verilog/behaviorLib/DFFRSHQ/veriloga/veriloga.va:45)先写时钟上升块，后写RN下降或SN下降的OR块。两块共用vout、vnow、td0和td。OR中两个叶触发源属于同一个事件体；时钟块则是另一个事件体。即使最终vout相同，中间读到的vnow及延迟选择仍可能不同。

这两份完整原件都不能直接作为本步整件通过线。PFD还依赖动态timer、$realtime和供电相关输出，原始边沿仅10fs；DFFRSHQ还包含voltage discipline、字符串初始化、case、输入相关初始化、随机函数及动态transition延迟。jitter默认0不等于可以不分析随机调用。第3步从原件提取多cross与共享状态、OR与条件赋值的有限夹具，保存原件与提取差异；完整原件继续保留为后续目标。

### Q13建议采用同一过程中的顺序可见状态

[Verilog-AMS LRM 2.4](https://www.accellera.org/images/downloads/standards/v-ams/VAMS-LRM-2-4.pdf)的§5.2、§5.3规定analog顺序语句的执行顺序；§5.10规定模拟事件控制不阻塞过程；§5.10.1允许OR中的任一事件激活共用语句。这支持源码顺序的解释，但不替宿主证明两个近邻根属于同一次发生，也不提供跨模块执行优先级。

本步建议只接收一个实例内的单一analog过程，初始化前缀及第1步纯输入别名前缀之后是有序事件块，输出贡献置于其后。对已确定为同一次逻辑时刻的触发集合，依次执行源码中被激活的事件体。每次赋值立即更新本次候选状态，后面的语句和事件体读取更新后的值；同一状态被多次赋值时，以最后实际执行的赋值为最终值。没有被触发的块跳过，不因后面状态发生变化而倒回重跑。

过程完成后，以最终状态计算输出贡献与transition目标，构造完整候选；只有宿主接受该步，才能提交接受帧。此限制避免在处理半批事件时安装临时输出。它不涵盖事件之间交错放置输出贡献、一般普通持久变量赋值或多analog过程。未来若支持这些源码形状，必须保留它们各自的执行位置，不能声称本步的“最后统一输出”覆盖一般Verilog-A。

例如，q和seen都初始化为0，下面两个块同刻触发时，结果为q=1、seen=1；交换块位置后为q=1、seen=0：

```verilog
@(cross(V(a)-0.5, +1, TTOL, VTOL)) q = 1;
@(cross(V(b)-0.5, +1, TTOL, VTOL)) seen = q;
```

这里保留两个互不替代的规则。真正同刻使用源码顺序，异刻始终使用物理先后。如果b先到，即便代码写在后面，seen仍读到0。不能由timer/cross类别、上升/下降方向或状态名称暗设优先级。Q10未来所需的关断、输入、开通顺序应由同源VA表达，动态日程的有效性仍要在第4步解决。

第六轮Q13还提出了普通语句`entry=q`的有限入口快照。本步建议暂不将它纳入，只支持事件体内部的顺序状态读取，以及第1步已接受的纯输入普通别名。前端保存过程顺序，为后续快照扩展留出位置，但不能把`entry=q`按纯表达式替换成每个读取点的当前q。

事件体限定标量real/integer状态、有限算术赋值、if/else、比较和逻辑及三元选择。读取已准入输入和当前状态，整数范围保持现有检查；不扩大到事件内循环、随机/历史函数、输出或内部电气求解节点读取。条件分支的支持不等于任意非线性表达式均可进入XSPICE。

### 触发集合、OR去重与时间先后

建议cross守卫继续限定为输入和参数的仿射表达式，可通过第1步的普通别名展开，不读本次事件会修改的状态或模型输出。timer仅使用第2步固定周期形式。这样可先确定本次活跃叶集合，再执行共享状态更新。事件体改阈值、动态timer改期、取消和新产生同刻事件的闭包都不纳入，不能在这些情形继续使用一次冻结的触发集合。

多个cross的方向覆盖+1、-1和0，容差按每个调用点分别保存。第一批采用可独立求根的PWL连续穿越，初态不在阈值上，不从这些夹具外推任意零平台、相切或不连续跨越。支持cross OR、固定周期timer OR，以及两者混合的有限平坦OR；initial_step与普通触发源的混合不因此扩大。保留已有`or`写法，标准的逗号别名和嵌套事件不作为本步完成线。

同一个OR体在同一次发生中只执行一次，仍保留所有触发叶身份。两个独立事件体即使使用同一守卫，也各自执行一次。OR两个叶在不同时刻触发，事件体执行两次，不能因ttol窗口重叠而去重。建议总容量沿用64个展开后的触发调用点，按叶计数，不按OR块计数；块、叶、实例和每次发生的身份分别记录。

同一个宿主TIME、重叠容差或很小的时间差都不足以证明精确同刻。现有Rust有根证书与OR分组基础，ngspice出口须建立自己的有限定位和观察依据。先验收同输入、重复及比例守卫，再验收具有独立解析答案的同步双输入。不同输入的数学同刻能否在宿主中稳定保留，是必须实测的问题，不能在设计文档中宣布已解决。出现无法判别的共享状态近碰撞时须细化定位或明确失败。

Q16的独立近邻共点只适用于已接受的有限独立时钟输出；本步有读写依赖的事件、同一OR体的不同发生不适用。时间误差即使小于0.1ps，只要使seen读错、分支改变或事件少执行一次，仍判失败。
