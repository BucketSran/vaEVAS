# Example：用 Verilog-A 自动测量 ADC 的 DNL/INL

状态：首题本地原型已制作，实际 Spectre/Harbor 校准待运行。原创任务、参考测量器与独立 checker 见 [va08](../tasks/va08-adc-linearity/SOURCE.md)。原设计稿的 Cadence 源码只说明工程用途，不进入原创资产。

## 工程用途与来源

工程师需要一个能驱动 ADC、等待转换、读取输出码并统计非线性的仿真测量模块。若激励和采样顺序错误，模块仍可能输出一张看似合理的结果表。

参考资产是 Cadence [adc_dnl_8bit__icadvm201.va](../reference/veriloga/cadence/measurement_stimulus/adc_dnl_8bit__icadvm201.va)，其[安装来源](../reference/veriloga/SOURCES.md#cadence-measurement_stimulus-adc_dnl_8bit__icadvm201)已记录。原文件按 4096 次转换统计 256 个码，并对内部 254 个码归一化。

本例保留“激励、采样和统计”的用途，重新明确转换延迟、输入采样点、文件格式与端点约定，并增加与本合同一致的累计 INL。它不是原文件的逐字翻译，也不声称原文件已经在本例环境中验证。

## 给模型的题面示例

> 编写一个 Verilog-A 测量模块，为提供的八位 ADC 产生均匀输入扫描和转换时钟，等待输出有效后读取 4096 个码，并输出各内部码的命中次数、DNL 与累计 INL。测量结果必须符合下面的定义；不能从被测模型内部读取阈值或直接使用预存结果。

### 提供什么与提交什么

提供 ADC 端口、时序合同、公开的理想 ADC 和若干非理想开发实例、仿真入口、输出文件格式。候选可以运行开发仿真；隐藏实例使用不同但满足公开合同的转换阈值与延迟。

提交 `/work/dut.va`，模块 `adc_linearity_tester(vin,clk,dout,done)`，其中 `vin/clk/done` 为输出，`dout[7:0]` 为输入，全部为电气端口。`dout[7]` 为最高位。

本题允许 VA 写 `/work/output/linearity.csv`，这是必须交付的测量结果。目录由环境创建。文件只包含本次仿真计算的结果，不允许读取被测模型文件或隐藏配置。输出格式为标题 `code,hits,dnl,inl` 及按码序排列的 254 行，码号为 `1..254`。

经用户批准补充 `/work/output/samples.csv`，标题 `index,time,code`，恰好4096行，
索引为0..4095，时间为实际读取时刻 `$abstime` 的秒数，码为当次实际解码结果。
否则少计首末端码或立即读旧码可能完全不改变内部254行，无法满足错误版本校准。
checker核对每行时间、实际原始总线及阈值真值，不以候选报告单独作证。

### 激励与读取时序

拟设 `M=4096`，`vmin=0 V`、`vmax=1 V`。第 `n` 个采样点为：

`x_n = vmin + (n+0.5)*(vmax-vmin)/M`，`n=0..M-1`。

使用区间中点，避免在扫描端点重复取样。第一次扫描在公开的 `t0` 开始；随后每个周期 `T` 执行：

| 时刻 | 操作 |
| --- | --- |
| `t0+n*T` | 把输入目标更新为 `x_n` |
| `t0+n*T+0.25*T` | 产生一次 ADC 采样时钟上升沿 |
| `t0+n*T+0.50*T` | 时钟下降 |
| `t0+n*T+0.75*T` | 读取本次 ADC 输出码并计数 |

输入与时钟使用 `1 ns` 有限边沿，`T` 拟为 `1 us`，`t0=5*T`。表中的输出变化时刻指目标值更新时刻，ADC 的实际采样边沿按时钟电压穿过阈值计算；读取时刻使用表中的绝对时间。环境保证 ADC 在实际采样边沿后 `0.25*T` 内完成所有数据位建立，并保持到下次转换；初始阶段复位由固定外围环境完成。

逻辑低、高为 `0/vlogic`，阈值为 `vlogic/2`，`vlogic` 默认 `1 V`。初始化 `clk=0`、`done=0`、`vin=x_0`。第 4096 次读取完成后输出结果并拉高 `done`，之后不再增加计数、不重复输出、不继续发转换时钟。稳态 `vin` 保持最后一个采样值。

### DNL/INL 的精确定义

记 `H_k` 为输出码 `k` 的命中次数，包含全部 `k=0..255`。先确认 `sum(H_k)=4096`。

只对内部码 `1..254` 定义本题指标：

`H_int = sum_{k=1..254} H_k`

`DNL_k = 254*H_k/H_int - 1`

`INL_k = sum_{j=1..k} DNL_j`，约定 `INL_0=0`。

这是一种明确的内部码归一化及累计约定，不与其他端点拟合或最佳直线 INL 定义混用。首版所有被测实例保证 `H_int>0`。端码 0 和 255 计入总次数，但不输出其 DNL/INL。

零命中的内部码得到 DNL 为 `-1`。有限扫描未命中一个码，并不单独证明其物理码宽严格为零；本题按有限扫描结果评分，不要求做没有测量分辨率支持的物理断言。

## Checker：测量程序不能自己给自己作证

使用转换阈值已知、单调、无随机噪声的合成 ADC 作为第一版被测器件。其转换定义为 `q(x)=sum_j [x >= T_j]`，`j=1..255`；非递减的重复阈值允许构造零宽码。这里的量化约定属于本题被测器件，与其他 ADC example 不混用。

对 ADC 阈值、扫描点和延迟先独立校准。输入实际达到的采样电压与阈值应有足够数值间隔，避免把模拟求解舍入变成不稳定的码翻转。阈值来自出题器件，不能由候选提供。

| 层次 | 独立检查 |
| --- | --- |
| 激励协议 | 输入确实遍历全部 4096 个规定点，每点恰好一次转换，建立及读取时刻正确 |
| 原始观测 | 从保存的 ADC 总线波形，在规定读取时刻独立解码，重算全部 `H_k` |
| 已知真值 | 根据隐藏阈值和规定输入点计算理论码流，与实际 ADC 波形确认一致 |
| 输出结果 | 检查 CSV 码序、整数命中数、DNL/INL 数值、无重复或遗漏行 |

命中次数要求整数完全相等；DNL/INL 的文件数值容差拟为 `1e-6 LSB`，候选应输出足够精度。首题冻结稳态电压容差为2 uV、时钟/done穿越时间为0.2 ns、读取记录时间为1 ps，实际 Spectre 校准仍待运行。若 ADC 实际行为不符合其公开转换合同，记录环境问题，不能用该场景判候选失败。

Checker 同时核对输入和时钟，防止候选只访问少量码却按理想分布报告结果。既不能只比较 CSV，也不能仅凭候选的 `done` 判断完成。

### 隐藏条件与错误版本

隐藏条件覆盖均匀阈值、交替宽窄码、零宽码、不同端码占比以及合法范围内的转换延迟。完整输入与全部码是评价单位，不只挑最大 DNL 那一个数。

校准使用以下错误版本：时钟触发时立即读取旧码、少计第一或最后一次转换、用全部 4096 个样本归一化内部码、把输入位序颠倒、只输出理想零 DNL。各错误都应被相应测试拒绝。

## 难度假设与落地缺口

本例考查仿真测量流程、时序和统计定义。统计公式本身很简单；没有证据说明强模型会在允许调试后持续失败。

已制作首题已知阈值的 ADC 环境、独立 checker、公开数据格式和参考测量器。仍需要实际 Spectre 与 Harbor 校准，以及模型试跑。后续若接真实晶体管 ADC，应先验证输出时序和测量精度，并将统计不确定性纳入新合同；本例的合成被测器件不能标成真实电路测量。
