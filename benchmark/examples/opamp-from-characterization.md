# Example：根据电路表征数据建立运放宏模型

状态：设计稿，2026-10-04。真实运放电路、数据集和新 checker 尚未取得或实现；没有执行本题，也没有测得模型提取成绩。下文数值是拟议验收参数，须先验证数据覆盖和参考实现可达。

## 工程用途与来源

工程师已有晶体管级运放，希望建立一个便于系统仿真的 VA 模型。模型需要在规定负载和信号范围内保留端口行为，使后续闭环建立过程的判断仍然可信。

Cadence 的 [opamp.va](../reference/veriloga/cadence/analog/opamp.va)提供有限输入电阻、偏置、主极点、压摆限制、输出电阻和软限幅的现成模型结构，来源见[总表](../reference/veriloga/SOURCES.md#cadence-analog-opamp)。它是本例的用途与结构参考，**不是某个已取得的晶体管运放的测量真值**。

既有[带负载运放题](../tasks/va06-loaded-opamp/instruction.md)直接给内部方程。本例改为提供表征数据，由候选选择模型结构和参数。若先用 Cadence 模型生成合成数据做原型，必须标记“合成模型辨识”，不能称为真实电路提取。

## 给模型的题面示例

> 根据提供的 DC、AC、瞬态及端口电流表征数据，建立一个 Spectre 兼容的 Verilog-A 运放宏模型。它应在公开工作范围内预测未提供的激励与负载响应，并能接入给定反馈网络。你可以选择内部模型阶数及等价实现，不需要恢复原电路拓扑。

拟采用接口 `opamp_fit(vout, vref, vin_p, vin_n, vdd, vss)`，全部为电气端口。电压统一给出参考节点，端口电流统一规定“流入模型为正”。固定采用一个器件实例、一个温度和一组供电；本题不要求从单个角落的数据外推其他工艺或温度。

### 提供什么

| 材料 | 必须包含的内容 |
| --- | --- |
| `interface.md` | 端口顺序、参考节点、供电、允许连接方式与初始条件 |
| `data/` | DC 转移、输入电流、输出负载扫描、AC 复数响应、小信号与大信号瞬态 |
| 每组数据的配置 | 激励、反馈网络、外部 R/C、测量单位、时间轴及参考仿真容差 |
| `envelope.json` | 测试工作范围、指标定义、绝对/相对误差容差 |
| 公开仿真网表 | 单位增益和增益为 2 的反馈连接，以及多个已知负载 |

这些文件尚未制作。拟议工作范围为固定 `1.8 V` 供电、输入共模 `0.7–1.1 V`、负载 `20–100 kΩ` 与 `0.5–5 pF`。频段及输入幅度需根据实际电路表征确定并公开；不能通过隐藏的超范围信号要求模型预测未观察到的物理效应。

提供的数据必须足以区分输入偏置、有限增益、动态响应和负载影响。例如，只给一个负载的一条阶跃，不能再把唯一识别输出阻抗或所有高阶极点作为验收要求。

### 交付物与允许操作

提交 `/work/dut.va` 和简短的 `model_notes.md`，说明模型适用范围和所采用的状态/参数。解释用于审计，自动通过以电路行为为准。

允许读取公开数据、做参数拟合、使用查表或解析关系、运行公开仿真。最终模型不能识别测试文件名、按绝对时间重放某条训练波形，或读取隐藏数据。模型内部结构可以与任何参考实现不同。

本例要求输入支路电流和有负载的输出响应与数据相符。供电电流、噪声、温度变化和上电过程不在首版合同内；这些行为没有相应表征数据时不加入隐藏评分。

## Checker：预测未见条件下的行为

先根据真实电路生成并冻结完整表征集合，再按**整组激励、负载和连接配置**划分公开与隐藏数据。不能把一条波形随机拆成训练采样点与测试采样点。隐藏条件在公开范围内，时间起点和输入触发方式完全已知。

| 检查层次 | 检查内容 | 拟议判据 |
| --- | --- | --- |
| DC 与端口电流 | 多个工作点的输出及输入电流 | 每点使用公开的 `abs_tol + rel_tol*abs(reference)`；电流绝对容差由实际数据尺度确定 |
| AC 响应 | 复数增益及幅相 | 增益误差不超过 `0.5 dB`、相位误差不超过 `3°`；低幅值区改用预先公开的复数绝对误差 |
| 瞬态波形 | 小信号、大信号、负载变化 | 最大电压误差不超过公开输出范围的 `1%`；时间轴固定，不允许评分时任意平移对齐 |
| 应用连接 | 单位增益和增益为 2 时的建立过程 | 采样时刻误差达标，建立时间与参考差异不超过 `5%` |

相位差按模 `360°` 的最小角差计算。相位评分的幅值下限、误差分母和每组波形的检查窗口必须公开并在发题前冻结。建立时间定义为：从输入变化开始，到输出进入并持续留在参考最终值附近的公开误差带；容许暂态峰值和持续判定窗口也必须明确。未在窗口内建立的案例单列失败，不能省略其建立时间。

这些数字不代表已有实验精度。参考实现必须先同时达到所有指标；若真实电路要求更复杂的行为，应补齐公开数据或缩小适用范围，再确定任务。

### Checker 校准与失败解释

校准时加入以下不合格模型：纯静态增益、忽略输出电阻、只拟合小信号但不处理大信号，以及直接重放某条公开波形。分别确认动态、负载、幅度和输入变化测试能发现问题。

若多个模型在全部指定条件下等效，均通过。不能通过检查内部极点数、某个参数值或与 Cadence 源码的相似程度排斥有效答案。

仿真速度在首版只记录，不设置性能门槛，避免把“提取正确模型”和“优化实现”混成一个无法归因的分数。性能目标可另用[仿真优化事例](opamp-simulation-optimization.md)定义。

## 难度假设与落地缺口

预期考查数据解释、结构选择、参数识别和跨条件泛化。是否难取决于真实电路的行为、数据覆盖以及允许的误差；增加表格行数并不会自动产生研究难度。

缺少的核心资产是真实运放网表或可信的授权表征数据。随后需要制作数据说明、划分条件、训练一个合格参考模型并实现 checker。它是有潜力的方向，当前不是可运行题目。
