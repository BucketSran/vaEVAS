# Example：为已有 ADC 模型增加复位、掉电与唤醒

状态：设计稿，2026-10-04。已有课题组量化模型，但新增模式是本例拟议的工程需求，不是已经恢复的历史需求；扩展实现和 checker 尚未制作或运行。

## 工程用途与来源

系统验证需要在 ADC 转换过程中复位或关闭模块，并在重新启用后继续转换。测试环境要能区分有效结果和旧数据，还要防止已排队的输出更新在掉电后重新出现。

原始资产是 [ideal_adc_vref_thresholds.va](../reference/veriloga/lab/data_converters/ideal_adc_vref_thresholds.va)，历史工程来源见[总表](../reference/veriloga/SOURCES.md#lab-data_converters-ideal_adc_vref_thresholds)。它在时钟上升沿采样差分输入，用 `LVL-1` 个门限量化，并以**电压数值表示整数码**，不是二进制电平总线。

原模型没有复位、掉电或 VALID 端口。本例在保留这种输出编码及量化规则的基础上新增状态。不能把原模型缺少新需求称作历史故障。

## 给模型的题面示例

> 扩展所附 Verilog-A ADC 模型，增加高有效复位 `RST`、高有效掉电 `PD` 和结果有效输出 `VALID`。保持正常工作时的差分采样、量化门限和延迟行为。掉电或复位必须取消尚未发布的转换结果；唤醒后只接受新的采样。

### 提供什么与提交什么

提供原始源码副本、量化合同、模式时序图、公开网表及可运行的开发 checker。提交 `/work/dut.va`，模块改为 `IDEAL_ADC_EXT(Digital,Vip,Vin,CLK,RST,PD,VALID)`，全部使用电气端口。最终只替换该模型。

保留原有 `Vref`、`LVL`、`Vtrans_clk`、`Tdel`、`Trise`、`Tfall` 参数，新增 `vlogic` 和 `Twake`。原源码中的 `seed`、`m_sigma` 未参与其量化运算；首版如保留这两个兼容参数，也明确不要求噪声行为。

### 必须保留的量化规则

设差分采样值为 `s=V(Vip)-V(Vin)`，`LSB=2*Vref/LVL`，门限为 `T_j=-Vref+j*LSB`，其中 `j=1..LVL-1`。

输出整数码为 `q(s)=sum_j [s > T_j]`，范围 `0..LVL-1`。**恰在门限时使用严格大于号，取门限下侧的码。** 差分输入越界时自然饱和为端码。稳定时 `V(Digital)=q V`，不能擅自归一化到电源电压。

### 新增状态合同

以下时间数值是拟议题目参数，参考实现通过后再冻结。`VALID` 使用 `0/vlogic` 电平，逻辑判断阈值为 `vlogic/2`。

| 状态或事件 | 必须发生的行为 |
| --- | --- |
| 初始化，两路控制均为低 | `Digital=0`、`VALID=0`，立即可接收第一个采样时钟 |
| 正常采样 | `CLK` 上升穿过 `Vtrans_clk` 时锁存差分输入；`VALID` 置低，输出保留上一结果直到提交 |
| 结果提交 | 采样后 `Tdel` 开始把 `Digital` 平滑更新为该次采样的整数码；建立后 `VALID` 拉高，保持到下一次采样或控制事件 |
| `RST=1` 或 `PD=1` | 禁止采样、取消所有未提交结果；输出归零、`VALID` 拉低并保持，不得因旧定时事件重新变化 |
| 两路控制都从禁用状态恢复为低 | 等待 `Twake`，期间忽略时钟；等待结束后只接受之后的新上升沿，不提交禁用前的结果 |
| 唤醒期间再次禁用 | 取消本次唤醒；下一次恢复时重新计算完整 `Twake` |

普通结果输出使用原有 `Trise/Tfall`。`VALID` 的拉高目标时刻为采样时刻加 `Tdel+max(Trise,Tfall)`，再使用公开的 `50 ps` 电平边沿；`Tdel=0` 时不要求可观测的零宽 VALID 低脉冲。

禁用事件触发后，输出归零和 VALID 拉低的目标变化必须在 `1 ns` 内开始，按各自规定边沿建立。这项取消语义优先于原来的输出延迟；不能简单让旧 `transition` 队列继续发布结果。

拟议测试范围：`LVL` 为 `8/16/32`，`Vref` 为 `0.5–1 V`，`Tdel` 为 `0–100 ns`，`Trise/Tfall` 为 `50–500 ps`，`Twake` 为 `50–200 ns`。时钟周期至少 `500 ns`，因此正常状态下不要求多笔并行转换。

控制边沿与采样、提交、唤醒截止时刻至少相隔 `2 ns`，首版不考查同刻事件的未定义排序。输入在采样窗口内稳定，但采样后可以改变，以验证模型保存了采样值。

### 兼容性边界

原模型没有显式初始化输出。本例明确初始化为零，兼容性回归从首个有效采样结果开始比较。原有正常工作功能不包括新定义的掉电和唤醒状态。

这个 ADC 的 `Digital` 是用于仿真的数值编码输出；它不代表真实 ADC 的功耗、电源电流或物理输出驱动能力。PD 在首版只定义功能状态，不加入没有依据的功耗评分。

## Checker：新行为和旧行为同时通过

独立 Python 事件模型按门限公式计算采样码，按模式合同维护有效的待提交事件。期望值不能只靠运行候选或把原模型的未知初始化当作真值。

| 测试 | 可以发现的问题 |
| --- | --- |
| 两路控制始终为低，改变 `LVL/Vref/Tdel` | 量化或参数兼容性被改坏 |
| 恰在门限以及门限两侧、超量程输入 | `>` 被改为 `>=`、饱和端码错误 |
| 采样后、提交前改变输入 | 提交时重新读取输入而非使用采样值 |
| 采样后、提交前掉电或复位 | 旧结果在禁用期间泄漏 |
| 唤醒窗口内连续时钟 | 提前恢复采样 |
| 唤醒中再次禁用，之后恢复 | 旧唤醒定时器导致提前启用 |
| 多轮转换、禁用、恢复 | 状态残留或只支持一次复位 |

过程检查覆盖合法电平、更新时间、VALID 与输出建立的关系。数值误差和边沿容差在参考环境校准后公开。对门限相等的测试，使用一致且可精确构造的数值，避免把输入构造的舍入误差算成模型错误。

Checker 校准使用改变门限比较符、忘记取消旧结果、忽略 `Twake`、唤醒后自动发布旧码等错误版本。全部正常模式及扩展模式均通过才算任务完成。
