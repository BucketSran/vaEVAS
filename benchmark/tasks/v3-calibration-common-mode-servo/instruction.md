# 给健康差分前端增加真实输出共模伺服

在固定差分前端中加入共模控制。根据两路实际输出测量共模并调整真实执行码，保留差分增益和正常信号。不能直接驱动、替代或使两路输出相等。

接口为 `calibration_controller(outp,outn,cal,enable,rst,code)`，参数mode=1。cal在此模式不限制更新。固定前端差模为2×输入差模，静态trim -.02V恰好抵消固定offset .02V。共模为.5+cmoffset+.002×actuator×code。actuator 范围.8到1.2。code 为 -64到64的整数，每路输出削顶到.05到.95V。enable低保持码，rst高清零；输出码在100ns内建立。整数码检查允许过渡沿上的非整数值持续至多150ns作为数值裕量。

差分输入幅度不超过.06V。cmoffset在 -.07到.07V内慢变，变化率不超过1400V/s；中间区间允许绝对值不超过.5V的大共模扰动，要求限幅后恢复。正常运行、暂停后恢复、reset后恢复的稳定窗口均需通过。在这些窗口，实际 `(outp+outn)/2` 与.5V之差最大8mV，同时 `outp-outn-2*(inp-inn)` 最大12mV。两路强制相等会因差模损坏失败。停启与复位码要求和轨限制与差分校准相同。

## 交付与环境

只提交 `/work/dut.va`，允许改变其中控制算法、辅助模块及连接。所有公开工程文件可读；`healthy.va` 是不可修改的行为电路环境。它没有晶体管器件数据。实际候选原字节在固定 Spectre 后端执行。编译、超时或后端证据不完整保留未评分状态，不当作语义失败。参考解和私有条件不属于公开包。

所有端口都是以地为参考的 electrical 节点。逻辑高 .9V，阈值 .45V。公开 `public-default.scs` 可供自测；隐藏条件只改变下面公布的范围，不按参考实现逐样本匹配。复位必须清除控制状态；无复位时不得偷偷周期性重新初始化。任务权重1。
