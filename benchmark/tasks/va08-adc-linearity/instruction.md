# 自动测量八位 ADC 的 DNL/INL

交付 `/work/dut.va`，其中模块 `adc_linearity_tester(vin,clk,dout,done)` 的
`vin/clk/done` 是电气输出，`dout[7:0]` 是电气输入，`dout[7]` 为最高位。
测量器必须驱动提供的合成 ADC，记录本次仿真的读取结果。不要读取 ADC 源码或预存结果。

每次仿真测量 4096 次转换。`T=1 us`、`t0=5 us`、逻辑电平为 `0/1 V`，
判决阈值为 `0.5 V`。第 `n` 次输入为 `(n+0.5)/4096 V`，`n=0..4095`。
初始化 `vin=0.5/4096 V`、`clk=0`、`done=0`。每次转换按下面的绝对时间执行。

| 时间 | 动作 |
| --- | --- |
| `t0+n*T` | 更新输入目标 |
| `t0+n*T+0.25*T` | 更新时钟目标为 1 V |
| `t0+n*T+0.50*T` | 更新时钟目标为 0 V |
| `t0+n*T+0.75*T` | 读取全部输出位并计数 |

输入、时钟与 done 的边沿时间均为 `1 ns`，没有额外延迟。
ADC 在时钟实际穿过 `0.5 V` 后采样输入，在其后 `0.25*T` 内建立全部输出位，
并保持到下一次转换。外围 ADC 初态为码 0。最后一次读取完成后写完结果并把 done
目标拉高，保持最后一个输入，停止时钟，不再增加计数或重复输出。

ADC 是单调、无噪声的八位量化器，码为 `sum_j [vin >= threshold_j]`。
重复阈值合法，可以产生零宽码。隐藏 ADC 使用相同端口及时序合同，阈值与转换延迟不同。
公开开发器件与网表在 `/work/public/`。完整仿真依赖外部 Spectre；任务镜像不提供商业工具。

结果目录 `/work/output` 已创建。写以下两个文件，仅允许对这两个固定路径使用写模式，
不允许读取外部文件、调用系统命令或引入其他 VA 文件。可包含 `disciplines.vams` 与 `constants.vams`。

- `samples.csv` 标题为 `index,time,code`，随后恰好 4096 行。按实际读取次序输出
  `index=0..4095`、读取时刻的秒数、实际解码的整数码 `0..255`。不要以计划时刻替代 `$abstime`。
- `linearity.csv` 标题为 `code,hits,dnl,inl`，随后按码序输出 `1..254` 的 254 行。
  命中数必须是整数。端码 0 和 255 也要计数，但不写入该文件。

记全部码的命中数为 `H_k`，必须满足 `sum(H_k)=4096`。
设 `H_int=sum(H_1..H_254)`，所有器件保证 `H_int>0`。
内部码的指标为 `DNL_k=254*H_k/H_int-1`，`INL_k=sum_{j=1..k}DNL_j`，`INL_0=0`。
零命中码 DNL 为 `-1`。这是有限扫描定义，不要求推断物理码宽。

验收同时检查实际输入和时钟、读取记录、ADC 原始总线及独立阈值真值。
命中数与读取码要求完全相等，DNL/INL 容差为 `1e-6 LSB`，文件时间容差为 `1 ps`。
稳态电压容差为 `2 uV`，时钟及 done 的10%、50%、90%穿越时刻容差为 `0.2 ns`，输入每次增量的10%、90%穿越时刻使用同一容差。
请输出足够的数值精度。实际 ADC 波形违反量化合同属于环境故障。
