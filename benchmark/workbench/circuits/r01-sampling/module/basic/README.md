# R01 无注入无漏电 track/hold（basic）

`r01_track_hold_basic` 是连续状态采样保持的中间档：保留有限建立和前拍记忆，
**按构造**删除电荷注入与保持漏电。它与[连续状态核心](../core/README.md)共用
状态方程结构和输入依赖采集，但保持分支 `rate=0`，存储值在保持期间严格冻结。

本目录提供可运行源码与激励台架，供电路 review 和后续出题选材。
当前没有评分 checker、Harbor 任务或模型解题实验。
2026-10-12 已在 Spectre 21.1 完成一次成功运行，实测记录见[运行记录](../../test/RUN-RECORD.md)。

## 三档阶梯中的位置

| | ideal | **basic（本模块）** | core |
| --- | --- | --- | --- |
| 采样动作 | 事件瞬时快照 | 一阶跟踪的有限建立 | 同 basic |
| 保持 | 严格冻结（代数值） | **严格冻结（ODE 状态）** | 注入台阶 + 漏电下垂 |
| 前拍记忆 | 无 | 有 | 有 |
| 考察点 | 事件语义边角 | 窗口规划：给多久、从哪来 | 全机制表征与测量 |

basic 把"建立误差"与"保持误差"解耦：短窗口结束时输出与输入的差完全由
`tau_eff(vin)` 和窗口初值决定，checker 归因时无需扣除注入和下垂的贡献。

## 与参数退化的边界

core 设 `pedestal=0`、`tau_hold` 取极大值可以逼近本模块，但 `tau_hold`
约束为有限正数（`from (0:inf)`），漏电只能压到 µV 级，不能严格归零；
本模块保持分支贡献恒为零，冻结是结构性语义，不是数值近似。
按组 README 的约定，这构成独立工程要求，因此单列源码而非对照实例。

## 接口与状态

```verilog
module r01_track_hold_basic(vin, track, rst, vout);
```

端口、`vth`、`vinit` 与 core 一致。状态方程：

```text
rst 高：  dx/dt = (vinit-x)/tau_reset
采集：    dx/dt = (vin-x)/tau_eff(vin),   tau_eff = tau_acq*(1+acq_curvature*u^2)
保持：    dx/dt = 0                        （u = (vin-vmid)/vscale）
```

参数取 core 的同名子集（`vth`、`vinit`、`tau_acq`、`vmid`、`vscale`、
`acq_curvature`、`tau_reset`，默认值一致）；`pedestal`、`tau_ped`、
`tau_hold`、`vleak` 及注入登记事件已删除。`idt(rate, vinit)` 无条件执行，
DC 与瞬态启动初值均为 `vinit`；复位、采集期间按对应时间常数 `$bound_step`。

## 运行与实测

从本目录进入对应台架目录后运行：

```sh
cd ../../test/basic
spectre tb.scs
```

台架复用 core/ideal 的同一 PWL 激励，同屏实例化 basic 与 core（`ref`）。
2026-10-12 在 Spectre 21.1（thu-sui）实际运行：返回码 0、0 错误、
17 µs 完整瞬态、5,141 接受步、5,142 保存点。保存点插值实测：

| 时刻 | 检查点 | basic | ref（core） |
| --- | --- | --- | --- |
| 5 ns | 启动保持 = vinit | 0.900000 | 0.899978 |
| 40 ns | 复位优先 | 0.899983 | 0.899983 |
| 100 ns | 复位释放后跟踪 | 0.237391 | 0.237391 |
| 148.15 ns | 第一个 8 ns 短窗残余 | 0.824900 | 0.826493 |
| 188.15 ns | 第二个相同短窗（前拍记忆） | 1.169117 | 1.171255 |
| 500.15 ns | 80 ns 长窗末 | 1.596081 | 1.596601 |
| 16.39 µs | 长保持末 | **1.596081（不变）** | 1.476102（下垂） |
| 16.9 µs | 末次保持 | 1.299577 | 1.299248 |

basic 在 0.5025–16.3995 µs 保持段的 max−min 为 4.4e-14 V，比 `vabstol=1e-7`
低约 7 个数量级：冻结是结构性的，残余只是积分器数值噪声，不是漏电模型。
basic 与 ref 在采集、复位段几乎逐位一致；两短窗与长窗末的 mV 级差异来自
ref 的注入历史进入后续窗口初值。该运行只覆盖默认参数这一套激励。

## 机制来源与适用边界

机制与 core 相同（[功能族总览](../../README.md)引用的 ADI MT-090），仅删除注入与漏电两项。
不描述输入阻抗、负载电流、噪声、孔径抖动或 PDK 条件；core 也未覆盖这些机制。是否以其出题、与 024/071 及 core 的分工属于后续审核问题。
