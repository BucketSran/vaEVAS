# 两支路时间交错采样

这份 VA 资产供 R01 电路功能与工程场景审核。两路跟踪保持单元采同一个模拟输入，
以不同相位结束采集，再交替读出真实保持节点。现有台架中，每支路每 200ns 产生一个样本，
组合序列每 100ns 更新一次，因此名义组合样率为 10MS/s。
它适用于审查高速 ADC 前端的交错采样与读出关系。本资产只包含电压域采样前端，
没有量化器、数字接口、端口电流或负载模型。

## 电路怎样保存与组合样本

`circuit.va` 的 `r01_interleaved_sampler` 实例化两份
[`r01_track_hold`](../../module/core/track_hold.va)。输入经过各支路的增益和失调后进入采集单元。
支路目标电压是 `vcm + gainN * (vin - vcm) + offsetN`。
增益和失调会改变采集状态，序列输出来自 `held0` 或 `held1`，不会重新读取 `vin`。

两支路在 `trackN > vth` 时连续采集，低电平时保持。
采集有有限时间常数，保持包含泄漏与采样基座扰动，具体动态由共享 core 定义。
进入下一次采集会使该支路尚未读出的旧样本失效。
`trackN` 的下降沿登记新样本与实际保持时刻。
`read_clk` 上升沿按支路 0、支路 1 的顺序消费新样本，并保存读出时的保持电压。
读出期间的泄漏和基座扰动因此会传到组合序列。

| 端口 | 电压含义 |
| --- | --- |
| `vin` | 两支路共同的模拟输入 |
| `track0`, `track1` | 各支路采集控制，阈值默认 0.9V |
| `read_clk`, `rst` | 上升沿读出时钟与高有效复位，阈值默认 0.9V |
| `held0`, `held1` | 两个 core 的连续状态输出 |
| `serial` | 最近一次有效读出的实际保持电压 |
| `valid` | 最近一次读出成功为 1.8V，否则为 0V |
| `branch_id` | 最近一次有效读出的支路，0V 是支路 0，1.8V 是支路 1 |
| `sample_index` | 最近一次有效读出的序号，1V 表示序号 1，首样本为 0 |
| `sample_time` | 最近一次有效样本的保持时刻，默认 1V 表示 1us |

`valid` 是读出结果状态，不是窄脉冲。相邻读出都成功时，它可以一直为高。
以 `read_clk` 的上升沿和输出 1ns 转换后的状态识别每次读出。
所需支路尚无新样本、正在采集、样本时刻不晚于上次成功样本，或复位为高时，
该次读出无效。此时 `valid` 变低，`serial`、身份、序号和样本时刻保留，
下一支路指针不前进。时钟输入不符合下面的时序约定时，不保证无丢样。
电路不缓存多帧样本，也不自动重排任意两相时钟。

初始状态和复位上升沿清空新样本标记，下一支路恢复为 0，序号为 -1，
`serial` 为 `vinit`，`valid` 为低。core 按自身有限复位动态恢复保持节点。
复位结束后必须经过新的采集与保持沿才能产生有效输出。

## 四个题目方向与交付草案

这四题共用本系统和采样 core，分别增加系统连接、幅值表征、时间表征和故障诊断工作。
以下是作者审核用伪代码，不是参考解或评分实现；题目材料尚需按各题边界拆分。
实际难度未评估，改变时钟数值或支路参数不另算新的工程方向。

### 组装两支路交错采样与有序读出系统

**扩展与集成。** 场景是把两个较慢的采样支路接成一个有序输出前端。
给定健康 core、支路输入变换、时钟与复位激励、顶层接口和读出协议；
求解者交付顶层 VA，完成实例连接、样本登记、消费和输出。
当前完整 `circuit.va` 是作者资产，出题时需要拆出保留这些待完成工作的 starter。

读出必须来自真实保持节点。每支路只有一个存储状态；新采集覆盖未读样本，
无效读请求不跳过支路、不增加序号。支路顺序固定为 0、1 交替，
不要求任意相位下自动重排、多帧队列或 ADC 量化。

```text
连接两个 core：各自采集本支路变换后的输入，公开 held[0:1]
初始或复位置位：清空 pending；next = 0；index = -1；输出复位状态
支路 b 开始采集：作废该支路旧的 pending 样本
支路 b 实际结束采集且未复位：登记 pending[b] 和 t_hold[b]

每次实际 read_clk 上升沿：
    先令本次 valid = false
    b = next
    若未复位，且 b 有新样本、仍在保持，样本时刻晚于上次成功样本：
        serial_saved = 当前 held[b]            # 读沿保存，不重新采 vin
        保存 b、t_hold[b]；index += 1；valid = true
        消费 pending[b]；next = 另一支路
    否则保持旧电压、身份、序号和 next
按约定转换时间驱动各输出；首个成功样本不要求存在上一样本
```

新增覆盖是两份连续状态与单个消费序列的协作。有限采集、漏电和注入直接复用 core，
不是新增三种模拟机制。后面的修复题应与本题保持同源关联。

### 表征两支路的增益与失调差异

**电路测试与表征。** 场景是判断两个支路在指定工作条件下是否有不同的幅值传递特性。
给定源码可读的完整系统、覆盖参考电平两侧的多电平直流激励与统一准备流程、采集及读出安排；
交付观测型 VA 模块，输出每支路的有效增益、有效失调、支路差值及拟合残差。
本题不要求设计校准环路、修改 DUT 参数，或从一个正弦输出分离全部失配机制。

使用 `serial` 的实际读出值拟合 `y - vcm = G_eff * (u - vcm) + O_eff`。
`u` 是该次采集实际观测到的输入电平，`vcm` 是公开参考电平。
结果只代表所记录的输入范围、准备过程、采集长度和保持等待条件。
有限建立、漏电和注入也可能影响拟合，不能把 `G_eff`、`O_eff` 直接称为内部
`gainN`、`offsetN` 的辨识结果；源码可读也不意味着可以复制参数代替测量。

两支路应使用可比的输入轨迹、实际采集时长、起始状态准备和保持到读出的间隔。
记录实际起始电压，核对准备是否达到约定条件；不凭“已复位”或“等得够久”假定完全建立。
当前正弦台架和失配条件可以复用，直流电平表、准备流程和可比范围还需补齐。
时偏组的读出等待不同，不能直接混入幅值比较并把差异全部归因于增益或失调。

```text
按实际复位、采集开始、保持沿和读时钟沿建立支路样本记录
每次采集开始：记录支路、实际初态、输入及准备历史
每次进入保持：保存 t_hold、实际输入参考 u、held_end 和实际采集长度
每次读沿：按协议找本次应消费的样本，保存 t_read 和 held_at_read
在约定输出观察时刻：
    若期间复位或输出被下一次读取替换，保留中断记录
    否则保存 serial 与身份；即使 DUT valid 错误也不跳过本次应有的观测
    将观测归到实际样本，核对输入、准备、窗口、读出等待及输出状态
    保留采集结束偏差、读前保持变化和最终读出偏差

对每个可比条件组、每个支路：
    使用多个不同实际输入电平及其 serial 观测值拟合 G_eff、O_eff
    报告电平范围、残差和参与记录；无足够可用电平则报告未完成
对两支路条件一致的组报告 ΔG_eff、ΔO_eff
不满足实验条件或输出协议的记录单列原因，不当成精度为零或正常拟合点
```

三阶段观测仍保留：采集结束偏差为 `held_end - u`，保持变化为
`held_at_read - held_end`，最终读出误差为 `serial(t_observe) - u`。
其中采集结束偏差还包含支路增益和失调，不能全称为有限建立残余。
这里的保持终点是读沿，不能用输出观察时刻的 `held` 替换已锁存的电压。
本题新增幅值实验与结果解释责任，复用现有失配和采样动态，不新增校准能力。

### 表征实际采样间隔与读出延迟

**电路测试与表征。** 场景是核对交错采样的实际时间分布，以及样本要等待多久才能交给后级。
给定完整系统、正常与确定性时偏激励和允许的时钟变化范围；
交付 VA 时间表征模块，报告采样间隔、各样本从保持到读出的等待和未被消费的情况。
现有支路 1 延后 12ns 的台架可复用；任务不增加随机抖动、频谱分析或时偏校准。

必须区分三个时刻：`t_hold` 是实际采集结束，`t_read` 是读沿锁存，
`t_observe` 是输出转换后按规定观察的时刻。读出等待是 `t_read - t_hold`，
观察避让不计入它。样本时间从采集控制观测，不能由序号乘名义周期反推，
也不能直接照抄 DUT 的 `sample_time`。

```text
初始或复位：开始新的记录段，不把复位前后拼成连续采样间隔
每次实际采集开始：记录起点；若覆盖未消费样本，保留该样本及覆盖原因
每次实际进入保持：
    生成本段的支路样本，记录 t_hold
    与本段上一个实际保持事件求间隔，记录两个端点的支路与样本
每次 read_clk 上升沿：
    独立按采集历史和消费协议判断本次应消费谁，记录 t_read
    若有应消费样本，记录 wait = t_read - t_hold，并推进观测端的消费状态
    否则记录无效请求及原因，不新增一个采样事件
    在 t_observe 记录 DUT 状态，与本次预期样本关联核对
    若观察被后续事件打断，保留中断原因，不接到下次读取
结束时分别列出实际采集序列、应消费序列和实际输出观测
保留覆盖、未读、复位中断与异常输出记录；按支路汇总间隔和等待
```

例如现有稳态台架的名义采样间隔是 100ns；只将支路 1 的采集窗口整体延后
12ns，会使相邻间隔交替为 112ns、88ns，同时缩短该支路的读出等待。
这是从激励安排推得的预期关系，不是本轮新测量。
幅值题研究“读出的电压怎样变化”，本题研究“何时采到、何时交出”；
两题可有不同交付，但属于同一交错系统来源。

### 修复重复样本或复位后的读出错序

**诊断与修复。** 场景是已有前端在重复读请求、未读样本被新采集覆盖，
或复位中断后，把旧数据当成新样本，造成电压与身份、序号或时刻不一致。
给定可读的故障工程、接口协议与能触发问题的激励；交付修复后的指定顶层 VA
及故障原因说明，保持健康 core 和外部协议。

目前只有健康资产，尚无选定的故障 starter 和复现记录，因此先保留为候选。
之后按具体故障选择必要场景，不把列出的所有异常硬凑进一道题。
仅修正一个 `branch_id` 标签可以作为基础变体，不能替代样本生命周期的诊断。

```text
用给定复现输入追踪：实际采集 → 待消费 → 读出 / 覆盖 / 复位作废
找出首次出现重复消费、旧样本存活或元数据与电压分离的事件
在指定顶层中修复状态更新：
    新采集作废本支路旧样本；成功读出只消费一次
    无效读请求不推进顺序和序号
    复位清空两支路待消费状态，恢复从支路 0 开始的序列
    电压、支路、序号与实际采样时刻在同一次成功读出中更新
交付修复代码和原因说明，说明复位前未读样本如何失效、恢复后首样本来自何处
```

它与系统集成题使用同一状态协议；新增的是从故障现象定位状态错误并修复，
不是新的采样架构或新的模拟效应。故障材料确定之前不宣称具备独立难度。

## 运行与观察

在[对应台架目录](../../test/interleaved/)运行 `spectre tb.scs`。网表通过相对路径载入公共采样核心和本系统的 `circuit.va`。
查看所用 Spectre 安装生成的 transient 波形。
本资产没有 checker、评分合同或预制结果，实际 Spectre 运行由本轮统一检查记录提供。

台架输入是以 0.9V 为中心、振幅 0.55V 的 1.37MHz 正弦，位于 10MS/s 的
Nyquist 范围内。每支路时钟周期为 200ns，平顶采集宽度为 80ns，
上升与下降各 1ns。支路 0 的首个采集脉冲从 60ns 开始，支路 1 从 160ns 开始。
以 0.9V 阈值计，首个保持沿分别约为 141.5ns 与 241.5ns。
读出沿从 75.5ns 开始，每 100ns 一次。首沿尚无样本，因而无效。
175.5ns、275.5ns 的读出分别消费支路 0 和支路 1。

每次读出必须处在所需支路的保持区间，且与采集切换及复位沿分离。
名义台架在保持沿后留 34ns，支路 1 的 +12ns 偏移条件仍留 22ns。
切换沿与读出沿重合时的事件执行顺序不属于合同。
初始复位约在 35ns 释放，约 2.001us 再次置位、2.040us 释放。
中途复位之后先观察无效读出，再观察从支路 0、序号 0 开始的新序列。

网表在同一次 transient 中并列运行四个条件，共用输入、复位和读出时钟。

| 波形前缀 | 条件与观察目的 |
| --- | --- |
| `m_` | 匹配支路，观察交替保持状态和组合样本顺序 |
| `g_` | 支路增益为 1.01 与 0.99，失调为 +6mV 与 -6mV，观察奇偶支路误差 |
| `s_` | 支路 1 整个采集脉冲延后 12ns，观察真实采样时刻与读出值改变 |
| `b_` | 支路采集时间常数为 10ns 与 25ns，观察有限采集带来的幅度与相位差 |

每组的 `h0`、`h1` 是真实支路输出，`serial` 是组合序列，`valid`、`branch_id`、
`index`、`time` 给出其元数据。比较各组相同序号的输出时，同时看 `time`。
特别是 `s_time` 的支路 1 样本时刻应比匹配组晚 12ns。
有限采集和保持动态存在于匹配组中，匹配组不是理想瞬时采样答案。
读取 `serial` 时，支路的 `heldN` 与它可能因后续泄漏或重新采集而不同。

## 工程依据与设计边界

Jonathan Harris 的 [The ABCs of Interleaved ADCs](https://www.analog.com/en/resources/technical-articles/the-abcs-of-interleaved-adcs.html)
说明交错采样的时钟相位关系，以及支路失调、增益、时序和带宽差异对组合输出的影响。
这里据此建立采样前端和失配条件。所有数值都是名义设计值，未从具体芯片测量拟合。
共享 core 是现象级有限采集与保持模型，不能代替晶体管开关、电荷注入或噪声分析。
当前只施加确定性时偏，没有随机 aperture jitter。

这份资产新增的是同一输入的交错采样、两份连续记忆状态与有序读出之间的关系，
以及支路失配和窗口偏移怎样进入输出序列。它可作为后续功能实现、系统集成或
故障修复题的电路材料，例如修复读出支路错序、保留真实采集误差，或扩展参数配平。
本阶段不创建新任务 ID，也不宣称完成这些题目的评分或校准。

后续扩展统一见[暂缓候选与优先级](../../README.md#暂缓候选与后续优先级)。本轮不建设这些候选。
