# 两支路时间交错采样

这份 VA 资产供 R01 电路功能与工程场景审核。两路跟踪保持单元采同一个模拟输入，
以不同相位结束采集，再交替读出真实保持节点。每支路每 200ns 产生一个样本，
组合序列每 100ns 更新一次，因此名义组合样率为 10MS/s。
它适用于审查高速 ADC 前端的交错采样与读出关系。本资产只包含电压域采样前端，
没有量化器、数字接口、端口电流或负载模型。

## 电路怎样保存与组合样本

`circuit.va` 的 `r01_interleaved_sampler` 实例化两份
[`r01_track_hold`](../../module/core/track_hold.va)。输入经过各支路的增益和失调后进入采集单元。
支路目标电压是 `vcm + gainN * (vin - vcm) + offsetN`。
增益和失调会改变采集状态，序列输出来自 `held0` 或 `held1`，不会重新读取 `vin`。

两支路在 `trackN > vth` 时连续采集，低电平时保持。
采集有有限时间常数，保持包含泄漏与采样基座扰动，具体动态由共享 core 定义。
进入下一次采集会使该支路尚未读出的旧样本失效。
`trackN` 的下降沿登记新样本与实际保持时刻。
`read_clk` 上升沿按支路 0、支路 1 的顺序消费新样本，并保存读出时的保持电压。
读出期间的泄漏和基座扰动因此会传到组合序列。

| 端口 | 电压含义 |
| --- | --- |
| `vin` | 两支路共同的模拟输入 |
| `track0`, `track1` | 各支路采集控制，阈值默认 0.9V |
| `read_clk`, `rst` | 上升沿读出时钟与高有效复位，阈值默认 0.9V |
| `held0`, `held1` | 两个 core 的连续状态输出 |
| `serial` | 最近一次有效读出的实际保持电压 |
| `valid` | 最近一次读出成功为 1.8V，否则为 0V |
| `branch_id` | 最近一次有效读出的支路，0V 是支路 0，1.8V 是支路 1 |
| `sample_index` | 最近一次有效读出的序号，1V 表示序号 1，首样本为 0 |
| `sample_time` | 最近一次有效样本的保持时刻，默认 1V 表示 1us |

`valid` 是读出结果状态，不是窄脉冲。相邻读出都成功时，它可以一直为高。
以 `read_clk` 的上升沿和输出 1ns 转换后的状态识别每次读出。
所需支路尚无新样本、正在采集、样本时刻不晚于上次成功样本，或复位为高时，
该次读出无效。此时 `valid` 变低，`serial`、身份、序号和样本时刻保留，
下一支路指针不前进。时钟输入不符合下面的时序约定时，不保证无丢样。
电路不缓存多帧样本，也不自动重排任意两相时钟。

初始状态和复位上升沿清空新样本标记，下一支路恢复为 0，序号为 -1，
`serial` 为 `vinit`，`valid` 为低。core 按自身有限复位动态恢复保持节点。
复位结束后必须经过新的采集与保持沿才能产生有效输出。

## 运行与观察

在[对应台架目录](../../test/interleaved/)运行 `spectre tb.scs`。网表通过相对路径载入公共采样核心和本系统的 `circuit.va`。
查看所用 Spectre 安装生成的 transient 波形。
本资产没有 checker、评分合同或预制结果，实际 Spectre 运行由本轮统一检查记录提供。

台架输入是以 0.9V 为中心、振幅 0.55V 的 1.37MHz 正弦，位于 10MS/s 的
Nyquist 范围内。每支路时钟周期为 200ns，平顶采集宽度为 80ns，
上升与下降各 1ns。支路 0 的首个采集脉冲从 60ns 开始，支路 1 从 160ns 开始。
以 0.9V 阈值计，首个保持沿分别约为 141.5ns 与 241.5ns。
读出沿从 75.5ns 开始，每 100ns 一次。首沿尚无样本，因而无效。
175.5ns、275.5ns 的读出分别消费支路 0 和支路 1。

每次读出必须处在所需支路的保持区间，且与采集切换及复位沿分离。
名义台架在保持沿后留 34ns，支路 1 的 +12ns 偏移条件仍留 22ns。
切换沿与读出沿重合时的事件执行顺序不属于合同。
初始复位约在 35ns 释放，约 2.001us 再次置位、2.040us 释放。
中途复位之后先观察无效读出，再观察从支路 0、序号 0 开始的新序列。

网表在同一次 transient 中并列运行四个条件，共用输入、复位和读出时钟。

| 波形前缀 | 条件与观察目的 |
| --- | --- |
| `m_` | 匹配支路，观察交替保持状态和组合样本顺序 |
| `g_` | 支路增益为 1.01 与 0.99，失调为 +6mV 与 -6mV，观察奇偶支路误差 |
| `s_` | 支路 1 整个采集脉冲延后 12ns，观察真实采样时刻与读出值改变 |
| `b_` | 支路采集时间常数为 10ns 与 25ns，观察有限采集带来的幅度与相位差 |

每组的 `h0`、`h1` 是真实支路输出，`serial` 是组合序列，`valid`、`branch_id`、
`index`、`time` 给出其元数据。比较各组相同序号的输出时，同时看 `time`。
特别是 `s_time` 的支路 1 样本时刻应比匹配组晚 12ns。
有限采集和保持动态存在于匹配组中，匹配组不是理想瞬时采样答案。
读取 `serial` 时，支路的 `heldN` 与它可能因后续泄漏或重新采集而不同。

## 工程依据与设计边界

Jonathan Harris 的 [The ABCs of Interleaved ADCs](https://www.analog.com/en/resources/technical-articles/the-abcs-of-interleaved-adcs.html)
说明交错采样的时钟相位关系，以及支路失调、增益、时序和带宽差异对组合输出的影响。
这里据此建立采样前端和失配条件。所有数值都是名义设计值，未从具体芯片测量拟合。
共享 core 是现象级有限采集与保持模型，不能代替晶体管开关、电荷注入或噪声分析。
当前只施加确定性时偏，没有随机 aperture jitter。

这份资产新增的是同一输入的交错采样、两份连续记忆状态与有序读出之间的关系，
以及支路失配和窗口偏移怎样进入输出序列。它可作为后续功能实现、系统集成或
故障修复题的电路材料，例如修复读出支路错序、保留真实采集误差，或扩展参数配平。
本阶段不创建新任务 ID，也不宣称完成这些题目的评分或校准。

后续扩展统一见[暂缓候选与优先级](../../README.md#暂缓候选与后续优先级)。本轮不建设这些候选。
