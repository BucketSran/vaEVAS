# R01 相关双采样（CDS）

`r01_cds_sampler` 把相关双采样包在[共享 core](../../module/core/README.md) 上：`ph1` 相把输入
钳到 `vcm+voff` 采参考，`ph2` 相采 `vin+voff`，输出为 `vcm + held_sig − held_ref`。
固定 `pedestal` 和共模 `voff` 提供两拍共有的偏移分量，差分可抑制这部分误差。
有限建立与不等保持时间会留下残差，因此默认非理想条件下不保证完全抵消。
它用于观察 CDS 的误差抑制范围。

本目录提供可运行源码与激励台架，供电路 review 和后续出题选材。
当前没有评分 checker、Harbor 任务或模型解题实验。
2026-10-12 已在 Spectre 21.1 完成一次成功运行，实测记录见[运行记录](../../test/RUN-RECORD.md)。

## 配对语义

两份 core 实例共享全部参数。一对样本的成立条件：`ph1` 下降沿（rst 低）登记参考，
随后 `ph2` 下降沿登记信号；两者都完成且 `ph1`、`ph2`、`rst` 均低时 `valid` 为高、
`vout` 输出差分值。`ph1` 上升沿开始新周期并作废尚未配对的旧信号；`ph2` 上升沿
只作废信号半边。初始状态与复位上升沿清空两侧。输出门控 `transition` 边沿 1 ns。

`held_ref`、`held_sig` 是两份 core 的真实连续状态输出，可直接观察各自的下垂与注入。

## 误差机制：什么消、什么不消

| 机制 | 在 CDS 输出中的表现 |
| --- | --- |
| 固定 `pedestal`（两实例同参数） | 无漏电且两次注入均充分完成时可以抵消；默认漏电模型会在不同保持时长内改变已注入的电压，仍有残差 |
| 共模 `voff` | 进入两个采集目标，差分后受到抑制；台架中增加 10 mV 失调后，输出改变约 11 µV |
| 保持漏电 | 残差同时取决于两拍的保持时长和保存电压，不能仅用时间间隔决定 |
| 有限建立 | 两拍采集目标和有效采集时间常数不同，建立残差不保证抵消 |

若把 `pedestal` 改为随信号变化（拓展方向），第一拍与第二拍注入不同，CDS 将消不净
——这是"校准极限"类题目的自然素材。

## 运行与实测

在[对应台架目录](../../test/cds/)运行 `spectre tb.scs`。台架跑两个 CDS 周期（150 ns 采集窗使建立残差可忽略），
并列三个实例：CDS 本体、`voff=10m` 失调对照、按 `ph2` 采样的单 core 对照（`ref_held`，
显示未消除的 pedestal）。2026-10-12 实测（Spectre 21.1，thu-sui，0 错误）：

| 读出时刻 | vin | CDS 输出（误差） | voff=10m 输出（误差） | 单 core（误差） |
| --- | --- | --- | --- | --- |
| 550 ns | 1.6 | 1.600962（+0.96 mV） | 1.600973（+0.97 mV） | 1.601664（+1.66 mV） |
| 1100 ns | 0.2 | 0.201345（+1.35 mV） | 0.201356（+1.36 mV） | 0.202048（+2.05 mV） |

两个读出点上，参考与信号分别已保持约 299.9 ns 和 49.9 ns，第二周期并未延长参考保持。
两个周期的信号电平不同，漏电项随保存电压变化，有限建立也可能留下残差；不能把第二周期
较大的残差归因于更长的参考保持时间。单 core 保留未做差分抑制的注入与下垂。
配对完成前 `valid=0`、`vout=0`，配对后 `valid=1.8 V`。

## 来源与边界

机制依据同 core（ADI MT-090 的 pedestal 与漏电）。v4 已有 308 题（相关双采样消失调）
是孤立合同；本资产提供带连续动态的电路侧材料，不修改 308 的合同。不描述噪声、
抖动、放大器建立或器件级开关；这些仍需另行补充。
