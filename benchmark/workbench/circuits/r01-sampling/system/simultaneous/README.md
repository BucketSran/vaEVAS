# 四路同步采样与共享读出

这个工程用于多传感器同步快照。四路输入各有一个独立保持节点，在同一个 `track` 下降沿进入保持，再由下游 ADC 控制器顺序读取。所有通道属于同一帧，但晚读通道经历更长保持时间，读数会因下垂改变。这是供电路 review 的工程资产，尚未冻结题目合同，不计入正式任务。

`circuit.va` 实例化四个 [公共采样核心](../../module/core/track_hold.va)。`held0` 至 `held3` 是各核心真实输出，也是观察节点。输出选择器直接读取这些节点，不在顶层重新计算采样结果。每个核心有连续采集恢复、保持漏泄和进入保持时的偏移；它们的模拟状态彼此独立。

## 接口与可用周期

输入电压使用 0.2 至 1.6 V，控制使用 0 与 1.8 V，判定阈值默认为 0.9 V。端口顺序见模块声明和台架实例。

| 端口 | 含义 |
| --- | --- |
| `ain0` 至 `ain3` | 四路模拟输入 |
| `track` | 高电平共同采集，下降沿结束采集并形成一帧 |
| `rst` | 高电平优先复位四个保持节点，并使当前帧无效 |
| `sel0`, `sel1` | 二进制读取通道，`sel0` 是低位 |
| `read_en` | 高电平请求读取所选通道；低电平暂停读出 |
| `dout`, `valid` | 可读时输出所选保持电压，并将 `valid` 驱动为 1.8 V；其他周期两者趋向 0 |
| `held0` 至 `held3` | 四个独立保持电压，持续可观察 |

`valid` 表示已有一帧且当前允许读出，不代表满足某个精度指标。采集期、复位期、尚未完成首次采集的周期不能读取有效样本。`read_en` 低时四个模拟状态仍继续漏泄，重新打开读取看到的是当时的状态。选择器不推进帧号，也不改变任何保持状态。

若仿真开始时 `track` 高且 `rst` 低，首次采集从仿真起点开始。若 `rst` 释放时 `track` 已高，首次采集从释放时开始。两种情况下都必须等 `track` 下降，帧才有效。复位是有限恢复过程，台架提供足够复位时间；不能把短复位脉冲当作精确赋值。

选择与读取属于下游控制器的边界，工程没有内部通道计数器。台架先设选择码，再开 `read_en`，在读取窗口内保持选择码稳定。输出门控有默认 1 ns 过渡，应在过渡后观察。新一轮采集会覆盖整帧，复位会丢弃整帧。不要令复位边沿与采集边沿同时发生；台架明确分开它们。这与仅在时钟沿复制输入到输出的旧多通道 mux 资产不同，四个存储节点会在等待期间持续改变。

## 运行与观察

从本目录进入对应台架目录后运行 Spectre：

```sh
cd ../../test/simultaneous
spectre tb.scs
```

台架通过相对路径引用 `module/core/track_hold.va` 与 `system/simultaneous/circuit.va`，路径均从台架目录解析。`tb.scs` 保存输入、控制、保持节点和读出波形，仿真结束时间为 45 us。这里没有评分程序，也没有预制测量数据。

首帧在约 1 us 结束采集。四路输入随后改变，保持电压不会随之跳到新输入。约 1.2、3、7、13 us 分别读取通道 0、1、2、3，约 21 us 重读通道 0，可以在同一个节点上比较读取等待产生的变化。24 至 25 us 共同采集第二帧，随后再次读取通道 0 和 3。32 至 33 us 复位，复位后未再采集，`valid` 保持低。

参数 `tau_acq=10 ns`、`tau_hold=200 us`、`vinit=0.9 V`、`vleak=0 V`、`pedestal=2 mV` 是本工程的设计取值，可从顶层传入各核心。它们不是某个器件的实测拟合。台架中采集是有限时长，所以快照电压也含输入斜率与有限采集误差。

## 表征题交付草案

候选名称为“同步采样的采集、保持与读出误差表征”，属于电路测试与表征，先按基础题设计。它帮助使用者区分采集结束时已经存在的误差、等待读出造成的保持变化，以及最终送到后级的总误差。三项定义与事件规则以[功能族约定](../../README.md#表征题的测量范围与实际事件)为准。

给定源码可读的完整 DUT、现有激励和网表、可观测端口、公开采集及读出协议，以及观察间隔。求解者交付可接入工程的 VA 测量模块和报告。固定 DUT 与激励由题目提供，这道题不要求优化读序或增加实验控制器；公开固定台架只是使用示例。

测量模块读取四路输入、四个保持节点、采集控制、复位、选择码、读使能、输出与 DUT 的 `valid`。它依照实际控制识别帧和通道，适应合法范围内的读序改变、等待、暂停、重复采集和同帧重读。四路的采集误差在帧完成时都可获得，没有读过的通道也保留这一部分。

一次读出记录包括帧与通道、该通道本帧第几次读取、实际采集及读出时刻、输入参考、保持电压、输出电压、三项指标和完成状态。DUT 的可读状态单独记录；精度是否达标不是测量是否完成的同义词。

### 作者审核用伪代码

下列伪代码描述交付责任，不是现有 VA 实现。各时间间隔来自公开参数，记录时刻来自实际信号。一次“关闭帧”只结束其可读生命周期，不删除已经保存的测量。

```text
初始化：
    当前帧为空，帧序号尚未分配，没有待读请求
    若 rst 已低且 track 已高，按实际初态开始一次采集

实际开始采集时：
    关闭旧帧，保留全部记录；尚待完成的读取注明“被新采集覆盖”
    分配新帧序号，保存 t_a，状态设为采集中
    清除旧帧的待读请求

实际结束采集时，若当前帧确实在采集且 rst 为低：
    保存 t_h
    对四个通道分别保存：
        u_ref = 当前 ain[channel]
        h_end = 当前 held[channel]
        采集误差 = h_end - u_ref
    将本帧标为已完成采集
    若 read_en 已高，按当前稳定选择码开始读出观察

实际 read_en 上升时：
    若本帧已完成采集且处于保持，开始读出观察
    若正在采集，等待实际采集结束，不提前形成读数
    若尚无采集结果，记录请求尚无对应样本

开始读出观察：
    保存请求时刻、帧序号和由 sel 确定的通道
    按公开观察间隔安排取样，不读取预先写好的绝对时刻表
    同一请求只安排一次取样

到达该请求的观察时刻：
    确认仍是同一帧、同一通道，处于保持、未复位且仍使能读取
    若中途已取消，保留中断记录，不补造读数
    否则保存实际 t_r、held[channel]、dout 和 DUT valid
    保持变化 = held[channel] - 本帧 h_end[channel]
    最终读出误差 = dout - 本帧 u_ref[channel]
    输出三项指标和这一次的读取序号
    若 DUT valid 与预期可读状态不符，注明异常，仍保留实际观察

read_en 降低或观察期间选择改变：
    取消尚未完成的读出观察并注明原因；不丢弃本帧基线
    下一次合法读请求仍可重读同一帧

复位到来或仿真结束：
    关闭当前帧，保存已知指标和未完成原因
    已完成采集但未读取的通道保留“已采集、未读出”
    尚未完成采集的帧保留起点与中断原因，不补造采集误差
    复位释放且 track 已高时，从释放事件开始一帧新采集
```

例如，选择码和读使能先后发起通道 3、0、3 的读取，模块应记录同一帧的三次观察，通道 3 的两条记录共用 `u_ref` 与 `h_end`，但具有各自的 `t_r`。若第三次读取在观察前被复位打断，前两条结果仍保留，第三条注明中断。

### 与相近题目的区别和材料缺口

系统集成题要求连接四个采样核心并管理帧；本题要求使用完整系统做测量。它复用同一 core 的有限采集、注入和漏电，增加的是事件关联与逐通道记录，不新增模拟机制。旧 349 的内部读指针和理想停钟保持也不能作为本题时序假设。

现有台架能说明用途，但尚需整理可接入的测量接口、报告形式和公开协议变体。观察间隔、控制边沿间隔、精度和中断报告细节在题面细化时确定。本文没有实现测量模块、参考解或 checker，也没有进行模型实验。

同步采样修复方向仍关注刷新或复位后的帧状态。只有一个标志位错误的版本可作基础修复候选；更复杂的诊断价值需由故障和复现材料证明。表征题不因此承担自动诊断根因的责任。

## 来源、范围与后续工程工作

[ADI MT-090](https://www.analog.com/media/en/training-seminars/tutorials/MT-090.pdf) 描述采样保持的存储节点、有限采集、保持下垂与保持偏移，也列出同步采样应用。本工程借用这些机制，以公共核心组成四路同步架构。[TI TIPD169](https://www.ti.com/tool/TIPD169) 说明多路数据采集对建立时间的要求，其实际系统采用输入复用；本工程选择独立采样节点来保持同时快照。

本资产只描述电压域采样与读出。它没有 ADC 量化、热噪声、输出负载建立、通道串扰、输入保护或器件级开关电荷分配。它适合讨论同步性、等待误差、采集窗口与读出安排，不能据此宣称实际板卡的 ENOB 或分辨率。

后续可以形成有工程意义的修改任务，例如在四通道都需同一误差预算时规划读取间隔、为不同漏泄通道安排读序，或加入带负载读出缓冲并验证其建立时间。这些方向需要另行建立输入要求、独立判据和实际仿真证据；本阶段只交付可运行电路材料。

后续扩展统一见[暂缓候选与优先级](../../README.md#暂缓候选与后续优先级)。本轮不建设这些候选。
