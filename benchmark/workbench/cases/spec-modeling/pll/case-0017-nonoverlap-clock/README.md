## 工程目标与拟定交付

在开关电容电路的两相控制场景中，按公开时序要求生成phi1、phi2。两相之间保留死区，复位或禁用时关闭输出，并正确处理尚未执行的相位请求。给Agent接口、可读固定驱动工程和时序规格，交付一个VA发生器模块。独立checker检查实际两相波形。首版归规格建模，不要求同时开发SC积分器。

2026-10-11作为首批时钟路线的代表入口登记，当前仍为材料筛选。本文说明改编目标，没有冻结端口、数值、输出平滑与同时事件规则。

## 原资产与改编

[来源卡](../../../../sources/v4-nonoverlap-clock.md)和[电路卡](../../../../circuits/v4-nonoverlap-clock.md)记录family375。旧参考遇到输入边沿先关闭相位，再按全局tick倒计时激活对应相位。它提供状态和激励素材，但不是精确的“输入沿后延迟dead_ticks乘tick”实现。旧`deadtime_metric`是等待状态标志；`tr`声明未用于输出平滑。

建设时先决定保留按tick调度的数字控制宏模型，还是改为按绝对时间定义的死区。两者都有工程用途，规格和参考必须对应同一种公开行为，不能混用。无论选择哪种，都要补初态、复位和禁用对挂起请求的处理、重复请求与重启规则。不能只允许两相永远为低来满足“不重叠”。

## 独立验收

从输入、复位、使能和实际phi1/phi2波形提取事件。分别检查请求对应的相位确实出现、相位顺序、死区、取消、重新使能及有效输出窗口。参数或输入周期变化必须仍在公开范围内。候选输出的metric或valid只能作为被核验的结果，不能作为时间真值。

校准应包含健康实现，以及相位互换、缺死区、一直关闭、禁用后残留请求等缺陷。若采用tick调度，应改变输入沿相对tick的位置；若采用精确死区，应按公开事件起点核对时间。保存波形精度与事件容差由所选后端实测确定，当前没有运行证据。

## 本轮需要确认

先确定调度模型及可观察死区的定义，再固定同时事件、边沿阈值、输出过渡和参数范围。源码可读与固定公开测试沿用已定方向。后端待环境校准后固定，不从旧Spectre网表推断新题已可运行。
