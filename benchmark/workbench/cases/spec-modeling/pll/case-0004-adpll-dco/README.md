## 工程目标与拟定交付

给定源码可读的 ADPLL 工程，固定频率计数、控制器、反馈连接和参考激励，Agent 根据完整规格补齐 VA DCO。交付物是可接入工程的模块；接口包括控制码、使能和输出时钟，具体电压编码、复位方式与边沿合同待冻结。

独立模块规格与闭环要求都要满足。工程保留 DCO 输出驱动实际反馈的路径；不能仅生成一个预知目标频率的时钟，绕过控制码与动态响应。这属于工程内补模块，未要求 Agent 从外部 ADC/PLL 功能自行设计整个系统。

## 原资产与改编

[Tiny Tapeout 来源](../../../../sources/tiny-tapeout-adpll.md)已经有数字控制架构、行为 DCO 和环振结构，但不是现成 VA 工程。[电路记录](../../../../circuits/tiny-tapeout-adpll.md)登记健康 VA 基线的缺口。

原 SIM 模型只用控制码高四位，恒码周期为 `60 - 2.56*k` ns；低六位没有细调效果。该公式可改编为公开行为规格，不能冒称真实环振表征。完整十位码频映射、连续相位换码和边沿斜率若被采用，均属我们新增的要求。结构分支与 SIM 控制方向的静态风险也须先处理，不能原样搬入闭环。

出题者先实现、校准健康闭环，再移除 DCO 实现。其余模块、连接及参数在解题中固定。公开规格应明确可达的目标频率、码范围、使能/复位、首次边沿和换码时刻；不隐藏依赖某种参考实现的算法。

## 独立验收

- 恒码场景从实际输出边沿计算周期、占空比和电平，覆盖中间码及边界码。
- 若采用连续相位合同，由公开码序列积分频率预测相位；换码、暂停和重启的判据分别按公开协议推导。不能把数字延迟过程的偶然行为当规范。
- 在固定闭环中检查外部输出频率及受控换目标后的响应，并改变参考或控制条件确认 DCO 参与反馈。`lock` 标志只能辅助观测，不能替代测量。
- 校准负例至少包括控制极性相反、忽略低位但题面要求低位有效、换码重置相位、关闭后残留边沿、固定频率作弊。只有题面实际规定的行为才进入终评。

独立 checker、数值容差、健康闭环和正式后端尚未建立；本轮没有仿真结果。与 case-0007 共用电路来源，须保留相关性。

## 本轮需要确认

先选择第一题的码频合同：建议从明确的粗调 DCO 开始，保留换码与使能的动态要求。若选十位细调，须先定义新映射及可达条件，不能直接引用原 SIM 证明其合理。

下一步是给出可执行的接口和相位协议，验证固定控制器能在这些条件下工作，再决定具体容差与题面数据。
