# 题面草案 r2：内部采样的 Alexander BBPD

> 2026-10-10，用户确认采用完整 Alexander 单模块，采样及历史对齐均在模块内部。下列初始化、输出和边沿重合规则是据此提出的 r2 草案，尚待设计 review；数值容差未校准。当前没有新参考解、可执行 checker 或运行证据。

实现一个全速 Alexander 型 bang-bang 相位检测器，交付 `alexander_bbpd.va`。模块从 DATA、CLK 自行取得前中心、边界、后中心三个数据样本，输出时钟偏早或偏晚的修正请求。本题建模理想采样和有限输出过渡，不要求建立完整 CDR 环路，也不模拟噪声、亚稳态电压及其统计分布。

## 接口与输入条件

模块名 `alexander_bbpd`，位置连接顺序为 `VDD, VSS, DATA, CLK, UP, DOWN`，均为 electrical 端口。外部提供固定 VDD、VSS，以及 DATA、CLK。模块只驱动 UP、DOWN。没有外部 retimed_data、复位或有效指示端口。

令 `Vspan = VDD−VSS > 0`。逻辑输出 0 对应 VSS，1 对应 VDD。所有输入门限以 VSS 为参考。

| 可覆盖参数 | 草案默认值 | 含义 |
| --- | --- | --- |
| `vth` | 0.45 V | DATA、CLK 共用的相对 VSS 门限，`0 < vth < Vspan` |
| `td` | 20 ps | 完成第三次采样后，到输出开始响应的传播延迟，`td >= 0` |
| `tedge` | 50 ps | 输出改变逻辑值时的名义过渡时长，`tedge > 0` |

供电从初始时刻起保持恒定，不同实验可以改变供电和参数。DATA、CLK 在电源轨之间变化，边沿连续、有限斜率、单调穿过门限，不在门限停留或来回穿越。初始电平不等于门限，CLK 初始高低均可。DATA 可以长期不变，也可构造使三点样本为 010、101 的短脉冲，处理规则见下文。

CLK 的上升沿和下降沿交替出现，可以改变周期、占空比或停止；模型不能使用预先给定的比特周期生成采样时刻。时间均按实际穿过门限的时刻定义。为隔开相邻输出过渡，本草案要求相邻 CLK 边沿的间隔至少为 `4 × (td + tedge + t_ap + epsilon_t)`。首个 CLK 边沿晚于 `4 × (t_ap + epsilon_t)`。参数 t_ap、epsilon_t 见容差表。

## 三点采样与初始化

记初始化之后的第一个上升沿为 r0，后续上升沿为 r1、r2……；r_i 与 r_(i+1) 之间的下降沿为 f_i。

```text
时刻          r_i              f_i              r_(i+1)
时钟边沿      上升沿           下降沿           上升沿
数据样本      C_i              B_i              C_(i+1)
本组角色      A                B                C
```

上升沿是目标比特中心，下降沿是目标比特边界。它们表示恢复时钟期望的位置，不预设时钟已经锁定。

1. 初始化时 UP=DOWN=0，采样历史无效。不得把初始 DATA 值或内部变量的默认值当作已经取得的有效样本。
2. r0 只保存第一个中心样本 C0，不发布方向。若 CLK 初始高，r0 之前出现的下降沿不构成有效边界样本。
3. f0 保存边界样本 B0，输出仍不改变。
4. r1 保存 C1，首次使用完整的 `(C0, B0, C1)` 判相。r1 的新中心样本随后成为下一组的 A，不能先覆盖 C0 再做本组比较。
5. 此后每个上升沿 r_(i+1) 使用 `(C_i, B_i, C_(i+1))` 得到一组结果；下降沿只更新边界样本，DATA 自身的跳变不直接更新输出。

同一个中心采样结果必须在相邻两组中保持身份一致，包括下述重合窗口内的采样。模块不必使用特定寄存器数量或指定 VA 语句实现这些行为。

## 判相与输出极性

以下 A、B、C 是同一组对齐后的逻辑样本。本题 UP 明确定义为“时钟晚，需要提前后续时钟”；DOWN 为“时钟早，需要推迟后续时钟”。若后级采用正增益 VCO，分别对应加速和减速，但本题不验收后级环路。

| A B C | UP | DOWN | 解释 |
| --- | --- | --- | --- |
| 001、110 | 0 | 1 | 边界样本仍为旧比特，时钟早 |
| 011、100 | 1 | 0 | 边界样本已为新比特，时钟晚 |
| 000、111 | 0 | 0 | 没有新的方向信息 |
| 010、101 | 0 | 0 | 两侧中心相同、边界相反，丢弃该组的方向信息 |

本题选择在 A=C 时两路均输出 0。这是输出互斥的具体模型约定；不声称所有 Alexander 电路都对 010、101 使用同一种门控。每一组都重新决定输出，无变化的比特不能沿用上一组非零方向。

## 输出发布、过渡与保持

在 r_(i+1) 形成结果，令 `p_(i+1) = r_(i+1) + td`。输出在 p_(i+1) 开始响应该结果，使用 tedge 完成连续、单调的电平过渡，无过冲或振铃。初始化直接给出低电平，不产生启动高脉冲。

输出建立后保持到下一组发布。连续两组方向相同时持续保持同一电平，不在周期边界清零，也不人为再发一个窄脉冲。没有新方向或无效三元组会在自己的发布时刻将输出改为两路低。若 CLK 停止，已经形成结果的延迟与过渡仍需完成，随后保持最后一组输出，不通过定时器自行清零或再采样。

两路的逻辑目标始终互斥。UP 与 DOWN 换向时，允许在规定过渡窗口内出现中间模拟电压，不要求 break-before-make；逐路仍须满足单调和端点时刻要求。过渡之外，两路必须建立到表中规定的电源轨。未改变逻辑值的那一路不得产生毛刺。

## DATA 与采样边沿重合

本题用很窄的采样不确定窗口处理恰好重合的边沿，不要求人为规定 data 事件和 clk 事件的执行先后。

对任一采样时刻 s，若没有 DATA 门限交越位于闭区间 `[s−t_ap, s+t_ap]`，采样结果必须是该时刻 DATA 在门限上方或下方对应的唯一逻辑值。窗口内若有一次交越，允许此次采样取得交越前或交越后的值。每个采样窗口最多包含一次 DATA 门限交越；输入不包含门限平台。

一次采样只能选定一个逻辑值，该值在被历史寄存器再次使用时不得变化。允许每次重合采样作出不同选择，不要求固定选择旧值或新值，不要求随机数、概率分布或亚稳态电压模型。普通瞬时采样实现不需要额外检测窗口；窗口用于界定验收允许的结果。

例如 A=0、C=1，而 B 正好与 0→1 数据跳变重合，则 B=0 对应 DOWN，B=1 对应 UP。两种结果都可接受，但两路全低或同时高均不符合这组样本。本规则只放宽不确定样本的取值，输出发布时间、保持、历史一致性仍需满足。

DATA 在数值上恰好等于 vth 只会出现在交越时刻，按上述窗口处理，不另外硬定 `>=` 与 `>` 的唯一优先级。t_ap 是本题拟定的理想模型验收边界，不代表晶体管触发器的实测 setup/hold 或亚稳态参数。

## 容差与公开测试

下列数值是待校准的草案。正式发布前须固定并公开，不得在隐藏测试中另行收紧。

| 量 | 草案值 | 用途 |
| --- | --- | --- |
| `epsilon_v` | `0.001 × Vspan` | 输出电平、保持、单调性和过冲检查 |
| `epsilon_t` | `0.1 × tedge` | 输出过渡起止时刻的测量容差 |
| `t_ap` | 10 ps | DATA 与采样边沿接近时允许两种采样结果的半窗口 |

对改变逻辑值的输出，以首次离开旧电平 ±epsilon_v 为过渡开始，以进入新电平 ±epsilon_v 并保持到下一次目标改变为过渡完成。开始须在 `[p−epsilon_t, p+epsilon_t]`，完成须在 `[p+tedge−epsilon_t, p+tedge+epsilon_t]`；中间单调且不越出电源轨容差带。时间容差用于数值测量，不允许实现预知未来采样。相同目标连续发布时，整段保持对应电平。

固定公开测试将展示初始化、明确早晚和无跳变情况，并给出一个重合边沿的合法结果集合。终评可在同一合同内变换数据极性、相位、序列、时钟间隔、占空比、初始 CLK、电源轨和参数，并检查短脉冲及停钟。解法不受后端语言子集限制。不得读取固定答案或按已知测试时间重放输出。
