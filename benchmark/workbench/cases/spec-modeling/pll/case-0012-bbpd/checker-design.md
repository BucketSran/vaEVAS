# Alexander BBPD r2 的独立 checker 方案

本页讨论如何验收 [r2 公开合同](instruction.md)，尚未实现评分程序或运行仿真。用户已确认内部采样的 Alexander 方向；窗口数值、输出细节与本方案仍待 review。任务是否通过取决于完整合同，不按场景数、文件长度或预计难度增加分值。

## 从输入波形建立独立答案

checker 使用固定测试台产生的输入 PWL 与导出的 DATA、CLK、UP、DOWN 电压波形。先验证实际输入与声明激励一致，再独立求出门限交越时刻。不得用候选内部变量、候选自报的早晚标签或旧 bbpd_ref 的输出定义答案。

对每个 CLK 上升、下降交越，用输入定义取得中心样本 C_i 和边界样本 B_i 的允许值集合。普通采样只有一个值，落在 t_ap 窗口内的交越允许两个值。按公开真值表得到每个发布时刻的目标，再检查实际两路输出的整个时间序列。

PWL 的门限交越可按所在单调线段直接插值，不必让另一个 VA 判相器充当 oracle。静态输入计算与导出输入的时间定位须交叉核对，防止检查器只检查了预期激励却没有发现实际连接错误。若连接或记录不完整，先归为评测环境问题。

## 普通场景检查唯一序列

对窗口外的输入，答案是唯一的 `(UP, DOWN)` 目标序列和发布时间。检查至少包括：

- 启动到第一组完整采样发布前，两路低；初始 CLK 高时忽略先来的下降沿。
- 每组的方向、无跳变清零及 010、101 清零，覆盖全部八个三元组。
- 当前上升沿完成 C 后才发布，并满足 td、tedge；检测提前半拍、整拍错位及先覆盖 A 的错误。
- 整个保持区间的波形，而非每拍只读一个点。DATA 变化、下降沿和下一采样前都不能额外更新。
- 连续同方向时没有周期性清零；停钟后没有自主采样或清零。
- 电源轨、有限过渡、逐路单调和过冲。互斥以稳定逻辑目标判断，换向窗口不额外要求模拟电压绝对不交叠。

举例：r0=1 ns、f0=1.5 ns、r1=2 ns，DATA 初始为0并在1.4 ns上升。取得011，结果为UP。默认 td=20 ps、tedge=50 ps 时，UP在2.020 ns附近开始上升，在2.070 ns附近建立。若 DATA 此后一直为1，下一组为111，则在3.020 ns开始清零，而不是在1.4 ns或下一下降沿动作。这里的数值是合同示例，不是模拟器测量结果。

## 重合场景检查一条自洽的历史

不能将重合窗口直接标为“不检查”，也不能每拍独立挑一个能通过的答案。中心样本 C_i 在前一组作 C、后一组作 A，必须保留同一值。

checker 可以维护有限的可行状态集合。初始化取得 C0 后，状态为 `(C0, 当前输出目标=两路低)`。每个完整周期：

1. 从输入取得 B_i、C_(i+1) 各自的允许值集合。
2. 对每条仍可行的历史，枚举这些取值，用公开表生成新目标。
3. 检查实际波形是否满足旧目标到新目标的发布时间、过渡及保持要求；删除不匹配的路径。
4. 以 `(C_(i+1), 新目标)` 合并等价状态，保留下一拍需要的历史。若无路径剩余，则失败。

这种检查不读取候选内部实现，也不要求复现随机决策；只要求整个可见输出对应至少一条合法历史。状态合并需保留当前输出目标，不能仅凭中心样本相同就丢掉不同的输出历史。停钟后的尾段及启动段也要检查。

一个可手算的反例：固定 `C0=0, B0=0, B1=1, C2=0`，仅 C1 恰好重合而可能为0或1。

| C1 的一次性选择 | 第一组 | 第二组 | 合法两拍结果 |
| --- | --- | --- | --- |
| 0 | 000 | 010 | 无修正、无修正 |
| 1 | 001 | 110 | DOWN、DOWN |

“无修正、DOWN”与“DOWN、无修正”每拍单独看似都能通过，但不存在一致的 C1，所以整条输出必须拒绝。另一个必要反例是 A=0、C=1、B重合：合法结果只有UP或DOWN，不能因为重合就放过两路低。

对 t_ap 边界附近的输入，先保证刺激分类的分辨率。固定场景可以取恰好重合、窗口内部及留足余量的窗口外位置，不把恰好位于窗口端点且数值定位不足的情况用于区分候选。无法确定场景属于哪一侧时应修复测试环境，不临时扩大允许集合掩盖问题。

## 场景与负例校准

各行是同一道题的测试条件，不新增任务或权重。公开与隐藏用例使用同一合同，隐藏仅改变合法输入和参数。

| 场景 | 主要要检出的错误 |
| --- | --- |
| CLK初始低与初始高；首组完整前多次DATA变化 | 使用初始DATA伪造历史、先来的下降沿误成有效样本 |
| 远离窗口的早、晚；两种DATA跳变极性 | 方向反接、只支持上升数据边沿 |
| 长连0、长连1，前面先有非零方向 | 默认一直低、无跳变时保留上一方向 |
| 早晚交替、连续同向、非周期数据序列 | 先覆盖A、边界错拍、仅能处理单个孤立跳变 |
| 改周期、占空比、首沿时间、供电和vth | 按固定时间重放、把下降沿写成固定半周期、使用对地门限 |
| 停在高相与低相，再恢复时钟 | 定时器自行清零、暂停时虚构采样或丢失历史 |
| 两次DATA变化形成010、101 | 直接暴露两路XOR同时高、不按公开无效规则处理 |
| B与DATA重合，但两侧中心确定且不同 | 对重合一律清零、跳过整拍验收 |
| 中心采样重合且被下一拍继续使用 | 每拍独立“任选答案”、历史不一致 |
| UP到DOWN和反向换向，变化td与tedge | 用固定脉宽代替保持、仅终值正确、过渡或延迟错误 |

至少准备两种不同写法的合规 VA 实现，避免 checker 只接受出题者的一份代码；其中至少覆盖明确时序，另用可控样本取值的合成轨迹检验窗口两种选择都被接纳。单次模拟器恰好选择其中一种，不证明 checker 接受了另一种。

负例可以先用手工构造的波形检查评分逻辑，再用实际 VA 错误实现运行。上述是拟造的校准错误，不声称来源于真实工程故障。全部低、方向交换、提前半拍、慢一拍、data触发、下降沿清除、窄脉冲、丢失历史、输出额外毛刺，都应有能明确拒绝它的合同内用例。

数据全反相后，明确时序下的方向应不变；整体平移输入时间后，采样和发布应相应平移。它们是辅助一致性检查，不能替代绝对真值表，因为两路恒低也能通过这些变换。

## 波形分辨率与正式准入

输出全轨迹检查需要明确最大步长、导出时间分辨率和事件附近取样。初始建议使记录间隔不大于 `min(epsilon_t/2, t_ap/4, tedge/10)`，并在校准时加密一次，核对起止测量和故障检出是否稳定。自适应数据中的时间间隔也须检查，不因点数多就认定分辨率足够。

这只能证明固定观测协议下的检出能力，不承诺捕获任意窄的脉冲。正式包应公开用于判定的数值容差及观测设置；边沿丢失、导出不足、环境能力不足属于环境问题。正常编译和出波形不等于答案正确，无法运行也不自动证明候选逻辑错误。

后续顺序为：确认本版语义，构造独立 oracle 和手算样例，验证 checker 接受与拒绝的边界，再以健康实现及负例校准固定后端，最后做模型试跑。必要的跨后端校准按任务风险选择，不要求所有题强制经过 Spectre。旧 spec-cdr-phase-detector 的结果不能继承为此版通过记录。
