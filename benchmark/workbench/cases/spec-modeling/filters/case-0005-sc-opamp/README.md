## 工程目标与拟定交付

候选任务是在固定开关电容滤波工程中建立运放模型。Agent 根据公开规格实现有限增益、主极点动态、压摆率、输出限幅及明确的过载恢复行为，并验证采样时刻的建立误差。内部状态和输出的关系应由题目定义，不能让隐藏 checker 假定一种未公开的限幅结构。

给定工程必须保留真实的 SC 架构含义：时钟相位、电容比例、运放所在反馈路径，以及这些因素对输出样本的影响。不能只给通用微分方程换一个电路名称，也不能让候选直接输出滤波器理想传递函数来绕过运放。

## 原资产与改编

[BMAS 2000 来源](../../../../sources/sc-filter-bmas2000.md)以一阶全差分 SC 低通电路讨论运放行为模型，包含增益、带宽、压摆率及限幅等问题。本轮读到的是方法与电路讨论，没有获得完整可运行源码或明确开放许可。

原文还涉及输出阻抗和开关负载相互作用，不能假定一个固定电压域运放自动复现这些效应。候选拟由我们编写固定的 SC 行为环境，并明示固定负载下的模型范围；若电荷转移或负载效应影响本题判定，就必须保留并校准，或重新收窄题目要求。收窄版本不能声称复现原论文完整电路。

目前没有选定可发布的具体 DUT，故电路记录与同源组留空。我们需要先形成有原理图含义的健康工程，再给 Agent 留出运放模块；不能把该准备工作算作已有资产。

## 独立验收

1. 模块级以静态增益、小信号建立、大信号压摆、限幅退出等场景验证公开合同。可解析区间使用独立公式，状态切换处使用独立事件/状态计算；不以参考 VA 的输出作为唯一正确性依据。
2. 系统级在公开时钟、输入和电容比范围内测输出样本，检查有限建立引入的误差及过载后的恢复。通过受控扰动确认运放模块实际影响系统结果。
3. 校准理想无限带宽替代、遗漏压摆、简单输出截断造成错误内部状态、只拟合单一激励等负例。

必须先证明环境中确实能观察并分离目标效应，再冻结容差。后端、固定工程、checker 和配套真实电路校准均未知，当前仅为材料筛选。

## 本轮需要确认

最先判断固定电压域 SC 环境是否足以考察目标效应。若不足，应选择具备相应网表能力的后端或重新设计模型边界，不能靠放松 checker 弥补。

确认后再选拓扑、公开状态合同和负载范围。这一题可作为规格建模中非理想行为的候选，暂不预判它比基础模块题更难。
