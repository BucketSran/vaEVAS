## 工程目标与拟定交付

给定 `sample_hold(VDD,VSS,IN,CLK,OUT)` 接口和详细行为要求，Agent 写一个 VA 模块，在时钟上升沿取得输入值并保持到下次采样。它作为最基础的单模块建模题；本卡没有增加开关电阻、建立时间、下垂或噪声要求。

## 原资产与迁移取舍

原题为 v4-024。参考使用 `V(IN,VSS)` 和相对 VSS 的时钟门限，初始保持值为零；VDD 没参与计算。原题面没有充分解释供电、初态与输入范围，迁移时需写清。来源和原文件链接见[筛选记录](../../../../migration/v4-spec-screening.md)。

可保留端口、vth/tedge 的用途和公开连接例子；不把旧语言子集限制带进新题。先按理想边沿采样讨论，不把参考的有限平滑误称为真实采样级建立动态。case-0006 是从真实采样级数据辨识动态的另一方向，两者并非同一来源。

## 已确认的范围与 r2 规格

2026-10-10，用户确认本题作为基础题保留，并授权补清规格。[题面草案 r2](instruction.md)是本卡当前公开行为说明：固定且正常的供电，门限与输出相对 VSS，初态 OUT=VSS，连续输入在时钟上升穿越时采样，下降沿及高相期间不跟踪，停钟后保持。

保留理想模型，不增加带宽、下垂、噪声或掉电要求。合法激励排除采样时输入跳变、初始高时钟、门限停留及重叠过渡，避免依靠未定义事件优先级判分。输出允许不同连续单调曲线，按开始、完成、保持误差验收。

r2 中的归一化电压/时间容差、可测跳变幅度门槛和过渡时间窗口是助手本轮补充的设计建议，尚未经过后端校准，不标为用户已批准的数值。具体定义只在题面维护。`review_status` 保持 pending 表示本版细节尚待核验，不再表示基础题方向待决定。

## 独立验收与下一步

checker 从输入和时钟波形独立求交点及采样值，检查初态、上下行采样跳变、保持、错边沿及高相透明跟踪。覆盖非零 VSS、非周期时钟、停钟和参数覆盖，不逐点要求与旧 reference 相同。数值精度须足以区分符合规格的实现和明确错误，波形记录不足时先处理环境。

尚未建立正式任务、checker 或新参考实现。下一步验证公开合同与不同合法实现是否相容，校准过渡时间的观测定义和容差，再固定后端及正式材料。当前无需再决定是否加入真实采样级非理想效应。
