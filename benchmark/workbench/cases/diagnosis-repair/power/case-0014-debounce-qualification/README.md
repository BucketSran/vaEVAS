## 工程目标与拟定交付

给定三端口 `sig, rst_n, out` 的 VA 故障模块，恢复“输入连续高到达资格时间才置高、下降或复位取消等待”的行为。可用于控制/使能信号抗毛刺的行为验证；尚未绑定具体 PMIC，不声称这是模拟去抖前端模型。

允许整体重写，保持公开接口和要求。验收激励与 checker 固定。题目所给复现现象拟为短脉冲也产生高输出，修复后既要拒绝毛刺，也要接受持续合法输入。

## 原资产与迁移取舍

来源 v4-1005，family005。实际 starter 在输入上升时立即置高，绕过稳定等待；本轮字节核对与声明故障一致。原源码、reference、provenance 和 SHA-256 见[修复筛选](../../../../migration/v4-repair-screening.md)。这是人工注错素材，没有真实工程 bug 记录。

保留低有效复位、资格取消和输出保持的工程意图。旧 reference 仅由 sig 上升启动等待，不默认将复位释放解释为重新资格；新题需显式说明。公开规格会删除旧语言子集限制。

## 公开材料与独立验收

拟提供可读故障源码、端口/参数表、状态规则、短脉冲复现及自测入口。checker 从 sig/rst_n 的输入交点安排并取消资格到期事件，独立验证毛刺、持续输入、等待中复位、再次上升和已置高后的清除；输出有限平滑按公开容差处理。

初始输入已高、复位释放时输入仍高、stable=0 和同刻事件尚需明确。checker 未实现，旧认证不沿用。

## 留给同行的问题

这个故障非常直接，完整重写也可能只需一个短状态模型。建议仅作为基础修复候选，后续比较修复与从零建模的表现，再判断保留价值。不要通过限制重写来人为制造诊断难度。
