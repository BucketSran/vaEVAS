# 题面草案：POR 电源序列与复位检查

> 作者工作稿，未达到可评分状态。下列待定合同补齐并校准前，不向模型发放。

给定源码可读的 POR 电路、固定连接和运行入口，请实现指定的 VA 激励与监控模块，完成上电、欠压及恢复测试，并报告每个阶段的复位事件、时间间隔和违规情况。

拟允许修改：指定激励、观测与报告模块。固定：DUT、连接、验收激励参数集及独立 checker。实际激励必须满足规定场景，观测模块不得驱动被测输出。

需要公开填全的合同：

| 项目 | 尚待确定 |
| --- | --- |
| 接口 | 供电、控制、被测复位输出、极性和电压域 |
| 工况 | 模式、斜坡、欠压深度/保持/恢复、初态、观察终点 |
| 行为 | 复位保持与释放、迟滞、再次断言、重复周期规则 |
| 时间 | 延迟起点、缺失事件/超时、阈值相等及同一时刻事件顺序 |
| 报告 | 文件/字段/单位、场景 ID、无效与未完成状态 |
| 误差 | 电压、事件时间和波形观测分辨率 |

验收依据实际激励与输出波形独立计算。除正常场景外，应正确报告公开合同内的违规情形。隐藏测试不得新增未公开性质。

本稿尚无确定数值、可运行资产或可信评分器。改题理由和 review 问题见 [设计卡](README.md)。
