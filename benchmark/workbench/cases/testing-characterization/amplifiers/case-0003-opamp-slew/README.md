## 工程动作与材料状态

拟给定源码可读的运放、规定反馈与负载，要求 Agent 编写 VA 阶跃激励和压摆率测量模块。Cadence 示例已展示供电、反馈、等待、输入阶跃以及输出两阈值穿越测量的组合方式。

当前只有方法来源，**尚未选定 DUT**，因此没有电路 ID、同源组、题面草案或运行证据。安装库原代码仅用于内部学习，新任务需原创实现与可使用的电路资产。

## 可以怎样形成一道题

基本形式是：在规定的共模、幅度、负载与稳定初态下施加阶跃；按输出指定阈值的有效穿越对计算 ΔV/Δt，报告压摆率和无效状态。必须确认这是目标大信号工况，不能通过很小的输入阶跃“完成”测量。

原示例只测正向响应。双向阶跃、不同极性状态重置、重复周期可以增加工程要求，但需结合实际运放决定，当前没有默认认定这些内容已获批准。只改变斜坡幅度或等待时间通常作为本题场景。

独立 checker 应从实际激励、连接和输出波形核对工况与阈值事件；遗漏穿越、错误事件配对或超时不能产生伪造指标。正常与受限响应、振铃多次穿越、未达到上阈值都是待研究的校准条件。阈值、方向、单位、窗口和误差全部需要公开。

## 本轮需要确认

先选具有可信大信号动态和明确使用许可的实际运放，最好同时具备器件网表与配套 VA 模型；随后确定先做单向还是双向测量，以及如何固定负载适用范围。缺少实际 DUT 时不先凑规格或宣布难度。

这与 POR 的完整流程、LDO 的限定测量环节属于同一工程类别的不同细分，不因此新增类别。
