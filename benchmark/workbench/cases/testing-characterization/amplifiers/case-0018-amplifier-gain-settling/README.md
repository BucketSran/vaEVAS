## 工程目标与拟定交付

给定可读的电压域放大模型、固定激励与连接，交付随仿真运行的VA测量模块，报告增益、建立结果及测量是否有效。先建设静态增益测量基线，再加入有限建立实验。两个实验可以分次运行，不把所有来源模型串成一个不存在的电路。

2026-10-11作为首批放大器路线入口登记。当前为材料筛选，具体测量窗口、接口、报告和数值标准尚未冻结。给Agent的是固定被测电路与测量接口，不提供待完成仪表的参考答案；允许读取被测源码，禁止修改被测电路、正式激励和checker。

## 原资产与改编

见[来源卡](../../../../sources/v4-amplifier-characterization.md)和[电路卡](../../../../circuits/v4-amplifier-characterization-fixtures.md)。038提供可选增益、共模与限幅输出；093提供差分输入输出的峰峰值比值测量思路；370提供按采样时钟更新的有限建立轨迹。它们分别有旧实验，尚未组成新的健康测量工程。

093旧实验用两个独立正弦源产生输入和输出，没有被测放大器。新题必须接入实际放大模型，并处理单端模型与差分测量端口的连接。093从start_time起持续累积极值，没有独立结束或重武装窗口；不能直接拿这个累积结果验收多次阶跃。038的主输出没有使用声明的tr做平滑，不能用它代表有限带宽运放。

370是离散一阶宏模型，输出逐步接近限幅后的增益目标。内部settled由连续三次内部误差合格置位，不能作为新测量模块的答案。首版计划围绕非饱和工作区的增益与有限观察窗内的建立；高阶稳定性、负载响应、噪声和压摆率不从这些资产中推导。压摆率仍由[case-0003](../case-0003-opamp-slew/README.md)单独探索。

## 独立验收

增益实验先定义固定观察窗、测量采样规则与最小输入跨度，再从实际输入输出计算同一口径的幅度比。连续极值与离散采样极值不能混用；若采用旧峰峰值口径，应声明不恢复增益符号。输入跨度不足时，正确报告无效可以通过任务验收。

建立实验需公开阶跃起点、目标来源、误差带、持续达标条件和观察截止时间。测量模块从实际输出确定进入误差带并满足保持条件的时间；有限观察窗内未建立须如实报告，不能直接转发DUT的settled。目标值由出题时选定的公开测量定义给出，不能暗中在标称目标与最终观测值之间切换。

独立checker核对实验确实发生、仪表未改变被测信号，并复算每个窗口的指标、有效性和报告。正确测出错误增益或未建立不应判为候选失败。校准负例应能区分硬编码增益码、沿用前一窗口、复制内部标志和伪造完成；良性实现须在同一公开口径下得到一致结果。

## 本轮需要确认

先连接并核实被测模型，固定静态增益的观察口径；再确定370的动态实验和建立定义。若两部分形成明显不同的独立工程交付，再拆分关联题卡；本轮不预设最终题量。数值容差、后端、健康实现、正式checker和难度均无校准结论。
