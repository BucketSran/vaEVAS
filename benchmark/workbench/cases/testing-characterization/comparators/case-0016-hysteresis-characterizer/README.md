## 工程目标与拟定交付

给定可读比较器和固定扫描工程，补写一个随仿真工作的VA仪表。仪表在比较器输出实际翻转时捕获输入电压，保持最近两种方向的结果，计算表观滞回宽度，并直接报告结果是否完整。属于电路测试与表征。无需因旧题标为DUT而归到规格建模，也不要求为同源资产再出一题。

这里测量的是指定扫描条件下可观察的翻转电压。静态上、下门限为内部切换条件；输出有延迟，仪表看到输出翻转时输入可能已越过该门限。去除动态误差、提取准静态迟滞或辨识延迟，属于另一个测量合同，首题暂不引入。

建议先提供固定公开测试。后续允许固定连接下自定义扫描，可单独比较其Agentic效果；本题不强制增加响应驱动激励。

### 拟公开的行为

令 `u(t)=V(vin,vss)`，`e(t)=V(cmp_out,vss)-V(vdd,vss)/2`。

- `e`从负变正时记录 `u(t)` 到 `trip_rise`；从正变负时记录到 `trip_fall`。
- 未捕获的通道输出相对VSS的0V；已经捕获的通道在下一次同方向事件之前保持。
- 两个方向都至少观察到一次，才输出 `hyst_width=trip_rise-trip_fall` 并置 `valid` 为高。在此之前width为相对VSS的0V、valid低。
- 四路输出均相对VSS；valid低为VSS，高为VDD。trip_rise、trip_fall、hyst_width直接以伏为单位，不按供电幅度归一化。
- 最近上升值与最近下降值分别更新，不要求来自同一个扫描周期。第二轮刚上升时，用新上升值减上一轮下降值；valid继续保持高。
- 每次仿真重新初始化。初始cmp_out已经处于高电平，不等于已经看到一次上升事件；初始化点本身不计数。若初始化后实际发生中点穿越，则按公开事件规则计数。
- `tr`用于测量输出的平滑响应。输出容许的更新时间和稳定窗口必须公开，具体数值待后端校准；不要求候选复刻参考解逐点平滑形状。

首版建议每次运行使用固定正电源跨度；不同运行改变VSS、VDD和参考电压。扫描连续、穿越孤立且留足输出稳定时间。噪声、反复触碰门限和动态供电另行设计，不作为未公开隐藏要求。

报告建议包含 `has_rise`、`has_fall`、最近两次捕获时间、两路trip、width及完整性状态。字段使用秒、伏，未观察到的事件时间明确缺失。数值与电气输出在稳定后必须一致。VA可用 `$strobe` 等输出任务形成机器可读报告；报告格式待题面实现时固定，不绑定源代码写法。每个事件的诊断日志可选，首题不额外考查日志排版。

仿真结束只有一个方向时，应如实报告测量不完整。隐藏测试有意只给一个方向，此时正确报告不完整是任务通过，不是被测电路失败。是否满足某个产品迟滞范围不在首题评分范围；测出偏大的宽度也可能是正确答案。

## 原资产与改编

来源身份、哈希、旧形态区别及GLM复核更正见[来源卡](../../../../sources/v4-hysteresis-characterizer.md)。具体比较器及PWL参数见[电路卡](../../../../circuits/v4-hysteretic-comparator.md)。

原比较器以差分输入与 `offset±vhys/2` 比较，状态在迟滞带内保持。原实验Vref为0.45V，offset为5mV，vhys为50mV，故静态输入上门限为0.480V、下门限为0.430V。

原测量器在cmp_out穿过0.45V输出中点时采样vin。端口的0.45V输出判定中点与0.480/0.430V输入切换门限是两个不同概念。初始vin=0.420V，测量通道为零，valid低。上扫得到rise，后续下扫得到fall，此时width与valid才有效。第二轮两次翻转继续刷新。

设从内部切换到输出中点的实际延迟为δ，局部上扫斜率为S_up，下扫斜率的幅值为S_down，参考端及电源不变且延迟期间未遇到PWL转折，则：

```text
rise_observed = 0.480 V + S_up × δ_rise
fall_observed = 0.430 V - S_down × δ_fall
width_observed = 0.050 V + S_up × δ_rise + S_down × δ_fall
```

例如只为说明机制，假设实测中点延迟均为0.15ns，扫描速度为±7mV/ns，便得到481.05mV、428.95mV和52.1mV。0.15ns是假设值，不是原模型运行结果；不能把td或 `td+tr/2` 未经核对直接代入正式验收。

保留原观察链、八端口和最近双向捕获语义。新增明确的初态、输入条件、报告、公开容差与独立验收；去掉历史题面中未由工程需求证明的语言子集禁令。原包只是行为级电路，尚无配套晶体管比较器或芯片测试记录。

## 独立验收

checker独立读取输入、cmp_out、电源轨和候选输出波形。候选报告是被核验对象，不作为真值来源；旧参考解也不是唯一判据。

1. **确认输入实验。** 冻结DUT、连接、激励、工具链身份和候选可修改文件。记录实际波形，确认预定扫描和电源条件确实运行、被测信号未被测量模块驱动改变。异常的环境运行不能伪装成候选测量失败。
2. **独立定位事件。** 从实际波形计算e(t)，按符号穿越找上升、下降时刻。用事件附近的时间包围区间与插值估计穿越时间，再计算该时刻的u(t)。合并同一过零点的重复表示；具体过零、恰好落零点规则由校准固定。
3. **逐事件重建状态。** 独立维护两个捕获标志和最近值，生成每段保持期的期望trip、width和valid。检查无事件期不更新、未就绪期不提前置valid、后续同向事件刷新。不能只比较最后一个width。
4. **核对输出与报告。** 检查公开更新时间窗内进入正确值并保持，允许输出平滑。最终报告必须与独立捕获历史一致；缺少最终报告不等于“没有事件”。校验有效标志、缺失值、单位和捕获时间。
5. **给出分项失败证据。** 分开报告漏事件、方向错误、捕获值错误、保持或刷新错误、valid错误、报告缺失或不一致；任务总分按冻结规则汇总，不因实验数量较多提高本题权重。

波形采样误差、事件定位误差和输出稳定误差分别校准。对斜坡，时间误差Δt会带来约 `|du/dt|×Δt` 的电压误差；可据此设计逐次事件的误差预算，再公开最终数值容差。隐藏扫描必须保证可区分的错误大于误差预算。若波形分辨率不足以确定事件，先修采样/验收环境，不能随意放大容差或把不确定性算成模型失败。

后端固定前，要用不同合法VA实现验证环境，而非只运行旧reference。正式评分期间使用冻结的保存精度和数值设置；校准时用更细设置验证事件重建的稳定性，不把每个提交都跨仿真器重跑作为默认要求。

### 首批验收场景与负例校准

| 场景 | 主要区分什么 |
| --- | --- |
| 完整上扫、下扫 | 边沿写反、采到cmp_out而非vin、宽度符号反、一直不valid |
| 改变offset、vhys、Vref | 硬编码公开示例的输入翻转电压 |
| 不同延迟和扫描速度 | 把模型vhys当实测width、在输入静态门限而非输出中点捕获 |
| 同一次运行内多次不同速度扫描 | 只记录第一组、不刷新；选取可观察差异大于容差的参数 |
| 固定VSS非零并改变供电跨度 | 使用绝对vin、忽略局部地、使用固定0.45V输出判定门限 |
| 没有翻转、只有上升 | 伪造结果、把单方向捕获当完整测量、空报告蒙混通过 |
| 初始输出已稳定高、只有下降 | 检查不凭初始高电平伪造rise；须先校准初态确实没有额外启动穿越 |
| 事件间保持区间 | 非事件时更新、固定时刻改值、报告与端口不一致 |

所有变化都在公开输入范围内。隐去的是具体组合，不是规则。良性对照至少覆盖两种独立正确实现；负例按真实缺陷组织，既保留旧边沿写反/符号反等线索，也补充硬编码静态门限、first-only、局部地错误和报告错误。不能用一个粗幅度缩放缺陷替代全部校准。
