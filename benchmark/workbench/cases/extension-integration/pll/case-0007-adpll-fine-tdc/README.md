## 工程目标与拟定交付

在已能正常捕获目标频率的粗调 ADPLL 工程中，新增 fine TDC 相位测量与跟踪路径。Agent 可修改题目指定的 TDC、适配逻辑、控制器、连接及参数；验收激励、checker 和其余环境固定。可修改清单与参数范围必须公开。

交付要求包含：关闭 fine 模式时保留旧行为；开启时按照公开协议完成测相、量化、更新控制与模式切换；重置或换目标时撤销旧资格并重新进入合法状态。这是从健康系统扩展能力，旧基线中的断路或极性错误应由出题者先修复。

## 原资产与新增要求

[Tiny Tapeout 来源](../../../../sources/tiny-tapeout-adpll.md)的窗口频率计数与 PI 是粗调架构起点，DVCon 论文提供 TDC 与跟踪方法。它们没有共同提供现成 VA fine TDC 系统。[电路记录](../../../../circuits/tiny-tapeout-adpll.md)同时被 case-0004 使用，两题不是独立电路样本。

本题仍需建立从 DCO 来的 N 分频相位反馈、边沿配对/PFD、量化合同、模式控制，以及真正能执行细调的 DCO 路径。原行为 DCO 低六位无作用，仅插入更精细的测量模块无法保证环路改善。

建议出题者提供健康的细调执行器，把本题范围放在测相与控制集成。若要求 Agent 一并扩展 DCO，则必须明示新增职责，不能作为隐藏要求。是否引入 dithering 或 DSM 尚未决定。

## 独立验收

- 模块级输入可控 lead/lag 边沿，验 TDC 的符号、分辨率、量程、饱和、同刻边沿、缺边沿和更新延迟；这些语义先公开。
- 系统级从实际输出与分频反馈独立提取频率、相差和扰动响应，按公开连续窗口判断状态。不能只看内部 `lock` 位。
- 对 reset、retune、模式开关和受控相位扰动验证资格撤销、切换连续性及恢复。关闭 fine 模式的兼容标准也须有明确窗口与容差。
- 校准反馈未闭合、符号相反、TDC 正确但控制码不作用、旧 lock 残留及绕过控制器等负例。

数值指标必须来自健康基线和 checker 校准，暂不承诺相噪、抖动或锁定时间改善幅度。当前没有运行验证，不能以“fine”命名本身证明新增能力。

## 本轮需要确认

先界定最小可成立的集成任务：建议固定细调 DCO 与分频反馈，由 Agent 完成 TDC、控制更新和模式接入。需要确认这一工作量是否仍足以构成独立工程目标。

然后建立健康粗调与完整参考系统，冻结可达工况、公开性质和容差，再考虑是否扩为更大系统任务。
