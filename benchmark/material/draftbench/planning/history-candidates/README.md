# 历史 benchmark 投稿候选规划

全面核对 Grok 的342项摘录完整来源及113项待改造来源后，建议将原108项扩展为 **138项规划候选，归属133个规划单元，另保留U30一项条件后备**。新增30项均有逐项理由，尚待用户审核；原105项确认与3项终审建议的状态保持。候选池没有题量上限，正式录取仍取决于合同、独立参考、评分校准和实测难度。

本规划只使用历史v1–v4资产，未加入现有56题、早期41题包、独立R01或UWB新资产。本轮只做规划，没有建题或修改历史合同，没有运行仿真和模型实验。EVAS当前支持范围不作为选题排除条件。

## 审核入口

- [455项来源全面复审](GROK-REVIEW.md)：每个条目的原题编号/版本、Grok分类、处置、关联目标、复用内容、改造和理由。
- [138项逐项候选清单与U30后备](CANDIDATES.md)：功能家族、S/R/T/I、预估难度、建设优先级及成本，每项可跳转详情。
- [全量复审机器登记](pool-review.json)：完整455项判断、历史归并、补充公开上下文及原108项的固定身份。原评论见[Issue #159](https://github.com/BucketSran/vaEVAS/issues/159#issuecomment-6401348069)。
- [候选机器登记](register.json)与[候选意见对应](review-response.json)：当前任务、422个历史案例、历史形式及建设条件。[inventory.jsonl](inventory.jsonl)保留751条原始去向及公开行为摘录，[sources.json](sources.json)保留版本与SHA256，[provenance.json](provenance.json)记录逐轮审查范围。

## 455项如何进入当前候选池

| 本轮处置 | 来源数 | 对当前候选池的影响 |
| --- | ---: | --- |
| 保留已有 | 107 | 直接关联原候选或U30后备，沿用上一轮逐项复审并重新核对身份和关联 |
| 新增建议 | 30 | 各形成一项有独立交付责任的规划任务 |
| 并入相关方向，保留变体 | 129 | 保存协议、对象或测量方法差异；不自动增加独立任务数 |
| 配套 | 185 | 用作公共构件、健康/违例对象、刺激、参考或语言工具检查 |
| 暂缓 | 4 | 目标机制缺少足够资产依据，先明确重建对象及真值 |
| 合计 | 455 | 覆盖342项摘录完整、101项规格待补及12项观测待改 |

107是来源条目数，108是原任务数，二者不能相减求新增题量。同源S/R/T可有不同交付，一个候选也可组合多来源。129项变体含给定DUT、接口/事件协议和测量方法的可选资产，并不表示已经写成129份题目或证明它们形式等价。

本轮不再以“基础层已经六题”为理由直接排除其他来源。静态传递、计数和单状态更新仍逐项检查是否有独立用途与可区分错误。原六项B类基础候选保留；新增C213、C228、C309、C379预估B–M，具有偏简单风险，安排P2后置校准，不预先承诺正式录取。其余候选的M/H同样只是结构估计，尚未证明与CVDP等难。

新增25项S、2项T、3项I。S的价值来自不同的状态关系和观测责任，例如跟踪到保持的下垂累计、不同码组的采样年龄、串行决定形成即时部分和输出、连续/离散高通的记忆与外部观测时钟。

## 四项暂缓的具体原因

| 来源 | 可复用部分 | 暂缓独立题的原因与重审条件 |

| bootstrappedsamplerchargemetric | 使能保持、下垂步进和误差旗标 | 近轨幅度指标没有改变采集电荷。需先给出自举电荷/有限采集模型及独立观测依据。 |

| vgastepresponseclassifier | 码变化接口和稳定计数 | 原文明确输出不出现过冲，指标只看码差。真实步响应需动态对象和输出测量真值。 |
| saturationrecoverylimiter | 夹限、enable与sat接口 | recovery句子确实截断，现有合同没有恢复记忆。需先确定过载动态、参数及恢复观测。 |

暂缓不等于资产删除。其他未新增来源大多已作为变体或配套保留，具体理由见455项表，而不是统称为“拒绝”。

## 建设顺序与进入正式集的条件

| 顺序 | 项数 | 安排 |
| --- | ---: | --- |
| P0首批 | 15 | 沿用已核对的首批：C055的S/R、C056的S/R、C060、C105、C109、C176、C260、C264、C266、U15、U16、U17、U18。 |
| P1第二批 | 90 | 原65项加25项新增，逐项看健康对象、观测真值、反馈和接口依赖，允许同一来源共建。 |
| P2后置 | 33 | 原28项加5项新增，其中C367规格建设较多；C213/C228/C309/C379先校准偏简单风险。 |
| HOLD后备 | 1 | U30先确认实际消费者能否暴露提前完成故障及诊断价值，不计入138。 |

优先级是建设顺序，不是正式主集/扩展集录取。建设成本L/M/H分别表示主要整理、补行为关系与参考、新增对象/真值或复杂故障复现；当前L17、M88、H33，是作者工作估计而非工期承诺。每项都有独立理由，未按功能矩阵分配题量。

正式录取前仍需完整公开合同、独立参考、正常与违约对照、评分校准和最小starter审核。公开必要公式、单位、采样含义、复位和输出边界；允许自主控制律时按公开性能目标评分。完整状态更新或测量实现不作为默认填空骨架，也不靠缺失正确行为制造难度。

原题版本、S/R/T派生形式与实质复用的DUT/故障/真值要共同考虑划分，避免同源泄漏。普通公共工具不自动把所有任务合成一个数据组。129条变体保留差异和来源，后续由任务责任与实测决定是否值得独立录取。

## 对Grok意见的处理与证据范围

评论由用户账号发布，Grok身份沿用用户说明。342表示按摘录可定义行为的来源代表，不能直接理解为满足论文难度、评分与可复现条件的342题。113项也不全是原题缺规格，需要回查完整合同。

本轮核对了455份首选公开原件身份，290份随仓库、165份仅本地可用。348项池外来源逐项阅读行为、参数及相关合同，107项已关联来源沿用6b1270f0的逐项复审，并重新核对身份和关联。回查发现高通系数、event-or事件周期、权重表等已在Task Contract/参数段公开；真实缺口仍逐项列出。

补充原文在`pool-review.json`及`review-response.json`中，旧`inventory.jsonl`摘录保持。来源总登记仍为1269份文件身份，676份仓库原件、593份local-only。可携带摘录和SHA身份不等于公开完整题包；资料使用与分发仍遵循[历史资料说明](../../../historyref/README.md)。

本轮未逐份深审所有版本的gold/checker，未运行仿真、评分或模型实验。选题判断需要人工审核，静态检查不能证明工程价值、难度或正式题目验收。本次规划差分由两个新上下文分别审查规范/证据和需求/选题。需求审查核对30项新增及4项暂缓，抽查变体，发现C124未提供比较器消费者的事实措辞已修正。它没有重新穷尽348项价值判断，也不替代正式题目验收；详细范围见provenance。
