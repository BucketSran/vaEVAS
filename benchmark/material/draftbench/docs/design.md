# Benchmark 人工审核原则

我们评估用 Verilog-A 完成电路工作的能力。人工审核先判断题目是否值得做、成绩是否能说明目标能力。

## 人工如何判断题目质量

1. **工作有价值。** 使用场景和交付物明确，能说明工程师为什么需要完成这项工作。
2. **电路行为合理。** 关键状态、动态与协作得到保留，模型假设和适用范围有依据，时序与验收边界说清楚。
3. **材料与验收可信。** 公开材料说清决定正确性的行为，合并重复表述；验收能接受不同正确方案，并检出典型错误和绕过目标的做法。
4. **贡献与结论清楚。** 说明相比已有题新增什么；基础题可以保留，难度由实测判断，内容质量与运行成熟度分别报告。

## 区分两条电路路线

- **真实电路结合**需要有来源的器件电路、数据与工况依据。固定数据建模不一定在解题时调用器件仿真。
- **全 Verilog-A**需要自洽的行为假设与有意义的电路工作。全 VA 不自动表示 EVAS 已兼容。

人工查看简短的内容结论、运行事实和待取舍。具体执行检查由 Agent 和工具完成，参考解通过不代替题目设计认可。

先明确有依据的用途和初步行为要求，再建立 gold、设计验收并完善 instruction。早期数字和证据可以待定；gold 是待核验参考，格式检查不替代工程判断。

## 人工在什么时候参与

- 批次开始时看任务清单、工程价值与行为边界，已确认的决定直接沿用。
- 代表题完成后看整套材料、验收依据及实际校准；在获准实测后判断难度，确定可复用范围。
- 批量产出后看每题短结论，按题决定录取、修改或暂缓；重点展开新假设、偏离样板与异常项。

gold、checker、用例展开、题面生成和常规修复由 Agent 完成。人工处理中途出现的实质工程取舍，
不逐项指定测试波形或检查点。[详细分工](evaluation.md#人工介入与批量交付)与
[验收设计](evaluation.md#逐题-checker-与终评设计)按需查看，未知数值和证据继续保留待定。
