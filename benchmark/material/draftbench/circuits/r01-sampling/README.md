# R01 采样与多通道读出

本阶段先收口 R01，再用首轮实测调整后续题目难度。沿用六类电路、21 个已保留方向，继续确定实际题目；以下内容尚未形成正式录取。

## 按电路类型看新增工作

| 电路 | 主要工程责任 |
| --- | --- |
| 单个采样保持 | ideal 隔离理想跟踪，basic 保留有限采集，core 再加入注入与漏电 |
| 同步多通道 | 多个独立状态同时采集成帧，等待不同时间后读出 |
| MUX 共享采样 | 多通道共用一个状态，处理前拍残余、路由与样本归属 |
| 时间交错 | 双支路错相采集，按读沿组合序列，避免重复或错误消费 |
| 乒乓采样 | 交替采集与保持，保证持续输出窗口和支路交接 |
| CDS | 参考与信号配对作差，区分共同偏移抑制与剩余误差 |

## 本轮内容审核与运行成熟度

上述模块、系统与现有响应驱动仪器属于全 VA 路线，共用的 core 是名义行为模型。
真实 SKY130 采样级题另属固定数据建模：真值来自器件仿真，候选重验使用固定数据；当前 core 尚未拟合这份数据。

已有原始资产的 Spectre 观测，不等于新题包的独立验收或 Agentic 就绪。当前代表题的版本与运行缺口只在[批次记录](../../batches/r01-sampling-01/README.md)维护。

响应驱动仪器尚未确认为题目方向，不属于原 21 项。全 VA 题推进到完整题包与一轮模型解题实测；真实电路结合题本轮完成 instruction 与 gold，暂不实际测试。完整阶段边界见[本阶段安排](../../DISCUSSION.md#r01-本阶段安排)。

## 单模块当前判断

ideal 已确认保留，当前先 review [全 VA 规格重建的 instruction、starter 与 gold](../../batches/r01-sampling-01/tasks/r01-spec-ideal/README.md)。真实 ADC 题已确认按指定边界替换采样保持，ENOB 门槛暂不确定；该路线尚未形成具体题目合同。
初步建议保留 basic 作为基础状态建模题：考有限采集和前拍继承，方程已给出，不考器件辨识。
core 的保持误差扩展与中断恢复仍待审核，继续采用模块级行为抽象；器件级建模研究推迟到 11 月 DAC 投稿之后。

人工下一步确定各题的工程工作、给定材料和交付：区分按给定方程实现，与根据真实电路或数据建立模块级模型，再判断 core 各题的独立价值。
实现误差与采集不足留下的电压差分别解释；具体范围与容差仍待[代表题合同审核](../../batches/r01-sampling-01/README.md)。
之后按同步、MUX、交错、乒乓、CDS 继续，看系统贡献与表征负担。真实数据的实验说明问题见[详细参考](reference.md#真实采样级数据建模的纳入方案)。
