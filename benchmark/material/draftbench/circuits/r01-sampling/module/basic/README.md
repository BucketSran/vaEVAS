# R01 无注入无漏电 track/hold（basic）

`r01_track_hold_basic` 是连续状态采样保持的中间档：保留有限建立和前拍记忆，
**按构造**删除电荷注入与保持漏电。它与[连续状态核心](../core/README.md)共用
状态方程结构和输入依赖采集，但保持分支 `rate=0`，存储值在保持期间严格冻结。

本目录提供可运行源码与激励台架，供电路 review 和后续出题选材。
当前没有本版评分 checker、完整 Harbor 题包或模型解题实验。
2026-10-12 已在 Spectre 21.1 完成一次成功运行，实测记录见[运行记录](../../test/RUN-RECORD.md)。

## 三档阶梯中的位置

| | ideal | **basic（本模块）** | core |
| --- | --- | --- | --- |
| 采样动作 | 跟踪透明，进入保持时冻结 | 一阶跟踪的有限建立 | 同 basic |
| 保持 | 严格冻结（代数值） | **严格冻结（ODE 状态）** | 注入台阶 + 漏电下垂 |
| 前拍记忆 | 无 | 有 | 有 |
| 考察点 | 事件语义边角 | 窗口规划：给多久、从哪来 | 全机制表征与测量 |

basic 把"建立误差"与"保持误差"解耦：短窗口结束时输出与输入的差完全由
`tau_eff(vin)` 和窗口初值决定，checker 归因时无需扣除注入和下垂的贡献。

## 与参数退化的边界

core 设 `pedestal=0`、`tau_hold` 取极大值可以逼近本模块，但 `tau_hold`
约束为有限正数（`from (0:inf)`），漏电只能压到 µV 级，不能严格归零；
本模块保持分支贡献恒为零，冻结是结构性语义，不是数值近似。
按组 README 的约定，这构成独立工程要求，因此单列源码而非对照实例。

## 接口与状态

```verilog
module r01_track_hold_basic(vin, track, rst, vout);
```

端口、`vth`、`vinit` 与 core 一致。状态方程：

```text
rst 高：  dx/dt = (vinit-x)/tau_reset
采集：    dx/dt = (vin-x)/tau_eff(vin),   tau_eff = tau_acq*(1+acq_curvature*u^2)
保持：    dx/dt = 0                        （u = (vin-vmid)/vscale）
```

参数取 core 的同名子集（`vth`、`vinit`、`tau_acq`、`vmid`、`vscale`、
`acq_curvature`、`tau_reset`，默认值一致）；`pedestal`、`tau_ped`、
`tau_hold`、`vleak` 及注入登记事件已删除。`idt(rate, vinit)` 无条件执行，
DC 与瞬态启动初值均为 `vinit`；复位、采集期间按对应时间常数 `$bound_step`。

## 机制来源与适用边界

机制与 core 相同（[功能族总览](../../README.md)引用的 ADI MT-090），仅删除注入与漏电两项。
不描述输入阻抗、负载电流、噪声、孔径抖动或 PDK 条件；core 也未覆盖这些机制。是否以其出题、与 024/071 及 core 的分工属于后续审核问题。

**工程场景与工作边界。** 采样电容需要时间建立，短采集窗口会留下前一拍的电压。
求解者把给定连续行为写成一个 VA 模块，供后续系统选择采集窗口。
这是基础规格建模题：方程已给出，工作是正确实现动态和状态继承。
输入相关时间常数是本项目的行为近似，尚未证明对应某个真实采样电路。

**材料与交付。** starter 只给 `track_hold` 的端口、七个参数和 TODO，
不指定内部节点、变量或积分算法。公开网表提供输入、采集和复位激励。
求解者原位编辑并提交 `/app/circuit.va`，不交记录协议或额外测量模块。

**代码大体思路。** 保存一个连续电压状态，按复位、采集、保持三个分支改变其变化率。
以下是作者导读，不进入 starter，也不规定必须采用哪种 VA 状态表示：

```text
开始瞬态：状态 = vinit
持续计算：
    若复位有效：按 tau_reset 向 vinit 返回
    否则若采集有效：按当前 vin 对应的 tau_eff 向 vin 建立
    否则：冻结状态
输出当前状态；切换模式不重新初始化
```

与旧 071 相比，新增的是连续时间跟踪、采集期间变化的输入、输入相关建立速度和有限时间复位。
前拍残余与有限采集本身已有覆盖，不把它们再算新增机制；注入和漏电留给同族扩展题。

### 待审核的验收方案

下表只定义需要观察什么，不是已实现或已运行的 checker。
各项输出误差均相对于本题方程定义的连续响应，拟要求最大绝对误差 ≤ 2 mV。
独立预期不能直接取参考 VA 的输出；恒定输入片段可用解析响应，变化输入片段需独立求解。

| 规格要求 | 台架实验 | 测量定义 | 拟判定标准 |
| --- | --- | --- | --- |
| 初态为 vinit | 分别从保持、采集、复位启动 | 起始输出及紧随其后的响应 | 初态和后续轨迹满足方程 |
| 有限、输入相关采集 | 不同输入电平、短窗和长窗 | 全窗轨迹和窗口末输出 | 最大响应误差 ≤ 2 mV |
| 采集期间持续跟随输入 | 窗口中途改变 vin | 变化前后连续轨迹 | 不冻结起始目标；误差 ≤ 2 mV |
| 前拍状态继承 | 多次短窗，中间改变输入 | 下一窗初态及随后响应 | 不重置记忆；误差 ≤ 2 mV |
| 理想保持 | 保持期间改变输入并延长等待 | 相对规定保持值的轨迹误差 | 不添加下垂；误差 ≤ 2 mV |
| 有限复位与优先级 | 采集或保持中复位，短复位后释放 | 复位阶段和恢复轨迹 | 不瞬时钳位；误差 ≤ 2 mV |
| 参数生效与完整覆盖 | 改 vinit、tau_acq，覆盖上述情形 | 各条件轨迹与完成情况 | 各项均满足；缺失或环境异常单列 |
