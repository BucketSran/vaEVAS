# R01 理想边沿 track/hold

`r01_track_hold_ideal` 是采样保持的理想行为资产：采集瞬时完成、保持严格冻结、
没有漏电、注入或输入依赖。它与[连续状态核心](../core/README.md)共用端口和控制约定，
但语义不同：核心用连续状态方程演化，本模块的存储值只在控制穿越时刻改变。

本目录提供可运行源码与激励台架，供电路 review 和后续出题选材。
当前没有评分 checker、Harbor 任务或模型解题实验。
2026-10-12 已在 Spectre 21.1 完成一次成功运行，实测记录见[运行记录](../../test/RUN-RECORD.md)。

## 接口与语义

```verilog
module r01_track_hold_ideal(vin, track, rst, vout);
```

端口、阈值 `vth` 和初值 `vinit` 与核心模块一致。三种控制状态的输出：

```text
rst 高：    vout = vinit        （复位优先，瞬时恢复）
track 高：  vout = vin          （理想缓冲，无建立时间）
两者均低：  vout = held         （冻结，无下垂、无注入）
```

`held` 只在两类事件更新：

- `track` 下降穿越：`held = V(vin)`，即穿越时刻的输入值，无孔径延迟。
- `rst` 下降穿越且 `track` 仍低：`held = vinit`。复位释放直接进入保持时
  冻结的是复位值，不是复位前的旧样本。若释放时 `track` 已高，不更新 `held`；
  随后的 `track` 下降沿会采到当前输入。
- `initial_step` 置 `held = vinit`：t=0 时 `track` 已低不虚构一次采样。

控制电平在阈值恰好相等时属于低电平，与核心模块约定相同。

## 与连续状态核心的对比

参数退化不能得到本模块的语义：核心把 `tau_acq`、`tau_reset` 趋于零后仍是
连续演化，不会产生穿越时刻的瞬时采样动作。两者是不同考察维度：

| | 本模块（ideal） | 连续状态核心（core） |
| --- | --- | --- |
| 采样动作 | `cross` 事件瞬时冻结 | 一阶跟踪的有限建立 |
| 保持 | 严格不变 | 注入台阶 + 漏电下垂 |
| 前拍记忆 | 无 | 短窗口残留上一拍 |
| 适合考察 | 事件边角：初始电平、复位释放进保持、相邻沿贴近、短窗口 | 测量与表征：建立误差、pedestal、droop |

台架复用 core 的同一 PWL 激励并同屏实例化两个模块，短采集窗口
（core README 的 8 ns 窗）和长保持段的差异逐穿越可见。

## 机制来源与适用边界

理想语义是标准采样保持教科书定义（见[功能族总览](../../README.md)引用的 ADI MT-090 第 2 页），
无新增机制来源。本模块不描述输入阻抗、负载电流、噪声、孔径抖动、时钟馈通或
任何非理想效应。core 仅增加其文档列明的采集、注入、漏电与复位动态，也未覆盖上述负载、噪声和抖动机制。

仓库已有[024 边沿采样保持任务](../../../../batches/v2-01/tasks/v2-spec-024-clocked-sample-and-hold/instruction.md)
覆盖边沿取样与保持。本资产是 review 材料，不修改 024 的合同，
也不自动成为新题。是否以其为基础出题、与 024 如何分工，属于后续审核问题。

## 运行

从本目录进入对应台架目录后运行：

```sh
cd ../../test/ideal
spectre tb.scs
```

2026-10-12 在 Spectre 21.1（thu-sui）实际运行一次：返回码 0、0 错误、17 µs 完整
瞬态、5,137 个保存点。实测：第一个 8 ns 短窗结束时 `ideal` 精确等于 1.600000 V，
`ref` 为 0.826496 V 建立残余；长保持 0.6 µs 至 16.39 µs 期间 `ideal` 的
max−min = 0，`ref` 下垂至 1.476102 V；复位优先期间两者同约 0.9 V，复位释放后
跟踪段 `ideal` 精确等于输入 0.200000 V；末次保持 `ideal` 为 1.300000 V。
`ref` 的数值与 attempt-02 的既有观测（150 ns 约 0.828 V、16.39 µs 约 1.476 V）
一致，确认两实例共享同一 core。完整观测和日志位置见[运行记录](../../test/RUN-RECORD.md)。
