# R01 连续状态 track/hold 核心

`r01_track_hold` 是供采样前端与多通道采集系统复用的电压域电路资产。
它把采集开关、保持电容和隔离输出缓冲器合并成一个连续状态模型。
短采集窗口保留前拍，采集速度随输入电压变化；断开采集后有有限电荷注入和保持下垂。
复位以有限时间常数恢复到初值。因此，重接同一输入也不能直接跳到该输入。

本目录提供可运行源码与实际激励台架，供电路 review 和后续出题选材。
当前没有评分 checker、Harbor 任务或模型解题实验。
默认参数是本资产的名义设计值，尚未以某颗芯片或 PDK 拟合。

## 接口与状态

```verilog
module r01_track_hold(vin, track, rst, vout);
```

四个端口均为 `electrical`，电压单位为 V。`vin` 是输入，`vout` 是缓冲后的保持电压。
`track > vth` 时采集，`track <= vth` 时保持。`rst > vth` 时复位，优先于采集。
控制电平在阈值恰好相等时属于低电平；没有迟滞或抖动滤波。
输入端口不拉电流，输出是理想电压驱动，不提供外部端口阻抗模型。
多通道电路可重复实例化此模块，各实例拥有独立存储状态。

内部状态 `x = V(memory)` 无条件用 `idt(rate, vinit)` 定义，输出为 `vout = x`。
积分初值在 DC 与瞬态启动均为 `vinit`。即使 t=0 的控制已经高，状态也从这个值开始，
随后按当前控制电平决定的方程演化。初始保持不会凭空注入 pedestal。
复位释放时若 `track` 仍低，电路从恢复后的状态进入保持，不补造一次采集。

## 动力学与参数

令 `u = (vin-vmid)/vscale`，采集时间常数为：

```text
tau_eff(vin) = tau_acq * (1 + acq_curvature * u^2)
```

该正值函数表示输入偏离中点时有效开关导通变弱。
它是可审查的行为建模选择，不是 MOS 器件方程。
默认输入 0.9 V 时 `tau_eff=10 ns`，输入 0.2 V 或 1.6 V 时约为 13.63 ns。
相同采集时间下，有限收敛会留下不同误差，误差也依赖进入该窗口之前的 `x`。

状态方程为：

```text
rst 高：   dx/dt = (vinit-x)/tau_reset
采集：     dx/dt = (vin-x)/tau_eff(vin)
保持：     dx/dt = (vleak-x)/tau_hold + injection(t)
```

保持下垂等效为储能电容经漏电导向 `vleak` 泄放。
固定 `vleak` 时，长保持段呈指数衰减，局部斜率为 `(vleak-x)/tau_hold`。
它没有把所有漏电机制强行设为恒定电流，不能据此宣称温度特性或某器件的长期保持准确度。

真正的 `track` 下降穿越在复位低时登记 `t_hold`。随后保持期间：

```text
injection(t) = pedestal/tau_ped * exp(-(t-t_hold)/tau_ped)
```

这是有限持续时间的电荷注入折算为电压变化率。
在无下垂且保持足够长时，积分总量趋于 `pedestal`。
默认 1 ns 后约完成 99.3% 注入，输出连续上升形成约 2 mV 的保持台阶。
注入直接进入存储状态，后续采集、下垂和复位都继承这段历史。
`track` 重开或 `rst` 断言时永久取消当前注入，之后释放控制不会恢复旧尾部。
注入被打断时只保留已进入电容的部分，不补足标称台阶。

| 参数 | 默认值 | 作用与单位 |
| --- | --- | --- |
| `vth` | 0.9 | 控制阈值，V |
| `vinit` | 0.9 | 积分初值及复位目标，V，可设为 0 |
| `tau_acq` | 10n | 中点采集时间常数，s，必须为正 |
| `vmid` | 0.9 | 导通最快的输入中点，V |
| `vscale` | 0.9 | 输入依赖的归一化电压，V，必须为正 |
| `acq_curvature` | 0.6 | 输入依赖强度，无量纲，必须非负；0 表示固定采集时间常数 |
| `tau_hold` | 200u | 漏电保持时间常数，s，必须为正 |
| `vleak` | 0.0 | 漏电平衡电压，V |
| `pedestal` | 2m | 完整保持进入后的电荷注入总电压，V，可正、负或为 0 |
| `tau_ped` | 200p | 电荷注入衰减时间常数，s，必须为正 |
| `tau_reset` | 2n | 复位恢复时间常数，s，必须为正 |

这些数值用于构造可区分的采样系统工作条件，没有伪造测量出处。
前拍记忆来自有限采集后的残余电压；本模型没有介质吸收状态。

## 运行与观察台架

从本目录进入对应台架目录后运行：

```sh
cd ../../test/core
spectre tb.scs
```

`tb.scs` 包含源码、输入与控制 PWL、六个参数对照实例和 17 us 瞬态分析。
控制边沿为 200 ps，阈值穿越发生在边沿中点。
`maxstep=10 ns` 给长保持段留出观察点；模型在采集、复位和注入期间用 `$bound_step`
收紧内部步长。积分器每个求解步更新连续状态，模型没有定时 tick 或波形回放。

| 保存输出 | 相对名义实例的变化 | 观察目的 |
| --- | --- | --- |
| `nominal` | 默认参数 | 工作序列与连续状态 |
| `no_pedestal` | `pedestal=0` | 单独观察进入保持的电荷注入 |
| `fast` | `tau_acq=5n` | 短窗口的采集不足 |
| `flat` | `acq_curvature=0` | 输入依赖采集速度 |
| `leaky` | `tau_hold=50u` | 同样保持时间下更大的下垂 |
| `zero_init` | `vinit=0` | 0 初值及相同控制下的复位恢复 |

台架的时间安排如下。表中的窗口边界指阈值穿越时刻。

| 时段 | 激励与应观察的行为 |
| --- | --- |
| 0 至 10.1 ns | 启动保持，名义状态从 0.9 V 下垂，0 初值实例保持在 0 V；无启动 pedestal |
| 20.1 至 60.1 ns | `track` 已高，`rst` 高优先；40 ns 相当于 20 个复位时间常数 |
| 60.1 至 125.1 ns | 跟踪 0.2 V，建立低前拍 |
| 140.1 至 148.1 ns | 跟踪 1.6 V 仅 8 ns，保持前拍残余 |
| 180.1 至 188.1 ns | 再跟踪相同 1.6 V 8 ns，前一次采集的进度进入本次初态 |
| 220.1 至 300.1 ns | 跟踪 1.6 V 80 ns，与短窗口对比 |
| 330.1 至 410.1 ns | 长窗口跟踪 0.2 V，重新建立低前拍 |
| 420.1 至 500.1 ns | 长窗口重新跟踪 1.6 V；保持入口比较 `nominal` 与 `no_pedestal` |
| 500.1 ns 至 16.4001 us | 长保持中 `vin` 多次改变，观察隔离保持与不同漏电时间常数 |
| 16.4051 至 16.4451 us | 在重开采集后断言复位，40 ns 恢复后再释放 |
| 16.4502 至 16.5301 us | 输入变为 1.3 V，复位后重新采集，结束后保持 |

表中趋势由方程确定，不是实测通过报告。

## 机制来源与适用边界

[ADI MT-090](https://www.analog.com/media/en/training-seminars/tutorials/mt-090.pdf)
第 2 至 4 页介绍保持电容、有限跟踪和进入保持时的 pedestal；第 8 页解释漏电下垂；
第 12 页定义重新采集到指定误差所需的时间。
本核心按这些机制建立连续电压状态，二次采集时间常数、指数注入形式和复位机制由本资产选定。

仓库已有[真实 SKY130 采样级数据任务](../../../../batches/v2-01/tasks/v2-data-sampling-identification/SOURCE.md)。
它的来源是固定 SKY130 晶体管仿真，并包含有限采集与历史影响。
本目录没有复用其拟合系数、CSV 或真值，也不继承其校准通过结论。

模型适合 0 至 1.8 V 输入和明确跨阈值的控制驱动，默认参数也按这个电压范围选择。
参数没有自动限制输入或输出，范围外运行不代表器件工作区已验证。
它不描述外部阻抗、负载电流、噪声、时钟抖动、aperture delay、介质吸收、保持态 feedthrough、
晶体管尺寸、PDK corner 或温度。`tau_ped` 只描述注入持续时间，不能当作 aperture 或 jitter。

后续可用它作为采样序列故障修复、非理想机制扩展、采集窗口配置和多通道采样系统集成的材料。
例如，删除前拍状态后，两个相同 8 ns 窗口会失去应有的不同起点；删除输入依赖后，
中点与端点的采集误差关系会改变。将其变成数据建模题仍需要独立数据与明确来源。
本目录仅保留电路资产及可运行台架，不给出评分阈值，也不增加题目计数。

后续扩展统一见[暂缓候选与优先级](../../reference.md#暂缓候选与后续优先级)。本轮不建设这些候选。
