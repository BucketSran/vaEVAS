# R01 相关双采样（CDS）

`r01_cds_sampler` 把相关双采样包在[共享 core](../../module/core/README.md) 上：`ph1` 相把输入
钳到 `vcm+voff` 采参考，`ph2` 相采 `vin+voff`，输出为 `vcm + held_sig − held_ref`。
固定 `pedestal` 和共有的输入偏移 `voff` 提供两拍相关的误差分量，差分可抑制其中的共同部分。
有限建立与不等保持时间会留下残差，因此默认非理想条件下不保证完全抵消。
它用于观察 CDS 的误差抑制范围。

本目录提供可运行源码与激励台架，供电路 review 和后续出题选材。
当前没有评分 checker、Harbor 任务或模型解题实验。
2026-10-12 已在 Spectre 21.1 完成一次成功运行，实测记录见[运行记录](../../test/RUN-RECORD.md)。

## 配对语义

两份 core 实例共享全部参数。一对样本的成立条件：`ph1` 下降沿（rst 低）登记参考，
随后 `ph2` 下降沿登记信号；两者都完成且 `ph1`、`ph2`、`rst` 均低时 `valid` 为高、
`vout` 输出差分值。`ph1` 上升沿开始新周期并作废旧参考和旧信号的完成标记；`ph2` 上升沿
只作废信号半边。初始状态与复位上升沿清空两侧。输出门控 `transition` 边沿 1 ns。

`held_ref`、`held_sig` 是两份 core 的真实连续状态输出，可直接观察各自的下垂与注入。
配对后的 `vout` 持续使用这两个节点作差，不是在配对完成时锁存一个固定结果。
因此，同一对样本在不同观察时刻可能产生不同输出。

一个已完成的参考可以与随后重新采集的信号配对，直到新参考采集或复位使它失效。
这与“一次参考只允许一个信号”不同，出题时不能暗中改成一次性消费。
正常参考与信号窗口先按现有台架的先后、非重叠顺序设计；重合控制边沿另行明确，不靠仿真事件顺序定义配对。

## 四个题目方向提案

四个方向已确认保留：沿用旧 308 作为基础建模方向，再从当前资产派生集成、表征和修复三个方向。
下文是题目设计草案与作者审核用伪代码，材料仍待补齐，不创建新任务，不展开独立 checker。
这些方向只覆盖确定性采样与误差，没有增加噪声模型。

工程场景可以参考 CCD 读出：先保存参考电平，再保存数据电平，两次采样的差提供信号信息。
ADI 的 [Integrated Solutions for CCD Signal Processing](https://www.analog.com/en/resources/analog-dialogue/articles/integrated-solutions-for-ccd-signal-processing.html)
在图 2 给出了两个采样保持单元和差分放大器的结构。
当前 R01 的参考来自内部 `vcm + voff`，不是实际像素复位波形；它只是这一差分采样关系的行为资产，
不代表已经建成含像素、读出放大器和噪声的成像链路。这里的 `rst` 是模型状态复位，也不等于传感器的参考电平。

### 沿用 308 的边沿采样与差分建模

**按规格构建模型。** 场景是按接口规格建立一个参考与信号两次取样的功能模型。
给定[旧 308 的接口、参数和模块职责](../../../../batches/v2-01/tasks/v2-spec-308-correlated-double-sampler-offset-cancel/instruction.md)，
交付 `dut.va`、`reset_sample_latch.va` 和 `signal_sample_latch.va`。
这里两次都从外部 `vin` 取样，参考不是当前 R01 的固定内部电平。

```text
复位时按旧合同初始化参考、输出、调试量和有效状态
clk 上升沿且参考采样使能：参考模块采 vin，并驱动真实 reset_node
之后的合法信号采样沿：
    信号模块采 vin，读取参考模块的 reset_node
    输出 vcm + cds_gain ×（信号样本 − 参考样本）
    更新参考调试量和有效状态
顶层连接并使用两个公开模块的真实输出，不另存一套私有答案
```

这是已有题目，不额外增加题数或机制覆盖。它考两次取样的关联和模块协作，
没有有限采集窗口、注入或漏电。旧合同的 `valid` 保持规则与当前 R01 不同，
继续沿用时须按原题面解释；本轮不把下面的新周期失效规则回写旧题。

### 组装连续采集与保持的 CDS 前端

**扩展与集成。** 场景是接好参考和信号两条采样路径，让后级得到已完成配对的差分电压。
给定健康 core、参考和信号输入形成方式、两相激励、接口及配对规则；
交付顶层 VA，完成实例连接、配对状态和差分输出。
完整 `circuit.va` 是作者资产，出题时需拆出保留连接与配对工作的初始工程。

```text
连接参考 core 到 vcm + voff，信号 core 到 vin + voff
初始或复位：清空参考与信号完成状态
参考开始采集：开启新周期，作废旧参考和旧信号的完成状态
参考实际结束采集且未复位：登记当前参考完成
信号开始采集：仅作废旧信号完成状态
信号实际结束采集：若未复位且当前参考已完成，登记新配对

两侧均完成、均在保持且未复位时：
    持续输出 vcm + held_sig − held_ref，并给出有效状态
否则：按规定转换时间回到无效输出
```

初始或复位释放时已处于采集的支路，仍需等实际结束采集后才能登记完成。
重新采信号可以继续使用当前参考，不能重读 `vin` 来重建参考。
任务不包含相位发生器、差分放大器有限带宽或输出锁存器。

相对旧 308，增加的是有限窗口、两份连续保持状态及它们共同决定输出的关系。
相对 R01 其他系统，core 的建立、注入和漏电仍然复用；CDS 新增的是参考与信号配对后作差，
不是再增加一套器件级采样机制。

### 表征共同偏移抑制与采样残差

**电路测试与表征。** 场景是判断 CDS 对共有偏移能抑制多少，以及当前采集和保持安排留下多少误差。
给定源码可读的 CDS、规定实验表和激励驱动、两采集目标与保持节点的观测连接；
交付 VA 表征模块，识别实际样本对，报告两侧采集误差、保持变化、最终输出误差及条件间差异。
先采用固定实验，交付物负责观测和报告，不要求自动寻找最优时钟。

每对样本冻结各自进入保持时的目标输入和保持电压。用 `u_ref`、`u_sig` 表示这两个目标，
本对理想差分参考是 `vcm + u_sig - u_ref`，不使用观察时刻可能已变化的 `vin`。
参考和信号各自的采集误差为“保持入口电压减去本次目标”；保持变化各自从自己的保持入口算到同一个输出观察时刻。
两侧先分别记录，再看它们的差，才能知道误差是在两侧相近还是已经抵消。

最终误差直接测量 `vout` 相对本对理想差分参考的偏差，不用两侧误差之差替代输出观察。
若输出路径或有效状态错误，也保留这次本来应有的观察。这里没有读沿锁存，
应在同一个观察时刻读取 `held_ref`、`held_sig` 和 `vout`。

实验先按下面几组条件组织，它们是同一道表征题的实验，不按扫描项增加题数：

| 要回答什么 | 主动改变什么 | 需要控制和实际记录什么 |
| --- | --- | --- |
| 共有输入偏移进入输出多少 | 同时加在两次采集目标上的 `voff` | 有效信号、两采集窗口、采样间隔、配对完成到观察的等待和准备流程一致；记录两侧真实初态 |
| 参考先采、先保持有什么影响 | 两次进入保持的实际时间间隔 | 固定两采集长度和信号完成到观察的等待，核对两侧起始状态与保持入口值可比 |
| 完成配对后再等一段时间有什么影响 | 同一配对的输出观察延迟 | 不开始新采集，不换参考；同时记录两侧在各观察时刻的变化 |
| 采集不足怎样进入最终误差 | 一侧的实际采集窗口长度 | 固定两保持入口时刻与观察等待，重复准备并记录初态，保留两侧建立误差 |

共有偏移的比较报告偏移增量引起的输出变化，不能用单次输出总误差直接代替抑制效果。
采样间隔按信号与参考实际进入保持的时刻之差计算，不用两条控制命令的发送间隔代替。
时间间隔比较若同时改变输入电平或起始状态，只能报告联合条件下的结果，不能归因为纯保持时间效应。
不同等待的重复观察属于同一配对，不当成新样本。

```text
从实际复位和 ph1、ph2 事件识别参考、信号与配对身份
参考开始时：作废旧配对，保留中断记录
信号开始时：作废旧信号及配对，保留仍有效的参考
各侧采集开始时：记录实际初态、目标输入轨迹和起点，包含初态或复位释放时已在采集的情况
各侧进入保持时：冻结该侧目标、电压和实际时刻
每次信号完成且存在本周期参考：
    建立配对，保留参考身份；安排相对实际完成事件的观察
每次约定观察到达：
    若配对已被刷新或复位，保留未完成原因
    否则同时记录两个 held、vout 和 valid
    报告两侧采集误差、两侧保持变化及直接测得的输出总误差
    不因 DUT 自报无效而跳过本来应有的观察
按实际条件分组，计算共有偏移引起的输出变化及时间安排带来的残差变化
条件不相符时保留记录，说明不能作单因素归因；结束时保留未配对或未观察的记录
```

现有本体、`voff=10m` 对照和单 core 对照可复用。单 core 没有参考相减，
它用于展示另一种读出结果，不能充当 CDS 的理想答案。
现有两个周期采用不同信号电平但相同采样间隔，不能拿它们直接证明“间隔变长导致残差变大”。
多条件实验包、采集目标观测连接和实际初态的准备方法还需补齐。

本题与集成题同源，新增的是样本配对测量、误差范围说明与受控比较。
`voff` 的确定性抑制不等于噪声抑制；固定注入也不等于像素复位噪声，本题不交付 SNR 或噪声统计。

### 修复中断后参考与信号的错误配对

**诊断与修复。** 场景是新参考采集、信号重采或复位后，旧信号仍被错误标成当前配对，
使输出出现看似合理但来自不同周期的差值。
给定可读的故障顶层、健康 core、配对协议和复现输入；交付修复后的指定 VA 与原因说明。
先围绕具体故障选场景，不把所有中断情形强行塞进同一道题。

```text
逐事件追踪参考来源、信号来源、两侧完成状态和当前输出
找到首次跨周期配对、复位后旧参考存活或过早声明有效的位置
修复指定顶层：
    新参考采集作废旧配对
    信号重采只替换信号侧，保留仍有效的参考
    复位清空两侧完成状态，旧配对不得在释放后恢复
    输出必须来自当前合法配对的两个真实保持节点
交付代码和故障解释，指出错误差值的两个样本原先分别属于哪个周期
```

当前只有健康资产，故障工程与复现记录待补；上面列的是故障候选，不是在断言现有代码有错。
它与 CDS 集成题共用配对协议，也与同步、MUX、交错修复共享中断后状态处理的能力。
只有一个有效标记赋值错误时可作基础变体，不能把它描述成新的电路机制或高难诊断。

## 误差机制：什么消、什么不消

| 机制 | 在 CDS 输出中的表现 |
| --- | --- |
| 固定 `pedestal`（两实例同参数） | 无漏电且两次注入均充分完成时可以抵消；默认漏电模型会在不同保持时长内改变已注入的电压，仍有残差 |
| 两次采集共有的 `voff` | 进入两个采集目标，差分后受到抑制；台架中增加 10 mV 失调后，输出改变约 11 µV |
| 保持漏电 | 残差同时取决于两拍的保持时长和保存电压，不能仅用时间间隔决定 |
| 有限建立 | 两拍采集目标和有效采集时间常数不同，建立残差不保证抵消 |

信号相关注入继续列为暂缓候选。两拍注入不同时可能留下差分残差，但需要先补有依据的
注入模型和适用场景；当前固定 `pedestal` 不能代表这项覆盖。

## 运行与实测

在[对应台架目录](../../test/cds)运行 `spectre tb.scs`。台架跑两个 CDS 周期（150 ns 采集窗使建立残差可忽略），
并列三个实例：CDS 本体、`voff=10m` 失调对照、按 `ph2` 采样的单 core 对照（`ref_held`，
显示未消除的 pedestal）。2026-10-12 实测（Spectre 21.1，thu-sui，0 错误）：

| 读出时刻 | vin | CDS 输出（误差） | voff=10m 输出（误差） | 单 core（误差） |
| --- | --- | --- | --- | --- |
| 550 ns | 1.6 | 1.600962（+0.96 mV） | 1.600973（+0.97 mV） | 1.601664（+1.66 mV） |
| 1100 ns | 0.2 | 0.201345（+1.35 mV） | 0.201356（+1.36 mV） | 0.202048（+2.05 mV） |

两个读出点上，参考与信号分别已保持约 299.9 ns 和 49.9 ns，第二周期并未延长参考保持。
两个周期的信号电平不同，漏电项随保存电压变化，有限建立也可能留下残差；不能把第二周期
较大的残差归因于更长的参考保持时间。单 core 保留未做差分抑制的注入与下垂。
配对完成前 `valid=0`、`vout=0`，配对后 `valid=1.8 V`。

## 来源与边界

机制依据同 core（ADI MT-090 的 pedestal 与漏电）。v4 已有 308 题（相关双采样消失调）
使用独立合同，与本资产功能关联，不是同一份 core 源码。本资产提供带连续动态的电路侧材料，不修改 308 的合同。不描述噪声、
抖动、放大器建立或器件级开关；这些仍需另行补充。

后续扩展统一见[暂缓候选与优先级](../../README.md#暂缓候选与后续优先级)。本轮不建设这些候选。
