# R01 乒乓采样（ping-pong）

`r01_pingpong_sampler` 用两份[共享 core](../../module/core/README.md) 采同一输入、反相窗口工作。
一支采集时另一支保持，输出持续选择当前处于保持且已完成采集的支路。
与[交错采样](../interleaved/README.md)复用相同的双支路采样核心，当前资产的主要区别是输出协议：
没有 `read_clk`、没有消费队列，输出是持续选中的保持节点。

本目录提供可运行源码与激励台架，供电路 review 和后续出题选材。
当前没有评分 checker、Harbor 任务或模型解题实验。
2026-10-12 已在 Spectre 21.1 完成一次成功运行，实测记录见[运行记录](../../test/RUN-RECORD.md)。

## 选择语义

`ph0`/`ph1` 反相。`phN` 上升沿作废该支路旧样本；下降沿（rst 低）登记完成。
输出选择“当前处于保持（`phN` 低）且已完成（done）”的支路；两支路都满足时，现有代码优先支路 0；都不满足时
`valid=0`、`vout` 趋向 0（例如仿真开始后第一次采集完成前）。`branch_id` 为 0/1.8 V。
切换用 1 ns `transition` 门控。正常反相驱动下同一时刻只有一支在保持，选择无歧义。

与 interleaved 的对照：

| | interleaved | ping-pong（本模块） |
| --- | --- | --- |
| 对后级提供什么 | 按读时钟交付有序样本 | 在另一支路采集期间持续提供保持电压 |
| 输出 | read_clk 沿锁存消费 | 电平持续选择保持支路 |
| 样本寿命 | 未消费样本被重采覆盖，成功读取后不再消费 | 选中期间持续提供，重新采集时旧样本失效 |
| 考察点 | 支路失配、采样时刻与消费顺序 | 可用窗口、连续选路与支路交接 |

不能仅用“一个提高样率、一个不提高样率”区分两者。本台架每支路周期为 200ns，
稳态下每 100ns 交接一次输出；是否提高系统吞吐还取决于对比对象和后级。
当前没有后级转换器，不能据此宣称已经实现转换与采集重叠的完整 ADC。

## 两个题目方向与交付草案

两题共用本电路，分别要求实现输出交接和编写观察交接的 VA 模块。
以下伪代码用于审核交付内容，未实现参考解或独立评分 checker。

### 组装交替采集、持续提供保持电压的前端

**扩展与集成。** 场景是后级需要一段可用的模拟电压窗口，同时前端继续采集下一样本。
给定两份健康 core、相位和复位激励、接口与选择规则；交付顶层 VA，
连接两支路并驱动持续输出、有效状态和支路身份。
当前完整系统可作作者材料，仍需拆出待完成连接与选择逻辑的 starter。

本题先采用规定的互补相位及有限切换时间。初态和复位后尚无完成采集的支路时输出无效；
复位释放时若某支路正在采集，须等实际保持沿才可使用。
输出跟随选中保持节点的真实变化，不要求一条完全水平的电压，也不能锁存 `vin` 代替该节点。
不增加独立读时钟、消费队列、后级握手或任意非互补时钟的调度责任。
双支路均可选时沿用现有支路 0 优先规则，不另立优化目标。

```text
连接两份 core 到共同输入，分别由 ph0、ph1 控制
初始或复位置位：清空两个 done
支路 b 开始采集：done[b] = false
支路 b 实际结束采集且未复位：done[b] = true
持续决定输出来源：
    若支路 0 在保持且 done[0]，选支路 0
    否则若支路 1 在保持且 done[1]，选支路 1
    否则不选任何支路
用规定转换时间切换选路，持续输出所选 held[b]，同步给出 valid、branch_id
没有可选支路时 valid = false，输出回到规定无效电平
```

新增工程工作是建立可用电压窗口和支路交接。两份记忆、有限建立、漏电和注入均复用 core。
它与交错集成共享双支路来源，但交付不能互换：每次读沿锁存一个数值不能代替持续选路。

### 编写乒乓输出窗口与支路交接检查模块

**电路测试与表征。** 场景是确认后级在规定窗口内一直得到正确支路，
并在交接后及时拿到新样本。给定源码可读的完整 DUT、两相控制、复位、保持节点与输出，
以及能让两支路电压出现可辨差异的输入台阶；交付观测型 VA 模块和分窗口报告。
这里“检查模块”是求解者交付的电路测试工具，本轮不设计对该工具评分的独立 checker。

期望窗口与支路由实际相位、采集完成历史和复位推导，不能仅在 DUT `valid` 为高时观察，
也不能用 DUT `branch_id` 决定应比较哪一路。否则漏报有效窗口或错标签会自行掩盖问题。
窗口内比较的是 `vout` 与当时应选的 `held[b]`，不是采集结束时冻结的一个常数；
保持节点的漏电或有限注入不能直接判为选路错误。

从实际交接事件划出有界的转换区间，再观察整个约定可用窗口。
转换区间内不要求瞬时等于新支路，但到期仍未交接必须报告；
不能任意延长避让，或只在 250ns、350ns 等固定示例时刻取一点。
窗口内的重复观察和相关事件记录应覆盖公开要求的时间分辨率，不宣称能发现任意窄脉冲。
现有台阶激励和端口可复用，可用窗口、转换界限、观察分辨率及故障演示材料仍需补齐。

```text
从实际相位和复位维护独立的 completed[b]，为每次完成采集登记身份
每次期望输出来源变化：
    结束上一窗口，保留持续时间和已有观察
    记录交接前后支路及实际时刻，开启有界的转换区间
转换区间到期：
    若期间又有相位或复位事件，记录窗口中断及原因
    否则开启应有的可用窗口，或进入应无效区间
在窗口内按规定分辨率重复观察，并记录相位、复位和状态变化事件：
    用控制历史确定 expected_branch，不依赖 DUT valid 或 branch_id
    若应有输出，记录 vout - held[expected_branch]、实际 valid 与身份
    若应无效，记录是否错误声明有效及实际输出
    即使 DUT 状态错误，也继续记录本来应有的窗口
交接或复位时关闭当前窗口；结束时保留未完整观察的末窗口
逐窗口报告可用时长、观察范围、选路偏差与状态异常，不拿缺失记录充当通过
```

与交错时间表征的区别是观测对象：交错题追踪离散样本的时刻与消费；
本题追踪持续输出窗口和切换过程。它新增窗口测试责任，没有引入新的模拟动态。
它与乒乓集成题属于同源的实现与测试任务；增益失调表征和简单复位修复不因换成
乒乓结构就自动再出一题，需有额外工程责任才扩展。

## 运行与实测

在[对应台架目录](../../test/pingpong)运行 `spectre tb.scs`。两相各 100 ns 高电平、200 ns 周期，`rst` 起始 40 ns。
输入三个台阶：450.2n→0.6 V（落在 ph1 采集窗中段，留 50 ns 部分建立）、902n→1.2 V
（与 ph1 下降沿分开 2 ns，避免边沿重合）、观察各支路捕获值。
2026-10-12 实测（Spectre 21.1，thu-sui，0 错误）：

| 时刻 | 支路 | vout | 说明 |
| --- | --- | --- | --- |
| 150 ns | — | 0（valid=0） | 首次采集完成前无效 |
| 250/350/450 ns | 0/1/0 | 1.6011/1.6012/1.6017 | 完全建立的 1.6 V 样本，交替输出 |
| 550 ns | 1 | 0.611029 | **部分建立**：输入在窗中段跳变，剩 50 ns 只建立到 9.1 mV 残余 + pedestal |
| 850/950 ns | 0/1 | 0.601925/0.601925 | 0.6 V 完全建立，两支路一致 |
| 1150/1250 ns | 1/0 | 1.201725/1.201776 | 1.2 V 完全建立 |

550 ns 一行是设计观察点：乒乓架构不消除有限建立误差，窗内输入跳变的样本
带着残余进入输出；950 ns 行经边沿分离修正后与解析值一致（0.602 − 50 ns 下垂）。

## 来源与边界

机制同 core。工程对应流水线 ADC 第一级采样/保持相与示波器前端。
不描述后级转换器的转换时间与流水级联；两支路参数当前完全相同，失配注入
（增益/失调/时偏）可作为拓展，届时与 interleaved 的失配考察衔接。

后续扩展统一见[暂缓候选与优先级](../../reference.md#暂缓候选与后续优先级)。本轮不建设这些候选。
