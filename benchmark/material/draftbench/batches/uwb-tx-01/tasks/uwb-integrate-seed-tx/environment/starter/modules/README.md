# Module library (fixed)

These nine modules are working parts of the seed transmitter. Include them from `/app/circuit.va` with `` `include "modules/<file>.va" `` and instantiate them; do not edit or copy them. Port order is as listed. All ports are voltages relative to ground; logic levels are 0 V / 1 V, threshold 0.5 V, with 2 ps output edges. Parameters not listed keep their defaults in the transmitter.

| File, module | Ports in order (`[n:0]` = bus) | Parameters used by the transmitter | Role |
| --- | --- | --- | --- |
| `serial_to_symbol6.va`, `uwb_serial_to_symbol6` | `bclk, din, rst, sym[5:0], sym_valid` | none | Samples `din` on rising `bclk`; the first bit after reset release is `sym[5]`. After the sixth bit `sym` updates and `sym_valid` rises (10 ps after the edge); `sym_valid` falls 10 ps after the third bit of the next word. |
| `dppm_fsk_encoder8.va`, `uwb_dppm_fsk_encoder8` | `sym[5:0], sym_valid, rst, pos[2:0], inc[2:0], fcode[2:0], req[7:0], enc_valid` | none | Takes the word at the falling `sym_valid`. D = gray2bin(sym[5:3]), F = gray2bin(sym[2:0]), absolute position P = (P + D) mod 8 from P = 0 at reset. Outputs P, D, F, one-hot F 10 ps later; `enc_valid` rises 30 ps after the capture for 400 ps. `inc` and `req` are debug outputs. |
| `ro_frequency_cal.va`, `uwb_ro_frequency_cal` | `ref, roclk, cal_start, rst, code[9:0], done, fail, busy` | `n_win`, `code_init` | Counter calibration of the master RO against `ref` (rules in Spec S3). Outputs `code_init` until the first `cal_start` and after `rst`. |
| `master_ro16.va`, `uwb_master_ro16` | `code[9:0], ph[15:0]` | none | Ring oscillator at f = 600 MHz + 0.25 MHz × code with 16 taps; tap k rises k/(16 f) after `ph[0]`. A code change is read 5 ps after the bits move and keeps the phase. |
| `pulse_generator.va`, `uwb_pulse_generator` | `ph[15:0], pos[2:0], fcode[2:0], pol, enc_valid, en, rst, pre_a, rf_a, sel_a[2:0], pol_a, pre_b, rf_b, sel_b[2:0], pol_b, overrun` | `n_pre` | Latches (P, F, `pol`) at rising `enc_valid`. A rising `ph[0]` starts a frame; if `en` is high there, the pending word is scheduled into the next frame on lane a or b (alternating): `pre_x` from tap P − n_pre to tap P, `rf_x` from tap P to tap P + 9, `sel_x` = F and `pol_x` from scheduling. `overrun` pulses when a pending word is replaced. |
| `ro_scheduler8.va`, `uwb_ro_scheduler8` | `pre_a, rf_a, sel_a[2:0], pre_b, rf_b, sel_b[2:0], rst, pwr[7:0], pre[7:0], rel[7:0], gate_a, gate_b, conflict, nsup, st[7:0]` | `n_pre` (must equal the PG's) | Two-supply scheduler for the eight RF branches (rules in Spec S5). Drives each branch's `pwr`, `pre`, `rel`, the lane gates, `conflict` and `nsup`. `st` is a state monitor. |
| `rf_ro_branch.va`, `uwb_rf_ro_branch` | `pwr, pre, rel, vro` | `f_rf` | One carrier oscillator. Released by rising `rel` while powered: vro = a(u)·cos φ(u), u = time since release, a = 1 − exp(−u/43.4 ps), φ = 2π f_rf (u + 0.434 ps (1 − exp(−u/43.4 ps))). The phase continues while `rel` stays high; output 0 when off or precharging. |
| `envelope_lane.va`, `uwb_envelope_lane` | `gate, clk, env` | none | At rising `gate` starts a raised-cosine window of length T_w = 9/16 of the last measured `clk` period, through a first-order response (time constant 10.9 ps); after the window or the gate falls it decays with the same constant. |
| `tx_output.va`, `uwb_tx_output` | `vro[7:0], env_a, env_b, gate_a, gate_b, sel_a[2:0], sel_b[2:0], pol_a, pol_b, outp, outn` | `g_pa`, `vcm` | Latches `sel_x`, `pol_x` at rising `gate_x`; v = g_pa Σ_x (−1)^pol_x · env_x · vro[sel_x]; outp = vcm + v/2, outn = vcm − v/2. |
